# 第33章 测试与质量保障

第32章把并发问题压住了，但"能跑"和"敢改"是两件事。没有测试的代码，重构一次要回归一周；有测试的代码，改完跑一遍绿灯就敢发。测试的价值不在覆盖率数字，而在**它把"我以为对"变成"我验证过对"**。本章按「单测基础 → 测试替身 → 用例设计 → 覆盖率 → Mock 框架 → 测试金字塔 → 测试数据 → 异常与并发测试 → 静态检查 → CI 门禁 → 综合案例」的顺序讲，从手写 60 行测试运行器开始，一路做到能跑通的质量门禁流水线。所有示例仍是纯 JDK：测试运行器用反射实现，Mock 框架用 `Proxy` 动态代理实现，集成测试真起 `com.sun.net.httpserver.HttpServer` 并用 `HttpClient` 打真实 HTTP 请求，静态检查用正则做圈复杂度与重复代码扫描，不需要引入 JUnit、Mockito、JaCoCo 或任何构建插件。

### 33-01 单元测试基础：从手写 main 到测试框架

**知识点**
- 单元测试的定义：**针对最小可测单元（通常是一个方法）**，隔离外部依赖，快速、可重复、可自动判定成败。它和"写个 main 打印看看"的本质区别是**断言 + 自动汇总 + 可回归**。
- 一个测试方法的四段结构（AAA）：**Arrange 准备数据 → Act 执行被测方法 → Assert 断言结果**，复杂用例再加 After 清理。
- JUnit 5 的核心注解：`@Test`、`@BeforeEach`/`@AfterEach`（每个用例前后）、`@BeforeAll`/`@AfterAll`（整个类一次，必须 `static`）、`@DisplayName`、`@Disabled`、`@ParameterizedTest` + `@ValueSource`/`@CsvSource`。
- 断言的正确姿势：**一个用例只验证一个行为**，失败信息要能自解释。`assertEquals(expected, actual)` 的参数顺序是"期望在前、实际在后"，写反了失败信息会误导人。
- `assertThrows` 用来验证异常路径：不仅验证抛了异常，还要验证**异常类型**，必要时再验证 message。只写 `try/catch` 不断言等于没测。
- 测试方法命名规范：`方法名_场景_期望结果`，例如 `discount_vipUser_returns90Percent`。名字本身就是文档。
- 测试的**独立性**：用例之间不能有顺序依赖，不能共享可变状态。每个用例自己造数据，跑单个和跑全部结果必须一致。
- 常见反模式：测试里 `Thread.sleep` 等异步（应改用轮询或注入时钟）、测试依赖真实数据库/网络、一个用例断言十几个不相关的东西、`System.out` 里人眼看结果。
- 想真正"自动判定"，就需要一个**运行器**：扫描类里所有 `@Test` 方法 → 逐个实例化并调用 → 捕获断言失败 → 汇总通过/失败。JUnit 做的就是这件事，本课用纯 JDK 反射实现一个 60 行的迷你版。
- 易错：`@BeforeAll` 写成非 `static`；测试方法写成 `private`（框架反射调用不到）；断言用 `==` 比较对象（比较的是引用）；捕获异常后忘了 `fail()`，导致异常没抛也判通过。

**示例代码**
```java
import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;
import java.lang.reflect.Constructor;
import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

public class UnitTestBasics {
    @Retention(RetentionPolicy.RUNTIME)
    @Target(ElementType.METHOD)
    @interface Test {
    }

    @Retention(RetentionPolicy.RUNTIME)
    @Target(ElementType.METHOD)
    @interface BeforeEach {
    }

    @Retention(RetentionPolicy.RUNTIME)
    @Target(ElementType.METHOD)
    @interface AfterEach {
    }

    @Retention(RetentionPolicy.RUNTIME)
    @Target(ElementType.METHOD)
    @interface DisplayName {
        String value();
    }

    static class AssertionFailedError extends RuntimeException {
        private static final long serialVersionUID = 1L;

        AssertionFailedError(String message) {
            super(message);
        }
    }

    static class Assert {
        static void assertEquals(long expected, long actual) {
            if (expected != actual) {
                throw new AssertionFailedError("期望 " + expected + "，实际 " + actual);
            }
        }

        static void assertEquals(Object expected, Object actual) {
            if (expected == null ? actual != null : !expected.equals(actual)) {
                throw new AssertionFailedError("期望 [" + expected + "]，实际 [" + actual + "]");
            }
        }

        static void assertTrue(boolean condition, String message) {
            if (!condition) {
                throw new AssertionFailedError(message);
            }
        }

        static void assertThrows(Class<? extends Throwable> expected, Runnable action) {
            try {
                action.run();
            } catch (Throwable t) {
                if (expected.isInstance(t)) {
                    return;
                }
                throw new AssertionFailedError("期望抛 " + expected.getSimpleName()
                        + "，实际抛 " + t.getClass().getSimpleName());
            }
            throw new AssertionFailedError("期望抛 " + expected.getSimpleName() + "，但什么都没抛");
        }
    }

    /** 迷你测试运行器：反射扫描 + 生命周期回调 + 结果汇总 */
    static class MiniRunner {
        static class Report {
            int passed;
            final List<String> failures = new ArrayList<>();

            boolean allGreen() {
                return failures.isEmpty();
            }
        }

        static Report run(Class<?> testClass) {
            Report report = new Report();
            List<Method> tests = new ArrayList<>();
            List<Method> beforeEach = new ArrayList<>();
            List<Method> afterEach = new ArrayList<>();
            for (Method m : testClass.getDeclaredMethods()) {
                if (m.isAnnotationPresent(Test.class)) {
                    tests.add(m);
                }
                if (m.isAnnotationPresent(BeforeEach.class)) {
                    beforeEach.add(m);
                }
                if (m.isAnnotationPresent(AfterEach.class)) {
                    afterEach.add(m);
                }
            }
            tests.sort(Comparator.comparing(Method::getName));
            System.out.println("  发现 " + tests.size() + " 个测试方法");
            for (Method test : tests) {
                String name = test.isAnnotationPresent(DisplayName.class)
                        ? test.getAnnotation(DisplayName.class).value()
                        : test.getName();
                try {
                    Object instance = newInstance(testClass);
                    for (Method b : beforeEach) {
                        invoke(b, instance);
                    }
                    try {
                        invoke(test, instance);
                    } finally {
                        for (Method a : afterEach) {
                            invoke(a, instance);
                        }
                    }
                    report.passed++;
                    System.out.println("    [PASS] " + name);
                } catch (Throwable t) {
                    Throwable root = unwrap(t);
                    report.failures.add(name + " -> " + root.getMessage());
                    System.out.println("    [FAIL] " + name + " -> " + root.getMessage());
                }
            }
            return report;
        }

        static Object newInstance(Class<?> c) throws Exception {
            Constructor<?> ctor = c.getDeclaredConstructor();
            ctor.setAccessible(true);
            return ctor.newInstance();
        }

        static void invoke(Method m, Object target) throws Exception {
            m.setAccessible(true);
            try {
                m.invoke(target);
            } catch (InvocationTargetException e) {
                Throwable cause = e.getCause();
                if (cause instanceof Exception) {
                    throw (Exception) cause;
                }
                throw new RuntimeException(cause);
            }
        }

        static Throwable unwrap(Throwable t) {
            return t.getCause() != null && t.getCause() != t ? unwrap(t.getCause()) : t;
        }
    }

    /** 被测类：订单折扣计算 */
    static class DiscountService {
        long discountPercent(int level, long amountCents) {
            if (amountCents < 0) {
                throw new IllegalArgumentException("金额不能为负: " + amountCents);
            }
            if (level <= 0) {
                return 100;
            }
            if (level == 1) {
                return 95;
            }
            if (level == 2) {
                return 90;
            }
            return amountCents >= 100_000 ? 80 : 85;
        }

        long finalPrice(int level, long amountCents) {
            return amountCents * discountPercent(level, amountCents) / 100;
        }
    }

    /** 测试类：每个用例自己造 SUT，互不影响 */
    static class DiscountServiceTest {
        private DiscountService service;
        private int setupCount;

        @BeforeEach
        void setUp() {
            service = new DiscountService();
            setupCount++;
        }

        @AfterEach
        void tearDown() {
            service = null;
        }

        @Test
        @DisplayName("普通用户不打折")
        void level0_returnsOriginalPrice() {
            Assert.assertEquals(10_000L, service.finalPrice(0, 10_000L));
        }

        @Test
        @DisplayName("VIP1 打 95 折")
        void level1_returns95Percent() {
            Assert.assertEquals(9_500L, service.finalPrice(1, 10_000L));
        }

        @Test
        @DisplayName("VIP3 大额（满 1000 元）打 8 折")
        void level3_bigAmount_returns80Percent() {
            Assert.assertEquals(80_000L, service.finalPrice(3, 100_000L));
        }

        @Test
        @DisplayName("负数金额抛 IllegalArgumentException")
        void negativeAmount_throwsIllegalArgument() {
            Assert.assertThrows(IllegalArgumentException.class, () -> service.finalPrice(1, -1L));
        }

        @Test
        @DisplayName("故意写错的用例：演示断言失败长什么样")
        void intentionallyWrong_demonstratesFailure() {
            Assert.assertEquals(9_999L, service.finalPrice(1, 10_000L));
        }

        @Test
        @DisplayName("前置方法每个用例都执行一次")
        void setupRunsPerTest() {
            Assert.assertEquals(1, setupCount);
            Assert.assertTrue(service != null, "service 应已初始化");
        }
    }

    public static void main(String[] args) {
        System.out.println("=== 1. 运行测试类 ===");
        MiniRunner.Report report = MiniRunner.run(DiscountServiceTest.class);

        System.out.println();
        System.out.println("=== 2. 汇总 ===");
        System.out.println("  通过 " + report.passed + "，失败 " + report.failures.size());
        for (String f : report.failures) {
            System.out.println("    失败用例: " + f);
        }
        System.out.println("  整体结果: " + (report.allGreen() ? "GREEN" : "RED"));

        System.out.println();
        System.out.println("=== 3. 断言顺序的重要性 ===");
        try {
            Assert.assertEquals(9_999L, 10_000L);
        } catch (AssertionFailedError e) {
            System.out.println("  正确顺序(期望在前) -> " + e.getMessage());
        }
        try {
            Assert.assertEquals(10_000L, 9_999L);
        } catch (AssertionFailedError e) {
            System.out.println("  写反顺序(实际在前) -> " + e.getMessage() + "（读起来像期望 10000 却得到 9999，容易误判）");
        }

        System.out.println();
        System.out.println("=== 4. JUnit 5 注解对照 ===");
        String[][] t = {
                {"@Test", "标记测试方法", "本课 @Test"},
                {"@BeforeEach", "每个用例前执行", "本课 @BeforeEach"},
                {"@AfterEach", "每个用例后执行", "本课 @AfterEach"},
                {"@BeforeAll", "整个类一次，必须 static", "示例省略"},
                {"@DisplayName", "可读的用例名", "本课 @DisplayName"},
                {"@ParameterizedTest", "参数化，一份逻辑多组数据", "见 33-03"},
                {"@Disabled", "临时跳过", "示例省略"},
                {"@Tag", "分组，按标签跑", "示例省略"}
        };
        for (String[] r : t) {
            System.out.printf("  %-22s %-26s %s%n", r[0], r[1], r[2]);
        }
    }
}
```

**课后练习**
1. 给 `MiniRunner` 加上"超时"能力（每个用例最多跑 500ms，超时判失败），说明为什么单测里不该出现长 `sleep`。
2. 增加一个 `@Disabled` 注解，被标记的用例跳过但计入"跳过数"，输出 `通过/失败/跳过` 三项统计。
3. 把 `DiscountService` 的等级判断从 `if` 链改成 `switch`，确认测试全部仍通过——体会"有测试才敢重构"。

### 33-02 测试替身：Stub、Mock、Spy、Fake

**知识点**
- **测试替身（Test Double）** 是"用一个假对象替换真实依赖"，目的是让单测**快、稳、可控**。真实数据库、HTTP 调用、时间、随机数都是要替换的目标。
- 五种替身：
  - **Dummy**：只为填参数，从不被使用（如 `null` 或空对象）。
  - **Stub**：返回**预设值**，不关心被调了几次。用于"喂数据"。
  - **Spy**：包住真实对象，记录调用、可部分打桩。用于"既想真跑又想观察"。
  - **Mock**：**预设期望**（被调几次、参数是什么），不符合就失败。用于"验证交互"。
  - **Fake**：有真实逻辑的简化实现（内存版 Repository、内存版消息队列）。
- 选择原则：**优先 Fake 和 Stub，谨慎用 Mock**。Mock 断言的是"实现细节"（调了哪个方法几次），重构时容易大面积红；Stub 断言的是"结果"，更稳。
- 状态验证 vs 交互验证：`assertEquals(订单状态, PAID)` 是状态验证；`verify(smsSender).send(...)` 是交互验证。业务核心用状态验证，外部副作用（发短信、扣款）用交互验证。
- 手写替身的三种方式：接口实现一个假类、匿名内部类、JDK 动态代理（`Proxy.newProxyInstance` 拦截所有方法）。动态代理适合"接口方法很多、只想关注几个"的场景。
- 依赖注入是替身的前提：被测类必须**通过构造器/方法参数接收依赖**，而不是自己 `new`。自己 `new` 的依赖无法替换，只能改代码。
- 时间也是依赖：`System.currentTimeMillis()` 直接调用就无法测试"过期"逻辑，应注入 `Clock`（JDK 8+ 自带 `java.time.Clock`，测试用 `Clock.fixed`）。
- 易错：Mock 了值对象（`new Money(100)` 也去 mock，毫无意义）；替身和真实实现行为不一致（Fake 的 bug 让测试假通过）；忘记验证"不该发生的调用"（如库存不足时**不应**调用支付）。

**示例代码**
```java
import java.lang.reflect.InvocationHandler;
import java.lang.reflect.Method;
import java.lang.reflect.Proxy;
import java.time.Clock;
import java.time.Instant;
import java.time.ZoneId;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class TestDoubles {
    interface UserRepo {
        String findName(long userId);
    }

    interface SmsSender {
        void send(String phone, String text);
    }

    interface OrderRepo {
        void save(long orderId, String status);
    }

    interface PaymentGateway {
        boolean charge(long userId, long cents);
    }

    /** 被测类：构造器注入所有外部依赖，才能替换 */
    static class OrderService {
        private final UserRepo userRepo;
        private final SmsSender smsSender;
        private final OrderRepo orderRepo;
        private final PaymentGateway gateway;
        private final Clock clock;

        OrderService(UserRepo userRepo, SmsSender smsSender, OrderRepo orderRepo,
                     PaymentGateway gateway, Clock clock) {
            this.userRepo = userRepo;
            this.smsSender = smsSender;
            this.orderRepo = orderRepo;
            this.gateway = gateway;
            this.clock = clock;
        }

        String placeOrder(long userId, long orderId, long cents, long expireAtMillis) {
            String name = userRepo.findName(userId);
            if (name == null) {
                return "USER_NOT_FOUND";
            }
            if (clock.millis() > expireAtMillis) {
                return "EXPIRED";
            }
            if (!gateway.charge(userId, cents)) {
                orderRepo.save(orderId, "PAY_FAILED");
                return "PAY_FAILED";
            }
            orderRepo.save(orderId, "PAID");
            smsSender.send("138****" + userId, "尊敬的" + name + "，您的订单 " + orderId + " 已支付");
            return "PAID";
        }
    }

    /** Stub：只返回预设值 */
    static class StubUserRepo implements UserRepo {
        private final Map<Long, String> data = new HashMap<>();

        StubUserRepo put(long id, String name) {
            data.put(id, name);
            return this;
        }

        public String findName(long userId) {
            return data.get(userId);
        }
    }

    /** Fake：内存版仓储，有真实逻辑 */
    static class FakeOrderRepo implements OrderRepo {
        final Map<Long, String> store = new HashMap<>();

        public void save(long orderId, String status) {
            store.put(orderId, status);
        }
    }

    /** Mock：记录调用，可断言交互 */
    static class MockSmsSender implements SmsSender {
        final List<String> calls = new ArrayList<>();

        public void send(String phone, String text) {
            calls.add(phone + "|" + text);
        }

        int callCount() {
            return calls.size();
        }
    }

    /** Spy：包住真实对象，转发并记录 */
    static class SpyPaymentGateway implements PaymentGateway {
        private final PaymentGateway real;
        final List<Long> chargedCents = new ArrayList<>();

        SpyPaymentGateway(PaymentGateway real) {
            this.real = real;
        }

        public boolean charge(long userId, long cents) {
            chargedCents.add(cents);
            return real.charge(userId, cents);
        }
    }

    static class AssertionFailedError extends RuntimeException {
        private static final long serialVersionUID = 1L;

        AssertionFailedError(String message) {
            super(message);
        }
    }

    static void check(String caseName, String expected, String actual) {
        boolean ok = expected.equals(actual);
        System.out.printf("    %-42s 期望=%-14s 实际=%-14s %s%n",
                caseName, expected, actual, ok ? "OK" : "FAIL");
        if (!ok) {
            throw new AssertionFailedError(caseName);
        }
    }

    static void checkTrue(String caseName, boolean condition) {
        System.out.printf("    %-42s %s%n", caseName, condition ? "OK" : "FAIL");
        if (!condition) {
            throw new AssertionFailedError(caseName);
        }
    }

    public static void main(String[] args) {
        Clock fixed = Clock.fixed(Instant.ofEpochMilli(1_000_000L), ZoneId.of("Asia/Shanghai"));

        System.out.println("=== 1. Stub + Fake + Mock：正常支付成功 ===");
        StubUserRepo userRepo = new StubUserRepo().put(7L, "张三");
        FakeOrderRepo orderRepo = new FakeOrderRepo();
        MockSmsSender sms = new MockSmsSender();
        SpyPaymentGateway pay = new SpyPaymentGateway((uid, cents) -> cents <= 50_000L);

        OrderService svc = new OrderService(userRepo, sms, orderRepo, pay, fixed);
        String r1 = svc.placeOrder(7L, 1001L, 9_900L, 2_000_000L);
        check("返回值", "PAID", r1);
        check("订单状态（状态验证）", "PAID", orderRepo.store.get(1001L));
        check("短信发送次数（交互验证）", "1", String.valueOf(sms.callCount()));
        checkTrue("短信内容含用户姓名", sms.calls.get(0).contains("张三"));
        check("扣款金额被 Spy 记录", "9900", String.valueOf(pay.chargedCents.get(0)));

        System.out.println();
        System.out.println("=== 2. 用户不存在：不应扣款、不应发短信 ===");
        MockSmsSender sms2 = new MockSmsSender();
        FakeOrderRepo repo2 = new FakeOrderRepo();
        SpyPaymentGateway pay2 = new SpyPaymentGateway((uid, cents) -> true);
        OrderService svc2 = new OrderService(new StubUserRepo(), sms2, repo2, pay2, fixed);
        check("返回值", "USER_NOT_FOUND", svc2.placeOrder(99L, 1002L, 100L, 2_000_000L));
        check("未调用扣款", "0", String.valueOf(pay2.chargedCents.size()));
        check("未发送短信", "0", String.valueOf(sms2.callCount()));
        checkTrue("未落库任何订单", repo2.store.isEmpty());

        System.out.println();
        System.out.println("=== 3. 已过期：同样不应扣款 ===");
        SpyPaymentGateway pay3 = new SpyPaymentGateway((uid, cents) -> true);
        OrderService svc3 = new OrderService(new StubUserRepo().put(1L, "李四"),
                new MockSmsSender(), new FakeOrderRepo(), pay3, fixed);
        check("返回值", "EXPIRED", svc3.placeOrder(1L, 1003L, 100L, 500_000L));
        check("未调用扣款", "0", String.valueOf(pay3.chargedCents.size()));

        System.out.println();
        System.out.println("=== 4. 支付失败：状态为 PAY_FAILED，不发短信 ===");
        MockSmsSender sms4 = new MockSmsSender();
        FakeOrderRepo repo4 = new FakeOrderRepo();
        OrderService svc4 = new OrderService(new StubUserRepo().put(2L, "王五"), sms4, repo4,
                new SpyPaymentGateway((uid, cents) -> false), fixed);
        check("返回值", "PAY_FAILED", svc4.placeOrder(2L, 1004L, 100_000L, 2_000_000L));
        check("订单状态", "PAY_FAILED", repo4.store.get(1004L));
        check("不发成功短信", "0", String.valueOf(sms4.callCount()));

        System.out.println();
        System.out.println("=== 5. 动态代理做通用 Spy（不改被测代码）===");
        List<String> log = new ArrayList<>();
        UserRepo proxied = (UserRepo) Proxy.newProxyInstance(
                UserRepo.class.getClassLoader(),
                new Class<?>[]{UserRepo.class},
                new InvocationHandler() {
                    public Object invoke(Object proxy, Method method, Object[] a) {
                        log.add(method.getName() + "(" + a[0] + ")");
                        return method.getName().equals("findName") && (Long) a[0] == 42L ? "赵六" : null;
                    }
                });
        OrderService svc5 = new OrderService(proxied, new MockSmsSender(), new FakeOrderRepo(),
                (uid, cents) -> true, fixed);
        check("代理返回预设值", "PAID", svc5.placeOrder(42L, 1005L, 1L, 2_000_000L));
        check("代理记录到调用", "findName(42)", String.join(",", log));

        System.out.println();
        System.out.println("=== 6. 五种替身对照 ===");
```

### 33-03 测试用例设计：等价类、边界值与参数化

**知识点**
- 测试用例的价值不在于数量，而在于**用最少用例覆盖最多风险**。核心方法：等价类划分、边界值分析、判定表、状态迁移、错误推测。
- **等价类划分**：把输入域切成若干类，每类里任取一个值效果相同。有效等价类（正常输入）+ 无效等价类（非法输入）。**无效等价类必须逐个单独测**，因为一个非法值可能掩盖另一个。
- **边界值分析**：bug 最爱藏在边界。对区间 `[a, b]`，至少测 `a-1, a, a+1, b-1, b, b+1` 六个点。off-by-one 是最高频缺陷。
- **参数化测试**：一份逻辑 + 一张数据表。JUnit 5 用 `@ParameterizedTest` + `@ValueSource`（单值）、`@CsvSource`（多列）、`@MethodSource`（复杂对象）。手写版就是"数据表 + for 循环"。
- **判定表**：多个条件组合时，列出所有条件组合与期望动作。适合"会员等级 × 是否首单 × 是否有券"这类规则叠加。
- **状态迁移测试**：把业务状态机画出来，覆盖"合法迁移"和"非法迁移"两类。非法迁移（如已取消订单再支付）往往比合法路径更容易漏测。
- **错误推测**：基于经验主动想"哪里会错"——空集合、`null`、超长字符串、并发、时区、闰年、金额精度、重复提交。
- 用例设计产出物是**用例表**（输入 / 前置条件 / 期望），先写表再写代码，避免"看着实现写测试"（那样只会覆盖已实现的路径，漏掉没实现的需求）。
- 覆盖强度阶梯：语句覆盖 < 判定覆盖 < 条件组合覆盖 < 路径覆盖。实际项目做到"判定 + 边界"通常足够，关键资金链路再上路径覆盖。
- 易错：只测正常值（happy path）不测异常；用 `Random` 造数据（失败无法复现）；把多个无效等价类塞进一个用例；只测 `[0,100]` 里的 50，不测 -1、0、100、101。

### 33-04 覆盖率：行覆盖、分支覆盖与未覆盖分支分析

**知识点**
- **覆盖率**回答"测试跑了多少代码"，是**发现测试盲区**的探针，不是质量目标。追 100% 覆盖率会写出大量"执行了但没断言"的空测试。
- 四种粒度：
  - **行覆盖**（Line）：某行被执行过。最弱，`if (a && b)` 一行也算覆盖。
  - **分支覆盖**（Branch）：每个 `if`/`switch`/三元/`&&`/`||` 的两个方向都走到。比行覆盖有意义得多。
  - **条件覆盖**：复合条件里每个原子条件取过 true/false。
  - **路径覆盖**：方法内所有执行路径组合。分支多时路径爆炸，实际少用。
- JaCoCo 的原理：**字节码插桩**——在 class 文件里每个分支跳转前插入探针（记录 boolean 数组），运行结束后 dump 出 `.exec` 文件，再结合源码生成报告。它不修改源码。
- 覆盖率报告要看的不是总数，而是**红色（未覆盖）的那几行**：往往是异常分支、`null` 判断、`default` 分支、边界 `else`。这些恰是最容易出 bug 的地方。
- 覆盖率的合理区间：核心业务（资金、库存、权限）分支覆盖 80% 以上；DTO/getter/setter、配置类不必强求；生成的代码排除。
- **覆盖率不等于断言**：`service.calculate()` 被调用就算覆盖，但不断言结果，测试毫无价值。变异测试（PIT）才能验证"断言是否有效"——故意改坏代码，看测试会不会红。
- 未覆盖分支的常见成因：只写 happy path、`catch` 块无法触发（依赖抛异常）、防御性 `null` 检查、`default` 兜底分支、并发分支。
- 纯 JDK 无法直接读字节码覆盖率，本课用**显式埋点 + 分支表**模拟 JaCoCo 的统计思路：业务代码在每个分支处打点，测试跑完后统计"哪些点没被命中"。
- 易错：把覆盖率当 KPI 导致写"调用即通过"的测试；只统计行覆盖不看分支；忽略 `catch` 分支；覆盖率高但断言缺失（变异测试会暴露）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

public class CoverageMetrics {
    /** 探针：模拟 JaCoCo 插入的 boolean 数组 */
    static class Probe {
        static final Set<String> HIT = new LinkedHashSet<>();
        static final Set<String> ALL = new LinkedHashSet<>();

        static void declare(String id) {
            ALL.add(id);
        }

        static void hit(String id) {
            HIT.add(id);
        }

        static void reset() {
            HIT.clear();
        }

        static double rate() {
            return ALL.isEmpty() ? 1.0 : (double) HIT.size() / ALL.size();
        }
    }

    /** 被测：运费计算，每个分支埋一个探针 */
    static class ShippingCalculator {
        static {
            Probe.declare("B1_weight<=0");
            Probe.declare("B2_weight<=1");
            Probe.declare("B3_weight<=5");
            Probe.declare("B4_remote");
            Probe.declare("B5_vip");
            Probe.declare("B6_freeThreshold");
            Probe.declare("B7_negativeAmount");
        }

        /** @return 运费（分） */
        long calc(int weightGram, boolean remote, boolean vip, long orderCents) {
            if (weightGram <= 0) {
                Probe.hit("B1_weight<=0");
                throw new IllegalArgumentException("重量必须为正: " + weightGram);
            }
            long base;
            if (weightGram <= 1000) {
                Probe.hit("B2_weight<=1");
                base = 800;
            } else if (weightGram <= 5000) {
                Probe.hit("B3_weight<=5");
                base = 800 + (weightGram - 1000) / 500 * 200;
            } else {
                base = 800 + 8 * 200 + (weightGram - 5000) / 1000 * 300;
            }
            if (remote) {
                Probe.hit("B4_remote");
                base += 1000;
            }
            if (vip) {
                Probe.hit("B5_vip");
                base = base * 80 / 100;
            }
            if (orderCents >= 9_900L) {
                Probe.hit("B6_freeThreshold");
                return 0;
            }
            if (orderCents < 0) {
                Probe.hit("B7_negativeAmount");
                throw new IllegalStateException("订单金额为负");
            }
            return base;
        }
    }

    static class Case {
        final String desc;
        final int weight;
        final boolean remote;
        final boolean vip;
        final long order;
        final boolean expectThrow;

        Case(String desc, int weight, boolean remote, boolean vip, long order, boolean expectThrow) {
            this.desc = desc;
            this.weight = weight;
            this.remote = remote;
            this.vip = vip;
            this.order = order;
            this.expectThrow = expectThrow;
        }
    }

    static long lastResult;

    static void run(ShippingCalculator c, Case k) {
        try {
            lastResult = c.calc(k.weight, k.remote, k.vip, k.order);
            if (k.expectThrow) {
                System.out.printf("    %-30s 期望抛异常但没抛 -> FAIL%n", k.desc);
            } else {
                System.out.printf("    %-30s 运费=%-6d OK%n", k.desc, lastResult);
            }
        } catch (RuntimeException e) {
            if (k.expectThrow) {
                System.out.printf("    %-30s 抛出 %-22s OK%n", k.desc, e.getClass().getSimpleName());
            } else {
                System.out.printf("    %-30s 意外异常 %s -> FAIL%n", k.desc, e.getMessage());
            }
        }
    }

    static void report(String title) {
        System.out.println("  " + title);
        System.out.printf("    分支覆盖率 = %d/%d = %.0f%%%n",
                Probe.HIT.size(), Probe.ALL.size(), Probe.rate() * 100);
        List<String> missed = new ArrayList<>(Probe.ALL);
        missed.removeAll(Probe.HIT);
        if (missed.isEmpty()) {
            System.out.println("    未覆盖分支: 无");
        } else {
            System.out.println("    未覆盖分支: " + missed);
        }
    }

    public static void main(String[] args) {
        ShippingCalculator calc = new ShippingCalculator();

        System.out.println("=== 1. 第一轮：只有 happy path（典型的低质量测试）===");
        Probe.reset();
        List<Case> round1 = new ArrayList<>();
        round1.add(new Case("1kg 普通 订单 50 元", 1000, false, false, 5_000, false));
        round1.add(new Case("3kg 普通 订单 50 元", 3_000, false, false, 5_000, false));
        for (Case k : round1) {
            run(calc, k);
        }
        report("第一轮结果");

        System.out.println();
        System.out.println("=== 2. 第二轮：补齐边界与异常分支 ===");
        Probe.reset();
        List<Case> round2 = new ArrayList<>();
        round2.add(new Case("1kg 普通", 1_000, false, false, 5_000, false));
        round2.add(new Case("1kg 偏远", 1_000, true, false, 5_000, false));
        round2.add(new Case("1kg VIP", 1_000, false, true, 5_000, false));
        round2.add(new Case("满 99 免运费", 1_000, false, false, 9_900, false));
        round2.add(new Case("0g 非法", 0, false, false, 5_000, true));
        round2.add(new Case("负金额", 1_000, false, false, -1, true));
        for (Case k : round2) {
            run(calc, k);
        }
        report("第二轮结果");

        System.out.println();
        System.out.println("=== 3. 两轮对比 ===");
        System.out.println("  第一轮 2 个用例：只覆盖常规路径，异常与优惠分支全漏");
        System.out.println("  第二轮 6 个用例：分支覆盖补齐到 100%");
        System.out.println("  关键：第二轮多出来的 4 个用例，正好是 4 个高风险分支");

        System.out.println();
        System.out.println("=== 4. 覆盖率的四种粒度 ===");
        String[][] t = {
                {"行覆盖", "该行是否执行过", "最弱，复合条件一行算一个"},
                {"分支覆盖", "if/switch/&&/|| 两方向", "性价比最高，项目基线"},
                {"条件覆盖", "复合条件内每个原子条件", "适合复杂布尔表达式"},
                {"路径覆盖", "所有路径组合", "分支多时爆炸，慎用"},
                {"变异覆盖", "改坏代码测试是否会红", "验证断言有效性（PIT）"}
        };
        for (String[] r : t) {
            System.out.printf("  %-12s %-28s %s%n", r[0], r[1], r[2]);
        }

        System.out.println();
        System.out.println("=== 5. 覆盖率报告该看什么 ===");
```

### 33-05 打桩与交互验证：手写一个 MiniMockito

**知识点**
- Mock 框架要解决三件事：**创建代理**（`mock`）、**预设返回值**（`when(...).thenReturn(...)`）、**验证交互**（`verify(mock, times(n))`）。
- 实现原理（Mockito 风格）：JDK 动态代理拦截所有方法调用 → 记录每次调用的"方法 + 参数" → `when()` 取"最后一次调用"作为打桩目标 → `thenReturn` 把结果存进 map → 下次同参数调用直接返回缓存值。
- `when()` 之后必须**清空调用记录**：否则 `when(repo.find(1L))` 这次调用本身会被算作一次交互，`verify(times(1))` 就会误报 2 次。
- 未打桩的方法返回**默认值**（对象 `null`、`int` 0、`boolean` false），而不是抛异常。这是 Mockito 的默认行为，容易造成 NPE，需要留意。
- **参数匹配器**：精确值匹配最简单；`any()`、`eq()`、`argThat()` 用于"不关心具体值"的场景。Mockito 要求"一旦用了匹配器，所有参数都得用匹配器"，手写版可以放宽，但要理解这条约束的来源。
- `verify(times(n))` / `never()` / `atLeast(n)` 是**交互验证**，断言的是"协作方式"。它比状态验证更脆弱：重构内部实现（换了个方法调用）就会红，所以只用于**外部副作用**（发短信、扣款、发 MQ）。
- `thenThrow` 用来测异常分支；`thenReturn(a, b)` 连续返回不同值，可测"重试成功"；`doAnswer` 用 lambda 动态计算结果（如"回显参数"）。
- Mock 的边界：**不要 mock 值对象、不要 mock 静态方法（需 PowerMock/内联 mock）、不要 mock final 类**（JDK 代理做不到，需要 ByteBuddy 类代理）。
- 自研 vs 框架：生产用 Mockito（`mockito-core` + `mockito-junit-jupiter`），理解原理是为了在"框架行为诡异"时能定位（如 `when` 失效、`NullPointerException` 来自未打桩的返回值）。
- 易错：`when` 里调用的是 mock 的方法但返回值被用在别处（`when(mock.get())` 里再调 mock 会破坏 lastInvocation）；`verify` 次数与实际不符却以为是框架 bug（多算了 `when` 那次调用）；对 `void` 方法用 `when`（应改 `doThrow().when(mock).method()`）。

**示例代码**
```java
import java.lang.reflect.InvocationHandler;
import java.lang.reflect.Method;
import java.lang.reflect.Proxy;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.HashMap;
import java.util.IdentityHashMap;
import java.util.List;
import java.util.Map;
import java.util.Objects;

public class MockStubbing {
    interface UserRepo {
        String findName(long userId);

        int countAll();

        boolean isActive(long userId);

        void delete(long userId);
    }

    interface SmsSender {
        void send(String phone, String text);
    }

    static class VerificationError extends RuntimeException {
        private static final long serialVersionUID = 1L;

        VerificationError(String message) {
            super(message);
        }
    }

    /** 一次方法调用的记录 */
    static class Invocation {
        final Method method;
        final Object[] args;

        Invocation(Method method, Object[] args) {
            this.method = method;
            this.args = args == null ? new Object[0] : args.clone();
        }

        String key() {
            return method.getName() + Arrays.deepToString(args);
        }

        @Override
        public String toString() {
            return method.getName() + Arrays.toString(args);
        }
    }

    /** 每个 mock 对象对应一个 Handler */
    static class MockHandler implements InvocationHandler {
        final List<Invocation> invocations = new ArrayList<>();
        final Map<String, Object> stubs = new HashMap<>();
        Invocation last;

        public Object invoke(Object proxy, Method method, Object[] args) {
            String name = method.getName();
            if ("toString".equals(name) && (args == null || args.length == 0)) {
                return "mock(" + method.getDeclaringClass().getSimpleName() + ")";
            }
            if ("hashCode".equals(name) && (args == null || args.length == 0)) {
                return System.identityHashCode(proxy);
            }
            if ("equals".equals(name) && args != null && args.length == 1) {
                return proxy == args[0];
            }
            Invocation inv = new Invocation(method, args);
            invocations.add(inv);
            last = inv;
            if (stubs.containsKey(inv.key())) {
                Object v = stubs.get(inv.key());
                if (v instanceof RuntimeException) {
                    throw (RuntimeException) v;
                }
                return v;
            }
            return defaultValue(method.getReturnType());
        }

        static Object defaultValue(Class<?> type) {
            if (!type.isPrimitive()) {
                return null;
            }
            if (type == boolean.class) {
                return false;
            }
            if (type == long.class) {
                return 0L;
            }
            if (type == double.class) {
                return 0.0d;
            }
            if (type == float.class) {
                return 0.0f;
            }
            if (type == char.class) {
                return (char) 0;
            }
            return 0;
        }

        int countOf(String methodName, Object... args) {
            int n = 0;
            for (Invocation i : invocations) {
                if (i.method.getName().equals(methodName)
                        && Arrays.deepEquals(i.args, args == null ? new Object[0] : args)) {
                    n++;
                }
            }
            return n;
        }
    }

    static final Map<Object, MockHandler> HANDLERS = new IdentityHashMap<>();

    @SuppressWarnings("unchecked")
    static <T> T mock(Class<T> type) {
        MockHandler handler = new MockHandler();
        Object proxy = Proxy.newProxyInstance(type.getClassLoader(), new Class<?>[]{type}, handler);
        HANDLERS.put(proxy, handler);
        return (T) proxy;
    }

    static MockHandler handlerOf(Object mock) {
        MockHandler h = HANDLERS.get(mock);
        if (h == null) {
            throw new IllegalArgumentException("不是本框架创建的 mock: " + mock);
        }
        return h;
    }

    /** when(mock.findName(1L)) -> 取最后一次调用作为打桩键 */
    static class Stubber<T> {
        private final MockHandler handler;

        Stubber(MockHandler handler) {
            this.handler = handler;
        }

        void thenReturn(T value) {
            Invocation inv = handler.last;
            if (inv == null) {
                throw new IllegalStateException("when() 里没有发生任何 mock 调用");
            }
            handler.stubs.put(inv.key(), value);
            handler.invocations.remove(handler.invocations.size() - 1);
            handler.last = null;
        }

        void thenThrow(RuntimeException e) {
            Invocation inv = handler.last;
            if (inv == null) {
                throw new IllegalStateException("when() 里没有发生任何 mock 调用");
            }
            handler.stubs.put(inv.key(), e);
            handler.invocations.remove(handler.invocations.size() - 1);
            handler.last = null;
        }
    }

    static <T> Stubber<T> when(T ignoredReturnValue) {
        return new Stubber<>(LAST_HANDLER.get());
    }

    static final ThreadLocal<MockHandler> LAST_HANDLER = new ThreadLocal<>();

    /** 在 mock 调用后记录 handler，供 when 使用 */
    static <T> T track(T mock) {
        LAST_HANDLER.set(handlerOf(mock));
        return mock;
    }

    static class Verifier {
        final MockHandler handler;
        final int expected;
        final String mode;

        Verifier(MockHandler handler, int expected, String mode) {
            this.handler = handler;
            this.expected = expected;
            this.mode = mode;
        }

        void call(String methodName, Object... args) {
            int actual = handler.countOf(methodName, args);
            boolean ok;
            if ("times".equals(mode)) {
                ok = actual == expected;
            } else if ("never".equals(mode)) {
                ok = actual == 0;
            } else {
                ok = actual >= expected;
            }
            String desc = "times".equals(mode) ? "恰好 " + expected + " 次"
                    : "never".equals(mode) ? "0 次" : "至少 " + expected + " 次";
            if (!ok) {
                throw new VerificationError("期望 " + methodName + Arrays.toString(args)
                        + " 被调用 " + desc + "，实际 " + actual + " 次");
            }
            System.out.printf("    verify %-14s %-18s 期望 %-10s 实际 %d 次 OK%n",
                    methodName, Arrays.toString(args), desc, actual);
        }
    }

    static Verifier verify(Object mock, int times) {
        return new Verifier(handlerOf(mock), times, "times");
    }

    static Verifier never(Object mock) {
        return new Verifier(handlerOf(mock), 0, "never");
    }

    static Verifier atLeast(Object mock, int n) {
        return new Verifier(handlerOf(mock), n, "atLeast");
    }

    /** 被测类 */
    static class UserService {
        private final UserRepo repo;
        private final SmsSender sms;

        UserService(UserRepo repo, SmsSender sms) {
            this.repo = repo;
            this.sms = sms;
        }

        String greet(long userId) {
            String name = repo.findName(userId);
            if (name == null) {
                return "访客";
            }
            if (!repo.isActive(userId)) {
                return "账号已停用";
            }
            sms.send("138****" + userId, "欢迎回来，" + name);
            return "欢迎回来，" + name;
        }
    }

    public static void main(String[] args) {
        System.out.println("=== 1. 打桩 + 状态验证 ===");
        UserRepo repo = mock(UserRepo.class);
        SmsSender sms = mock(SmsSender.class);

        when(track(repo).findName(1L)).thenReturn("张三");
        when(track(repo).isActive(1L)).thenReturn(true);

        UserService svc = new UserService(repo, sms);
        String r = svc.greet(1L);
        System.out.println("    greet(1) = " + r);

        System.out.println();
        System.out.println("=== 2. 交互验证：发短信恰好一次，且参数正确 ===");
        verify(sms, 1).call("send", "138****1", "欢迎回来，张三");
        verify(repo, 1).call("findName", 1L);

        System.out.println();
        System.out.println("=== 3. 未打桩返回默认值（Mockito 默认行为，也是 NPE 来源）===");
        long unknown = 2L;
        System.out.println("    findName(2) = " + repo.findName(unknown) + "（未打桩 -> null）");
        System.out.println("    countAll()  = " + repo.countAll() + "（int 默认 0）");
        System.out.println("    isActive(2) = " + repo.isActive(unknown) + "（boolean 默认 false）");
        System.out.println("    greet(2)    = " + svc.greet(unknown) + "（走 null 分支返回访客）");

        System.out.println();
        System.out.println("=== 4. 验证失败长什么样 ===");
        try {
            verify(sms, 3).call("send", "138****1", "欢迎回来，张三");
        } catch (VerificationError e) {
            System.out.println("    捕获 VerificationError: " + e.getMessage());
        }
        try {
            never(repo).call("delete", 1L);
            System.out.println("    never(delete) 通过（确实没调用）");
        } catch (VerificationError e) {
            System.out.println("    意外: " + e.getMessage());
        }

        System.out.println();
        System.out.println("=== 5. thenThrow 测异常分支 ===");
        UserRepo broken = mock(UserRepo.class);
        when(track(broken).findName(9L)).thenThrow(new IllegalStateException("数据库连接失败"));
        try {
            broken.findName(9L);
        } catch (RuntimeException e) {
            System.out.println("    打桩异常生效: " + e.getClass().getSimpleName() + " - " + e.getMessage());
        }

        System.out.println();
        System.out.println("=== 6. 停用账号：不应发短信（负向验证）===");
        UserRepo repo3 = mock(UserRepo.class);
        SmsSender sms3 = mock(SmsSender.class);
        when(track(repo3).findName(5L)).thenReturn("王五");
        when(track(repo3).isActive(5L)).thenReturn(false);
        String r3 = new UserService(repo3, sms3).greet(5L);
        System.out.println("    greet(5) = " + r3);
        never(sms3).call("send", "138****5", "欢迎回来，王五");
        System.out.println("    结论：状态验证（返回值）+ 交互验证（未发短信）才是完整断言");

        System.out.println();
        System.out.println("=== 7. when() 为什么必须清空那次调用记录 ===");
        System.out.println("    when(mock.findName(1)) 本身会调用一次 mock 并记录；");
        System.out.println("    不清空的话 verify(mock, 1).call(\"findName\", 1) 会看到 2 次而误报失败。");
        System.out.println("    Mockito 内部同样依赖这个 lastInvocation + 清除机制。");

        System.out.println();
        System.out.println("=== 8. Mock 的边界 ===");
        String[] limits = {
                "值对象（Money/OrderId）不要 mock，直接 new",
                "静态方法 JDK 代理拦不到，需 mockito-inline / PowerMock",
                "final 类无法用 JDK 代理，需 ByteBuddy 类代理",
                "void 方法不能用 when，需 doThrow().when(mock).method()",
                "mock 只验证协作，业务结果仍应用 Stub/Fake 做状态验证"
        };
        for (String s : limits) {
            System.out.println("    - " + s);
        }
    }
}
```

### 33-06 测试分层：单元、集成与端到端

**知识点**
- **测试金字塔**：底层大量单元测试（快、稳、定位准），中层少量集成测试（验证组件协作），顶层极少量端到端测试（验证用户视角的完整链路）。倒金字塔（大量 E2E）会导致构建慢、失败难定位。
- **单元测试**：单类/单方法，依赖全部替换（Stub/Fake），毫秒级，不碰网络/文件/数据库。
- **集成测试**：真实组件协作，但外部系统可替换。典型是"Service + 真实 Repository（内存库）+ 真实事务"，验证 SQL/映射/事务边界。
- **端到端测试**：从 HTTP 入口到数据库全链路。数量要少（10~30 个核心链路），因为慢且脆弱。
- 分层的**判定标准**不是"用了多少层"，而是"**失败时能否快速定位**"。单元测试红了指向一个方法，E2E 红了只能知道"下单不行"。
- 集成测试的隔离手段：每个用例独立事务回滚（`@Transactional`）、独立临时库/schema、内存实现（H2/SQLite）、Testcontainers（真容器）。
- **测试数据隔离**：用例间共享数据是 flaky 的头号原因。方案：每用例造唯一数据（UUID 后缀）、`@BeforeEach` 清表、临时目录用 `@TempDir`。
- **测试顺序无关**：单独跑和全量跑结果必须一致。用固定随机种子（`new Random(42)`）而不是无种子随机。
- 端到端测试的稳定性技巧：不用 `Thread.sleep`（改轮询 + 超时）、给 HTTP 客户端设超时、测试端口用 0（随机端口）、失败时保留现场（日志、临时文件不删）。
- 易错：把集成测试当单元测试写（每个方法都起 Spring 容器，构建 10 分钟）；E2E 覆盖所有分支；用例间靠执行顺序传数据；集成测试连生产库。

**示例代码**
```java
import com.sun.net.httpserver.HttpExchange;
import com.sun.net.httpserver.HttpServer;
import java.io.IOException;
import java.io.OutputStream;
import java.net.InetSocketAddress;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.charset.StandardCharsets;
import java.time.Duration;
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class TestPyramid {
    /** ---------- 领域层 ---------- */
    static class StockRepo {
        private final Map<String, Integer> stock = new LinkedHashMap<>();

        void set(String sku, int qty) {
            stock.put(sku, qty);
        }

        int get(String sku) {
            return stock.getOrDefault(sku, 0);
        }

        boolean tryDeduct(String sku, int qty) {
            int cur = get(sku);
            if (cur < qty) {
                return false;
            }
            stock.put(sku, cur - qty);
            return true;
        }
    }

    static class StockService {
        private final StockRepo repo;

        StockService(StockRepo repo) {
            this.repo = repo;
        }

        String deduct(String sku, int qty) {
            if (qty <= 0) {
                return "BAD_QTY";
            }
            return repo.tryDeduct(sku, qty) ? "OK" : "NO_STOCK";
        }
    }

    /** ---------- 应用层（HTTP 入口）---------- */
    static class OrderApi {
        private final StockService service;

        OrderApi(StockService service) {
            this.service = service;
        }

        HttpServer start(int port) throws IOException {
            HttpServer server = HttpServer.create(new InetSocketAddress("127.0.0.1", port), 0);
            server.createContext("/deduct", this::handle);
            server.setExecutor(null);
            server.start();
            return server;
        }

        private void handle(HttpExchange ex) throws IOException {
            URI uri = ex.getRequestURI();
            String query = uri.getRawQuery() == null ? "" : uri.getRawQuery();
            String sku = "A";
            int qty = 1;
            for (String kv : query.split("&")) {
                int i = kv.indexOf('=');
                if (i < 0) {
                    continue;
                }
                String k = kv.substring(0, i);
                String v = kv.substring(i + 1);
                if ("sku".equals(k)) {
                    sku = v;
                } else if ("qty".equals(k)) {
                    try {
                        qty = Integer.parseInt(v);
                    } catch (NumberFormatException e) {
                        respond(ex, 400, "BAD_PARAM");
                        return;
                    }
                }
            }
            respond(ex, 200, service.deduct(sku, qty));
        }

        private void respond(HttpExchange ex, int code, String body) throws IOException {
            byte[] bytes = body.getBytes(StandardCharsets.UTF_8);
            ex.getResponseHeaders().add("Content-Type", "text/plain; charset=UTF-8");
            ex.sendResponseHeaders(code, bytes.length);
            try (OutputStream os = ex.getResponseBody()) {
                os.write(bytes);
            }
        }
    }

    static int passed;
    static final List<String> failures = new ArrayList<>();

    static void check(String layer, String name, boolean ok, String detail) {
        if (ok) {
            passed++;
            System.out.printf("    [%s] %-46s OK%n", layer, name);
        } else {
            failures.add(layer + " / " + name + " -> " + detail);
            System.out.printf("    [%s] %-46s FAIL: %s%n", layer, name, detail);
        }
    }

    public static void main(String[] args) throws Exception {
        System.out.println("=== 1. 单元测试：Stub 替身，不碰真实仓储 ===");
        StockRepo stub = new StockRepo() {
            @Override
            int get(String sku) {
                return 10;
            }

            @Override
            boolean tryDeduct(String sku, int qty) {
                return qty <= 10;
            }
        };
        StockService unitSvc = new StockService(stub);
        check("UNIT", "qty=3 扣减成功", "OK".equals(unitSvc.deduct("A", 3)), "返回值不符");
        check("UNIT", "qty=11 库存不足", "NO_STOCK".equals(unitSvc.deduct("A", 11)), "返回值不符");
        check("UNIT", "qty=0 参数非法", "BAD_QTY".equals(unitSvc.deduct("A", 0)), "返回值不符");
        check("UNIT", "qty=-1 参数非法", "BAD_QTY".equals(unitSvc.deduct("A", -1)), "返回值不符");

        System.out.println();
        System.out.println("=== 2. 集成测试：真实仓储 + 真实服务，验证状态变化 ===");
        StockRepo realRepo = new StockRepo();
        realRepo.set("SKU-1", 5);
        StockService integSvc = new StockService(realRepo);
        check("INTEG", "扣 2 返回 OK", "OK".equals(integSvc.deduct("SKU-1", 2)), "返回值不符");
        check("INTEG", "扣减后库存 = 3", realRepo.get("SKU-1") == 3, "实际=" + realRepo.get("SKU-1"));
        check("INTEG", "再扣 4 失败", "NO_STOCK".equals(integSvc.deduct("SKU-1", 4)), "返回值不符");
        check("INTEG", "失败后库存不变 = 3", realRepo.get("SKU-1") == 3, "实际=" + realRepo.get("SKU-1"));
        check("INTEG", "扣 3 后库存 = 0", "OK".equals(integSvc.deduct("SKU-1", 3))
                && realRepo.get("SKU-1") == 0, "库存=" + realRepo.get("SKU-1"));

        System.out.println();
        System.out.println("=== 3. 端到端测试：真起 HTTP 服务 + 真发请求 ===");
        StockRepo e2eRepo = new StockRepo();
        e2eRepo.set("A", 2);
        HttpServer server = new OrderApi(new StockService(e2eRepo)).start(0);
        int port = server.getAddress().getPort();
        System.out.println("    HttpServer 随机端口 = " + port + "（端口 0 避免冲突）");
        HttpClient client = HttpClient.newBuilder()
                .connectTimeout(Duration.ofSeconds(2))
                .build();
        try {
            String r1 = get(client, port, "/deduct?sku=A&qty=1");
            check("E2E", "第 1 次扣减", "OK".equals(r1), "body=" + r1);
            String r2 = get(client, port, "/deduct?sku=A&qty=1");
            check("E2E", "第 2 次扣减", "OK".equals(r2), "body=" + r2);
            String r3 = get(client, port, "/deduct?sku=A&qty=1");
            check("E2E", "第 3 次扣减库存不足", "NO_STOCK".equals(r3), "body=" + r3);
            String r4 = get(client, port, "/deduct?sku=A&qty=abc");
            check("E2E", "非法参数", "BAD_PARAM".equals(r4), "body=" + r4);
            check("E2E", "最终库存 = 0", e2eRepo.get("A") == 0, "库存=" + e2eRepo.get("A"));
        } finally {
            server.stop(0);
            System.out.println("    服务已停止（finally 里清理，避免端口泄漏）");
        }

        System.out.println();

        String[][] t = {
```

### 33-07 测试数据构建：ObjectMother、Builder 与夹具清理

**知识点**
- 测试代码里最烦的两件事：**造一个合法对象要写 10 行**、**用例之间数据互相污染**。前者用 ObjectMother/Builder 解决，后者用夹具（fixture）清理解决。
- **ObjectMother**：一组静态工厂方法，返回"典型场景的现成对象"。`Users.aVipUser()`、`Orders.paidOrder()`。优点是语义清晰、一行造数据；缺点是固定值多，容易变成"什么都想加参数"的巨型工厂。
- **Test Data Builder**：链式构建 + 合理默认值，只覆盖关心的字段。`anOrder().withAmount(9900).build()`。比 ObjectMother 灵活，是当前主流（`java-faker`、`Instancio` 都是这个思路）。
- 关键设计：**Builder 必须有能构建出"合法对象"的默认值**。每个用例只改它要测的那一个字段，其余保持默认——这样用例失败时原因唯一。
- **测试夹具（Fixture）**：用例运行前准备好的数据与环境。清理三原则：`finally`/`@AfterEach` 一定执行、删除自己创建的东西、不删除别人的。
- **唯一性**：并发或共享库场景下，用 `UUID` / 时间戳 / 自增序号做后缀，避免主键冲突。不要用固定 ID（`id=1`）在共享库里写数据。
- **临时文件**：用 `Files.createTempDirectory` 而不是硬编码路径；测试结束递归删除；JUnit 5 的 `@TempDir` 会自动清理。
- **不变式断言**：造完数据后先断言"这个夹具确实是我以为的样子"（如"库存确实为 5"），否则夹具写错会让测试失败指向错误的地方。
- 反模式：`@BeforeAll` 里造全局共享可变数据（用例顺序耦合）；Builder 的默认值不合法（每次都要改三个字段）；测试里硬编码时间（用固定 `Clock`）；一个 Builder 服务所有场景导致参数爆炸。
- 易错：Builder 复用同一个实例（`build()` 应每次返回新对象，或至少不共享可变状态）；清理时漏掉关联表；用生产数据做测试夹具（含真实手机号）。

### 33-08 异常契约、参数校验与并发测试

**知识点**
- **异常契约**：方法除了"返回什么"，还要约定"什么情况下抛什么异常"。契约要写进 JavaDoc 的 `@throws`，测试要覆盖它。异常类型选错（该 `IllegalArgumentException` 却抛 `NullPointerException`）会让调用方无法精准处理。
- 异常分类的用法：**参数非法** → `IllegalArgumentException`（含 `Objects.requireNonNull` 的 `NullPointerException`）；**状态不允许** → `IllegalStateException`；**受检的业务失败** → 自定义 `XxxException extends Exception`；**不该发生** → `AssertionError` / 直接让 NPE 暴露。
- 不要用异常做流程控制：能用返回值表达"业务失败"（如 `Result.fail("NO_STOCK")`）就不要抛异常。异常只用于"调用方写错了"或"环境异常"。
- **异常包装**：底层异常（SQLException）不要直接抛给上层，要转成领域异常并**保留 cause**（`new OrderException("创建订单失败", e)`）。丢掉 cause 会毁掉排查线索。
- 测试异常的三个层次：**类型**（`assertThrows(IllegalArgumentException.class, ...)`）、**message 关键片段**（`contains("金额")`）、**cause 链**（`assertEquals(SQLException.class, e.getCause().getClass())`）。只测类型常常不够。
- **不该抛的异常**要显式验证：正常路径不应抛异常（用 `assertDoesNotThrow`），或者"某异常绝不该出现"（捕获后 `fail()`）。
- **参数校验**放在方法入口，越早越好（fail fast）。`Objects.requireNonNull(x, "x 不能为空")`、`Objects.checkIndex`、`Math.addExact`（溢出即抛）都是 JDK 自带的好工具。
- **并发测试**的难点是"不确定性"。三个手段：`CountDownLatch` 让线程同时起跑、重复多次（1000 轮）提高暴露概率、断言**不变式**（总量守恒）而不是具体交错顺序。
- 并发测试不要断言"顺序"，只断言"结果合法"。同时给测试设超时（`@Timeout`），避免挂死。
- 易错：`catch (Exception e) {}` 吞异常（测试永远绿）；断言 message 用全等（改文案就红，应用 `contains`）；并发测试只跑一次就认为没问题；用 `Thread.sleep` 代替同步。

**示例代码**
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Objects;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicInteger;

public class ExceptionContract {
    static class OrderException extends Exception {
        private static final long serialVersionUID = 1L;

        OrderException(String message, Throwable cause) {
            super(message, cause);
        }
    }

    /** 模拟底层存储异常 */
    static class DiskFullException extends RuntimeException {
        private static final long serialVersionUID = 1L;

        DiskFullException(String msg) {
            super(msg);
        }
    }

    static class OrderRepo {
        private final boolean broken;
        private final AtomicInteger writes = new AtomicInteger();

        OrderRepo(boolean broken) {
            this.broken = broken;
        }

        int write(String orderNo) {
            if (broken) {
                throw new DiskFullException("磁盘已满");
            }
            return writes.incrementAndGet();
        }

        int writes() {
            return writes.get();
        }
    }

    static class OrderService {
        private final OrderRepo repo;

        OrderService(OrderRepo repo) {
            this.repo = repo;
        }

        /**
         * 创建订单。
         *
         * @throws NullPointerException     orderNo 为 null
         * @throws IllegalArgumentException orderNo 为空白、金额不为正
         * @throws OrderException           底层写入失败（保留 cause）
         */
        String create(String orderNo, long amountCents) throws OrderException {
            Objects.requireNonNull(orderNo, "orderNo 不能为 null");
            if (orderNo.isBlank()) {
                throw new IllegalArgumentException("orderNo 不能为空白");
            }
            if (amountCents <= 0) {
                throw new IllegalArgumentException("金额必须为正，实际=" + amountCents);
            }
            try {
                repo.write(orderNo);
                return "CREATED:" + orderNo;
            } catch (RuntimeException e) {
                throw new OrderException("创建订单失败: " + orderNo, e);
            }
        }

        /** 状态类错误用 IllegalStateException */
        void pay(String status) {
            if (!"CREATED".equals(status)) {
                throw new IllegalStateException("当前状态不允许支付: " + status);
            }
        }
    }

    static int passed;
    static final List<String> failures = new ArrayList<>();

    static void check(String name, boolean ok, String detail) {
        if (ok) {
            passed++;
            System.out.printf("    %-56s OK%n", name);
        } else {
            failures.add(name + " -> " + detail);
            System.out.printf("    %-56s FAIL: %s%n", name, detail);
        }
    }

    interface ThrowingCall {
        void run() throws Exception;
    }

    /** 断言异常类型 + message 片段 + cause 类型 */
    static void assertThrows(String name, Class<? extends Throwable> type,
                             String messagePart, Class<? extends Throwable> causeType,
                             ThrowingCall call) {
        try {
            call.run();
            check(name, false, "期望抛 " + type.getSimpleName() + "，但没抛");
        } catch (Throwable t) {
            if (!type.isInstance(t)) {
                check(name, false, "期望 " + type.getSimpleName() + "，实际 " + t.getClass().getSimpleName());
                return;
            }
            if (messagePart != null && (t.getMessage() == null || !t.getMessage().contains(messagePart))) {
                check(name, false, "message 不含 [" + messagePart + "]，实际=[" + t.getMessage() + "]");
                return;
            }
            if (causeType != null && (t.getCause() == null || !causeType.isInstance(t.getCause()))) {
                check(name, false, "cause 期望 " + causeType.getSimpleName()
                        + "，实际 " + (t.getCause() == null ? "null" : t.getCause().getClass().getSimpleName()));
                return;
            }
            check(name, true, "");
        }
    }

    static void assertDoesNotThrow(String name, ThrowingCall call) {
        try {
            call.run();
            check(name, true, "");
        } catch (Throwable t) {
            check(name, false, "不该抛却抛了 " + t.getClass().getSimpleName() + ": " + t.getMessage());
        }
    }

    public static void main(String[] args) throws Exception {
        System.out.println("=== 1. 参数非法：类型 + message 双重断言 ===");
        OrderService ok = new OrderService(new OrderRepo(false));
        assertThrows("orderNo=null -> NullPointerException", NullPointerException.class,
                "orderNo", null, () -> ok.create(null, 100L));
        assertThrows("orderNo 空白 -> IllegalArgumentException", IllegalArgumentException.class,
                "空白", null, () -> ok.create("   ", 100L));
        assertThrows("金额 0 -> IllegalArgumentException", IllegalArgumentException.class,
                "金额必须为正", null, () -> ok.create("ORD-1", 0L));
        assertThrows("金额 -1 -> IllegalArgumentException", IllegalArgumentException.class,
                "实际=-1", null, () -> ok.create("ORD-1", -1L));

        System.out.println();
        System.out.println("=== 2. 底层异常包装：保留 cause 才能排查 ===");
        OrderService broken = new OrderService(new OrderRepo(true));

        System.out.println();
        System.out.println("=== 8. 异常契约设计清单 ===");
        String[] rules = {
                "参数非法 -> IllegalArgumentException / NullPointerException",
                "状态不允许 -> IllegalStateException",
                "可恢复业务失败 -> 返回值 Result，不要抛异常",

        }
```

### 33-09 静态检查：规范、坏味道与自定义规则引擎

**知识点**
- **静态检查**在**不运行代码**的前提下发现问题，能在提交前拦住一大类缺陷：空指针风险、资源未关闭、`equals`/`hashCode` 不配对、可变静态字段、`catch` 空块、魔法值、命名不规范。
- 工具分工：
  - **Checkstyle**：纯风格（缩进、命名、行宽、import 顺序、JavaDoc）。快，但只能管"形"。
  - **SpotBugs**：字节码级缺陷检测（NPE 风险、`equals` 未覆盖 `hashCode`、`Stream` 未关闭、锁未释放）。能管"实"。
  - **PMD**：源码级坏味道（圈复杂度、重复代码、过长方法、未使用变量）。
  - **ErrorProne / SonarQube**：编译期/平台级，规则最全，Sonar 还能做质量门禁。
- **圈复杂度**（Cyclomatic Complexity）= 判定点数量 + 1。经验阈值：方法 > 10 就该拆，> 15 几乎必然难测。它是"可测性"的量化指标。
- **重复代码**检测思路：滑动窗口 + 归一化（去空白/去注释/变量名归一）+ 哈希比对。重复率高的地方，改一处漏一处。
- 规则引擎的最小实现：**解析**（按行/按 token）→ **匹配**（正则或 AST 访问）→ **报告**（文件:行:规则:说明）→ **分级**（ERROR 阻断构建，WARN 仅提示）。
- **质量门禁**（quality gate）：把静态检查结果变成"能不能合并"的硬条件——`ERROR = 0`、圈复杂度超标的文件数不增加、新增代码覆盖率 ≥ 80%。
- 规则要**可执行、可解释、可豁免**。豁免必须有理由和责任人（`@SuppressWarnings("rule")` + 注释说明），否则规则会被集体绕过。
- 渐进式落地：先只开 ERROR 级别的少数规则（空 `catch`、资源未关闭、`equals/hashCode`），全绿后再逐步加 WARN，最后接入 CI 阻断。一次性开 200 条规则必然被抵制。
- 易错：规则太多导致 `// CHECKSTYLE:OFF` 满天飞；只看报告不修（技术债累积）；把风格问题和缺陷问题混在一个等级；自研规则正则写得太宽（误报率高）或太窄（漏报）。

```java
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.HashMap;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.regex.Matcher;
import java.util.regex.Pattern;
import java.util.stream.Stream;

public class StaticAnalysis {
    enum Severity {
        ERROR, WARN, INFO
    }

    /** 一条规则 */
    static class Rule {
        final String id;
        final String desc;
        final Severity severity;
        final Pattern pattern;

        Rule(String id, String desc, Severity severity, String regex) {
            this.id = id;
            this.desc = desc;
            this.severity = severity;
            this.pattern = Pattern.compile(regex);
        }
    }

    /** 一条发现 */
    static class Finding {
        final String file;
        final int line;
        final Rule rule;
        final String snippet;

        Finding(String file, int line, Rule rule, String snippet) {
            this.file = file;
            this.line = line;
            this.rule = rule;
            this.snippet = snippet;
        }

        @Override
        public String toString() {
            return String.format("[%s] %s:%d %s | %s", rule.severity, file, line,
                    rule.id, snippet.trim());
        }
    }

    static final List<Rule> RULES = List.of(
            new Rule("EMPTY_CATCH", "空的 catch 块会吞掉异常", Severity.ERROR,
                    "^\\s*catch\\s*\\([^)]*\\)\\s*\\{\\s*$"),
            new Rule("SYSTEM_OUT", "生产代码不应直接 System.out", Severity.WARN,
                    "System\\.(out|err)\\.print"),
            new Rule("MAGIC_NUMBER", "出现魔法数字，应提取常量", Severity.INFO,
                    "[^\\w.]\\d{3,}[^\\w.]"),
            new Rule("TODO_FIXME", "遗留 TODO/FIXME", Severity.INFO,
                    "//\\s*(TODO|FIXME)"),
            new Rule("THREAD_SLEEP", "测试/生产代码里的 sleep 是 flaky 源头", Severity.WARN,
                    "Thread\\.sleep\\s*\\("),
            new Rule("CATCH_GENERIC", "catch Exception 过宽", Severity.WARN,
                    "catch\\s*\\(\\s*Exception\\s+\\w+\\s*\\)")
    );

    /** 迷你规则引擎 */
    static class Analyzer {
        final List<Finding> findings = new ArrayList<>();
        final Map<String, Integer> perRule = new LinkedHashMap<>();

        void analyze(Path file) throws IOException {
            List<String> lines = Files.readAllLines(file, StandardCharsets.UTF_8);
            String name = file.getFileName().toString();
            for (int i = 0; i < lines.size(); i++) {
                String text = lines.get(i);
                String stripped = stripComment(text);
                for (Rule rule : RULES) {
                    if (rule.pattern.matcher(stripped).find()) {
                        if ("EMPTY_CATCH".equals(rule.id) && !isEmptyCatchBlock(lines, i)) {
                            continue;
                        }
                        findings.add(new Finding(name, i + 1, rule, text));
                        perRule.merge(rule.id, 1, Integer::sum);
                    }
                }
            }
        }

        /** 判断 catch 行之后是否紧跟空块 */
        static boolean isEmptyCatchBlock(List<String> lines, int catchLine) {
            for (int j = catchLine + 1; j < Math.min(lines.size(), catchLine + 3); j++) {
                String t = lines.get(j).trim();
                if (t.isEmpty()) {
                    continue;
                }
                return t.startsWith("}") || t.startsWith("//") || t.startsWith("/*");
            }
            return false;
        }

        static String stripComment(String s) {
            int idx = s.indexOf("//");
            return idx >= 0 ? s.substring(0, idx) : s;
        }

        /** 圈复杂度：判定点 + 1 */
        static int cyclomatic(String source) {
            String[] keywords = {"if ", "else if", "for ", "while ", "case ", "catch ", "&&", "||", "?"};
            int score = 1;
            for (String k : keywords) {
                int from = 0;
                while (true) {
                    int idx = source.indexOf(k, from);
                    if (idx < 0) {
                        break;
                    }
                    score++;
                    from = idx + k.length();
                }
            }
            return score;
        }

        /** 重复代码：按 6 行滑动窗口做归一化哈希 */
        static Map<String, List<Integer>> duplicateBlocks(List<String> lines) {
            Map<String, List<Integer>> map = new HashMap<>();
            int window = 6;
            for (int i = 0; i + window <= lines.size(); i++) {
                StringBuilder sb = new StringBuilder();
                boolean meaningful = false;
                for (int j = i; j < i + window; j++) {
                    String t = lines.get(j).trim().replaceAll("\\s+", " ");
                    if (t.isEmpty() || t.startsWith("//") || t.equals("{") || t.equals("}")) {
                        continue;
                    }
                    meaningful = true;
                    sb.append(t).append(';');
                }
                if (meaningful) {
                    map.computeIfAbsent(sb.toString(), k -> new ArrayList<>()).add(i + 1);
                }
            }
            map.entrySet().removeIf(e -> e.getValue().size() < 2);
            return map;
        }
    }

    static final String SAMPLE = """
            public class BadSample {
                private static int total;

                public int calc(int a) {
                    try {
                        System.out.println("计算中");
                        Thread.sleep(100);
                    } catch (Exception e) {
                    }
                    if (a > 1000) {
                        total = a * 2;
                    }
                    // TODO 这里要改成配置
                    return total;
                }

                public int calc2(int a) {
                    try {
                        System.out.println("计算中");
                        Thread.sleep(100);
                    } catch (Exception e) {
                    }
                    if (a > 1000) {
                        total = a * 2;
                    }
                    return total;
                }
            }
            """;

    public static void main(String[] args) throws Exception {
        Path dir = Files.createTempDirectory("static-");
        Path file = dir.resolve("BadSample.java");
        Files.writeString(file, SAMPLE, StandardCharsets.UTF_8);

        try {
            System.out.println("=== 1. 扫描示例文件 ===");
            Analyzer analyzer = new Analyzer();
            analyzer.analyze(file);

            for (Finding f : analyzer.findings) {
                System.out.println("  " + f);
            }
            System.out.println("  共 " + analyzer.findings.size() + " 条发现");

            System.out.println();
            System.out.println("=== 2. 按规则汇总 ===");
            analyzer.perRule.entrySet().stream()
                    .sorted(Comparator.comparing(e -> e.getKey()))
                    .forEach(e -> System.out.printf("  %-14s %d 次%n", e.getKey(), e.getValue()));

            System.out.println();
            System.out.println("=== 3. 质量门禁判定 ===");
            long errors = analyzer.findings.stream()
                    .filter(f -> f.rule.severity == Severity.ERROR).count();
            long warns = analyzer.findings.stream()
                    .filter(f -> f.rule.severity == Severity.WARN).count();
            long infos = analyzer.findings.stream()
                    .filter(f -> f.rule.severity == Severity.INFO).count();
            System.out.printf("  ERROR=%d WARN=%d INFO=%d%n", errors, warns, infos);
            boolean gatePass = errors == 0;
            System.out.println("  门禁（ERROR 必须为 0）: " + (gatePass ? "PASS" : "BLOCKED"));
            if (!gatePass) {
                System.out.println("  阻断原因：存在空 catch 块，异常被吞掉，测试无法发现问题");
            }

            System.out.println();
            System.out.println("=== 4. 圈复杂度 ===");
            List<String> lines = Files.readAllLines(file, StandardCharsets.UTF_8);
            String whole = String.join("\n", lines);
            int cc = Analyzer.cyclomatic(whole);
            System.out.println("  整个文件圈复杂度 = " + cc);
            System.out.println("  单方法阈值参考：<=10 良好，11~15 需关注，>15 应拆分");

            System.out.println();
            System.out.println("=== 5. 重复代码检测（6 行窗口）===");
            Map<String, List<Integer>> dup = Analyzer.duplicateBlocks(lines);
            if (dup.isEmpty()) {
                System.out.println("  未发现重复块");
            } else {
                for (Map.Entry<String, List<Integer>> e : dup.entrySet()) {
                    System.out.println("  重复块出现在行 " + e.getValue()
                            + "，片段: " + e.getKey().substring(0, Math.min(60, e.getKey().length())) + "...");
                }
                System.out.println("  calc 与 calc2 的 try/catch 逻辑完全重复 -> 应抽成方法");
            }

            System.out.println();
            System.out.println("=== 6. 工具分工 ===");
            String[][] t = {
                    {"Checkstyle", "源码风格", "命名、缩进、行宽、import", "快，只管形"},
                    {"SpotBugs", "字节码缺陷", "NPE、equals/hashCode、资源泄漏", "能管实"},
                    {"PMD", "源码坏味道", "圈复杂度、重复代码、未用变量", "规则可自定义"},
                    {"ErrorProne", "编译期", "编译即报，接入零成本", "需改构建"},
                    {"SonarQube", "平台", "规则最全 + 质量门禁 + 趋势", "需部署"}
            };
            System.out.printf("  %-12s %-12s %-34s %s%n", "工具", "层次", "擅长", "特点");
            for (String[] r : t) {
                System.out.printf("  %-12s %-12s %-34s %s%n", r[0], r[1], r[2], r[3]);
            }

            System.out.println();
            System.out.println("=== 7. 渐进式落地建议 ===");
            String[] steps = {
                    "第 1 周：只开 ERROR 三条（空 catch、资源未关闭、equals/hashCode）",
                    "第 2 周：全绿后接入 CI，PR 时阻断",
                    "第 3 周：加 WARN（System.out、sleep、catch Exception）",
                    "第 4 周：加圈复杂度与重复率阈值，只对新增代码生效",
                    "持续：豁免必须写理由，每季度清理一次豁免清单"
            };
            for (String s : steps) {
                System.out.println("  - " + s);
            }
        } finally {
            try (Stream<Path> s = Files.walk(dir)) {
                for (Path p : s.sorted(Comparator.reverseOrder()).toList()) {
                    Files.deleteIfExists(p);
                }
            }
        }
    }
}
```

### 33-10 CI 流水线与质量门禁

**知识点**
- **CI（持续集成）** 的核心不是"自动构建"，而是"**每次提交都在 10 分钟内给出可信的通过/失败结论**"。慢的流水线等于没有流水线。
- 标准阶段：**检出 → 编译 → 静态检查 → 单元测试 → 集成测试 → 打包 → 制品归档 → 通知**。前面的阶段失败就立刻终止（fail fast），不要跑完所有阶段才发现编译不过。
- **质量门禁**是流水线里的硬闸门：编译 0 error、静态检查 0 ERROR、单测全绿、新增代码覆盖率 ≥ 阈值、无高危依赖漏洞。任一不满足即阻断合并。
- **流水线要可复现**：固定 JDK 版本、固定依赖版本（`pom.xml` 锁版本）、固定随机种子、隔离外部依赖。本地能过、CI 不能过，多半是环境或时序差异。
- **构建缓存**：依赖缓存（`~/.m2`）、编译缓存能显著缩短时间。但缓存 key 要包含依赖文件哈希，否则会用到过期缓存。
- **并行化**：测试按模块/包拆分并行跑；静态检查与单元测试可并行。注意并行时数据隔离（数据库、端口、临时目录）。
- **失败信息要可行动**：报告要给出"哪个文件哪一行、期望什么、实际什么、怎么复现"。只输出 `BUILD FAILED` 等于没给信息。
- **制品（artifact）**：构建产物带版本号与提交哈希，可追溯到具体 commit。不要用 `latest` 这种可变标签。
- **流水线的可观测性**：每阶段耗时、失败率、平均修复时间。发现"测试阶段从 2 分钟涨到 8 分钟"就该处理，别等它变成 30 分钟。
- 易错：CI 里跑 `mvn test` 但跳过失败（`-Dmaven.test.failure.ignore=true`）；测试依赖本地数据库；覆盖率阈值设在总覆盖率而不是新增代码（老代码拖累永远不达标）；流水线里 `sleep 30` 等部署。

```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class CiPipeline {
    enum Status {
        PASS, FAIL, SKIP
    }

    /** 阶段结果 */
    static class StageResult {
        final String name;
        final Status status;
        final long costMs;
        final String detail;

        StageResult(String name, Status status, long costMs, String detail) {
            this.name = name;
            this.status = status;
            this.costMs = costMs;
            this.detail = detail;
        }
    }

    /** 一个阶段 */
    interface Stage {
        StageResult run(Context ctx) throws Exception;
    }

    /** 流水线上下文：阶段间共享的"工作区" */
    static class Context {
        final Map<String, Object> data = new LinkedHashMap<>();
        final List<StageResult> results = new ArrayList<>();
        final List<String> artifacts = new ArrayList<>();
        boolean blocked;
        String blockReason;

        void block(String reason) {
            this.blocked = true;
            this.blockReason = reason;
        }
    }

    /** 质量门禁 */
    static class QualityGate {
        int minCoveragePercent = 70;
        int maxCyclomatic = 10;
        int maxStaticErrors = 0;
        boolean allowWarnings = true;

        String evaluate(Context ctx) {
            int errors = (int) ctx.data.getOrDefault("staticErrors", 0);
            int coverage = (int) ctx.data.getOrDefault("coverage", 0);
            int cc = (int) ctx.data.getOrDefault("maxCyclomatic", 0);
            int failedTests = (int) ctx.data.getOrDefault("failedTests", 0);

            List<String> reasons = new ArrayList<>();
            if (failedTests > 0) {
                reasons.add("单元测试失败 " + failedTests + " 个");
            }
            if (errors > maxStaticErrors) {
                reasons.add("静态检查 ERROR=" + errors + " 超过阈值 " + maxStaticErrors);
            }
            if (coverage < minCoveragePercent) {
                reasons.add("覆盖率 " + coverage + "% 低于阈值 " + minCoveragePercent + "%");
            }
            if (cc > maxCyclomatic) {
                reasons.add("最大圈复杂度 " + cc + " 超过阈值 " + maxCyclomatic);
            }
            return reasons.isEmpty() ? null : String.join("；", reasons);
        }
    }

    /** 流水线执行器 */
    static class Pipeline {
        final List<Stage> stages = new ArrayList<>();
        final QualityGate gate = new QualityGate();

        Pipeline add(Stage s) {
            stages.add(s);
            return this;
        }

        void run(String title) {
            System.out.println("=== " + title + " ===");
            Context ctx = new Context();
            long totalStart = System.nanoTime();
            for (Stage stage : stages) {
                String name = stage.getClass().getSimpleName();
                try {
                    StageResult r = stage.run(ctx);
                    ctx.results.add(r);
                    String mark = r.status == Status.PASS ? "PASS" : r.status == Status.FAIL ? "FAIL" : "SKIP";
                    System.out.printf("  [%-4s] %-22s %5d ms  %s%n",
                            mark, r.name, r.costMs, r.detail);
                    if (r.status == Status.FAIL) {
                        ctx.block("阶段 " + r.name + " 失败: " + r.detail);
                        break;
                    }
                } catch (Exception e) {
                    ctx.block("阶段异常: " + e.getMessage());
                    System.out.printf("  [FAIL] %-22s 异常 %s%n", name, e.getMessage());
                    break;
                }
            }
            long totalMs = (System.nanoTime() - totalStart) / 1_000_000;

            System.out.println();
            if (ctx.blocked) {
                System.out.println("  流水线结果: BLOCKED");
                System.out.println("  原因: " + ctx.blockReason);
            } else {
                String gateFail = gate.evaluate(ctx);
                if (gateFail != null) {
                    System.out.println("  流水线结果: BLOCKED（质量门禁）");
                    System.out.println("  原因: " + gateFail);
                } else {
                    System.out.println("  流水线结果: PASS");
                    System.out.println("  制品: " + ctx.artifacts);
                }
            }
            System.out.println("  总耗时: " + totalMs + " ms（真实流水线要求 10 分钟内）");
            System.out.println();
        }
    }

    /** ---------- 具体阶段 ---------- */
    static class CheckoutStage implements Stage {
        public StageResult run(Context ctx) {
            ctx.data.put("commit", "a1b2c3d");
            ctx.data.put("branch", "feature/order");
            return new StageResult("检出代码", Status.PASS, 120,
                    "commit=a1b2c3d branch=feature/order");
        }
    }

        public StageResult run(Context ctx) {

        }
    }

    static class StaticCheckStage implements Stage {
        private final int errors;
        private final int warns;

        StaticCheckStage(int errors, int warns) {
            this.errors = errors;
            this.warns = warns;
        }

        public StageResult run(Context ctx) {
            ctx.data.put("staticErrors", errors);

                    "ERROR=" + errors + " WARN=" + warns);
        }
    }

    static class UnitTestStage implements Stage {
        private final int total;
        private final int failed;
        private final int coverage;

        UnitTestStage(int total, int failed, int coverage) {
            this.total = total;
            this.failed = failed;
            this.coverage = coverage;
        }

        public StageResult run(Context ctx) {

            ctx.data.put("coverage", coverage);

    }

    static class PackageStage implements Stage {
        public StageResult run(Context ctx) {

    }

    static class NotifyStage implements Stage {
        public StageResult run(Context ctx) {
            return new StageResult("通知", Status.PASS, 50, "已推送结果到群聊");
        }
    }

    static Pipeline standardPipeline(boolean compileBroken, int staticErrors,
                                     int tests, int failed, int coverage) {
        return new Pipeline()
                .add(new CheckoutStage())
                .add(new CompileStage(compileBroken))
                .add(new StaticCheckStage(staticErrors, 3))

                .add(new PackageStage())
                .add(new NotifyStage());
    }

        System.out.println("=== 阶段耗时分布（优化依据）===");
```

3. 设计一条"只对新增代码生效"的覆盖率门禁规则，说明为什么它比"整体覆盖率"更容易落地。

### 33-11 综合案例：为订单模块搭建质量保障体系

**知识点**
- 质量保障体系由四层构成：**规范层**（编码规范、异常契约）、**测试层**（单元/集成/E2E 金字塔）、**门禁层**（静态检查 + 覆盖率 + CI 阻断）、**观测层**（线上监控、日志、告警）。缺一层就有盲区。
- 落地顺序：**先有测试，再有门禁**。没有测试就设覆盖率门禁，只会逼团队写假测试。
- 关键业务（资金、库存、权限）的保障标准要**高于**普通业务：分支覆盖 ≥ 90%、必须有并发测试、必须有对账/幂等验证。
- **回归清单**：每个线上 bug 修复后必须补一个能复现它的测试（回归测试），否则同类问题必然复发。
- **缺陷分析**：把线上 bug 按"哪个环节本该拦住"归类（单测漏了/集成漏了/门禁没设/规范没写），归因结果直接变成下一轮改进项。
- **质量度量**要少而准：缺陷逃逸率（线上 bug / 总 bug）、平均修复时间、CI 通过率、新增代码覆盖率。指标过多会失真。
- 综合案例的结构：领域模型 → 业务规则 → 测试金字塔（单测覆盖规则、集成覆盖协作、E2E 覆盖链路）→ 门禁判定 → 缺陷归因。
- 易错：只做单测不做集成（SQL 映射错误测不出）；只做 E2E 不做单测（失败无法定位）；门禁设了但没人看告警；线上 bug 修了不补测试。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class QualitySystemCase {
    /** ---------- 领域模型 ---------- */
    static class Money {
        final long cents;

        Money(long cents) {
            this.cents = cents;
        }

        Money plus(Money o) {
            return new Money(Math.addExact(cents, o.cents));
        }

        Money minus(Money o) {
            return new Money(cents - o.cents);
        }

        Money percent(int p) {
            return new Money(cents * p / 100);
        }

        boolean gte(Money o) {
            return cents >= o.cents;
        }

        @Override
        public String toString() {
            return String.format("%d.%02d", cents / 100, cents % 100);
        }
    }

    enum OrderStatus {
        CREATED, PAID, SHIPPED, CANCELLED
    }

    static class Order {
        final String no;
        final Money amount;
        final Money paid;
        OrderStatus status;

        Order(String no, Money amount) {
            this.no = no;
            this.amount = amount;
            this.paid = new Money(0);
            this.status = OrderStatus.CREATED;
        }
    }

    /** ---------- 业务规则（被测核心）---------- */
    static class OrderDomain {
        /** 支付：只有 CREATED 可支付，金额必须完全匹配 */
        void pay(Order o, Money paid) {
            if (o.status != OrderStatus.CREATED) {
                throw new IllegalStateException("状态不允许支付: " + o.status);
            }
            if (!paid.gte(o.amount)) {
                throw new IllegalArgumentException(
                        "支付金额不足，应付 " + o.amount + "，实付 " + paid);
            }
            if (paid.cents > o.amount.cents) {
                throw new IllegalArgumentException("支付金额超额，应付 " + o.amount + "，实付 " + paid);
            }
            o.status = OrderStatus.PAID;
        }

        /** 取消：PAID 需退款，已发货不可取消 */
        Money cancel(Order o) {
            if (o.status == OrderStatus.SHIPPED) {
                throw new IllegalStateException("已发货不可取消");
            }
            if (o.status == OrderStatus.CANCELLED) {
                throw new IllegalStateException("订单已取消");
            }
            Money refund = o.status == OrderStatus.PAID ? o.amount : new Money(0);
            o.status = OrderStatus.CANCELLED;
            return refund;
        }

        /** 发货：只有 PAID 可发货 */
        void ship(Order o) {
            if (o.status != OrderStatus.PAID) {
                throw new IllegalStateException("只有已支付订单可发货，当前 " + o.status);
            }
            o.status = OrderStatus.SHIPPED;
        }
    }

    /** ---------- 测试框架（极简）---------- */
    static int passed;
    static int failed;
    static final List<String> failureDetails = new ArrayList<>();
    static final Map<String, Integer> layerCount = new LinkedHashMap<>();

    static void caseOf(String layer, String name, Runnable body) {
        try {
            body.run();
            passed++;
            layerCount.merge(layer, 1, Integer::sum);
            System.out.printf("    [%-5s] %-48s OK%n", layer, name);
        } catch (Throwable t) {
            failed++;
            layerCount.merge(layer, 1, Integer::sum);
            String d = layer + " / " + name + " -> " + t.getMessage();
            failureDetails.add(d);
            System.out.printf("    [%-5s] %-48s FAIL: %s%n", layer, name, t.getMessage());
        }
    }

    static void eq(Object expected, Object actual) {
        if (!expected.equals(actual)) {
            throw new AssertionError("期望 " + expected + "，实际 " + actual);
        }
    }

    static void throwsEx(Class<? extends Throwable> type, Runnable body) {
        try {
            body.run();
        } catch (Throwable t) {
            if (type.isInstance(t)) {
                return;
            }
            throw new AssertionError("期望 " + type.getSimpleName() + "，实际 " + t.getClass().getSimpleName());
        }
        throw new AssertionError("期望抛 " + type.getSimpleName() + "，但没抛");
    }

    /** ---------- 覆盖统计（模拟探针）---------- */
    static class Coverage {
        static final Map<String, Boolean> BRANCHES = new LinkedHashMap<>();

        static void mark(String b) {
            BRANCHES.put(b, true);
        }

        static void declare(String b) {
            BRANCHES.putIfAbsent(b, false);
        }

        static int percent() {
            long hit = BRANCHES.values().stream().filter(Boolean::booleanValue).count();
            return BRANCHES.isEmpty() ? 100 : (int) (hit * 100 / BRANCHES.size());
        }

        static List<String> missed() {
            List<String> list = new ArrayList<>();
            BRANCHES.forEach((k, v) -> {
                if (!v) {
                    list.add(k);
                }
            });
            return list;
        }
    }

    public static void main(String[] args) {
        OrderDomain domain = new OrderDomain();
        Coverage.declare("pay:CREATED");
        Coverage.declare("pay:非CREATED");
        Coverage.declare("pay:金额不足");
        Coverage.declare("pay:金额超额");
        Coverage.declare("cancel:SHIPPED");
        Coverage.declare("cancel:已取消");
        Coverage.declare("cancel:PAID退款");
        Coverage.declare("cancel:CREATED无退款");
        Coverage.declare("ship:PAID");
        Coverage.declare("ship:非PAID");

        System.out.println("=== 第一层：单元测试（业务规则）===");

        caseOf("UNIT", "CREATED 全额支付成功", () -> {
            Order o = new Order("O1", new Money(9_900));
            domain.pay(o, new Money(9_900));
            Coverage.mark("pay:CREATED");
            eq(OrderStatus.PAID, o.status);
        });

        caseOf("UNIT", "已支付订单再支付抛 IllegalState", () -> {
            Order o = new Order("O2", new Money(100));
            domain.pay(o, new Money(100));
            Coverage.mark("pay:CREATED");
            throwsEx(IllegalStateException.class, () -> domain.pay(o, new Money(100)));
            Coverage.mark("pay:非CREATED");
        });

        caseOf("UNIT", "支付金额不足抛 IllegalArgument", () -> {
            Order o = new Order("O3", new Money(10_000));
            throwsEx(IllegalArgumentException.class, () -> domain.pay(o, new Money(9_999)));
            Coverage.mark("pay:金额不足");
            eq(OrderStatus.CREATED, o.status);
        });

        caseOf("UNIT", "支付金额超额抛 IllegalArgument", () -> {
            Order o = new Order("O4", new Money(10_000));
            throwsEx(IllegalArgumentException.class, () -> domain.pay(o, new Money(10_001)));
            Coverage.mark("pay:金额超额");
            eq(OrderStatus.CREATED, o.status);
        });

        caseOf("UNIT", "已发货订单不可取消", () -> {
            Order o = new Order("O5", new Money(500));
            domain.pay(o, new Money(500));
            Coverage.mark("pay:CREATED");
            domain.ship(o);
            Coverage.mark("ship:PAID");
            throwsEx(IllegalStateException.class, () -> domain.cancel(o));
            Coverage.mark("cancel:SHIPPED");
        });

        caseOf("UNIT", "重复取消抛 IllegalState", () -> {
            Order o = new Order("O6", new Money(500));
            domain.cancel(o);
            Coverage.mark("cancel:CREATED无退款");
            throwsEx(IllegalStateException.class, () -> domain.cancel(o));
            Coverage.mark("cancel:已取消");
        });

        caseOf("UNIT", "已支付订单取消返回全额退款", () -> {
            Order o = new Order("O7", new Money(12_345));
            domain.pay(o, new Money(12_345));
            Coverage.mark("pay:CREATED");
            Money refund = domain.cancel(o);
            Coverage.mark("cancel:PAID退款");
            eq(12_345L, refund.cents);
            eq(OrderStatus.CANCELLED, o.status);
        });

        caseOf("UNIT", "未支付订单取消不退款", () -> {
            Order o = new Order("O8", new Money(777));
            Money refund = domain.cancel(o);
            Coverage.mark("cancel:CREATED无退款");
            eq(0L, refund.cents);
        });

        caseOf("UNIT", "未支付订单不可发货", () -> {
            Order o = new Order("O9", new Money(100));
            throwsEx(IllegalStateException.class, () -> domain.ship(o));
            Coverage.mark("ship:非PAID");
        });

        caseOf("UNIT", "Money.plus 溢出抛 ArithmeticException", () -> {
            throwsEx(ArithmeticException.class,
                    () -> new Money(Long.MAX_VALUE).plus(new Money(1)));
        });

        System.out.println();
        System.out.println("=== 第二层：集成测试（状态机全链路）===");

        caseOf("INTEG", "下单->支付->发货 状态链完整", () -> {
            Order o = new Order("I1", new Money(5_000));
            domain.pay(o, new Money(5_000));
            Coverage.mark("pay:CREATED");
            domain.ship(o);
            Coverage.mark("ship:PAID");
            eq(OrderStatus.SHIPPED, o.status);
            throwsEx(IllegalStateException.class, () -> domain.cancel(o));
            Coverage.mark("cancel:SHIPPED");
        });

        caseOf("INTEG", "下单->取消->再支付 被拒", () -> {
            Order o = new Order("I2", new Money(5_000));
            domain.cancel(o);
            Coverage.mark("cancel:CREATED无退款");
            throwsEx(IllegalStateException.class, () -> domain.pay(o, new Money(5_000)));
            Coverage.mark("pay:非CREATED");
        });

        System.out.println();
        System.out.println("=== 第三层：端到端（模拟接口契约）===");
        caseOf("E2E", "接口契约：支付成功返回 200 + PAID", () -> {
            Order o = new Order("E1", new Money(3_000));
            String resp = apiPay(domain, o, 3_000);
            Coverage.mark("pay:CREATED");
            eq("200|PAID", resp);
        });
        caseOf("E2E", "接口契约：金额不符返回 400", () -> {
            Order o = new Order("E2", new Money(3_000));
            String resp = apiPay(domain, o, 2_999);
            Coverage.mark("pay:金额不足");
            eq("400|支付金额不足", resp);
        });
        caseOf("E2E", "接口契约：状态错误返回 409", () -> {
            Order o = new Order("E3", new Money(3_000));
            domain.cancel(o);
            Coverage.mark("cancel:CREATED无退款");
            String resp = apiPay(domain, o, 3_000);
            Coverage.mark("pay:非CREATED");
            eq("409|状态不允许支付", resp);
        });

        System.out.println();
        System.out.println("=== 质量报告 ===");
        System.out.println("  用例总数: " + (passed + failed));
        System.out.println("  通过: " + passed + "  失败: " + failed);
        System.out.println("  分层分布: " + layerCount);
        System.out.printf("  分支覆盖率: %d%%（%d 条分支，未覆盖 %s）%n",
                Coverage.percent(), Coverage.BRANCHES.size(), Coverage.missed());
        for (String d : failureDetails) {
            System.out.println("    失败: " + d);
        }

        System.out.println();
        System.out.println("=== 质量门禁判定 ===");
        List<String> gates = new ArrayList<>();
        if (failed > 0) {
            gates.add("单元/集成/E2E 存在失败用例");
        }
        if (Coverage.percent() < 90) {
            gates.add("分支覆盖率 " + Coverage.percent() + "% < 90%（资金链路要求）");
        }
        if (!Coverage.missed().isEmpty()) {
            gates.add("存在未覆盖分支: " + Coverage.missed());
        }
        if (gates.isEmpty()) {
            System.out.println("  结果: PASS（可合并）");
        } else {
            System.out.println("  结果: BLOCKED");
            for (String g : gates) {
                System.out.println("    - " + g);
            }
        }

        System.out.println();
        System.out.println("=== 缺陷归因表（把线上 bug 变成改进项）===");
        String[][] attribution = {

            return "200|PAID";
```
