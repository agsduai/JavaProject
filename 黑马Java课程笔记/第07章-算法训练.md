### 7-01 删除数据

**知识点**
- 题意：把数组中指定索引（或指定值）的元素"去掉"，其余元素保持相对顺序
- 核心思路：数组没有真正的"删除"，所谓删除就是让后面的元素整体前移一位，把要删的位置覆盖掉
- 数组长度不可变，用"有效长度 count"变量控制实际参与读写的元素个数
- 删除后末尾空出来的位置补 0（或干脆不再打印它）
- 按值删除 = 先查找该值的索引（找不到给出提示），再按索引删除
- 复杂度感受：查找 O(n) + 前移 O(n)，删除一个元素的时间复杂度是 O(n)；批量删除时倒序遍历可避免前移导致的漏删

**示例代码**
```java
public class DeleteDemo {
    public static void main(String[] args) {
        int[] arr = {11, 22, 33, 44, 55};
        int count = 5; // 有效元素个数（数组长度不变，用 count 控制）

        // 一、按索引删除：删掉索引 1 上的 22，后面元素整体前移覆盖
        for (int i = 1; i < count - 1; i++) {
            arr[i] = arr[i + 1];
        }
        count--;        // 有效长度减一
        arr[count] = 0; // 末尾空位补 0
        printArr(arr, count); // 输出：11 33 44 55

        // 二、按值删除：先找到 44 的索引，再前移覆盖
        int index = -1;
        for (int i = 0; i < count; i++) {
            if (arr[i] == 44) {
                index = i;
                break;
            }
        }
        if (index == -1) {
            System.out.println("没有找到要删除的值");
        } else {
            for (int i = index; i < count - 1; i++) {
                arr[i] = arr[i + 1];
            }
            count--;
            arr[count] = 0;
        }
        printArr(arr, count); // 输出：11 33 55
    }

    // 只打印前 count 个有效元素
    public static void printArr(int[] arr, int count) {
        for (int i = 0; i < count; i++) {
            System.out.print(arr[i] + " ");
        }
        System.out.println();
    }
}
```

**课后练习**
1. 编写方法 `deleteByIndex(int[] arr, int count, int index)`：删除数组中指定索引的元素并返回新的有效长度，索引非法时返回 -1。测试数据 `{10, 20, 30, 40}`，分别删除索引 0、索引 3、索引 9，打印每次的结果。
2. 编写方法 `deleteAll(int[] arr, int value)`：删除数组中所有等于 value 的元素，返回新的有效长度。例如 `{1, 2, 3, 2, 4, 2}` 删除 2 后应输出 `1 3 4`、长度为 3。
3. 进阶：如果不要求保持元素相对顺序，能否用"末尾元素覆盖被删位置"的方式把单次删除做到 O(1)？写出这种思路的实现并说明它会带来什么副作用。

### 7-02 红包问题

**知识点**
- 题意：模拟微信手气红包——把固定总金额随机分给 n 个人，抢到多少全凭运气
- 核心思路：二倍均值法——每次在 [0.01, 剩余金额 ÷ 剩余人数 × 2) 的范围内随机
- 数学保证：每次最多抢走剩余均值的两倍，因此后面的人永远有得抢，且每人至少 0.01 元
- 最后一个人直接拿走剩余全部金额，保证总额不多不少、也不会出现负数
- 工程细节：金额全程用"分"做整数运算，输出时再 ÷100 换算成元，规避浮点数精度误差
- 复杂度感受：时间 O(n)、空间 O(n)；每一次分配都是常数时间操作

**示例代码**
```java
import java.util.ArrayList;
import java.util.Random;

public class RedPacket {
    public static void main(String[] args) {
        int total = 10000; // 总金额，单位：分（100 元）
        int size = 3;      // 抢红包的人数
        ArrayList<Integer> packets = new ArrayList<>();
        Random r = new Random();

        // 前面 size-1 人每人随机抢一次（二倍均值法）
        for (int i = 0; i < size - 1; i++) {
            int remainPeople = size - i;          // 还没抢的人数
            int bound = total / remainPeople * 2; // 随机上限 = 剩余金额 ÷ 剩余人数 × 2
            int money = r.nextInt(bound - 1) + 1; // 至少抢到 1 分（0.01 元）
            packets.add(money);
            total -= money; // 抢走的部分从总额中扣除
        }
        // 最后一个人拿走剩余全部，总额不变
        packets.add(total);

        System.out.println("手气红包分配结果（单位：元）：");
        for (int i = 0; i < packets.size(); i++) {
            System.out.println("第" + (i + 1) + "个人抢到：" + packets.get(i) / 100.0);
        }
        // 输出示例（每次运行随机）：
        // 第1个人抢到：45.32
        // 第2个人抢到：37.86
        // 第3个人抢到：16.82
    }
}
```

**课后练习**
1. 修改算法：总金额 20 元、5 个人抢，要求每人至少抢到 1 元，写出新的随机范围并实现。
2. 在分配完成后，找出"手气最佳"的人（金额最大者），输出他的序号和金额，例如"手气最佳：第2个人，抢到 51.30 元"。
3. 模拟 10000 次"3 人抢 100 元"，统计每个人抢到的平均值，验证二倍均值法是否公平（理论上每人期望都约为 33.33 元）。

### 7-03 二路归并找中位数

**知识点**
- 题意：给定两个各自有序的数组，求合并成一个有序数组后的中位数（LeetCode 4 的入门实现）
- 中位数：元素个数为奇数时取正中间那个；为偶数时取中间两个数的平均值
- 核心思路：双指针归并——两个指针分别指向两数组头部，每次比较，较小者进入结果数组并后移
- 某个数组走完后，另一个数组剩余部分整体接到结果末尾
- 进阶方向：其实不用真的合并完，只归并到中位数位置就可以提前返回
- 复杂度感受：时间 O(m+n)、空间 O(m+n)；易错点是偶数个元素求平均要除以 2.0，整数除法会丢失小数

**示例代码**
```java
public class MergeMedian {
    public static void main(String[] args) {
        int[] a = {1, 3, 5, 7};
        int[] b = {2, 4, 6, 8, 10};
        System.out.println("中位数是：" + findMedian(a, b));
        // 输出：中位数是：5.0（合并后为 1,2,3,4,5,6,7,8,10，共 9 个，取第 5 个）

        int[] c = {1, 3};
        int[] d = {2, 4};
        System.out.println("中位数是：" + findMedian(c, d));
        // 输出：中位数是：2.5（合并后为 1,2,3,4，取中间两数的平均）
    }

    // 双指针归并两个有序数组，再取中位数
    public static double findMedian(int[] a, int[] b) {
        int[] merged = new int[a.length + b.length];
        int i = 0, j = 0, k = 0;

        // 两个数组都没走完时：谁的首元素小，谁先进入结果
        while (i < a.length && j < b.length) {
            merged[k++] = a[i] <= b[j] ? a[i++] : b[j++];
        }
        // 把没走完的数组剩余部分直接接上
        while (i < a.length) merged[k++] = a[i++];
        while (j < b.length) merged[k++] = b[j++];

        int mid = merged.length / 2;
        if (merged.length % 2 == 1) {
            return merged[mid]; // 奇数个：正中间那个
        }
        return (merged[mid - 1] + merged[mid]) / 2.0; // 偶数个：除以 2.0 保留小数
    }
}
```

**课后练习**
1. 编写方法 `merge(int[] a, int[] b)`：把两个有序数组合并为一个有序数组并返回（对应 LeetCode 88 合并两个有序数组的思路），测试数据 `{1,4,7}` 与 `{2,3,9}`，输出 `[1, 2, 3, 4, 7, 9]`。
2. 改进原代码：不创建完整的结果数组，只在双指针归并过程中走到中位数位置就停止并返回中位数，把额外空间降到 O(1)（注意偶数长度时需要多走一步）。
3. 进阶：给定两个有序数组，求它们合并后第 k 小的数（k 由参数传入），先写出 O(m+n) 的解法，再思考能否只走 k 步完成。

### 7-04 多数据统计

**知识点**
- 题意：对一组数据求总和、平均值、最大值、最小值，以及满足某个条件的元素个数
- 通用套路：一趟遍历 + 若干临时变量（sum、max、min、count），遍历中同步更新
- max、min 的初值取数组第一个元素，不要写 0——数据全是负数时用 0 会得到错误答案
- 平均值 = 总和 ÷ 个数，注意先把其中一个转成 double，否则整数除法会丢小数
- 条件统计：满足条件时 count++，如统计及格人数、高于平均分的人数
- 复杂度感受：一趟循环全部算完，时间 O(n)、空间 O(1)，是数组题最基础的"遍历 + 临时变量"模型

**示例代码**
```java
public class DataStatistics {
    public static void main(String[] args) {
        int[] scores = {88, 45, 92, 67, 59, 73};

        int sum = 0;              // 总和
        int max = scores[0];      // 最大值：初值取第一个元素
        int min = scores[0];      // 最小值：同上，别用 0
        int passCount = 0;        // 及格（>=60）人数

        for (int i = 0; i < scores.length; i++) {
            sum += scores[i];                       // 累加求和
            if (scores[i] > max) max = scores[i];   // 打擂台更新最大值
            if (scores[i] < min) min = scores[i];   // 打擂台更新最小值
            if (scores[i] >= 60) passCount++;       // 条件统计
        }

        System.out.println("总分：" + sum);                       // 424
        System.out.println("平均分：" + (double) sum / scores.length); // 70.666...
        System.out.println("最高分：" + max);                     // 92
        System.out.println("最低分：" + min);                     // 45
        System.out.println("及格人数：" + passCount);             // 4
    }
}
```

**课后练习**
1. 在示例基础上增加两个统计：及格率（百分比保留两位小数）以及最高分所在的位置（索引），测试数据不变，输出"及格率：66.67%、最高分位置：索引 2"。
2. 从键盘循环录入一批整数（输入 0 表示结束，0 不参与统计），在不使用数组的前提下求出最大值、最小值和平均值，体会"边录入边统计"的写法。
3. 进阶：找出一组数据中的众数（出现次数最多的值）及其出现次数；若众数有多个，输出最小的那个。测试数据 `{3, 1, 2, 2, 3, 3}` 应输出众数 3、出现 3 次。

### 7-05 接雨水

**知识点**
- 题意：LeetCode 42——给定柱子高度数组，问这个柱状图最多能接多少单位的雨水
- 关键结论：每个位置能接的水 = min(它左边最高的柱子, 它右边最高的柱子) − 它自己的高度
- 前缀最大值：从左往右扫一遍得到 `leftMax[i]`（含自身），从右往左扫一遍得到 `rightMax[i]`（含自身）
- 最后按位置累加每个位置的存水量，柱子本身不存水，所以结果可能为 0，不会出现负数
- 直观理解：水位由两侧较矮的那一侧决定——木桶效应，短板决定盛水
- 复杂度感受：三次遍历，时间 O(n)、空间 O(n)；用双指针从两端收缩可以优化到 O(1) 空间

**示例代码**
```java
public class RainWater {
    public static void main(String[] args) {
        int[] height = {4, 2, 0, 3, 2, 5};
        System.out.println("能接住的雨水总量：" + trap(height));
        // 输出：能接住的雨水总量：9

        /*
         * 各位置的接水量（min(左最大,右最大) - 自身）：
         * 高度  : 4  2  0  3  2  5
         * 左最大: 4  4  4  4  4  5
         * 右最大: 5  5  5  5  5  5
         * 存水  : 0  2  4  1  2  0   合计 = 9
         */
    }

    // 按位置计算每个格子能存多少水，再累加
    public static int trap(int[] height) {
        int n = height.length;
        int[] leftMax = new int[n];  // leftMax[i]：i 及其左侧最高的柱子
        int[] rightMax = new int[n]; // rightMax[i]：i 及其右侧最高的柱子

        leftMax[0] = height[0];
        for (int i = 1; i < n; i++) {
            leftMax[i] = Math.max(leftMax[i - 1], height[i]); // 从左往右推
        }
        rightMax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            rightMax[i] = Math.max(rightMax[i + 1], height[i]); // 从右往左推
        }

        int water = 0;
        for (int i = 0; i < n; i++) {
            // 水位由两侧较矮的一侧决定，减去自身高度就是这一格的存水
            water += Math.min(leftMax[i], rightMax[i]) - height[i];
        }
        return water;
    }
}
```

**课后练习**
1. 编写程序对 `{0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1}` 求接雨水总量（答案应为 6），并打印每个位置的存水量数组，检验你是否真的理解了计算过程。
2. 用双指针（左右两个指针从两端向中间收缩，配合左侧最大值、右侧最大值两个变量）重写本题，要求额外空间复杂度 O(1)、时间复杂度 O(n)，并用练习 1 的数据验证结果一致。
3. 进阶（LeetCode 11 盛最多水的容器）：把"接雨水"换成"两条竖线与底边围成的容器"，容量 = min(左线高度, 右线高度) × 两线距离，求最大容量，尝试用双指针一次遍历解决。

### 7-06 大乐透

**知识点**
- 题意：模拟超级大乐透机选号码：前区从 1~35 随机 5 个不重复号码，后区从 1~12 随机 2 个不重复号码
- 核心思路：随机生成一个号码后，先检查它在前面是否已经出现过，重复就重新生成（do-while 循环直到取满）
- 判重逻辑封装成独立方法，传入"数组 + 已生成个数 + 新号码"，返回 boolean
- 号码全部生成后用 `Arrays.sort` 排序，按"前区 + 后区"的格式输出
- 进阶思路：把 1~35 放入集合后 `Collections.shuffle` 洗牌，取前 5 个同样能保证不重复
- 复杂度感受：O(n × k)（k 为号码个数），数据量极小可忽略；易错点是 `nextInt(35)` 生成的是 0~34，必须 +1 才是 1~35

**示例代码**
```java
import java.util.Arrays;
import java.util.Random;

public class SuperLotto {
    public static void main(String[] args) {
        int[] front = new int[5]; // 前区：35 选 5
        int[] back = new int[2];  // 后区：12 选 2
        Random r = new Random();

        // 前区随机取 5 个不重复号码（1~35）
        for (int i = 0; i < front.length; i++) {
            int num;
            do {
                num = r.nextInt(35) + 1; // nextInt(35) 是 0~34，+1 才是 1~35
            } while (isExist(front, i, num)); // 与已生成号码重复就重取
            front[i] = num;
        }
        // 后区随机取 2 个不重复号码（1~12）
        for (int i = 0; i < back.length; i++) {
            int num;
            do {
                num = r.nextInt(12) + 1;
            } while (isExist(back, i, num));
            back[i] = num;
        }

        Arrays.sort(front); // 号码从小到大输出
        Arrays.sort(back);
        System.out.println("前区号码：" + Arrays.toString(front));
        System.out.println("后区号码：" + Arrays.toString(back));
        // 输出示例（每次运行随机）：
        // 前区号码：[3, 11, 17, 25, 34]
        // 后区号码：[5, 9]
    }

    // 判断 num 是否已出现在 arr 的前 count 个元素中
    public static boolean isExist(int[] arr, int count, int num) {
        for (int i = 0; i < count; i++) {
            if (arr[i] == num) {
                return true;
            }
        }
        return false;
    }
}
```

**课后练习**
1. 把取号逻辑改写成方法 `pickNumbers(int max, int count)`：返回一个长度为 count 的数组，内容是从 1~max 中随机取出的不重复号码，用 `pickNumbers(35, 5)` 和 `pickNumbers(12, 2)` 完成大乐透机选。
2. 编写双色球机选程序：红球 33 选 6 个不重复号码、蓝球 16 选 1 个号码，按"红球：… 蓝球：…"格式输出。
3. 进阶：让用户自选一注号码（或硬编码一注），与机选号码比对，输出中了几个前区号码、几个后区号码，并按对照表给出中奖等级；再模拟机选 100 万次，统计"前区 5 个全中"出现的次数，体会一等奖概率有多低。
