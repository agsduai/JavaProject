# 第3章 判断与循环

本章掌握 Java 的流程控制：先用 if 与 switch 学会"判断和选择"，再用 for、while、do-while 以及嵌套循环实现重复执行，并通过游戏血条、水仙花数、猜数字、打印图形等大量练习打下算法思维基础。

## 判断（3-01 ~ 3-05）

### 3-01 if的第一种格式

**知识点**
- 格式：`if (关系表达式) { 语句体; }`
- 执行流程：先计算关系表达式，结果为 true 执行大括号中的语句体，结果为 false 直接跳过整个 if
- 关系表达式的结果必须是 boolean 类型（true / false），不能像 C 语言那样用数字代替
- 条件常用比较运算符（`>`、`<`、`>=`、`==`）和逻辑运算符（`&&`、`||`）组合
- 大括号里的代码就是 if 的控制范围，即使只有一句代码也建议写上大括号
- if 不成立时程序会继续往下执行 if 之后的代码

**示例代码**
```java
public class IfDemo01 {
    public static void main(String[] args) {
        int money = 5200;
        // 如果余额大于 5000，就买新手机
        if (money > 5000) {
            System.out.println("余额充足，入手新手机");
        }

        int score = 95;
        // 条件不成立时，大括号里的代码不会执行
        if (score == 100) {
            System.out.println("满分，奖励夏令营");
        }
        System.out.println("程序结束");
    }
}
```

**课后练习**
1. 定义一个整数变量 age 表示年龄，当 age 大于等于 18 时，打印"已成年，可以进入网吧"。
2. 定义两个整数变量 a 和 b，当 a 大于 b 时，打印"a 更大"。
3. 键盘录入一个整数，如果是偶数就打印"偶数"，否则不打印任何内容。例如输入 8 输出：偶数；输入 9 时无任何输出。

### 3-02 练习：游戏血条计算

**知识点**
- 练习1：游戏角色当前血量 100，本回合受到 45 点伤害，计算剩余血量，若小于等于 0 输出"角色阵亡"，否则输出当前血量
- 练习2：键盘录入当前血量，低于等于总血量 100 的 30% 时输出"血量危险"，否则输出"状态良好"
- 游戏数值的本质就是变量运算：扣血写作 `blood = blood - hurt`
- if 只在条件成立时执行，所以"阵亡"和"存活"两种情况要写成两个互补的 if
- 比较"是否阵亡"用 `blood <= 0`，注意临界值 0 也要算进去

**示例代码**
```java
public class GameBloodDemo {
    public static void main(String[] args) {
        // 角色初始血量
        int blood = 100;
        // 本回合受到的伤害
        int hurt = 45;
        System.out.println("受到 " + hurt + " 点伤害");
        // 扣血：剩余血量 = 原血量 - 伤害
        blood = blood - hurt;
        // 判断角色是否阵亡
        if (blood <= 0) {
            System.out.println("角色阵亡");
        }
        // 没有阵亡时打印当前状态
        if (blood > 0) {
            System.out.println("角色存活，当前血量为 " + blood);
        }
    }
}
```

**课后练习**
1. 键盘录入当前血量（总血量 100），小于等于 30 时输出"血量危险，请及时治疗"，否则输出"状态良好"。例如输入 25 输出：血量危险，请及时治疗。
2. 角色初始血量 100，连续受到两波伤害（用变量 hurt1、hurt2 表示），每波伤害后都判断一次角色是否阵亡，未阵亡则打印当前血量。
3. 变形：键盘录入受到的伤害值（初始血量 100），扣血后血量小于等于 0 输出"阵亡"，1~30 输出"残血，快撤退"，31~70 输出"受伤"，大于 70 输出"血量健康"。

### 3-03 if语句的细节

**知识点**
- 大括号可以省略：不写大括号时 if 只控制紧跟它的第一条语句，建议永远写大括号
- 分号陷阱：`if (条件);` 多写一个分号会把 if 变成空语句，后面的大括号无条件执行，是最常见的坑
- 作用域：在大括号里定义的变量，出了大括号就不能再使用
- 条件表达式必须是 boolean 类型，`if (1)` 这种写法编译不通过
- 代码缩进只是给人看的，实际执行范围完全由大括号决定

**示例代码**
```java
public class IfDetailDemo {
    public static void main(String[] args) {
        int score = 60;
        // 细节1：不加大括号时，if 只控制紧跟的一条语句
        if (score >= 60)
            System.out.println("及格了");

        // 细节2：if 后面多写了一个分号，大括号里的内容无条件执行
        int money = 10;
        if (money > 100); {
            System.out.println("我是百万富翁");
        }

        // 细节3：大括号内定义的变量，出了大括号就失效
        if (money > 0) {
            int temp = money * 2;
            System.out.println("翻倍后：" + temp);
        }
        // System.out.println(temp); // 编译报错，temp 已超出作用域
    }
}
```

**课后练习**
1. 阅读程序写结果：`int x = 5; if (x > 3); System.out.println("A");` 请写出输出内容，并说明原因。
2. 定义一个 double 变量 temp 表示体温，体温大于等于 37.3 时打印"体温异常"，其他情况不打印任何内容，要求规范使用大括号。
3. 改错：下面代码的本意是体温超过 37.3 才打印"体温异常"，但实际运行时无论体温多少都会打印，请找出错误并改正：`double t = 36.8; if (t > 37.3); { System.out.println("体温异常"); }`

### 3-04 if的第二种格式和练习（if-else）

**知识点**
- 格式：`if (条件) { 语句体1 } else { 语句体2 }`
- 执行流程：条件为 true 执行语句体1，为 false 执行语句体2，两条路径必走其一、只走其一
- 与两个独立 if 的区别：两个 if 都要判断一次，if-else 只判断一次且结果互斥，效率更高
- 适用场景：结果只有两种对立情况的问题，如奇偶、及格与否、成年与否
- 判断奇偶的通用思路：`num % 2 == 0` 为偶数

**示例代码**
```java
import java.util.Scanner;

public class IfElseDemo {
    public static void main(String[] args) {
        // 键盘录入一个整数，判断奇偶
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入一个整数：");
        int num = sc.nextInt();
        // 能被 2 整除是偶数，否则是奇数
        if (num % 2 == 0) {
            System.out.println(num + " 是偶数");
        } else {
            System.out.println(num + " 是奇数");
        }
    }
}
```

**课后练习**
1. 键盘录入一个整数表示年龄，大于等于 18 打印"成年人"，否则打印"未成年人"。
2. 键盘录入一个整数表示分数，大于等于 60 打印"及格"，否则打印"不及格"。
3. 键盘录入一个整数作为密码，等于 123456 时打印"登录成功"，否则打印"登录失败，密码错误"。

### 3-05 if的第三种格式和多个经典案例

**知识点**
- 练习1（成绩等级）：键盘录入 0~100 的分数，90~100 输出"优秀"，80~89 输出"良好"，70~79 输出"中等"，60~69 输出"及格"，60 以下输出"不及格"
- 练习2（求最大值）：键盘录入三个整数，输出其中最大的一个
- 练习3（会员折扣）：键盘录入消费金额和会员等级（1 金卡、2 银卡、3 普通），分别按 8 折、9 折、原价结算并输出应付金额
- 格式：`if (条件1) {...} else if (条件2) {...} ... else {...}`
- 执行流程：自上而下逐个判断条件，命中某个分支就执行并跳过整个结构，全不满足走 else
- 区间判断要写清边界（如 `score >= 80 && score < 90`），避免条件重叠或遗漏；else if 可以写多个，最后的 else 可以省略

**示例代码**
```java
import java.util.Scanner;

public class ScoreLevelDemo {
    public static void main(String[] args) {
        // 键盘录入成绩，输出对应等级
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入成绩（0~100）：");
        int score = sc.nextInt();
        // 自上而下判断，命中一个分支后整个结构结束
        if (score >= 90 && score <= 100) {
            System.out.println("优秀");
        } else if (score >= 80 && score < 90) {
            System.out.println("良好");
        } else if (score >= 70 && score < 80) {
            System.out.println("中等");
        } else if (score >= 60 && score < 70) {
            System.out.println("及格");
        } else {
            System.out.println("不及格");
        }
    }
}
```

**课后练习**
1. 求最大值：键盘录入三个整数，打印其中最大的一个。例如输入 12、45、23，输出 45。
2. 会员折扣：键盘录入消费金额和会员等级（1 金卡、2 银卡、3 普通），金卡打 8 折、银卡打 9 折、普通不打折，打印应付金额。例如输入 100 和 1，输出 80.0。
3. 变形：键盘录入月份（1~12），输出对应季节：3~5 春季、6~8 夏季、9~11 秋季、12 和 1 和 2 冬季，超出范围提示"输入有误"。

## 选择（3-06 ~ 3-07）

### 3-06 switch语句

**知识点**
- 格式：`switch (表达式) { case 值1: 语句体1; break; ... default: 语句体n; break; }`
- 执行流程：拿表达式的值依次与各 case 匹配，命中后执行对应语句体，遇到 break 结束整个 switch
- 所有 case 都不匹配时执行 default（兜底分支）
- 表达式支持的类型：byte、short、char、int 及其包装类、枚举、String（JDK17）
- case 后面只能写字面量或常量，不能写变量；各 case 的值不能重复
- switch 适合"一个值对应固定几种结果"的场景，比多分支 if 更清晰

**示例代码**
```java
import java.util.Scanner;

public class SwitchDemo {
    public static void main(String[] args) {
        // 键盘录入星期几，输出当天安排
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入今天星期几（1~7）：");
        int week = sc.nextInt();
        switch (week) {
            case 1:
                System.out.println("周一：开始上课");
                break;
            case 2:
                System.out.println("周二：写练习题");
                break;
            case 3:
                System.out.println("周三：阶段性测试");
                break;
            case 4:
                System.out.println("周四：错题复盘");
                break;
            case 5:
                System.out.println("周五：项目实战");
                break;
            default:
                System.out.println("周末：好好休息");
                break;
        }
    }
}
```

**课后练习**
1. 键盘录入 1~7 输出对应的星期名称（星期一 ~ 星期日），超出范围的数字输出"输入有误"。
2. 键盘录入手机按键编号 1~3：1 打印"打开相册"，2 打印"打开相机"，3 打印"打开通讯录"，其他编号打印"按键无效"。
3. 键盘录入会员积分档位：100 输出"青铜会员"，200 输出"白银会员"，300 输出"黄金会员"，其他数值输出"普通用户"。

### 3-07 switch的其他知识点

**知识点**
- default 的位置灵活，可以写在最前或中间；省略 break 时它会继续往下执行，一般建议放最后并写上 break
- case 穿透：case 中不写 break 时，执行完本 case 会继续执行下一个 case 的语句体，直到遇到 break 或 switch 结束
- 穿透的妙用：把结果相同的多个 case 连续书写并共用一个语句体，可以简化代码
- JDK12 新特性：箭头表达式 `case 值 -> 语句体`，不用写 break、不会穿透，还支持多值匹配 `case 1, 2, 3 ->`
- switch 不支持 long、float、double、boolean 类型

**示例代码**
```java
import java.util.Scanner;

public class SwitchDemo2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入星期几（1~7）：");
        int week = sc.nextInt();
        // 利用 case 穿透把工作日的多个值合并到同一个出口
        switch (week) {
            case 1:
            case 2:
            case 3:
            case 4:
            case 5:
                System.out.println("工作日");
                break;
            case 6:
            case 7:
                System.out.println("休息日");
                break;
            default:
                System.out.println("输入有误");
                break;
        }
        // JDK12+ 箭头表达式：不用写 break，也不会穿透
        switch (week) {
            case 1, 2, 3, 4, 5 -> System.out.println("上班搬砖");
            case 6, 7 -> System.out.println("快乐周末");
            default -> System.out.println("输入有误");
        }
    }
}
```

**课后练习**
1. 键盘录入 1~7，用 case 穿透判断"工作日 / 休息日"，要求把结果相同的 case 合并书写。
2. 键盘录入月份 1~12，用 JDK12 箭头表达式输出对应季节（3~5 春季、6~8 夏季、9~11 秋季、12/1/2 冬季），非法月份输出"输入有误"。
3. 分析题：switch 中 default 写在最前面且所有 case 都不写 break 时，输入一个与任何 case 都不匹配的值，程序会执行哪些语句？输出什么？

## 循环（3-08 ~ 3-20）

### 3-08 for循环

**知识点**
- 格式：`for (初始化语句; 条件判断语句; 条件控制语句) { 循环体语句; }`
- 执行流程：初始化只执行一次 → 判断条件 → true 执行循环体 → 执行条件控制语句（如 i++）→ 再判断条件，直到条件为 false 循环结束
- 循环变量 i 的作用域只在 for 的小括号和大括号内，循环结束后不能再使用
- 求和思想：循环外定义求和变量 sum 并初始化为 0，循环体内累加 `sum += i`
- 常见错误：条件永远成立导致死循环、循环体内误改循环变量导致次数错乱

**示例代码**
```java
public class ForDemo {
    public static void main(String[] args) {
        // 打印 3 次同一句话
        for (int i = 1; i <= 3; i++) {
            System.out.println("黑马程序员 牛逼!");
        }
        System.out.println("----------------");

        // 求 1~5 的和：演示累加思想
        int sum = 0;
        for (int i = 1; i <= 5; i++) {
            sum += i;
        }
        System.out.println("1~5的和是：" + sum);
    }
}
```

**课后练习**
1. 用 for 循环打印 5 行"循环成功"。
2. 用 for 循环打印 1~10 之间每个整数的平方，每行一个（如第 3 行输出 9）。
3. 求 1~10 的乘积（即 1×2×3×…×10），打印最终结果。

### 3-09 for的4道基本练习

**知识点**
- 练习1：求 1~100 所有整数之和（正确结果 5050）
- 练习2：求 1~100 所有偶数之和（正确结果 2550）
- 练习3：求 1~100 所有奇数之和（正确结果 2500）
- 练习4：统计 1~100 中能被 3 整除的数的个数（共 33 个）
- 累加三要素：循环外建 sum 变量、循环体内累加、循环结束后打印
- 挑偶数 / 奇数：循环体内用 `i % 2` 判断再累加，或调整循环起点和步长
- 计数器与求和变量用法相同，只是每次 `count++`

**示例代码**
```java
public class ForPractice {
    public static void main(String[] args) {
        // 练习1：求 1~100 的和
        int sum = 0;
        for (int i = 1; i <= 100; i++) {
            sum += i;
        }
        System.out.println("1~100的和：" + sum);

        // 练习2：求 1~100 的偶数和
        int evenSum = 0;
        for (int i = 1; i <= 100; i++) {
            // 只累加偶数
            if (i % 2 == 0) {
                evenSum += i;
            }
        }
        System.out.println("1~100的偶数和：" + evenSum);
    }
}
```

**课后练习**
1. 求 1~100 之间所有奇数的和，打印结果。
2. 统计 1~100 之间能被 3 整除的数的个数，打印结果。
3. 求 1×2×3×…×10 的结果并打印。

### 3-10 for的3道算法题

**知识点**
- 练习1（水仙花数）：打印所有三位水仙花数并统计个数——各位数字的立方和等于它本身的数（如 153 = 1³ + 5³ + 3³）
- 练习2（回文数）：打印 100~999 之间所有的三位回文数并统计个数——个位与百位相同的数（如 121）
- 练习3（逢七过）：报数 1~100，凡是含 7 或 7 的倍数说"过"，其余说数字本身，最后统计"过"的次数
- 拆位技巧：个位 `i % 10`，十位 `i / 10 % 10`，百位 `i / 100 % 10`
- "含 7"要同时判断个位、十位、百位是否等于 7，用 `||` 连接
- 这类题的通用套路：for 遍历范围 + if 筛选 + 计数器统计

**示例代码**
```java
public class NarcissusNumber {
    public static void main(String[] args) {
        // 水仙花数：三位数，每个位上的立方和等于它本身
        int count = 0;
        for (int i = 100; i <= 999; i++) {
            int ge = i % 10;        // 个位
            int shi = i / 10 % 10;  // 十位
            int bai = i / 100 % 10; // 百位
            // 立方和等于本身则是水仙花数
            if (ge * ge * ge + shi * shi * shi + bai * bai * bai == i) {
                System.out.println(i + " 是水仙花数");
                count++;
            }
        }
        System.out.println("水仙花数共有 " + count + " 个");
    }
}
```

**课后练习**
1. 回文数：打印 100~999 之间所有的三位回文数（个位与百位相同的数，如 101、121），并统计个数。
2. 逢七过：从 1 报数到 100，遇到含 7 或 7 的倍数打印"过"，其余打印数字本身；最后统计一共说了多少次"过"。
3. 变形：打印所有"四叶玫瑰数"——1000~9999 中各位数字的 4 次方之和等于它本身的四位数（如 1634），并统计个数。

### 3-11 while循环

**知识点**
- 格式：`初始化语句; while (条件判断语句) { 循环体语句; 条件控制语句; }`
- 执行流程与 for 相同：先判断条件，true 执行循环体和条件控制语句，false 结束循环
- 与 for 的选择：循环次数明确用 for，次数不明确、只知结束条件用 while；两者可以互相转换
- while 的循环变量定义在循环外，循环结束后依然可以访问（与 for 的重要区别）
- 忘写条件控制语句（如 i++）会让条件永远成立，程序陷入死循环

**示例代码**
```java
public class WhileDemo {
    public static void main(String[] args) {
        // 打印 1~5
```

### 3-12 while的3道算法题

**知识点**
- 练习1（纸张折叠）：纸张厚度 0.1 毫米，每次对折厚度翻倍，求对折多少次后厚度超过珠穆朗玛峰（8844430 米），注意毫米和米的单位换算
- 练习2（求商和余数）：不用 `/` 和 `%` 运算符，键盘录入被除数和除数，用循环做减法求商和余数（如 17 ÷ 5 商 3 余 2）
- 练习3（数位求和）：键盘录入一个整数，求它各位数字之和（如 123 的结果是 6）
- 折纸题是"次数未知"的典型场景，正好体现 while 的价值
- 数位操作的通用套路：`num % 10` 取出个位累加，`num / 10` 去掉个位，循环到 num 为 0
- 这类题循环条件写什么（如 `paper <= peak`、`num > 0`）是关键，别写成死循环

**示例代码**
```java
public class WhilePractice {
    public static void main(String[] args) {
        // 练习1：纸张折叠超过珠峰高度
        double paper = 0.0001; // 纸张厚度 0.1 毫米，换算成米
        int peak = 8844430;    // 珠穆朗玛峰高度（米）
        int count = 0;         // 对折次数
        while (paper <= peak) {
            paper = paper * 2; // 每对折一次厚度翻倍
            count++;
        }
        System.out.println("对折 " + count + " 次后超过珠峰高度");
        System.out.println("----------------");

        // 练习3：数位求和
        int num = 123;
        int sum = 0;
        while (num > 0) {
            sum += num % 10; // 取出个位累加
            num = num / 10;  // 去掉个位
        }
        System.out.println("123 各位数字之和：" + sum);
    }
}
```

**课后练习**
1. 求商和余数：键盘录入被除数和除数，不使用 `/` 和 `%` 运算符，用循环求出商和余数并输出。例如输入 17 和 5，输出：商为 3，余数为 2。
2. 反转数：键盘录入一个三位数，输出它反转后的数字。例如输入 123，输出 321。
3. 统计位数：键盘录入一个整数，输出它是几位数。例如输入 4567，输出：4 位数。

### 3-13 dowhile循环

**知识点**
- 格式：`初始化语句; do { 循环体语句; 条件控制语句; } while (条件判断语句);`
- 特点：先执行一次循环体，再判断条件，因此条件不成立时循环体也至少执行一次
- while 结尾的分号不能少，漏写会编译报错
- 三种循环对比：for 和 while 是先判断后执行（可能一次都不执行），do-while 是先执行后判断（至少一次）
- do-while 实际使用较少，适合"先操作一次再问要不要继续"的场景
- 同样要注意循环内必须有条件控制语句，否则死循环

**示例代码**
```java
public class DoWhileDemo {
    public static void main(String[] args) {
        // 打印 1~5：先执行一次，再判断条件
        int i = 1;
        do {
            System.out.println(i);
            i++;
        } while (i <= 5); // 这里必须写分号

        // 条件一开始就不成立，循环体也执行了一次
        int j = 100;
        do {
            System.out.println("我至少会执行一次，j = " + j);
            j++;
        } while (j < 100);
    }
}
```

**课后练习**
1. 用 do-while 循环打印 1~10，每行一个。
2. 用 do-while 循环求 1~100 的和，打印结果。
3. 键盘录入一个正整数，用 do-while 循环把它从个位开始逐位拆出并打印，每行一个。例如输入 345，依次打印 5、4、3。

### 3-14 无限循环

**知识点**
- 三种写法：`for(;;){}`、`while(true){}`、`do{...}while(true);`，最常用 `while(true)`
- 无限循环（死循环）没有结束条件，会一直执行下去，程序停在循环里不出来
- 死循环后面的代码永远不会被执行，直接在其后写语句会编译报错（不可达语句）
- 使用场景：不知道循环要执行多少次、需要程序一直运行等用户主动退出，如菜单程序、服务器监听
- 实际开发中要在循环体内设置退出条件，满足条件时用 break 跳出（下一课详细讲）

**示例代码**
```java
public class InfiniteLoopDemo {
    public static void main(String[] args) {
        // 死循环最常用的写法
        int count = 0;
        while (true) {
            count++;
            System.out.println("第 " + count + " 次执行");
            // 满足条件时用 break 跳出，避免真的永远循环
            if (count == 5) {
                System.out.println("执行完毕，退出循环");
                break;
            }
        }
        System.out.println("程序结束");
    }
}
```

**课后练习**
1. 用 `for(;;)` 写一个无限循环，循环体内打印"循环中…"，并用计数器在执行满 3 次时 break 退出，退出后打印"结束"。
2. 在无限循环中每圈把变量 money 翻倍（初始值为 1），当 money 超过 10000 时输出一共循环了多少圈并退出。
3. 分析题：在 `while(true){}` 的死循环后面再写一条打印语句，编译会发生什么？为什么？

### 3-15 break关键字和综合练习

**知识点**
- 练习1（死循环菜单）：循环打印食堂菜单（1 宫保鸡丁、2 鱼香肉丝、3 结账退出），根据键盘输入执行对应操作，输入 3 时结束整个程序循环
- 练习2（提前结束累加）：从 1 开始累加整数，一旦总和超过 2000 就停止累加，输出此时加到了哪个数字
- break 只能用在循环和 switch 中，作用是结束整个循环（或当前 switch）
- 嵌套结构中：switch 里的 break 只能跳出 switch；想结束外层死循环需要在循环上再写判断配合 break
- 死循环 + break 是"菜单程序"的标准写法：一直服务用户，直到用户选择退出

**示例代码**
```java
import java.util.Scanner;

public class BreakMenuDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        // 死循环 + 菜单：只有用户选择退出才结束
        while (true) {
            System.out.println("===== 黑马食堂 =====");
            System.out.println("1.宫保鸡丁 2.鱼香肉丝 3.结账退出");
            System.out.println("请输入编号：");
            int choice = sc.nextInt();
            switch (choice) {
                case 1:
                    System.out.println("宫保鸡丁已下单");
                    break;
                case 2:
                    System.out.println("鱼香肉丝已下单");
                    break;
                case 3:
                    System.out.println("欢迎下次光临");
                    break; // 这里只能跳出 switch
                default:
                    System.out.println("没有这个菜");
                    break;
            }
            // 用户选了 3 时，结束整个死循环
            if (choice == 3) {
                break;
            }
        }
    }
}
```

**课后练习**
1. 提前结束累加：从 1 开始逐个累加整数，一旦总和超过 2000 就停止，输出此时加到了哪个数字。
2. 键盘循环录入整数，当录入 0 时结束录入，输出本次一共录入了多少个数字（0 本身不计入）。
3. 循环打印 1~100，当打印到第一个既是 3 的倍数又是 5 的倍数的数字时，打印它并用 break 结束循环。

### 3-16 continue关键字和综合练习

**知识点**
- 练习1：打印 1~100 之间的所有奇数，遇到偶数用 continue 跳过
- 练习2：求 1~100 所有整数的和，但跳过所有 7 的倍数不参与累加
- continue 只能用在循环中，作用是跳过本次循环体剩余内容，直接进入下一次循环
- break 是结束整个循环，continue 是只结束本次循环，注意区分
- for 循环中 continue 后会自动执行 i++，次数不会乱；while 循环中 continue 会直接跳回条件判断，若把 i++ 写在 continue 之后会造成死循环
- continue 常与 if 搭配：条件成立就跳过，不成立才执行后面的代码

**示例代码**
```java
public class ContinueDemo {
    public static void main(String[] args) {
        // 练习1：打印 1~100 中的奇数，偶数直接跳过
        for (int i = 1; i <= 100; i++) {
            if (i % 2 == 0) {
                continue; // 跳过本次循环，直接进入下一圈
            }
            System.out.print(i + " ");
        }
        System.out.println();

        // 练习2：求 1~100 的和，跳过所有 7 的倍数
        int sum = 0;
        for (int i = 1; i <= 100; i++) {
            if (i % 7 == 0) {
                continue;
            }
            sum += i;
        }
        System.out.println("1~100去掉7的倍数后的和：" + sum);
    }
}
```

**课后练习**
1. 打印 1~20 之间所有不能被 3 整除的数，用 continue 跳过 3 的倍数。
2. 统计 1~100 之间不含数字 7 的数有多少个（含 7 的数用 continue 跳过）。
3. 分析题：在 `while (i <= 5)` 的循环里，把 continue 写在 i++ 之前运行会发生什么？应该怎样调整语句位置避免这个问题？

### 3-17 练习：猜数字小游戏

**知识点**
- 题目：程序生成一个 1~100 的随机数作为答案，用户循环键盘录入猜测，猜大了提示"猜大了"，猜小了提示"猜小了"，猜中了提示成功并结束
- 随机数用法：`Random r = new Random();` 之后 `r.nextInt(n)` 生成 0 ~ n-1 的随机整数
- 生成 1~100 的随机数要整体加 1：`r.nextInt(100) + 1`
- 主体结构是无限循环 + if-else 判断大小，猜中时用 break 结束
- 扩展：用计数器统计猜测次数，猜中时一并输出

**示例代码**
```java
import java.util.Random;
import java.util.Scanner;

public class GuessNumberGame {
    public static void main(String[] args) {
        // 生成 1~100 之间的随机数作为答案
        Random r = new Random();
        int answer = r.nextInt(100) + 1;
        Scanner sc = new Scanner(System.in);
        int count = 0; // 记录猜测次数
        while (true) {
            System.out.println("请猜一个 1~100 的整数：");
            int guess = sc.nextInt();
            count++;
            if (guess > answer) {
                System.out.println("猜大了");
            } else if (guess < answer) {
                System.out.println("猜小了");
            } else {
                System.out.println("猜中了！你一共猜了 " + count + " 次");
                break; // 猜中后结束循环
            }
        }
    }
}
```

**课后练习**
1. 简化版：答案改为 1~50 的随机数，完成猜数字游戏，猜中时输出总猜测次数。
2. 限定次数版：最多允许猜 5 次，5 次内猜中输出"猜中了"，5 次用完仍未猜中输出"挑战失败，正确答案是 x"（x 为真实答案）。
3. 变形：程序随机生成 1~6 的骰子点数，用户键盘录入 1 表示猜"大"（对应 4~6 点）、录入 2 表示猜"小"（对应 1~3 点），程序输出是否猜对以及真实点数。

### 3-18 循环嵌套

**知识点**
- 嵌套循环：循环体内再写一个循环，外层循环执行一次，内层循环要完整执行一轮
- 打印矩形的标准写法：外层控制行数，内层控制每行列数
- 总执行次数 = 外层次数 × 内层次数（如外层 3 次、内层 4 次共 12 次）
- 理解口诀：外层管"第几行"，内层管"这一行打印什么"
- 内外层循环变量要用不同的名字（如 i 和 j）
- `System.out.print()` 不换行用于打印同一行内容，每行结束后用 `System.out.println()` 换行

**示例代码**
```java
public class LoopNestDemo {
    public static void main(String[] args) {
        // 打印 3 行 4 列的星号矩形
        // 外层：控制一共打印几行
        for (int i = 1; i <= 3; i++) {
            // 内层：控制每一行打印几个星号
            for (int j = 1; j <= 4; j++) {
                System.out.print("* ");
            }
            // 每行打印完换行
            System.out.println();
        }
        System.out.println("----------------");

        // 体会执行顺序：外层转 1 圈，内层完整跑一轮
        for (int i = 1; i <= 2; i++) {
            for (int j = 1; j <= 3; j++) {
                System.out.println("i = " + i + "，j = " + j);
            }
        }
    }
}
```

**课后练习**
1. 打印 4 行 6 列的星号矩形（每行 6 个 `*`，共 4 行）。
2. 打印 3 行 3 列的数字方块，每个位置打印当前行号：第 1 行为 1 1 1，第 2 行为 2 2 2，第 3 行为 3 3 3。
3. 打印一个 5 行 10 列的条纹图案：奇数列打印 `*`，偶数列打印 `-`，即每行形如 `* - * - * - * - * -`。

### 3-19 练习：打印多个复杂图形

**知识点**

- 复杂图形的核心：内层循环的次数不再是固定值，而是与外层行号 i 相关的表达式
- 金字塔需要两个内层循环：一个专门打空格，一个专门打星号
- 拿不准次数时，先列一张"行号 → 空格数 → 星号数"的表格找规律

```java
public class ShapePrintDemo {

        for (int i = 1; i <= 5; i++) {
            for (int j = 1; j <= i; j++) {
                System.out.print("*");
            }
            System.out.println();
        }
        System.out.println("----------------");

        // 练习3：等腰三角形（第 i 行：5-i 个空格 + 2i-1 个星号）

            }

            }
            System.out.println();
        }
    }
}
```

### 3-20 练习：打印九九乘法表

**知识点**
- 题目：打印九九乘法表，第 1 行 1 个式子，第 2 行 2 个……第 9 行 9 个，整体呈三角形
- 结构：外层 i 从 1 到 9 控制行，内层 j 从 1 到 i 控制列，内层条件写 `j <= i` 是关键
- 每个式子的打印：`System.out.print(j + "×" + i + "=" + j*i + "\t")`，不换行
- 用 `\t`（制表符）对齐每列；每行结束后用 `System.out.println()` 换行
- 内层条件若误写成 `j <= 9`，会打印出 9×9 的完整矩形而不是三角形
- 变形方向：倒三角乘法表、按条件筛选式子等，都只改外层或内层的范围

**示例代码**
```java
public class NineNineTable {
    public static void main(String[] args) {
        // 外层循环控制第几行（一共 9 行）
        for (int i = 1; i <= 9; i++) {
            // 内层循环控制这一行打印几列（第 i 行有 i 列）
            for (int j = 1; j <= i; j++) {
                // 打印一个式子，用制表符对齐，不换行
                System.out.print(j + "×" + i + "=" + j * i + "\t");
            }
            // 一行结束后换行
            System.out.println();
        }
    }
}
```

**课后练习**
1. 倒三角乘法表：第 1 行打印 1×1=1 一直到 1×9=9 共 9 个式子，第 2 行从 2×2 开始，依此类推，最后一行只有 9×9=9。
2. 筛选版乘法表：按九九乘法表的结构输出，但只打印乘积不超过 30 的式子。
3. 九九加法表：仿照乘法表的结构打印一个加法表，第 i 行打印 j+i 的所有算式，例如第 2 行是 1+2=3 和 2+2=4。
