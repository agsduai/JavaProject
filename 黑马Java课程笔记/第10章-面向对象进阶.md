# 第10章 面向对象进阶

本章在面向对象基础上继续进阶：学习 static 与 final 两个关键字，掌握静态变量的内存图、工具类的规范写法，并认识一种特殊的类——枚举，理解它的定义方式、内存规则与常见注意事项。

### 10-01 static修饰成员变量

**知识点**
- static 是静态修饰符，被它修饰的成员变量叫静态变量（也叫类变量），属于类而不属于某个对象。
- 静态变量被该类的所有对象共享，全类只有一份；非静态成员变量则是每个对象各有一份。
- 调用格式：推荐"类名.静态变量名"；用对象名调用语法上也允许，但不推荐（IDEA 会提示警告）。
- 应用场景：当某个数据需要被所有对象共享时使用，例如统计一共创建了多少个对象、在线人数等。
- 静态变量随类加载而存在，优先于对象出现：类加载时它已经有了，此时可能还没有任何对象。
- 记忆口诀：静态的属于类，非静态的属于对象。

**示例代码**
```java
// 文件名: StaticStudent.java
public class StaticStudent {
    private String name;
    // 静态变量：属于类，被所有对象共享一份，随类加载而存在
    public static int count = 0;

    public StaticStudent(String name) {
        this.name = name;
        count++; // 每创建一个对象，共享的 count 就加 1
    }

    public void show() {
        System.out.println("姓名：" + name + "，已创建人数：" + count);
    }
}
```

```java
// 文件名: StaticStudentTest.java
public class StaticStudentTest {
    public static void main(String[] args) {
        StaticStudent s1 = new StaticStudent("阿玮");
        StaticStudent s2 = new StaticStudent("小黑");
        StaticStudent s3 = new StaticStudent("小明");

        s1.show(); // 姓名：阿玮，已创建人数：3
        s3.show(); // 姓名：小明，已创建人数：3（共享同一份 count）

        // 静态变量推荐用"类名.静态变量"调用
        System.out.println("共创建：" + StaticStudent.count);

        // 对象名调用语法允许但不推荐，IDEA 会给出警告
        System.out.println("s1看到的count：" + s1.count);
    }
}
```

### 10-02 static静态变量的内存图

**知识点**
- 静态变量存放在堆中的静态存储位置（JDK8 及以后方法区由堆中的元空间实现，静态变量随类信息存放在堆的静态位置），全类只有一份。
- 静态变量随类加载而创建、随类卸载而消失，比对象出现得早，存在的时间也最长。
- new 出来的对象空间里只有非静态成员变量，没有静态变量；画内存图时静态变量要单独画在静态位置。
- 通过对象名访问静态变量时，底层仍然是按类找到静态位置上的那一份数据。
- 任何一个对象（或类名本身）修改静态变量，所有对象再访问时看到的都是修改后的值。
- 画图口诀：栈存地址，堆存对象和静态位置，对象里没有静态变量。

**示例代码**
```java
// 文件名: StaticMemoryDemo.java
// 内存变化演示（结合注释画出内存图）
// 1. StaticPerson.class 加载进方法区（元空间）
// 2. 静态变量 country 在堆的静态存储位置出现，先为默认值 null，后赋值"中国"
// 3. main 进栈
// 4. new StaticPerson()：堆中开辟对象空间（里面只有 name），地址 0x0011 给 p1
// 5. new StaticPerson()：堆中再开一块（也只有 name），地址 0x0022 给 p2
//    注意：country 不在任何对象空间里，它在静态位置，全类只有一份
public class StaticMemoryDemo {
    public static void main(String[] args) {
        StaticPerson p1 = new StaticPerson();
        p1.name = "阿玮";

        StaticPerson p2 = new StaticPerson();
        p2.name = "小黑";

        // 类名和两个对象访问到的都是静态位置那同一份
        System.out.println(StaticPerson.country); // 中国
        p1.country = "华夏";
        System.out.println(p2.country);           // 华夏（改的是共享的那一份）
        System.out.println(StaticPerson.country); // 华夏
    }
}
```

```java
// 文件名: StaticPerson.java
public class StaticPerson {
    String name;                  // 非静态成员变量：随对象存放在堆的对象空间里
    public static String country; // 静态变量：存放在堆的静态存储位置，全类一份
}
```

### 10-03 static修饰成员方法

**知识点**
- static 修饰的成员方法叫静态方法，属于类，推荐用"类名.方法名()"调用，也可以用对象名调用但不推荐。
- 静态方法最典型的应用是工具类：把一些常用的、与具体对象无关的功能封装成静态方法，方便直接拿来用。
- 工具类书写规范：构造方法私有（外界无法创建对象）+ 所有方法都是静态方法。
- 私有构造的意义：工具类里的方法用类名就能调用，创建对象毫无意义，私有化还能防止别人乱 new。
- JDK 中的 Math、Arrays 就是典型的工具类，本课自己动手封装一个 ArrayUtil。
- 工具类方法写好后，任何项目中都可以直接"类名.方法"复用，这就是封装带来的复用性。

**示例代码**
```java
// 文件名: ArrayUtil.java
// 数组工具类：私有构造方法 + 静态方法
public class ArrayUtil {
    // 私有构造：工具类不需要对象，防止外界 new
    private ArrayUtil() {
    }

    // 打印数组内容，格式如 [1, 2, 3]
    public static void printArray(int[] arr) {
        System.out.print("[");
        for (int i = 0; i < arr.length; i++) {
            if (i == arr.length - 1) {
                System.out.print(arr[i]);
            } else {
                System.out.print(arr[i] + ", ");
            }
        }
        System.out.println("]");
    }

    // 求数组最大值
    public static int getMax(int[] arr) {
        int max = arr[0];
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > max) {
                max = arr[i];
            }
        }
        return max;
    }

    // 求数组总和
    public static int getSum(int[] arr) {
        int sum = 0;
        for (int i = 0; i < arr.length; i++) {
            sum += arr[i];
        }
        return sum;
    }
}
```

```java
// 文件名: ArrayUtilTest.java
public class ArrayUtilTest {
    public static void main(String[] args) {
        int[] arr = {3, 7, 1, 9, 4};

        // 工具类的静态方法直接用类名调用
        ArrayUtil.printArray(arr);
        System.out.println("最大值：" + ArrayUtil.getMax(arr));
        System.out.println("总和：" + ArrayUtil.getSum(arr));
    }
}
```

### 10-04 static关键字的注意事项

**知识点**
- 静态方法中没有 this：this 代表当前对象，而静态方法随类加载、与对象无关，调用它时可能还没有任何对象。
- 静态方法只能访问静态成员（静态变量、静态方法），不能访问非静态成员变量，也不能调用非静态方法。
- 非静态方法则谁都能访问：既可以访问静态成员，也可以访问非静态成员。
- 原因归纳：静态成员随类加载而存在，非静态成员随对象创建而存在，"先存在的不能访问可能不存在的"。
- main 方法本身就是静态方法，所以 main 中想调用本类的非静态方法必须先 new 对象。
- 记忆口诀：静态的只能访问静态的；非静态的访问谁都可以。

**示例代码**
```java
// 文件名: StaticNoteDemo.java
// 演示 static 的访问规则（注释中的写法都会编译报错）
public class StaticNoteDemo {
    String name = "对象自己的";     // 非静态成员变量
    static String school = "黑马"; // 静态成员变量

    // 静态方法：随类加载而存在，与对象无关
    public static void staticShow() {
        // System.out.println(name); // 报错：静态方法不能访问非静态变量
        // nonStaticShow();          // 报错：静态方法不能调用非静态方法
        // System.out.println(this); // 报错：静态方法中没有 this
        System.out.println(school);  // 正确：静态访问静态
        System.out.println("静态方法执行了");
    }

    // 非静态方法：随对象而存在，可以访问一切成员
    public void nonStaticShow() {
        System.out.println(name);   // 正确：非静态访问非静态
        System.out.println(school); // 正确：非静态也能访问静态
        staticShow();               // 正确：非静态也能调用静态
    }
}
```

```java
// 文件名: StaticNoteTest.java
public class StaticNoteTest {
    public static void main(String[] args) {
        // main 是静态方法，直接用类名调用静态方法
        StaticNoteDemo.staticShow();

        // 想调用非静态方法，必须先创建对象
        StaticNoteDemo demo = new StaticNoteDemo();
        demo.nonStaticShow();

        // 如果在 main 中直接写 nonStaticShow(); 会编译报错
        // 原因：main 是静态的，静态不能访问非静态
    }
}
```

### 10-05 final关键字

**知识点**
- final 表示"最终的、不可改变的"，可以修饰类、方法、变量三种东西。
- final 修饰类：该类不能被继承，JDK 中的 String、Integer 等核心类都是 final 类。
- final 修饰方法：该方法不能被重写（重写的细节在继承章节学习）。
- final 修饰基本类型变量：变量的值不能再被修改；修饰引用类型变量：地址值不能再改，但对象内部的属性可以改。
- final 修饰的变量就是常量，命名规范：全部大写，多个单词之间用下划线分隔，如 MAX_SCORE、DEFAULT_NAME。
- 常量通常配合 static 一起使用（static final），成为类常量，可以直接用类名调用。

**示例代码**
```java
// 文件名: FinalDemo.java
public class FinalDemo {
    // final + static 组合：类常量，命名全大写、下划线分隔
    public static final double PI = 3.1415926535;
    public static final int MAX_SCORE = 100;
    public static final String DEFAULT_NAME = "阿玮";

    public static void main(String[] args) {
        // final 修饰基本类型变量：值不能再改
        final int a = 10;
        // a = 20; // 编译报错：final 变量不能被重新赋值
        System.out.println(a);

        // final 修饰引用类型变量：地址值不能改，但对象内部属性可以改
        final FinalPhone p = new FinalPhone();
        p.brand = "华为";      // 正确：改的是堆中对象的内容
        System.out.println(p.brand);
        // p = new FinalPhone(); // 编译报错：final 引用不能再指向别的对象

        // 常量直接用类名调用
        System.out.println(PI);
        System.out.println(MAX_SCORE);
        System.out.println(DEFAULT_NAME);
    }
}
```

```java

    String brand;
}
```

### 10-06 枚举

**知识点**
- 枚举是一种特殊的类，用于把取值范围有限的、需要一一列举的数据定义出来，如星期、季节、性别、方向。
- 定义格式：`public enum 枚举名 { 枚举项1, 枚举项2, 枚举项3; }`，每个枚举项就是枚举类的一个实例对象。
- 枚举项名字习惯全部大写（遵循常量命名规范），如 SPRING、MONDAY。
- 枚举可以有成员变量、成员方法，构造方法默认（且必须）私有，外界不能 new 枚举对象。
- 枚举项需要携带参数时写成"枚举项(参数)"，并定义对应的构造方法完成初始化。
- 枚举与 switch 天然配合：case 后直接写枚举项，分支逻辑清晰且不容易写错。

**示例代码**
```java
// 文件名: Season.java
// 枚举：列举一年四季
public enum Season {
    // 枚举项必须写在最前面，带参数时会调用对应的构造方法
    SPRING("春天", "万物复苏"),
    SUMMER("夏天", "烈日炎炎"),
    AUTUMN("秋天", "硕果累累"),
    WINTER("冬天", "白雪皑皑");

    private String name; // 季节名
    private String desc; // 季节描述

    // 枚举的构造方法默认私有，外界不能调用
    Season(String name, String desc) {
        this.name = name;
        this.desc = desc;
    }

    public String getName() {
        return name;
    }

    public String getDesc() {
        return desc;
    }
}
```

```java
// 文件名: EnumDemo.java
public class EnumDemo {
    public static void main(String[] args) {
        // 直接使用枚举项（本质是枚举类中现成的实例对象）
        Season s = Season.SPRING;
        System.out.println(s.getName() + "：" + s.getDesc());

        // 枚举配合 switch
        Season cur = Season.SUMMER;
        switch (cur) {
            case SPRING -> System.out.println("去踏青");
            case SUMMER -> System.out.println("去游泳");
            case AUTUMN -> System.out.println("去登山");
            case WINTER -> System.out.println("去滑雪");
        }
    }
}
```

### 10-07 枚举的注意事项

**知识点**
- 枚举的构造方法必须是私有的（连访问修饰符都不写时默认也是私有），外界不能创建枚举对象，只能使用现成的枚举项。
- 枚举项必须写在枚举类的第一行，多个枚举项用逗号分隔，最后一个枚举项后面用分号结束，之后才能写成员变量和方法。
- 枚举的本质是一个类，默认已经继承了 java.lang.Enum，由于 Java 单继承，枚举不能再继承其他类，但可以实现接口。
- 枚举项之间比较可以直接用 ==，也可以用 equals，结果一样。
- 常用方法：values() 返回所有枚举项组成的数组；valueOf(String) 把字符串转成对应的枚举项，字符串不存在时会抛出 IllegalArgumentException 异常。
- 其他方法：name()/toString() 返回枚举项名字；ordinal() 返回枚举项在枚举中的序号，从 0 开始。

**示例代码**
```java
// 文件名: EnumNoteDemo.java
public class EnumNoteDemo {
    public static void main(String[] args) {
        // values()：获取所有枚举项
        Week[] weeks = Week.values();
        for (Week w : weeks) {
            System.out.println(w + " 序号：" + w.ordinal());
        }

        // valueOf()：把字符串转成对应的枚举项
        Week w1 = Week.valueOf("MONDAY");
        System.out.println(w1);

        // 枚举项比较：== 或 equals 都可以
        System.out.println(w1 == Week.MONDAY);       // true
        System.out.println(w1.equals(Week.TUESDAY)); // false

        // 枚举的本质：默认继承 java.lang.Enum，打印父类名验证
        System.out.println(Week.class.getSuperclass()); // class java.lang.Enum

        // Week bad = Week.valueOf("SOMEDAY");
        // 字符串在枚举中不存在，运行时会抛出 IllegalArgumentException
    }
}
```

```java
// 文件名: Week.java
// 枚举项必须在第一行，最后一个枚举项后面用分号结束，之后才能写其他成员

    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY;
}
```
