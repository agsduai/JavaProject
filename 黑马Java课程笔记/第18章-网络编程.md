# 第18章 网络编程

本章学习"程序之间怎么通过网络通信"：先掌握 IP、端口、协议三个基本概念，再理解 TCP 与 UDP 的差异；随后用 Socket 写出能互发消息的客户端与服务端，最后实现多客户端聊天室与文件传输。网络编程是 Web 服务、微服务、聊天工具的底层基础。

### 18-01 网络编程三要素

**知识点**
- IP 地址：网络中设备的唯一标识，IPv4 是 32 位（点分十进制），IPv6 是 128 位；`127.0.0.1` 表示本机回环地址。
- 端口号：标识设备上的某个应用程序，范围 0~65535，其中 0~1023 是系统保留端口（HTTP 80、HTTPS 443）。
- 协议：通信双方约定的数据格式规则，常见有 TCP、UDP、HTTP、FTP。
- `InetAddress` 类表示 IP 地址：`getByName`、`getLocalHost`、`getHostName`、`getHostAddress`。
- 一个程序要能被访问，必须"IP + 端口 + 协议"三者确定，缺一不可。
- 易错：端口号被占用会抛 `BindException`；同一端口同一时刻只能被一个程序监听（TCP）。

**示例代码**
```java
import java.net.InetAddress;
import java.net.UnknownHostException;

public class NetworkBasicDemo {
    public static void main(String[] args) {
        try {
            // 获取本机地址
            InetAddress local = InetAddress.getLocalHost();
            System.out.println("本机主机名：" + local.getHostName());
            System.out.println("本机 IP：" + local.getHostAddress());

            // 通过域名获取 IP
            InetAddress baidu = InetAddress.getByName("www.baidu.com");
            System.out.println("百度的 IP：" + baidu.getHostAddress());

            // 通过 IP 字符串获取
            InetAddress loopback = InetAddress.getByName("127.0.0.1");
            System.out.println("回环地址：" + loopback.getHostAddress());

            // 判断是否可达（会发起网络请求，可能较慢）
            System.out.println("本机是否可达：" + local.isReachable(1000));
        } catch (UnknownHostException e) {
            System.out.println("域名解析失败：" + e.getMessage());
        } catch (java.io.IOException e) {
            System.out.println("网络异常：" + e.getMessage());
        }

        // 常用端口说明
        System.out.println("HTTP 默认端口：80");
        System.out.println("HTTPS 默认端口：443");
        System.out.println("MySQL 默认端口：3306");
    }
}
```

### 18-02 UDP通信

**知识点**
- UDP 是面向无连接的协议：发送方不管对方在不在、收没收到，直接发，速度快但不保证可靠。
- 核心类：`DatagramSocket`（发送/接收端）、`DatagramPacket`（数据包，包含数据 + 目标 IP + 端口）。
- 发送流程：创建 `DatagramSocket` → 构造 `DatagramPacket(byte[], length, InetAddress, port)` → `send()`。
- 接收流程：创建 `DatagramSocket(port)` 绑定端口 → 构造空包 `DatagramPacket(byte[], length)` → `receive()` 阻塞等待。
- UDP 单包大小受 MTU 限制，一般不超过 64KB；适合视频直播、游戏、DNS 等能容忍丢包的场景。
- 易错：接收端 `receive` 是阻塞的，没有数据时会一直卡住；`getData()` 返回的是整个缓冲区，要按 `getLength()` 截取。

**示例代码**
```java
import java.net.DatagramPacket;
import java.net.DatagramSocket;
import java.net.InetAddress;
import java.nio.charset.StandardCharsets;

public class UdpDemo {
    public static void main(String[] args) throws Exception {
        int port = 9999;

        // 接收端：单独线程持续监听
        Thread receiver = new Thread(() -> {
            try (DatagramSocket socket = new DatagramSocket(port)) {
                System.out.println("UDP 接收端已启动，监听端口：" + port);
                byte[] buffer = new byte[1024];
                DatagramPacket packet = new DatagramPacket(buffer, buffer.length);
                socket.receive(packet); // 阻塞等待数据

                String msg = new String(packet.getData(), 0, packet.getLength(),
                        StandardCharsets.UTF_8);
                System.out.println("收到来自 " + packet.getAddress().getHostAddress()
                        + ":" + packet.getPort() + " 的消息：" + msg);
            } catch (Exception e) {
                System.out.println("接收端异常：" + e.getMessage());
            }
        });
        receiver.start();

        Thread.sleep(300); // 等接收端就绪

        // 发送端
        try (DatagramSocket socket = new DatagramSocket()) {
            byte[] data = "你好，UDP！".getBytes(StandardCharsets.UTF_8);
            InetAddress target = InetAddress.getByName("127.0.0.1");
            DatagramPacket packet = new DatagramPacket(data, data.length, target, port);
            socket.send(packet);
            System.out.println("UDP 消息已发送");
        }

        receiver.join();
    }
}
```

### 18-03 TCP通信：客户端与服务端

**知识点**
- TCP 是面向连接的协议：通信前先"三次握手"建立连接，传输可靠、有序、不丢数据。
- 服务端：`ServerSocket(port)` → `accept()` 阻塞等待连接，返回一个 `Socket`。
- 客户端：`new Socket(host, port)` 连接服务端，连接成功后双方各有一个 `Socket`。
- 通信靠流：`getInputStream()` 读数据，`getOutputStream()` 写数据，可用转换流包装成字符流。
- 关闭顺序：先关输出流（`shutdownOutput` 或 `close`），再关输入流，最后关 Socket；服务端 `accept` 会阻塞，需用线程处理多个连接。
- 易错：客户端写数据后不关闭输出流，服务端 `read` 会一直阻塞等待"读完"。

**示例代码**
```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.PrintWriter;
import java.net.ServerSocket;
import java.net.Socket;

public class TcpDemo {
    public static void main(String[] args) throws Exception {
        int port = 8888;

        // 服务端线程
        Thread server = new Thread(() -> {
            try (ServerSocket serverSocket = new ServerSocket(port)) {
                System.out.println("服务端启动，端口：" + port);
                try (Socket socket = serverSocket.accept()) { // 阻塞等待连接
                    System.out.println("客户端已连接：" + socket.getInetAddress().getHostAddress());

                    BufferedReader reader = new BufferedReader(
                            new InputStreamReader(socket.getInputStream(), "UTF-8"));
                    PrintWriter writer = new PrintWriter(
                            new java.io.OutputStreamWriter(socket.getOutputStream(), "UTF-8"), true);

                    String line = reader.readLine();
                    System.out.println("服务端收到：" + line);

                    writer.println("你好客户端，我已收到：" + line);
                }
            } catch (Exception e) {
                System.out.println("服务端异常：" + e.getMessage());
            }
        });
        server.start();

        Thread.sleep(300); // 等服务端就绪

        // 客户端
        try (Socket socket = new Socket("127.0.0.1", port)) {
            System.out.println("客户端已连接到服务端");
            PrintWriter writer = new PrintWriter(
                    new java.io.OutputStreamWriter(socket.getOutputStream(), "UTF-8"), true);
            BufferedReader reader = new BufferedReader(
                    new InputStreamReader(socket.getInputStream(), "UTF-8"));

            writer.println("你好服务端，我是客户端");
            String response = reader.readLine();
            System.out.println("客户端收到：" + response);
        }

        server.join();
    }
}
```

### 18-04 TCP多客户端与聊天室

**知识点**
- 一个 `ServerSocket` 可以接受多个连接，每次 `accept` 返回一个新的 `Socket`，需为每个连接单独开线程。
- 聊天室核心：服务端保存所有客户端连接的输出流集合，收到一条消息就转发给所有人。
- 转发时用 `CopyOnWriteArrayList` 或加锁的 `List` 保存客户端，避免并发修改异常。
- 客户端需要两个线程：一个负责读服务端消息（接收），一个负责读键盘输入并发送。
- 客户端下线要通知服务端移除连接，否则转发时会抛异常。
- 易错：直接在 `accept` 循环里处理读写，会导致只能服务一个客户端，必须"一个连接一个线程"。

**示例代码**
```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.net.ServerSocket;
import java.net.Socket;
import java.util.List;
import java.util.concurrent.CopyOnWriteArrayList;

public class ChatRoomDemo {
    // 保存所有在线客户端的输出流
    private static final List<PrintWriter> CLIENTS = new CopyOnWriteArrayList<>();

    public static void main(String[] args) throws Exception {
        int port = 8899;

        Thread server = new Thread(() -> {
            try (ServerSocket serverSocket = new ServerSocket(port)) {
                System.out.println("聊天室服务端启动，端口：" + port);
                while (true) {
                    Socket socket = serverSocket.accept();
                    System.out.println("新用户上线：" + socket.getPort());
                    // 每个客户端一个线程
                    new Thread(() -> handleClient(socket)).start();
                }
            } catch (Exception e) {
                System.out.println("服务端异常：" + e.getMessage());
            }
        });
        server.setDaemon(true);
        server.start();

        Thread.sleep(300);

        // 启动两个客户端，模拟群聊
        Thread clientA = new Thread(() -> runClient("用户A", "大家好，我是A"));
        Thread clientB = new Thread(() -> runClient("用户B", "我是B，很高兴认识大家"));
        clientA.start();
        clientB.start();
        clientA.join();
        clientB.join();

        Thread.sleep(500);
        System.out.println("演示结束，在线客户端数：" + CLIENTS.size());
    }

    private static void handleClient(Socket socket) {
        PrintWriter writer = null;
        try {
            BufferedReader reader = new BufferedReader(
                    new InputStreamReader(socket.getInputStream(), "UTF-8"));
            writer = new PrintWriter(
                    new OutputStreamWriter(socket.getOutputStream(), "UTF-8"), true);
            CLIENTS.add(writer);

            String line;
            while ((line = reader.readLine()) != null) {
                System.out.println("收到消息：" + line);
                // 群发给所有客户端
                for (PrintWriter client : CLIENTS) {
                    client.println(line);
                }
            }
        } catch (Exception e) {
            System.out.println("客户端连接异常：" + e.getMessage());
        } finally {
            CLIENTS.remove(writer);
            try {
                socket.close();
            } catch (Exception ignored) {
            }
        }
    }

    private static void runClient(String name, String message) {
        try (Socket socket = new Socket("127.0.0.1", 8899)) {
            PrintWriter writer = new PrintWriter(
                    new OutputStreamWriter(socket.getOutputStream(), "UTF-8"), true);
            BufferedReader reader = new BufferedReader(
                    new InputStreamReader(socket.getInputStream(), "UTF-8"));

            writer.println(name + "：" + message);
            String response = reader.readLine();
            System.out.println(name + " 收到转发：" + response);
        } catch (Exception e) {
            System.out.println(name + " 异常：" + e.getMessage());
        }
    }
}
```

### 18-05 TCP文件上传

**知识点**
- 文件上传流程：客户端用 `FileInputStream` 读文件 → 通过 Socket 输出流发送 → 服务端从输入流读并写入 `FileOutputStream`。
- 关键约定：客户端发送完文件后必须 `shutdownOutput()`，服务端才知道"数据到此为止"。
- 文件名可以在发送文件内容前先发一行文本告诉服务端，服务端先读这一行再读文件字节。
- 服务端收到文件后要回一条确认消息，让客户端知道上传成功。
- 二进制文件（图片、压缩包）必须用字节流，不能用字符流，否则文件会损坏。
- 易错：服务端用 `readLine()` 读文件名、再用字节流读内容时，两者不能共用同一个 `BufferedReader`，否则会吞掉文件开头的字节。

**示例代码**
```java
import java.io.BufferedInputStream;
import java.io.BufferedOutputStream;
import java.io.BufferedReader;
import java.io.DataInputStream;
import java.io.File;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.InputStreamReader;
import java.io.PrintWriter;
import java.net.ServerSocket;
import java.net.Socket;

public class FileUploadDemo {
    public static void main(String[] args) throws Exception {
        int port = 8877;
        File uploadDir = new File("demo/upload");
        uploadDir.mkdirs();

        // 服务端
        Thread server = new Thread(() -> {
            try (ServerSocket serverSocket = new ServerSocket(port)) {
                System.out.println("文件服务端启动，端口：" + port);
                try (Socket socket = serverSocket.accept()) {
                    DataInputStream in = new DataInputStream(
                            new BufferedInputStream(socket.getInputStream()));

                    // 先读文件名长度和文件名
                    int nameLength = in.readInt();
                    byte[] nameBytes = new byte[nameLength];
                    in.readFully(nameBytes);
                    String fileName = new String(nameBytes, "UTF-8");
                    System.out.println("接收文件名：" + fileName);

                    // 再读文件内容
                    File dest = new File(uploadDir, fileName);
                    long total = 0;
                    try (FileOutputStream out = new FileOutputStream(dest)) {
                        byte[] buffer = new byte[4096];
                        int len;
                        while ((len = in.read(buffer)) != -1) {
                            out.write(buffer, 0, len);
                            total += len;
                        }
                    }
                    System.out.println("文件已保存：" + dest.getAbsolutePath() + "，共 " + total + " 字节");

                    PrintWriter writer = new PrintWriter(
                            new java.io.OutputStreamWriter(socket.getOutputStream(), "UTF-8"), true);
                    writer.println("上传成功：" + fileName + "，" + total + " 字节");
                }
            } catch (Exception e) {
                System.out.println("服务端异常：" + e.getMessage());
            }
        });
        server.start();

        Thread.sleep(300);

        // 准备一个测试文件
        File src = new File("demo/upload_src.txt");
        try (FileOutputStream out = new FileOutputStream(src)) {
            out.write("这是要上传的文件内容。\n第二行。".getBytes("UTF-8"));
        }

        // 客户端上传
        try (Socket socket = new Socket("127.0.0.1", port)) {
            BufferedOutputStream out = new BufferedOutputStream(socket.getOutputStream());
            byte[] nameBytes = src.getName().getBytes("UTF-8");
            java.io.DataOutputStream dataOut = new java.io.DataOutputStream(out);
            dataOut.writeInt(nameBytes.length);
            dataOut.write(nameBytes);

            try (FileInputStream fileIn = new FileInputStream(src)) {
                byte[] buffer = new byte[4096];
                int len;
                while ((len = fileIn.read(buffer)) != -1) {
                    dataOut.write(buffer, 0, len);
                }
            }
            dataOut.flush();
            socket.shutdownOutput(); // 告诉服务端：文件发完了

            BufferedReader reader = new BufferedReader(
                    new InputStreamReader(socket.getInputStream(), "UTF-8"));
            System.out.println("服务端回应：" + reader.readLine());
        }

        server.join();
    }
}
```

### 18-06 HTTP请求与URL访问

**知识点**
- HTTP 是应用层协议，基于 TCP，一次请求一次响应，服务端默认端口 80（HTTPS 443）。
- 请求方法：GET 把参数拼在 URL 后，POST 把参数放在请求体中；GET 有长度限制、会留在历史记录里。
- 状态码：200 成功、301/302 重定向、400 参数错误、404 资源不存在、500 服务器内部错误。
- `URL` 类表示统一资源定位符，`openStream()` 可以直接读取网页内容；`openConnection()` 返回 `HttpURLConnection` 可设置请求头、方法。
- `HttpURLConnection` 的 `setRequestMethod`、`setRequestProperty`、`getResponseCode`、`getInputStream` 是常用 API。
- 易错：读取 `getErrorStream()` 才能拿到 4xx/5xx 响应体；连接用完要 `disconnect()` 释放资源。

**示例代码**
```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.net.HttpURLConnection;
import java.net.URI;
import java.net.URL;
import java.nio.charset.StandardCharsets;

public class HttpDemo {
    public static void main(String[] args) {
        String urlStr = "https://www.example.com";
        HttpURLConnection conn = null;
        try {
            // JDK 20 起 URL 构造器已过时，推荐 URI.create(...).toURL()
            URL url = URI.create(urlStr).toURL();
            conn = (HttpURLConnection) url.openConnection();
            conn.setRequestMethod("GET");
            conn.setConnectTimeout(5000);  // 连接超时
            conn.setReadTimeout(5000);     // 读取超时
            conn.setRequestProperty("User-Agent", "Mozilla/5.0");

            int code = conn.getResponseCode();
            System.out.println("响应状态码：" + code);
            System.out.println("响应类型：" + conn.getContentType());

            if (code == 200) {
                try (BufferedReader reader = new BufferedReader(
                        new InputStreamReader(conn.getInputStream(), StandardCharsets.UTF_8))) {
                    String line;
                    int lineCount = 0;
                    while ((line = reader.readLine()) != null) {
                        lineCount++;
                        if (lineCount <= 10) {
                            System.out.println(line);
                        }
                    }
                    System.out.println("共读取 " + lineCount + " 行");
                }
            } else {
                System.out.println("请求失败，状态码：" + code);
            }
        } catch (Exception e) {
            System.out.println("请求异常：" + e.getMessage());
        } finally {
            if (conn != null) {
                conn.disconnect(); // 释放连接
            }
        }
    }
}
```
