# 第15章 集合框架

本章从"数组为什么不够用"出发，系统学习 Java 集合框架：先掌握 `Collection` 体系与 `List` 的两种实现，再用泛型让容器类型安全；随后弄清 `Set` 去重的底层依据、`Map` 的键值对操作与三种遍历方式，最后用 `Collections` 工具类和 Stream 流把集合操作写得更简洁。集合是后续 IO、多线程、JDBC 项目里出现频率最高的容器，必须练熟。

### 15-01 为什么需要集合

**知识点**
- 数组长度固定，创建后无法改变；集合长度可变，添加元素时自动扩容。
- 数组增删元素需要手动移动数据、自己维护有效元素个数，集合把这些操作封装成了方法。
- 集合只能存储引用数据类型（对象）；存 `int` 这类基本类型时会自动装箱成 `Integer`。
- 集合体系分两支：`Collection` 是单列集合顶层接口，`Map` 是双列（键值对）集合顶层接口。
- `Collection` 下又分 `List`（有序、可重复、有索引）和 `Set`（无序、不可重复、无索引）。
- 易错：`Collection` 是接口，`Collections` 是工具类，名字只差一个 s，作用完全不同。

**示例代码**
```java
import java.util.ArrayList;

public class CollectionDemo {
    public static void main(String[] args) {
        // 数组：长度固定，第 4 个元素放不进去
        int[] arr = new int[3];
        arr[0] = 10;
        arr[1] = 20;
        arr[2] = 30;
        System.out.println("数组长度：" + arr.length); // 3，永远是 3

        // 集合：长度可变，想加多少加多少
        ArrayList<String> list = new ArrayList<>();
        list.add("张三");
        list.add("李四");
        list.add("王五");
        list.add("赵六");
        System.out.println("集合元素：" + list);
        System.out.println("集合大小：" + list.size()); // 4，可以继续增长

        // 集合只能存引用类型，基本类型会自动装箱
        ArrayList<Integer> scores = new ArrayList<>();
        scores.add(90);      // 自动装箱为 Integer.valueOf(90)
        scores.add(85);
        int first = scores.get(0); // 自动拆箱为 int
        System.out.println("第一门成绩：" + first);
    }
}
```

### 15-02 Collection的常用方法

**知识点**
- `add(E e)` 添加元素，成功返回 `true`；`remove(Object o)` 删除指定元素，删除成功返回 `true`。
- `contains(Object o)` 判断是否包含某元素；`isEmpty()` 判断集合是否为空；`size()` 返回元素个数。
- `clear()` 清空集合；`toArray()` 把集合转成数组。
- 集合重写了 `toString`，直接打印集合名就能看到 `[元素1, 元素2]` 的内容。
- `List` 特有的 `remove(int index)` 与 `Collection` 的 `remove(Object o)` 重载，参数传 `int` 时删的是索引，不是元素。
- 易错：`contains` 和 `remove` 底层依赖 `equals`，自定义对象不重写 `equals` 时比较的是地址，往往判断不出来。

**示例代码**
```java
import java.util.ArrayList;
import java.util.Collection;

public class CollectionMethodDemo {
    public static void main(String[] args) {
        Collection<String> c = new ArrayList<>();
        System.out.println(c.add("Java"));      // true
        c.add("MySQL");
        c.add("JDBC");
        System.out.println("集合内容：" + c);    // [Java, MySQL, JDBC]
        System.out.println("元素个数：" + c.size());  // 3

        System.out.println("包含 Java 吗：" + c.contains("Java")); // true
        System.out.println("删除 MySQL：" + c.remove("MySQL"));    // true
        System.out.println("删除后：" + c);      // [Java, JDBC]

        System.out.println("是否为空：" + c.isEmpty()); // false
        Object[] arr = c.toArray();
        System.out.println("转数组后长度：" + arr.length); // 2

        c.clear();
        System.out.println("清空后：" + c + "，是否为空：" + c.isEmpty()); // []，true
    }
}
```

### 15-03 List接口与ArrayList

**知识点**
- `List` 有序（存入顺序就是取出顺序）、可重复、有索引，可以用下标访问元素。
- 特有方法：`add(int index, E e)` 指定位置插入、`get(int index)` 取元素、`set(int index, E e)` 修改并返回旧值、`remove(int index)` 按索引删除。
- `ArrayList` 底层是数组，查询快（按下标直接定位）、增删慢（要移动元素）。
- `ArrayList` 初始容量为 10，容量不够时按 1.5 倍扩容。
- 插入位置越界会抛 `IndexOutOfBoundsException`，合法范围是 `0 ~ size()`。
- 易错：`list.remove(1)` 删除的是索引 1 的元素；想删除元素 1 要写 `list.remove(Integer.valueOf(1))`。

**示例代码**
```java
import java.util.ArrayList;
import java.util.List;

public class ListDemo {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>();
        list.add("A");
        list.add("B");
        list.add("C");
        System.out.println("原始：" + list);       // [A, B, C]

        list.add(1, "X");                        // 在下标 1 处插入
        System.out.println("插入后：" + list);     // [A, X, B, C]

        System.out.println("下标 2 的元素：" + list.get(2)); // B
        String old = list.set(0, "AA");           // 修改并返回旧值
        System.out.println("被替换的旧值：" + old + "，现在：" + list);

        String removed = list.remove(1);          // 按索引删除，返回被删元素
        System.out.println("删掉的是：" + removed + "，剩下：" + list);

        // 基本类型包装类的坑：remove(1) 删索引，remove(Integer.valueOf(1)) 删元素
        List<Integer> nums = new ArrayList<>();
        nums.add(10);
        nums.add(20);
        nums.add(1);
        nums.remove(1);                           // 删索引 1，即 20
        System.out.println("remove(1) 之后：" + nums); // [10, 1]
        nums.remove(Integer.valueOf(1));          // 删元素 1
        System.out.println("按值删除后：" + nums);      // [10]
    }
}
```

### 15-04 List的遍历与并发修改异常

**知识点**
- 三种遍历方式：普通 for（有索引才能用）、增强 for（写法最简洁）、迭代器 `Iterator`。
- 迭代器的三个方法：`hasNext()` 判断还有没有元素、`next()` 取出下一个元素、`remove()` 删除刚取出的元素。
- 并发修改异常 `ConcurrentModificationException`：用集合自身的 `add`/`remove` 在遍历过程中改动集合，迭代器检测到"修改次数"不一致就会抛出。
- 解决办法：用迭代器自己的 `remove()`；或者用普通 for 倒序遍历删除；或者先收集要删的元素，遍历结束后统一删除。
- 增强 for 底层就是迭代器，所以增强 for 中调用集合的删除方法同样会抛异常。
- 易错：`for (String s : list) { list.remove(s); }` 是新手最常写出的崩溃代码。

**示例代码**
```java
import java.util.ArrayList;
import java.util.Iterator;
import java.util.List;

public class ListTraversalDemo {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>();
        list.add("张三");
        list.add("李四");
        list.add("王五");
        list.add("赵六");

        // 方式一：普通 for，靠索引
        for (int i = 0; i < list.size(); i++) {
            System.out.println("普通 for：" + list.get(i));
        }

        // 方式二：增强 for，底层是迭代器
        for (String name : list) {
            System.out.println("增强 for：" + name);
        }

        // 方式三：迭代器，遍历过程中删除元素必须用它自己的 remove
        Iterator<String> it = list.iterator();
        while (it.hasNext()) {
            String name = it.next();
            if ("李四".equals(name)) {
                it.remove(); // 安全删除，不会抛并发修改异常
            }
        }
        System.out.println("删除李四后：" + list); // [张三, 王五, 赵六]

        // 反向演示：普通 for 倒序遍历删除，同样安全
        List<Integer> nums = new ArrayList<>(List.of(1, 2, 3, 4, 5, 6));
        for (int i = nums.size() - 1; i >= 0; i--) {
            if (nums.get(i) % 2 == 0) {
                nums.remove(i);
            }
        }
        System.out.println("去掉偶数后：" + nums); // [1, 3, 5]
    }
}
```

**课后练习**

### 15-05 LinkedList与链表结构

**知识点**
- `LinkedList` 底层是双向链表，每个节点保存"前一个节点地址 + 数据 + 后一个节点地址"。
- 查询慢（要从头或从尾逐个找），增删快（只改相邻节点的指针，不移动数据）。
- 特有方法：`addFirst`/`addLast`、`getFirst`/`getLast`、`removeFirst`/`removeLast`，可以当栈或队列使用。
- `LinkedList` 实现了 `Deque` 接口，所以 `push`/`pop`/`offer`/`poll` 也能用。
- 选择建议：查询多用 `ArrayList`，频繁在头尾增删用 `LinkedList`；实际开发中 `ArrayList` 使用频率更高。
- 易错：对 `LinkedList` 用普通 for 加 `get(i)` 遍历，时间复杂度会退化成 O(n²)。

**示例代码**
```java
import java.util.LinkedList;

public class LinkedListDemo {
    public static void main(String[] args) {
        LinkedList<String> list = new LinkedList<>();
        list.add("B");
        list.addFirst("A");   // 头部添加
        list.addLast("D");    // 尾部添加
        list.add(2, "C");
        System.out.println("链表内容：" + list); // [A, B, C, D]

        System.out.println("第一个：" + list.getFirst()); // A
        System.out.println("最后一个：" + list.getLast()); // D
        System.out.println("删除第一个：" + list.removeFirst()); // A
        System.out.println("剩余：" + list);  // [B, C, D]

        // 当栈用：后进先出
        LinkedList<Integer> stack = new LinkedList<>();
        stack.push(1);
        stack.push(2);
        stack.push(3);
        System.out.println("出栈：" + stack.pop()); // 3
        System.out.println("栈内：" + stack);       // [2, 1]

        // 当队列用：先进先出
        LinkedList<String> queue = new LinkedList<>();
        queue.offer("第一个");
        queue.offer("第二个");
        queue.offer("第三个");
        System.out.println("出队：" + queue.poll()); // 第一个
        System.out.println("队列剩余：" + queue);     // [第二个, 第三个]
    }
}
```

### 15-06 泛型类与泛型方法

**知识点**
- 泛型就是把类型当成参数，写在尖括号里，使用时再指定具体类型，让编译器帮我们做类型检查。
- 泛型类：`class Box<T> { private T data; }`，创建对象时 `new Box<String>()` 指定 T 为 String。
- 泛型方法：`public <T> T getFirst(List<T> list)`，类型参数写在返回值前面。
- 好处：把运行期的 `ClassCastException` 提前到编译期发现，同时省去强制类型转换。
- 泛型只在编译期有效，编译后会被擦除（类型擦除），运行时看不到泛型信息。
- 易错：`new T()`、`new T[]()` 都不允许，因为运行时 T 已经被擦除了。

**示例代码**
```java
import java.util.ArrayList;
import java.util.List;

class Box<T> {
    private T data;

    public void set(T data) {
        this.data = data;
    }

    public T get() {
        return data;
    }
}

public class GenericDemo {
    public static void main(String[] args) {
        // 泛型类：同一个 Box 可以装不同类型，且类型安全
        Box<String> stringBox = new Box<>();
        stringBox.set("你好");
        String text = stringBox.get();   // 不需要强转
        System.out.println(text.length()); // 3

        Box<Integer> intBox = new Box<>();
        intBox.set(100);
        int number = intBox.get();
        System.out.println(number + 1);  // 101

        // 泛型方法：调用时由参数推断类型
        System.out.println(firstElement(List.of("A", "B", "C"))); // A
        System.out.println(firstElement(List.of(10, 20)));        // 10

        // 自己实现一个简单的泛型工具方法
        List<String> names = new ArrayList<>();
        names.add("张三");
        names.add("李四");
        System.out.println("最后一个：" + lastElement(names)); // 李四
    }

    public static <T> T firstElement(List<T> list) {
        if (list.isEmpty()) {
            return null;
        }
        return list.get(0);
    }

    public static <T> T lastElement(List<T> list) {
        if (list.isEmpty()) {
            return null;
        }
        return list.get(list.size() - 1);
    }
}
```

### 15-07 泛型通配符与上下限

**知识点**
- `?` 是无界通配符，表示"任意类型"，常用于只读场景，如 `void print(List<?> list)`。
- `? extends Number` 是上限通配符，表示 Number 或其子类（Integer、Double 等），只能读不能写。
- `? super Integer` 是下限通配符，表示 Integer 或其父类（Number、Object），可以写入。
- 记忆口诀：上限只读（生产者），下限只写（消费者）。
- 泛型不支持协变：`List<Integer>` 不是 `List<Number>` 的子类型，所以需要通配符来放宽。
- 易错：`List<Object> list = new ArrayList<String>()` 编译不通过，必须写 `List<?>` 或 `List<? extends Object>`。

**示例代码**
```java
import java.util.ArrayList;
import java.util.List;

public class GenericWildcardDemo {
    public static void main(String[] args) {
        List<Integer> ints = List.of(1, 2, 3);
        List<Double> doubles = List.of(1.5, 2.5);
        List<String> names = List.of("张三", "李四");

        printAll(ints);    // 无界通配符：什么集合都能传
        printAll(doubles);
        printAll(names);

        System.out.println("整数和：" + sum(ints));     // 6.0
        System.out.println("小数和：" + sum(doubles));  // 4.0
        // sum(names); // 编译报错：String 不是 Number 的子类

        List<Number> numbers = new ArrayList<>();
        addIntegers(numbers);  // 下限通配符：可以往里写 Integer
        System.out.println("写入后：" + numbers); // [10, 20]
    }

    // 无界通配符：只读遍历，最通用
    public static void printAll(List<?> list) {
        for (Object o : list) {
            System.out.print(o + " ");
        }
        System.out.println();
    }

    // 上限通配符：Number 及其子类，可以安全地当 Number 读
    public static double sum(List<? extends Number> list) {
        double total = 0;
        for (Number n : list) {
            total += n.doubleValue();
        }
        return total;
    }

    // 下限通配符：Integer 及其父类，可以安全地写入 Integer
    public static void addIntegers(List<? super Integer> list) {
        list.add(10);
        list.add(20);
    }
}
```

### 15-08 Set接口与HashSet去重原理

**知识点**
- `Set` 无序（不保证存取顺序）、不可重复、无索引，不能用普通 for 按下标遍历。
- `HashSet` 底层是哈希表（JDK8 起为数组 + 链表 + 红黑树），增删查平均时间复杂度接近 O(1)。
- 去重依据：先比 `hashCode()`，哈希值不同一定不是同一元素；哈希值相同再比 `equals()`，返回 `true` 才判定重复。
- 自定义对象要参与去重，必须同时重写 `hashCode()` 和 `equals()`，只重写一个会导致去重失效或性能退化。
- 存储过程：用 `hashCode` 经扰动函数算出下标 → 该位置为空直接放 → 有元素则用 `equals` 逐个比较。
- 易错：`HashSet` 的"无序"是指不保证顺序，不是随机；`LinkedHashSet` 才能保证插入顺序。

**示例代码**
```java
import java.util.HashSet;
import java.util.Objects;
import java.util.Set;

class Student {
    private String name;
    private int age;

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 参与去重必须重写 hashCode：属性相同则哈希值相同
    @Override
    public int hashCode() {
        return Objects.hash(name, age);
    }

    // equals 判断属性内容是否一致
    @Override
    public boolean equals(Object o) {
        if (this == o) {
            return true;
        }
        if (o == null || getClass() != o.getClass()) {
            return false;
        }
        Student student = (Student) o;
        return age == student.age && Objects.equals(name, student.name);
    }

    @Override
    public String toString() {
        return name + "(" + age + ")";
    }
}

public class HashSetDemo {
    public static void main(String[] args) {
        Set<String> set = new HashSet<>();
        set.add("Java");
        set.add("MySQL");
        set.add("Java");   // 重复元素，添加失败
        System.out.println("元素个数：" + set.size()); // 2
        System.out.println("内容：" + set);            // 顺序不保证

        // 自定义对象去重：重写 hashCode 与 equals 后属性相同即视为重复
        Set<Student> students = new HashSet<>();
        students.add(new Student("张三", 18));
        students.add(new Student("张三", 18)); // 被判定为重复
        students.add(new Student("李四", 20));
        System.out.println("学生人数：" + students.size()); // 2
        System.out.println(students);
    }
}
```

### 15-09 LinkedHashSet与TreeSet

**知识点**
- `LinkedHashSet` 继承 `HashSet`，底层在哈希表基础上额外维护一条双向链表，因此**存取顺序一致**。
- `TreeSet` 底层是红黑树，元素**自动排序**，增删查时间复杂度 O(log n)。
- `TreeSet` 排序规则：元素实现 `Comparable` 接口则用 `compareTo`；否则创建时传入 `Comparator`。
- `TreeSet` 判断重复用的是 `compareTo`/`compare` 返回 0，而不是 `equals`，返回值 0 的元素加不进去。
- 三种 Set 的选择：只要去重用 `HashSet`，要保留插入顺序用 `LinkedHashSet`，要排序用 `TreeSet`。
- 易错：向 `TreeSet` 添加没有实现 `Comparable` 且未传比较器的对象，会抛 `ClassCastException`。

**示例代码**
```java
import java.util.LinkedHashSet;
import java.util.Set;
import java.util.TreeSet;

public class SetOrderDemo {
    public static void main(String[] args) {
        // LinkedHashSet：存取顺序一致
        Set<String> linked = new LinkedHashSet<>();
        linked.add("C");
        linked.add("A");
        linked.add("B");
        linked.add("A"); // 重复，加不进去
        System.out.println("LinkedHashSet：" + linked); // [C, A, B]

        // TreeSet：自然排序（字符串按字典序）
        Set<String> tree = new TreeSet<>();
        tree.add("banana");
        tree.add("apple");
        tree.add("cherry");
        System.out.println("TreeSet 字典序：" + tree); // [apple, banana, cherry]

        // TreeSet 存自定义对象：必须给出比较规则
        TreeSet<Integer> scores = new TreeSet<>((a, b) -> b - a); // 降序
        scores.add(88);
        scores.add(95);
        scores.add(70);
        scores.add(88); // 比较结果为 0，视为重复
        System.out.println("降序成绩：" + scores); // [95, 88, 70]

        // 常用导航方法：first/last 按"排序规则"取首尾，降序规则下首元素就是最大值
        System.out.println("排序后第一个：" + scores.first()); // 95
        System.out.println("排序后最后一个：" + scores.last()); // 70
        System.out.println("比 90 小的元素：" + scores.headSet(90)); // [95]（按降序规则 95 排在 90 前）
    }
}
```

**课后练习**
1. 用 `LinkedHashSet` 去掉一段文字中的重复字符，并保持字符原本出现的顺序。
2. 用 `TreeSet` 对 8 个学生的成绩排序，分别按升序和降序输出。
3. 定义 `Person` 类（姓名、年龄），用 `TreeSet` 按年龄升序、年龄相同按姓名排序，输出全部对象。

### 15-10 Map接口与HashMap

**知识点**
- `Map<K, V>` 存储键值对，键唯一、值可重复，一个键对应一个值。
- 常用方法：`put(K, V)` 添加或覆盖（返回被覆盖的旧值）、`get(K)` 取值、`remove(K)` 删除、`containsKey`/`containsValue`。
- `size()` 返回键值对数量，`isEmpty()` 判断是否为空，`clear()` 清空。
- `put` 遇到已存在的键会覆盖旧值，并返回旧值；键不存在时返回 `null`。
- `HashMap` 底层与 `HashSet` 相同（哈希表），键的去重同样依赖 `hashCode` + `equals`。
- 易错：`Map` 不是 `Collection` 的子接口，不能用增强 for 直接遍历，必须先转成 `Set`。

**示例代码**
```java
import java.util.HashMap;
import java.util.Map;

public class HashMapDemo {
    public static void main(String[] args) {
        Map<String, Integer> scores = new HashMap<>();
        scores.put("张三", 90);
        scores.put("李四", 85);
        scores.put("王五", 78);
        System.out.println("原始：" + scores);

        // 键已存在：覆盖并返回旧值
        Integer old = scores.put("张三", 95);
        System.out.println("被覆盖的旧值：" + old);  // 90
        System.out.println("覆盖后：" + scores);

        // 键不存在时 put 返回 null
        System.out.println("新增赵六返回：" + scores.put("赵六", 60)); // null

        System.out.println("张三的成绩：" + scores.get("张三"));      // 95
        System.out.println("不存在的键：" + scores.get("钱七"));       // null
        System.out.println("包含李四吗：" + scores.containsKey("李四")); // true
        System.out.println("有 60 分吗：" + scores.containsValue(60));  // true

        System.out.println("删除李四：" + scores.remove("李四")); // 85
        System.out.println("键值对数量：" + scores.size());      // 3
        System.out.println("最终：" + scores);
    }
}
```

**课后练习**
1. 用 `HashMap<String, Integer>` 统计一个字符串中每个字符出现的次数，输出统计结果。
2. 用 `HashMap` 保存 5 个学生的姓名和成绩，找出成绩最高的学生并输出。
3. 编写方法 `merge(Map<String, Integer> map, String key, int value)`，若键已存在则累加值，否则新增键值对。

### 15-11 Map的遍历与嵌套集合

**知识点**
- 遍历方式一：`keySet()` 拿到所有键，再逐个 `get` 取值，适合需要键的场景。
- 遍历方式二：`entrySet()` 拿到所有键值对对象 `Map.Entry`，`getKey()`/`getValue()` 直接取值，效率最高。
- 遍历方式三：`forEach((k, v) -> ...)`，JDK8 的 Lambda 写法，代码最简洁。
- `Map.Entry` 是 `Map` 的静态内部接口，代表一个键值对。
- 嵌套集合：`Map<String, List<Student>>` 表示"班级 → 学生列表"，实际项目中非常常见。
- 易错：遍历 `entrySet` 时调用 `map.remove` 同样会抛并发修改异常，要删就用迭代器的 `remove`。

**示例代码**
```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class MapTraversalDemo {
    public static void main(String[] args) {
        Map<String, Integer> scores = new HashMap<>();
        scores.put("张三", 90);
        scores.put("李四", 85);
        scores.put("王五", 78);

        // 方式一：keySet 遍历键
        for (String name : scores.keySet()) {
            System.out.println(name + " = " + scores.get(name));
        }

        // 方式二：entrySet 遍历键值对，效率最高
        for (Map.Entry<String, Integer> entry : scores.entrySet()) {
            System.out.println(entry.getKey() + " -> " + entry.getValue());
        }

        // 方式三：Lambda 写法
        scores.forEach((k, v) -> System.out.println("forEach：" + k + " 考了 " + v));

        // 嵌套集合：班级 -> 学生姓名列表
        Map<String, List<String>> classes = new HashMap<>();
        List<String> classA = new ArrayList<>(List.of("张三", "李四"));
        List<String> classB = new ArrayList<>(List.of("王五", "赵六", "钱七"));
        classes.put("一班", classA);
        classes.put("二班", classB);

        for (Map.Entry<String, List<String>> entry : classes.entrySet()) {
            System.out.println(entry.getKey() + " 共 " + entry.getValue().size() + " 人：" + entry.getValue());
        }
    }
}
```

**课后练习**

2. 统计一段英文句子中每个单词出现的次数，按次数从高到低输出前 3 个单词。
3. 用 `Map<String, List<Integer>>` 保存每个学生的多门成绩，计算每个学生的平均分并输出。

### 15-12 TreeMap与比较器

**知识点**
- `TreeMap` 底层是红黑树，按键自动排序，遍历时输出顺序即为排序后的顺序。
- 排序依据：键实现 `Comparable` 用自然排序；否则在构造时传入 `Comparator`。
- `TreeMap` 判断键重复同样是看比较结果是否为 0，返回 0 的键会覆盖原值。
- `Comparable` 是"内部比较器"，类实现后只能有一种默认排序；`Comparator` 是"外部比较器"，可以随时传入不同规则。
- `Comparator` 常用静态方法：`comparing`、`thenComparing`、`reversed`、`nullsFirst`。
- 易错：`Comparator` 返回 `o1 - o2` 在数值极大时可能溢出，推荐写 `Integer.compare(o1, o2)`。

**示例代码**
```java
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;

class Employee {
    private String name;
    private int salary;

    public Employee(String name, int salary) {
        this.name = name;
        this.salary = salary;
    }

    public String getName() {
        return name;
    }

    public int getSalary() {
        return salary;
    }

    @Override
    public String toString() {
        return name + ":" + salary;
    }
}

public class TreeMapDemo {
    public static void main(String[] args) {
        // 键是 String，默认字典序
        Map<String, String> capitals = new TreeMap<>();
        capitals.put("shanghai", "上海");
        capitals.put("beijing", "北京");
        capitals.put("guangzhou", "广州");
        System.out.println("按 key 排序：" + capitals); // beijing, guangzhou, shanghai

        // 自定义比较器：按 key 长度排序，长度相同按字典序
        Map<String, String> byLength = new TreeMap<>(
                Comparator.comparingInt(String::length).thenComparing(Comparator.naturalOrder()));
        byLength.put("java", "语言");
        byLength.put("sql", "查询");
        byLength.put("jdbc", "连接");
        System.out.println("按长度排序：" + byLength);

        // 对象列表排序：多级比较器
        List<Employee> employees = new ArrayList<>();
        employees.add(new Employee("张三", 12000));
        employees.add(new Employee("李四", 15000));
        employees.add(new Employee("王五", 12000));
        employees.sort(Comparator.comparingInt(Employee::getSalary)
                .reversed()
                .thenComparing(Employee::getName));
        System.out.println("薪资降序：" + employees);
    }
}
```

**课后练习**
1. 用 `TreeMap` 保存学生姓名和成绩，分别按姓名和按成绩两种规则输出。
2. 定义 `Product` 类（名称、价格、销量），用 `Comparator` 实现"先按销量降序，销量相同按价格升序"。
3. 用 `TreeMap` 统计一段文字中各字符出现次数，并按字符升序输出结果。

### 15-13 Collections工具类与不可变集合

**知识点**
- `Collections` 是操作集合的工具类，方法全是静态的，位于 `java.util` 包。
- 常用方法：`sort(List)` 排序、`reverse(List)` 反转、`shuffle(List)` 随机打乱、`max`/`min` 求最值、`swap` 交换。
- `Collections.sort` 的第二种重载可以传 `Comparator` 自定义排序规则。
- 不可变集合：`List.of(...)`、`Set.of(...)`、`Map.of(...)`，创建后不能增删改，长度固定。
- 不可变集合好处：线程安全、可以放心共享；`List.of` 不允许 `null` 元素，重复元素会抛 `IllegalArgumentException`。
- 易错：`Collections.sort` 只能排序 `List`，不能排序 `Set`；不可变集合调用 `add` 会抛 `UnsupportedOperationException`。

**示例代码**
```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

public class CollectionsDemo {
    public static void main(String[] args) {
        List<Integer> nums = new ArrayList<>(List.of(5, 2, 9, 1, 7));

        Collections.sort(nums);                       // 升序
        System.out.println("升序：" + nums);           // [1, 2, 5, 7, 9]

        Collections.sort(nums, (a, b) -> b - a);      // 自定义降序
        System.out.println("降序：" + nums);           // [9, 7, 5, 2, 1]

        Collections.reverse(nums);
        System.out.println("反转：" + nums);           // [1, 2, 5, 7, 9]

        System.out.println("最大值：" + Collections.max(nums)); // 9
        System.out.println("最小值：" + Collections.min(nums)); // 1

        Collections.swap(nums, 0, 4);
        System.out.println("交换首尾：" + nums);        // [9, 2, 5, 7, 1]

        Collections.shuffle(nums);
        System.out.println("随机打乱：" + nums);

        // 不可变集合：创建后不能修改
        List<String> fruits = List.of("苹果", "香蕉", "橙子");
        System.out.println("不可变集合：" + fruits);
        try {
            fruits.add("西瓜"); // 抛异常
        } catch (UnsupportedOperationException e) {
            System.out.println("不可变集合不能添加元素");
        }
    }
}
```

**课后练习**
1. 创建一个含 10 个随机数的 `ArrayList`，用 `Collections` 完成排序、反转、打乱并分别输出。
2. 用 `List.of` 创建一周七天的不可变集合，尝试修改并捕获异常，输出提示信息。
3. 编写方法 `List<String> sortedNames(List<String> names)`，返回按长度升序排列的新列表，不修改原列表。

### 15-14 Stream流入门

**知识点**
- Stream 是 JDK8 引入的流式 API，用于对集合做"声明式"的批量处理，代码比循环更简洁。
- 三步走：获取流（`list.stream()`）→ 中间操作（`filter`、`map`、`sorted`、`limit`、`distinct`）→ 终结操作（`forEach`、`collect`、`count`、`sum`）。
- 中间操作是**惰性**的，只有遇到终结操作才会真正执行；一个流只能被消费一次，用完就失效。
- `filter` 过滤、`map` 映射转换、`sorted` 排序、`distinct` 去重、`limit`/`skip` 分页。
- `collect(Collectors.toList())` 收集成集合，`Collectors.groupingBy` 分组，`Collectors.joining` 拼接字符串。
- 易错：Stream 不修改原集合；把 `stream()` 的结果赋值给变量后重复使用会抛 `IllegalStateException`。

**示例代码**
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.stream.Collectors;

class Employee {
    private String name;
    private String dept;
    private int salary;

    public Employee(String name, String dept, int salary) {
        this.name = name;
        this.dept = dept;
        this.salary = salary;
    }

    public String getName() {
        return name;
    }

    public String getDept() {
        return dept;
    }

    public int getSalary() {
        return salary;
    }

    @Override
    public String toString() {
        return name + "(" + salary + ")";
    }
}

public class StreamDemo {
    public static void main(String[] args) {
        List<Employee> list = new ArrayList<>();
        list.add(new Employee("张三", "研发部", 15000));
        list.add(new Employee("李四", "研发部", 18000));
        list.add(new Employee("王五", "市场部", 12000));
        list.add(new Employee("赵六", "市场部", 13000));
        list.add(new Employee("钱七", "财务部", 11000));

        // 过滤 + 排序 + 输出
        list.stream()
                .filter(e -> e.getSalary() > 12000)
                .sorted((a, b) -> b.getSalary() - a.getSalary())
                .forEach(e -> System.out.println("高薪：" + e));

        // 映射：只取姓名，收集成列表
        List<String> names = list.stream()
                .map(Employee::getName)
                .collect(Collectors.toList());
        System.out.println("所有姓名：" + names);

        // 分组：按部门分组
        Map<String, List<Employee>> byDept = list.stream()
                .collect(Collectors.groupingBy(Employee::getDept));
        byDept.forEach((dept, emps) -> System.out.println(dept + " -> " + emps));

        // 统计：总人数、总薪资
        long count = list.stream().filter(e -> e.getSalary() >= 12000).count();
        int total = list.stream().mapToInt(Employee::getSalary).sum();
        System.out.println("薪资不低于 12000 的人数：" + count + "，总薪资：" + total);

        // 字符串拼接
        String joined = list.stream().map(Employee::getName).collect(Collectors.joining("、"));
        System.out.println("姓名拼接：" + joined);
    }
}
```

**课后练习**
1. 给定 `List<Integer>`，用 Stream 过滤出所有偶数、平方后去重、按降序输出前 5 个。
2. 给定 `List<String>`，用 Stream 过滤长度大于 3 的字符串，转成大写并收集到新列表。
3. 给定员工列表，用 Stream 按部门分组统计各部门的平均薪资，并输出结果。

### 综合题：学生成绩多维分析

**场景**

给定一批学生的姓名、班级、三科成绩，用集合完成：按班级分组、按总分排名、去重同名学生、用 Stream 做一次统计，最后输出一份分析报告。

**任务**
1. 用 List<Student> 存数据，用 Map<String, List<Student>> 按班级分组，遍历输出每组人数与平均总分。
2. 用 TreeSet 或排序把学生按总分降序排列，总分相同时按姓名升序，说明比较器怎么写才稳定。
3. 用 HashSet 演示去重：同名同班视为重复，重写 equals 与 hashCode，并验证重写前后去重效果差异。
4. 用 Stream 完成一次链式统计：过滤总分及格 → 按班级分组 → 求每组最高分学生 → 收集成 Map 输出。

**验收清单**
- [ ] 分组结果人数之和等于学生总数，没有遗漏也没有重复计入。
- [ ] 排名结果在总分相同的情况下顺序稳定可复现。
- [ ] 重写 equals/hashCode 后 HashSet 能正确去重，注释说明两者必须同时重写。
- [ ] Stream 链式写法没有副作用，中间操作与终端操作职责清晰。
