# 第19章 反射与注解

本章学习 Java 的"自省"能力：反射让程序在运行时查看和操作类的结构，是框架（Spring、MyBatis）的底层基石；注解则是给代码打标记，配合反射实现"配置即代码"。掌握这两者，才能看懂框架源码、写出通用工具。

### 19-01 反射入门与获取Class对象

**知识点**
- 反射：在程序**运行期间**动态获取类的信息（成员变量、方法、构造器）并操作对象的机制。
- 正射是"先有类再 new 对象"，反射是"先拿到 Class 对象，再反向创建对象、调用方法"。
- 获取 Class 对象的三种方式：`类名.class`、`对象.getClass()`、`Class.forName("全限定类名")`。
- `Class.forName` 会触发类加载和静态代码块执行，是框架最常用的方式（配置文件中写类名）。
- 同一个类在 JVM 中只有一个 Class 对象，三种方式拿到的都是同一个。
- 易错：`Class.forName` 的类名必须是**全限定名**（含包名），写错会抛 `ClassNotFoundException`。

**示例代码**
```java
class Person {
    static {
        System.out.println("Person 类的静态代码块执行了");
    }

    private String name = "张三";

    public void sayHello() {
        System.out.println("你好，我是" + name);
    }
}

public class ReflectBasicDemo {
    public static void main(String[] args) throws Exception {
        // 方式一：类名.class
        Class<Person> c1 = Person.class;

        // 方式二：对象.getClass()
        Person p = new Person();
        Class<? extends Person> c2 = p.getClass();

        // 方式三：Class.forName（传入全限定类名，会触发类加载）
        // 这里用 getName() 动态取全限定名，避免把包名和类名写死在字符串里
        Class<?> c3 = Class.forName(Person.class.getName());

        System.out.println("三种方式是否同一个对象：" + (c1 == c2) + "，" + (c1 == c3));
        System.out.println("类名：" + c1.getName());
        System.out.println("简单类名：" + c1.getSimpleName());
        System.out.println("包名：" + c1.getPackageName());
        System.out.println("是否是接口：" + c1.isInterface());
        System.out.println("父类：" + c1.getSuperclass().getName());

        // 通过 Class 对象反向创建实例
        Object obj = c1.getDeclaredConstructor().newInstance();
        System.out.println("反射创建的对象：" + obj.getClass().getSimpleName());
    }
}
```

**课后练习**
1. 用三种方式分别获取 `String` 类的 Class 对象，比较它们是否相等并打印类名、包名。
2. 用 `Class.forName` 加载自己写的一个类，观察它的静态代码块是否执行，并解释原因。
3. 编写方法 `boolean isSameClass(Object a, Object b)`，用反射判断两个对象的类型是否完全一致。

### 19-02 获取构造方法并创建对象

**知识点**
- `getConstructors()` 获取所有 **public** 构造器；`getDeclaredConstructors()` 获取全部（含私有）。
- `getConstructor(Class... params)` 按参数类型获取指定 public 构造器；`getDeclaredConstructor` 对应全部。
- `newInstance(Object... args)` 用构造器创建对象，参数类型和个数必须与构造器匹配。
- 私有构造器需要 `setAccessible(true)` 取消访问检查才能使用（暴力反射）。
- 无参构造器可以直接用 `class对象.newInstance()`（已过时），推荐 `getDeclaredConstructor().newInstance()`。
- 易错：用 `getConstructor` 找私有构造器会抛 `NoSuchMethodException`，要用 `getDeclaredConstructor`。

**示例代码**
```java
import java.lang.reflect.Constructor;

class Student {
    private String name;
    private int age;

    public Student() {
        System.out.println("无参构造器执行");
    }

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
        System.out.println("有参构造器执行：" + name + ", " + age);
    }

    private Student(String name) {
        this.name = name;
        System.out.println("私有构造器执行：" + name);
    }

    @Override
    public String toString() {
        return "Student{name='" + name + "', age=" + age + "}";
    }
}

public class ReflectConstructorDemo {
    public static void main(String[] args) throws Exception {
        Class<Student> clazz = Student.class;

        // 获取所有 public 构造器
        System.out.println("public 构造器数量：" + clazz.getConstructors().length);
        System.out.println("全部构造器数量（含私有）：" + clazz.getDeclaredConstructors().length);

        // 用无参构造器创建对象
        Student s1 = clazz.getDeclaredConstructor().newInstance();
        System.out.println(s1);

        // 用有参构造器创建对象
        Constructor<Student> ctor = clazz.getConstructor(String.class, int.class);
        Student s2 = ctor.newInstance("李四", 20);
        System.out.println(s2);

        // 私有构造器：暴力反射
        Constructor<Student> privateCtor = clazz.getDeclaredConstructor(String.class);
        privateCtor.setAccessible(true); // 取消访问权限检查
        Student s3 = privateCtor.newInstance("王五");
        System.out.println(s3);
    }
}
```

**课后练习**
1. 定义一个含无参、有参、私有三种构造器的类，用反射分别通过三种构造器创建对象。
2. 编写方法 `Object create(String className, Object... args)`，根据类名和参数反射创建对象。
3. 说明 `setAccessible(true)` 的作用和风险，以及在什么场景下需要用它。

### 19-03 获取成员变量并赋值

**知识点**
- `getFields()` 获取所有 public 字段（含继承的）；`getDeclaredFields()` 获取本类全部字段（含私有）。
- `getField(String name)` / `getDeclaredField(String name)` 按名字获取指定字段。
- `set(Object obj, Object value)` 给字段赋值；`get(Object obj)` 取出字段值。
- 私有字段同样需要 `setAccessible(true)` 才能读写。
- `Field.getType()` 返回字段类型，`getName()` 返回字段名，`getModifiers()` 返回修饰符。
- 易错：静态字段赋值时 `set` 的第一个参数可以传 `null`；实例字段传 `null` 会抛 `NullPointerException`。

**示例代码**
```java
import java.lang.reflect.Field;

class User {
    public String username;
    private String password;
    private int age;
    private static String systemName = "学习系统";

    public User(String username, String password, int age) {
        this.username = username;
        this.password = password;
        this.age = age;
    }

    @Override
    public String toString() {
        return "User{username='" + username + "', password='" + password
                + "', age=" + age + ", system=" + systemName + "}";
    }
}

public class ReflectFieldDemo {
    public static void main(String[] args) throws Exception {
        Class<User> clazz = User.class;
        User user = new User("zhangsan", "123456", 18);

        // 获取所有字段
        System.out.println("本类全部字段：");
        for (Field f : clazz.getDeclaredFields()) {
            System.out.println("  " + f.getName() + " : " + f.getType().getSimpleName());
        }

        // 读写 public 字段
        Field username = clazz.getField("username");
        System.out.println("原用户名：" + username.get(user));
        username.set(user, "lisi");
        System.out.println("修改后：" + username.get(user));

        // 读写 private 字段：需要暴力反射
        Field password = clazz.getDeclaredField("password");
        password.setAccessible(true);
        System.out.println("原密码：" + password.get(user));
        password.set(user, "abc888");
        System.out.println("修改后：" + password.get(user));

        // 静态字段：对象参数传 null
        Field systemName = clazz.getDeclaredField("systemName");
        systemName.setAccessible(true);
        System.out.println("静态字段原值：" + systemName.get(null));
        systemName.set(null, "反射系统");
        System.out.println("静态字段新值：" + systemName.get(null));

        System.out.println("最终对象：" + user);
    }
}
```

**课后练习**
1. 用反射获取一个类的全部字段，输出每个字段的名称、类型和修饰符。
2. 编写方法 `void setField(Object obj, String fieldName, Object value)`，通过反射给指定字段赋值（支持私有字段）。
3. 用反射把所有 `String` 类型的字段值替换成"***"，实现简单的脱敏工具。

### 19-04 获取成员方法并调用

**知识点**
- `getMethods()` 获取所有 public 方法（含父类）；`getDeclaredMethods()` 获取本类全部方法（含私有）。
- `getMethod(String name, Class... params)` 按方法名和参数类型获取指定 public 方法。
- `invoke(Object obj, Object... args)` 调用方法，返回值是方法的返回结果；静态方法 obj 传 `null`。
- 私有方法需要 `setAccessible(true)`；`Method.getName()`、`getParameterTypes()`、`getReturnType()` 用于获取方法信息。
- 反射调用方法的性能低于直接调用，频繁调用场景应缓存 `Method` 对象。
- 易错：`invoke` 参数类型必须匹配，传 `Integer` 给 `int` 形参会自动拆箱，但传 `null` 给基本类型会抛异常。

**示例代码**
```java
import java.lang.reflect.Method;

class Calculator {
    public int add(int a, int b) {
        return a + b;
    }

    public String greet(String name) {
        return "你好，" + name;
    }

    private double secret(double x) {
        return x * x;
    }

    public static void staticInfo() {
        System.out.println("这是一个静态方法");
    }
}

public class ReflectMethodDemo {
    public static void main(String[] args) throws Exception {
        Class<Calculator> clazz = Calculator.class;
        Calculator calc = new Calculator();

        // 获取所有 public 方法（包含 Object 继承来的）
        System.out.println("public 方法数量：" + clazz.getMethods().length);
        System.out.println("本类声明的方法数量：" + clazz.getDeclaredMethods().length);

        // 调用 public 方法
        Method add = clazz.getMethod("add", int.class, int.class);
        Object result = add.invoke(calc, 10, 20);
        System.out.println("add 结果：" + result);
        System.out.println("返回值类型：" + add.getReturnType().getSimpleName());
        System.out.println("参数个数：" + add.getParameterCount());

        Method greet = clazz.getMethod("greet", String.class);
        System.out.println("greet 结果：" + greet.invoke(calc, "张三"));

        // 调用私有方法
        Method secret = clazz.getDeclaredMethod("secret", double.class);
        secret.setAccessible(true);
        System.out.println("私有方法结果：" + secret.invoke(calc, 3.0));

        // 调用静态方法：obj 传 null
        Method staticInfo = clazz.getMethod("staticInfo");
        staticInfo.invoke(null);
    }
}
```

**课后练习**
1. 用反射调用 `String` 类的 `length`、`substring`、`toUpperCase` 方法，输出调用结果。
2. 编写方法 `Object call(Object obj, String methodName, Object... args)`，按方法名动态调用方法并返回结果。
3. 用反射统计一个类中所有 public 方法的数量，并列出方法名和参数个数。

### 19-05 反射综合案例

**知识点**
- 反射最常见的应用：把配置文件/数据库中的"属性名 → 属性值"自动填充到对象中（对象映射）。
- 通用套路：读取 Map/Properties → 遍历键值 → `getDeclaredField` 找到字段 → `setAccessible` → `set`。
- 反射 + 泛型：`<T> T mapToObject(Map<String, Object> data, Class<T> clazz)` 是 ORM 框架的雏形。
- 反射可以突破封装，但会破坏类型安全，业务代码应尽量少用，框架内部才大量使用。
- 反射的性能开销主要来自方法查找和访问检查，缓存 `Class`/`Method`/`Field` 可以显著提升。
- 易错：字段名大小写必须与 Map 的 key 完全一致，否则找不到字段。

**示例代码**
```java
import java.lang.reflect.Field;
import java.util.HashMap;
import java.util.Map;

class Book {
    private String title;
    private String author;
    private double price;
    private int stock;

    @Override
    public String toString() {
        return "Book{title='" + title + "', author='" + author
                + "', price=" + price + ", stock=" + stock + "}";
    }
}

public class ReflectMappingDemo {
    public static void main(String[] args) throws Exception {
        Map<String, Object> data = new HashMap<>();
        data.put("title", "Java 编程思想");
        data.put("author", "Bruce Eckel");
        data.put("price", 108.0);
        data.put("stock", 30);

        // 把 Map 自动映射成对象
        Book book = mapToObject(data, Book.class);
        System.out.println(book);

        // 把对象自动转回 Map
        Map<String, Object> back = objectToMap(book);
        System.out.println("转回 Map：" + back);

        // 反射执行 getter：打印所有以 get 开头的方法返回值
        System.out.println("---- 反射调用 getter ----");
        printGetters(book);
    }

    // 通用映射：Map -> 对象
    public static <T> T mapToObject(Map<String, Object> data, Class<T> clazz) throws Exception {
        T obj = clazz.getDeclaredConstructor().newInstance();
        for (Map.Entry<String, Object> entry : data.entrySet()) {
            try {
                Field field = clazz.getDeclaredField(entry.getKey());
                field.setAccessible(true);
                field.set(obj, convert(field.getType(), entry.getValue()));
            } catch (NoSuchFieldException e) {
                System.out.println("字段不存在，忽略：" + entry.getKey());
            }
        }
        return obj;
    }

    // 通用映射：对象 -> Map
    public static Map<String, Object> objectToMap(Object obj) throws Exception {
        Map<String, Object> map = new HashMap<>();
        for (Field field : obj.getClass().getDeclaredFields()) {
            field.setAccessible(true);
            map.put(field.getName(), field.get(obj));
        }
        return map;
    }

    // 简单类型转换
    private static Object convert(Class<?> type, Object value) {
        if (value == null) {
            return null;
        }
        String s = value.toString();
        if (type == int.class || type == Integer.class) {
            return Integer.parseInt(s);
        }
        if (type == double.class || type == Double.class) {
            return Double.parseDouble(s);
        }
        if (type == long.class || type == Long.class) {
            return Long.parseLong(s);
        }
        if (type == boolean.class || type == Boolean.class) {
            return Boolean.parseBoolean(s);
        }
        return value;
    }

    private static void printGetters(Object obj) throws Exception {
        for (java.lang.reflect.Method m : obj.getClass().getDeclaredMethods()) {
            if (m.getName().startsWith("get") && m.getParameterCount() == 0) {
                m.setAccessible(true);
                System.out.println(m.getName() + "() = " + m.invoke(obj));
            }
        }
    }
}
```

**课后练习**
1. 读取一个 `Properties` 配置文件，用反射把其中的键值自动填充到一个 JavaBean 对象中。
2. 编写通用方法 `void printObject(Object obj)`，用反射打印对象的所有字段名和字段值（不依赖 toString）。
3. 说明反射为什么能"突破封装"，并举例说明框架中哪些功能依赖反射实现。

### 19-06 注解的定义与使用

**知识点**
- 注解（Annotation）是 JDK5 引入的元数据，用 `@注解名` 标记在类、方法、字段、参数上，本身不影响程序逻辑。
- 定义注解：`public @interface MyAnnotation { String value() default ""; int count() default 1; }`。
- 元注解用于修饰注解：`@Target` 指定作用位置，`@Retention` 指定保留阶段，`@Documented`、`@Inherited`。
- `@Retention` 三档：`SOURCE`（源码，编译丢弃）、`CLASS`（默认，保留到 class 文件）、`RUNTIME`（运行时，可被反射读取）。
- 注解属性类型只能是基本类型、String、Class、枚举、注解以及它们的数组。
- 易错：只有 `RetentionPolicy.RUNTIME` 的注解才能通过反射读取，写框架时最常犯的错就是漏写这一项。

**示例代码**
```java
import java.lang.annotation.Documented;
import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;
import java.lang.reflect.Method;

// 自定义注解：运行时保留，作用于方法
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
@interface LogInfo {
    String value() default "";        // 默认属性，使用时可省略属性名

    int level() default 1;

    String[] tags() default {};
}

class OrderService {
    @LogInfo(value = "创建订单", level = 2, tags = {"order", "create"})
    public void createOrder(String orderId) {
        System.out.println("创建订单：" + orderId);
    }

    @LogInfo("查询订单")
    public void queryOrder(String orderId) {
        System.out.println("查询订单：" + orderId);
    }

    public void noAnnotation() {
        System.out.println("没有注解的方法");
    }
}

public class AnnotationDemo {
    public static void main(String[] args) throws Exception {
        Class<OrderService> clazz = OrderService.class;
        for (Method m : clazz.getDeclaredMethods()) {
            // 判断方法上是否有指定注解
            if (m.isAnnotationPresent(LogInfo.class)) {
                LogInfo info = m.getAnnotation(LogInfo.class);
                System.out.println("方法：" + m.getName()
                        + "，描述：" + info.value()
                        + "，级别：" + info.level()
                        + "，标签：" + String.join(",", info.tags()));
            } else {
                System.out.println("方法：" + m.getName() + "，无注解");
            }
        }
    }
}
```

**课后练习**
1. 定义一个 `@Author(name, date)` 注解，标注在类和方法上，用反射读取并打印注解信息。
2. 定义一个 `@Range(min, max)` 注解用于校验数值字段，编写方法检查对象的字段值是否在范围内。
3. 说明 `@Retention(RetentionPolicy.SOURCE/CLASS/RUNTIME)` 三者的区别，并指出 Spring 的 `@Autowired` 属于哪一种。

### 19-07 反射+注解综合案例

**知识点**
- 反射 + 注解是框架实现"声明式编程"的核心：注解负责标记意图，反射负责执行逻辑。
- 典型应用：简易测试框架（`@Test`）、参数校验（`@NotNull`、`@Range`）、依赖注入（`@Inject`）、接口文档（`@ApiOperation`）。
- 实现套路：遍历类的字段/方法 → `isAnnotationPresent` 判断注解 → 读取注解属性 → 执行对应逻辑。
- 注解在运行时通过 `getAnnotation` 拿到的是 JDK 动态生成的代理对象，属性值由方法调用返回。
- 这套机制让业务代码保持干净，校验/日志/事务等横切逻辑被"织入"。
- 易错：注解本身不执行任何逻辑，必须配合反射（或注解处理器）才能产生效果。

**示例代码**
```java
import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;
import java.lang.reflect.Field;
import java.util.ArrayList;
import java.util.List;

// 校验注解：不能为空
@Target(ElementType.FIELD)
@Retention(RetentionPolicy.RUNTIME)
@interface NotNull {
    String message() default "不能为空";
}

// 校验注解：数值范围
@Target(ElementType.FIELD)
@Retention(RetentionPolicy.RUNTIME)
@interface Range {
    int min() default Integer.MIN_VALUE;

    int max() default Integer.MAX_VALUE;

    String message() default "超出范围";
}

class RegisterForm {
    @NotNull(message = "用户名不能为空")
    private String username;

    @NotNull(message = "密码不能为空")
    private String password;

    @Range(min = 1, max = 120, message = "年龄必须在 1~120 之间")
    private int age;

    public RegisterForm(String username, String password, int age) {
        this.username = username;
        this.password = password;
        this.age = age;
    }
}

public class ValidationDemo {
    public static void main(String[] args) throws Exception {
        // 合法数据
        System.out.println("---- 合法对象 ----");
        validate(new RegisterForm("张三", "123456", 25));

        // 非法数据
        System.out.println("---- 非法对象 ----");
        validate(new RegisterForm(null, "", 200));
    }

    // 通用校验器：反射读取注解并检查
    public static List<String> validate(Object obj) throws Exception {
        List<String> errors = new ArrayList<>();
        Class<?> clazz = obj.getClass();
        for (Field field : clazz.getDeclaredFields()) {
            field.setAccessible(true);
            Object value = field.get(obj);

            if (field.isAnnotationPresent(NotNull.class)) {
                NotNull notNull = field.getAnnotation(NotNull.class);
                if (value == null || value.toString().isBlank()) {
                    errors.add(field.getName() + "：" + notNull.message());
                }
            }

            if (field.isAnnotationPresent(Range.class) && value instanceof Integer) {
                Range range = field.getAnnotation(Range.class);
                int v = (Integer) value;
                if (v < range.min() || v > range.max()) {
                    errors.add(field.getName() + "：" + range.message() + "（当前 " + v + "）");
                }
            }
        }

        if (errors.isEmpty()) {
            System.out.println("校验通过");
        } else {
            errors.forEach(e -> System.out.println("校验失败 -> " + e));
        }
        return errors;
    }
}
```

**课后练习**

## 本章综合练习

### 综合题：迷你依赖注入容器与校验框架

**场景**

用反射 + 注解手写两个小框架：一个能扫描类、读取注解、创建对象并注入字段的迷你容器；一个能读取字段上的校验注解并在运行时拦截非法值的校验器。

**任务**
1. 自定义 @Component 与 @Inject 注解，用反射扫描指定包下的类，实例化带 @Component 的类并按类型注入带 @Inject 的字段。
2. 自定义 @NotNull、@MaxLength 注解，写一个 validate(Object) 方法，反射读取字段值与注解参数，收集全部错误信息后一次性返回。
3. 通过反射调用私有方法、修改私有字段，并说明 setAccessible(true) 的作用与风险。
4. 在 main 中定义两个互相依赖的类，验证注入成功；再故意注入一个不存在的类型，观察并处理异常。

**验收清单**
- [ ] 容器能创建对象并把依赖注入进去，注入后调用方法输出正确结果。
- [ ] 校验器一次能返回多条错误，而不是遇到第一条就中断。
- [ ] 非法值被拦截，合法值全部通过，注解参数（如 max）真实生效。
- [ ] 注入失败时抛出有明确信息的异常，不出现 NullPointerException。
