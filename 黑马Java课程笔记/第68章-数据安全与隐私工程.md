# 第68章 数据安全与隐私工程

第36章防的是"外部攻击导致泄露"，本章管的是"系统内部对数据的合法使用"——即使没有黑客，超范围使用也是违规。隐私工程是"把法律要求翻译成技术控制"：分类分级知道哪些敏感，脱敏降低可见精度，加密与密钥管理做静态保护，行列权限与审计管谁能看、看了什么，最后还要能删得干净。本章按「隐私工程全景 → 分类分级 → 静态与动态脱敏 → 加密与密钥管理 → 行列级权限 → 出境与本地化 → 差分隐私 → 联邦学习 → 审计与可追溯 → 删除与遗忘权 → 全生命周期治理案例」的顺序讲。所有示例仍是纯 JDK：分级字典与自动识别、六种脱敏算法、AES-GCM 与信封加密及密钥轮换、行列权限矩阵、出境评估、拉普拉斯机制与隐私预算、FedAvg 聚合、哈希链审计与篡改检测、全链路删除与加密擦除全部真实运行。

### 68-01 隐私工程全景：从合规到技术

**知识点**
- **隐私工程是"把法律要求翻译成技术控制"**：GDPR/《个人信息保护法》要求"最小必要、告知同意、可删除、可携带、不泄露"——**每一条都要落到代码与流程上**，否则就是纸面合规（52 章门禁思想）。
- **五项核心原则**：**最小必要**（只采集业务必需的数据）、**目的限定**（采集时的用途不能挪作他用）、**默认保护**（默认脱敏/默认不采集）、**全生命周期**（采集/传输/存储/使用/共享/销毁）、**可问责**（每一步有审计 68-09）。
- **隐私 vs 安全**：**安全**防"外部攻击导致泄露"（36 章）；**隐私**管"系统内部对数据的合法使用"——**即使没有黑客，超范围使用也是违规**。两者技术有重叠（加密/权限/审计）但目标不同。
- **四类技术手段**：**分类分级**（68-02，知道哪些数据敏感）、**脱敏**（68-03，降低可见精度）、**加密与密钥管理**（68-04，静态保护）、**访问控制与审计**（68-05/68-09，谁能看、看了什么）。
- **与 55/67 章的关系**：55-10 讲 SaaS 合规（多租户边界）、67-10 讲位置隐私（敏感数据子集）——**本章是通用框架**，把散落的合规要求体系化。
- 易错点：把隐私当"加个脱敏函数"（是全生命周期治理）；只在展示层脱敏（导出/日志/下游仍然泄露）；无数据清单（不知道有哪些敏感数据）；合规文档与实现不一致。

### 68-02 数据分类分级

**知识点**
- **分类分级是一切隐私工作的起点**：不知道"哪些数据敏感"，脱敏/权限/审计都无从下手——**分级结果决定后续所有控制强度**。
- **分类（按业务属性）与分级（按敏感程度）是两件事**：分类如"用户身份/交易/行为/设备"；分级通常四级：**公开（L1）/内部（L2）/敏感（L3）/高敏（L4）**——**《个人信息保护法》的"敏感个人信息"对应 L3/L4**（身份证、生物识别、行踪、健康、金融账户）。
- **分级的影响字段**：**保留期**（L4 最短）、**加密要求**（L3/L4 必加密）、**访问审批**（L4 需二次审批）、**脱敏策略**（L3 展示脱敏、L4 默认不可见）、**出境**（L4 禁止）、**审计粒度**（L4 每次访问留痕）。
- **分级的落地形态**：**数据字典标注**（字段级 `level` 元数据）+ **自动识别**（正则识别手机号/身份证，扫描存量表）+ **动态标注**（新建字段必须声明级别，CI 校验 46-08 契约思想）。
- **与 46/55 章的衔接**：分级结果进元数据目录（46-04）；多租户场景下分级与租户隔离叠加（55-04）。
- 易错点：只分"敏感/不敏感"两级（控制粒度不够）；分级只做一次（新字段不标注）；分级结果不落元数据（无法自动化）；把"脱敏后"的数据重新定为低级别（脱敏可逆则不可降级）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.regex.Pattern;

public class DataClassification {
    enum Level {
        L1_PUBLIC, L2_INTERNAL, L3_SENSITIVE, L4_HIGH
    }

    record Field(String table, String column, String category, Level level) {
        String control() {
            return switch (level) {
                case L1_PUBLIC -> "无特殊控制";
                case L2_INTERNAL -> "登录可见 + 常规日志";
                case L3_SENSITIVE -> "加密存储 + 展示脱敏 + 访问审计";
                case L4_HIGH -> "加密 + 默认不可见 + 双人审批 + 禁止出境";
            };
        }
    }

    static final List<Field> dictionary = new ArrayList<>();

    static void register() {
        dictionary.add(new Field("user", "phone", "用户身份", Level.L3_SENSITIVE));
        dictionary.add(new Field("user", "id_card", "用户身份", Level.L4_HIGH));
        dictionary.add(new Field("user", "nickname", "用户身份", Level.L1_PUBLIC));
        dictionary.add(new Field("order", "amount", "交易", Level.L2_INTERNAL));
        dictionary.add(new Field("order", "address", "用户身份", Level.L3_SENSITIVE));
        dictionary.add(new Field("location", "lat_lng", "行踪轨迹", Level.L4_HIGH));
        System.out.println("【数据字典（字段级分级）】");
        dictionary.forEach(f -> System.out.printf("  %-8s.%-10s %-8s %-14s %s%n",
                f.table(), f.column(), f.category(), f.level(), f.control()));
        System.out.println();
    }

    /** 自动识别：正则扫描未标注字段（存量治理） */
    static void autoDetect(List<String[]> samples) {
        Pattern phone = Pattern.compile("^1[3-9]\\d{9}$");
        Pattern idCard = Pattern.compile("^\\d{17}[\\dXx]$");
        System.out.println("【自动识别敏感字段】");
        for (String[] s : samples) {
            String level = "未识别";
            if (phone.matcher(s[1]).matches()) {
                level = "L3（手机号）";
            } else if (idCard.matcher(s[1]).matches()) {
                level = "L4（身份证）";
            }
            System.out.printf("  %-20s 样例=%-12s -> %s%n", s[0], mask(s[1]), level);
        }
        System.out.println();
    }

    static String mask(String v) {
        if (v == null || v.length() <= 4) {
            return "***";
        }
        return v.substring(0, 2) + "***" + v.substring(v.length() - 2);
    }

    static void governance() {
        System.out.println("【分级治理机制】");
        Map<String, String> rules = new LinkedHashMap<>();
        rules.put("新建字段必声明", "DDL 评审时必须在字典登记级别（CI 校验）");
        rules.put("存量扫描", "正则识别 + 人工复核，补齐历史字段");
        rules.put("脱敏不可逆原则", "脱敏后的数据不能降级（可逆脱敏等同明文）");
        rules.put("定期复核", "季度复审分级，业务变化可能改变敏感度");
        rules.forEach((k, v) -> System.out.printf("  %-12s %s%n", k, v));
    }

    public static void main(String[] args) {
        register();
        autoDetect(List.of(
                new String[]{"user.phone", "13800001234"},
                new String[]{"user.id_card", "110101199001011234"},
                new String[]{"user.nickname", "小明"},
                new String[]{"order.remark", "随便写"}));
        governance();
    }
}
```

### 68-03 静态脱敏与动态脱敏

**知识点**
- **静态脱敏（SDM）**：**数据落地前/复制时脱敏**（生产 -> 测试环境的数据导出、数据共享给第三方）——脱敏后的数据**永久不可还原**，用于"非生产环境"与"对外共享"。
- **动态脱敏（DDM）**：**查询时按访问者身份实时脱敏**（同一张表，客服看到 `138****1234`，风控看到全量）——**原数据不变，视图因人而异**，用于"生产环境内的差异化访问"。
- **脱敏算法的六种**：**掩码**（保留首尾，中间 `*`）、**替换**（用假名/字典映射）、**截断**（只留前 N 位）、**泛化**（年龄 28 -> "20-30"）、**哈希**（不可逆，用于关联分析）、**加噪**（数值扰动，68-07 差分隐私的基础）——**按用途选算法**（要关联分析用哈希/假名，要展示用掩码）。
- **脱敏不可逆与可关联的取舍**：**掩码/截断**不可关联（同一手机号每次掩码相同但无法 join）；**假名化**（`user_8f3a2b`）既可关联又不泄露——**跨表分析需要假名化而非掩码**。
- **动态脱敏的实现位置**：**代理层**（数据库代理改写结果集）、**应用层**（DAO 拦截器 23 章插件）、**视图层**（数据库视图 + 权限）——**应用层最灵活**（能按业务上下文判断）。
- 易错点：测试环境用生产数据未脱敏（最常见的泄露）；只脱敏手机号忘了地址/身份证；掩码规则可逆（保留位数太多可反推）；脱敏字段参与 join 失败（掩码后无法关联，应假名化）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class DataMasking {
    enum Algorithm {
        MASK, TRUNCATE, GENERALIZE, PSEUDONYMIZE, HASH
    }

    record Rule(String field, Algorithm algorithm, String note) {
    }

    static final List<Rule> rules = new ArrayList<>();

    static {
        rules.add(new Rule("phone", Algorithm.MASK, "138****1234"));
        rules.add(new Rule("idCard", Algorithm.MASK, "1101**********34"));
        rules.add(new Rule("bankCard", Algorithm.TRUNCATE, "只留后 4 位"));
        rules.add(new Rule("age", Algorithm.GENERALIZE, "28 -> 20-30"));
        rules.add(new Rule("userId", Algorithm.PSEUDONYMIZE, "user_8f3a2b（可关联）"));
        rules.add(new Rule("email", Algorithm.HASH, "sha256 前 8 位"));
    }

    /** 掩码：保留首尾 */
    static String mask(String v, int head, int tail) {
        if (v == null || v.length() <= head + tail) {
            return "***";
        }
        StringBuilder sb = new StringBuilder(v.substring(0, head));
        for (int i = head; i < v.length() - tail; i++) {
            sb.append('*');
        }
        return sb.append(v.substring(v.length() - tail)).toString();
    }

    /** 假名化：稳定映射（同一输入同一假名，可关联） */
    static String pseudonymize(String v) {
        return "user_" + Integer.toHexString(v.hashCode() & 0xFFFFFF);
    }

    /** 泛化：年龄分桶 */
    static String generalize(int age) {
        int low = age / 10 * 10;
        return low + "-" + (low + 9);
    }

    static String apply(Rule rule, String value) {
        return switch (rule.algorithm()) {
            case MASK -> mask(value, 3, 4);
            case TRUNCATE -> "****" + value.substring(Math.max(0, value.length() - 4));
            case GENERALIZE -> generalize(Integer.parseInt(value));
            case PSEUDONYMIZE -> pseudonymize(value);
            case HASH -> "h" + Integer.toHexString(value.hashCode()).substring(0, 8);
        };
    }

    /** 静态脱敏：导出前批量处理（不可还原） */
    static void staticMasking() {
        System.out.println("【静态脱敏：导出到测试环境】");
        String[][] rows = {
                {"phone", "13800001234"}, {"idCard", "110101199001011234"},
                {"bankCard", "6222021234567890"}, {"age", "28"},
                {"userId", "1001"}, {"email", "alice@example.com"}};
        for (String[] r : rows) {
            Rule rule = rules.stream().filter(x -> x.field().equals(r[0]))
                    .findFirst().orElse(null);
            if (rule == null) {
                continue;
            }
            System.out.printf("  %-10s %-24s -> %-20s（%s）%n", r[0], r[1],
                    apply(rule, r[1]), rule.note());
        }
        System.out.println();
    }

    /** 动态脱敏：同一字段按角色不同视图 */
    static void dynamicMasking() {
        System.out.println("【动态脱敏：按角色实时生效】");
        String phone = "13800001234";
        Map<String, String> viewByRole = new LinkedHashMap<>();
        viewByRole.put("客服", mask(phone, 3, 4));
        viewByRole.put("风控", phone);
        viewByRole.put("运营", mask(phone, 0, 0));
        viewByRole.forEach((role, v) -> System.out.printf("  %-4s 看到：%s%n", role, v));
        System.out.println();
    }

    static void choice() {
        System.out.println("【算法选型】");
        Map<String, String> choice = new LinkedHashMap<>();
        choice.put("展示给用户", "掩码（保留首尾，可识别）");
        choice.put("跨表分析", "假名化（稳定映射，可 join）");
        choice.put("统计报表", "泛化（分桶）");
        choice.put("去重比对", "哈希（不可逆）");
        choice.put("数值统计", "加噪（68-07）");
        choice.forEach((k, v) -> System.out.printf("  %-8s %s%n", k, v));
    }

    public static void main(String[] args) {
        staticMasking();
        dynamicMasking();
        choice();
        System.out.println("  铁律：测试环境永远不用未脱敏的生产数据");
    }
}
```

### 68-04 加密与密钥管理

**知识点**
- **加密的三个层次**：**传输加密**（TLS，35-07）、**存储加密**（静态加密：磁盘/表空间/字段级）、**应用层加密**（字段级 + 密钥自管）——**敏感字段（L3/L4）建议应用层加密**（不依赖 DBA 与云厂商）。
- **算法选择**：**对称加密 AES-GCM**（快，适合大数据量，**必须带认证**，防篡改）；**非对称 RSA/EC**（密钥交换/签名，慢，不适合大数据）；**哈希+盐**（密码存储，36-06）——**"自己发明的加密"一律不可用**（36-01）。
- **密钥管理的四要素**：**密钥与数据分离**（密钥在 KMS/Vault，不在数据库/代码库）、**分级密钥**（主密钥加密数据密钥（DEK），DEK 加密数据——信封加密）、**轮换**（定期换 DEK，主密钥更长周期）、**可销毁**（密钥销毁 = 数据不可恢复，用于"加密擦除" 68-10）。
- **信封加密（Envelope Encryption）的流程**：数据用 DEK 加密 -> DEK 用主密钥（KMS 托管）加密 -> 加密后的 DEK 与数据一起存 -> 解密时先解 DEK 再解数据——**这样轮换主密钥不需要重加密全部数据**。
- **与 36-06 的关系**：36-06 讲"密码要慢哈希"，本章讲"数据要可逆加密"——**场景不同，算法不同**（密码不需要解密，数据需要）。
- 易错点：用 ECB 模式（相同明文出相同密文，可分析）；IV 复用（GCM 下复用 IV 会导致密钥泄露）；密钥硬编码/放代码库（36 章）；加密后无法检索（需要"盲索引"设计）。

**示例代码**
```java
import javax.crypto.Cipher;
import javax.crypto.KeyGenerator;
import javax.crypto.SecretKey;
import javax.crypto.spec.GCMParameterSpec;
import javax.crypto.spec.SecretKeySpec;
import java.security.SecureRandom;
import java.util.Base64;
import java.util.LinkedHashMap;
import java.util.Map;

public class EncryptionDemo {
    /** AES-GCM 加密：返回 (iv + 密文) 的 Base64 */
    static String encrypt(String plain, SecretKey key) throws Exception {
        byte[] iv = new byte[12];
        new SecureRandom().nextBytes(iv);
        Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
        cipher.init(Cipher.ENCRYPT_MODE, key, new GCMParameterSpec(128, iv));
        byte[] ct = cipher.doFinal(plain.getBytes("UTF-8"));
        byte[] out = new byte[iv.length + ct.length];
        System.arraycopy(iv, 0, out, 0, iv.length);
        System.arraycopy(ct, 0, out, iv.length, ct.length);
        return Base64.getEncoder().encodeToString(out);
    }

    static String decrypt(String packed, SecretKey key) throws Exception {
        byte[] all = Base64.getDecoder().decode(packed);
        byte[] iv = new byte[12];
        System.arraycopy(all, 0, iv, 0, 12);
        Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
        cipher.init(Cipher.DECRYPT_MODE, key, new GCMParameterSpec(128, iv));
        return new String(cipher.doFinal(all, 12, all.length - 12), "UTF-8");
    }

    /** 模拟 KMS：主密钥池 + DEK 池（信封加密） */
    static final Map<String, SecretKey> masterKeys = new LinkedHashMap<>();
    static final Map<String, String> encryptedDeks = new LinkedHashMap<>();
    static SecretKey currentDek;

    static void initKms() throws Exception {
        masterKeys.put("master-v1", generate());
        masterKeys.put("master-v2", generate());
        currentDek = generate();
        encryptedDeks.put("dek-v1", wrap(currentDek, masterKeys.get("master-v1")));
        System.out.println("  KMS 初始化：主密钥 v1，DEK v1 已用主密钥包裹");
    }

    static SecretKey generate() throws Exception {
        KeyGenerator kg = KeyGenerator.getInstance("AES");
        kg.init(256);
        return kg.generateKey();
    }

    /** 包裹 DEK：用主密钥加密 DEK（真实系统用 AES-KW/RFC 3394 专用包裹算法，此处用 AES 简化） */
    static String wrap(SecretKey dek, SecretKey master) throws Exception {
        Cipher cipher = Cipher.getInstance("AES/ECB/PKCS5Padding");
        cipher.init(Cipher.ENCRYPT_MODE, master);
        return Base64.getEncoder().encodeToString(cipher.doFinal(dek.getEncoded()));
    }

    static SecretKey unwrap(String wrapped, SecretKey master) throws Exception {
        Cipher cipher = Cipher.getInstance("AES/ECB/PKCS5Padding");
        cipher.init(Cipher.DECRYPT_MODE, master);
        byte[] raw = cipher.doFinal(Base64.getDecoder().decode(wrapped));
        return new SecretKeySpec(raw, "AES");
    }

    static void envelopeDemo() throws Exception {
        System.out.println("【信封加密】");
        String phone = "13800001234";
        String cipherText = encrypt(phone, currentDek);
        System.out.println("  明文：" + phone);
        System.out.println("  密文（iv+ct base64）：" + cipherText);
        System.out.println("  解密：" + decrypt(cipherText, currentDek));

        System.out.println();
        System.out.println("【密文不可分析】");
        String c1 = encrypt(phone, currentDek);
        String c2 = encrypt(phone, currentDek);
        System.out.println("  同一明文两次加密结果不同（随机 IV）-> " + (!c1.equals(c2)));

        System.out.println();
        System.out.println("【篡改检测（GCM 认证）】");
        byte[] tampered = Base64.getDecoder().decode(cipherText);
        tampered[tampered.length - 1] ^= 0x01;
        try {
            decrypt(Base64.getEncoder().encodeToString(tampered), currentDek);
            System.out.println("  篡改未被发现（不应该发生）");
        } catch (Exception e) {
            System.out.println("  篡改被拒绝：" + e.getClass().getSimpleName()
                    + "（GCM 认证标签校验失败）");
        }
    }

    static void keyRotation() {
        System.out.println();
        System.out.println("【密钥轮换：只换 DEK，不重加密全量数据】");
        Map<String, String> steps = new LinkedHashMap<>();
        steps.put("1", "生成新 DEK v2，用主密钥包裹");
        steps.put("2", "新写入用 DEK v2；旧数据解密仍用 DEK v1");
        steps.put("3", "后台任务逐步用 v2 重加密旧数据（可分批）");
        steps.put("4", "全部迁移完成后销毁 DEK v1");
        steps.forEach((k, v) -> System.out.printf("  %s. %s%n", k, v));
        System.out.println();
        System.out.println("【密钥管理四原则】");
        System.out.println("  分离（KMS 托管）/ 分级（主密钥+DEK）/ 轮换（定期）/ 可销毁（加密擦除）");
    }

    public static void main(String[] args) throws Exception {
        initKms();
        System.out.println();
        envelopeDemo();
        keyRotation();
    }
}
```

### 68-05 数据权限：行列级控制

**知识点**
- **数据权限的三个粒度**：**库/表级**（能不能看这张表）、**行级**（能看到哪些行——如只能看本部门订单）、**列级**（能看到哪些字段——如客服看不到身份证）——**敏感数据的访问控制必须细到行列**。
- **行级权限的两种实现**：**SQL 改写**（在查询条件里自动注入 `dept_id = 当前用户部门`，类似 55-03 的租户注入）、**视图/行安全策略**（数据库原生 RLS）——**应用层改写最通用**。
- **列级权限的实现**：**动态脱敏**（68-03，无权看则掩码）、**字段过滤**（不返回该字段）、**加密字段**（无权者拿不到密钥）——**按角色配置"字段 × 角色"矩阵**。
- **权限模型的演进**：**RBAC**（角色权限，最常用）-> **ABAC**（属性权限，按数据属性+用户属性动态判定，更灵活但更难测）——**多数系统 RBAC + 少量 ABAC 规则**足够。
- **与 36-05/49 章的关系**：36-05 讲"越权漏洞"（IDOR）、49-07 讲"防腐层双键校验"——**行级权限就是"数据访问的 IDOR 防护"**（查不到不属于你的行，而不是查到了不给你看）。
- 易错点：只做菜单权限不做数据权限（能调接口但看到全量）；行级权限在应用层拼 SQL（注释/绕过）；列级权限只在前端隐藏（接口仍返回）；权限矩阵无评审（越加越乱）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class DataPermission {
    record User(String id, String role, String dept) {
    }

    record OrderRow(String orderId, String dept, String ownerId,
                    long amountCents, String phone) {
    }

    /** 行级权限：按角色注入数据范围 + 列级权限：字段可见性 */
    static List<String> query(User user, List<OrderRow> all,
                              Map<String, List<String>> columnPerm) {
        List<String> out = new ArrayList<>();
        List<String> visibleCols = columnPerm.getOrDefault(user.role(), List.of());
        for (OrderRow row : all) {
            if (!visible(user, row)) {
                continue;                      // 行级过滤：看不到的行直接不返回
            }
            StringBuilder line = new StringBuilder();
            line.append(row.orderId());
            if (visibleCols.contains("amount")) {
                line.append(" 金额=").append(row.amountCents());
            }
            if (visibleCols.contains("phone")) {
                line.append(" 手机=").append(row.phone());
            } else if (visibleCols.contains("phone_masked")) {
                line.append(" 手机=").append(maskPhone(row.phone()));
            }
            out.add(line.toString());
        }
        return out;
    }

    /** 行级策略：管理员全量，主管看本部门，客服看本部门 */
    static boolean visible(User user, OrderRow row) {
        return switch (user.role()) {
            case "admin" -> true;
            case "manager", "agent" -> row.dept().equals(user.dept());
            case "owner" -> row.ownerId().equals(user.id());
            default -> false;
        };
    }

    static String maskPhone(String phone) {
        return phone.length() >= 7
                ? phone.substring(0, 3) + "****" + phone.substring(phone.length() - 4)
                : "***";
    }

    public static void main(String[] args) {
        List<OrderRow> all = new ArrayList<>(List.of(
                new OrderRow("o-1", "杭州", "u-1", 6900, "13800001234"),
                new OrderRow("o-2", "杭州", "u-2", 3900, "13800005678"),
                new OrderRow("o-3", "上海", "u-3", 12900, "13900001111")));

        Map<String, List<String>> columnPerm = new LinkedHashMap<>();
        columnPerm.put("admin", List.of("amount", "phone"));
        columnPerm.put("manager", List.of("amount", "phone_masked"));
        columnPerm.put("agent", List.of("amount", "phone_masked"));
        columnPerm.put("owner", List.of("amount"));

        System.out.println("【列权限矩阵】");
        columnPerm.forEach((role, cols) -> System.out.printf("  %-8s 可见列=%s%n", role, cols));

        System.out.println();
        System.out.println("【不同角色的查询结果】");
        List<User> users = List.of(
                new User("u-0", "admin", "-"),
                new User("u-1", "manager", "杭州"),
                new User("u-2", "agent", "杭州"),
                new User("u-3", "owner", "上海"));
        for (User u : users) {
            System.out.printf("  %s（%s/%s）：%n", u.id(), u.role(), u.dept());
            query(u, all, columnPerm).forEach(line -> System.out.println("    " + line));
        }

        System.out.println();
        System.out.println("【要点】");
        System.out.println("  行级：不返回无权行（不是返回来再隐藏）——否则接口可被穷举");
        System.out.println("  列级：无权列要么不返回、要么掩码；绝不只在前端隐藏");
    }
}
```

2. 把"只在前端隐藏字段"改成"服务端不返回"，用抓包对比说明两者安全差异。
3. 思考题：为什么行级权限要"不返回"而不是"返回空值"？从"存在性泄露"与"穷举攻击"分析（55-04 同款）。

### 68-06 数据出境与本地化

**知识点**
- **数据出境是强监管红线**：向境外提供个人信息需满足**安全评估/标准合同/认证**三条路径之一（《个人信息保护法》第 38 条）；**关键信息基础设施与达到数量阈值的个人信息必须境内存储 + 出境评估**。
- **四类应对策略**：**本地化部署**（数据不出境，按区域独立部署 55-10）、**去标识化后出境**（脱敏/聚合后的数据风险降低但仍需评估）、**隐私计算跨境**（联邦学习/多方安全计算，数据不动模型动 68-08）、**禁止出境**（L4 高敏数据一律不出）。
- **工程落点**：**数据标记"归属地域"**（分区域存储 46-03 桶策略）、**出口流量审计**（哪个系统往外发了什么）、**SDK 与第三方服务的境外调用**（日志/监控/APM 上报也可能出境——**Agent 上报 66-10 的合规风险**）。
- **与 55-10 的关系**：55-10 讲了 SaaS 的多地域部署，本章把它上升为"合规要求"：**注册时确定归属地，数据按归属地路由，跨区只允许聚合结果**。
- 易错点：以为"匿名化"就能出境（可重新识别的仍算出境）；忽略监控/日志/APM 的境外上报；跨境备份（备份也是数据出境）；三方 SDK 暗地传数据。

**示例代码**

```java
import java.util.ArrayList;
import java.util.LinkedHashMap;

public class CrossBorderData {
    enum Region {

                     boolean aggregated) {
    }

                .filter(a -> a.name().equals(t.asset()))

        }
        if (asset.aggregated() && asset.level() == Level.L2) {
            return "有条件允许：聚合数据出境需做安全评估备案";

                a.name(), a.level(), a.allowedRegion(), a.aggregated()));
```

### 68-07 隐私计算入门：差分隐私

**知识点**
- **差分隐私（Differential Privacy）的核心承诺**：**查询结果对"任何单条记录是否存在"不敏感**——加入或删除一个人的数据，发布结果的分布几乎不变，从而无法推断个体信息。**它不是加密，而是"结果加噪"**。
- **ε（隐私预算）参数**：**ε 越小越隐私、噪声越大、数据越失真**；ε 越大越精确、隐私越弱——**ε 是"隐私与可用性"的旋钮**，需要业务确认（通常 0.1~1）。
- **拉普拉斯机制**：对数值查询加**拉普拉斯噪声**，噪声尺度 = `敏感度 / ε`——**敏感度 = 单条记录变化对结果的最大影响**（计数查询敏感度=1；求和查询敏感度=单条最大值）。
- **组合定理**：多次查询会累积消耗隐私预算（ε 相加）——**同一数据集查询次数越多，隐私保护越弱**，所以要做**预算管理**（记录已用 ε，超预算拒绝）。
- **本地差分隐私（LDP）**：**在客户端加噪再上报**（苹果/谷歌的统计采集）——服务端永远看不到原始数据，代价是噪声更大；**中心差分隐私（CDP）**：服务端加噪，精确度更高但要求服务端可信。
- 易错点：以为"删掉姓名"就匿名（其余属性可重标识）；ε 设得极大（等于没加噪）；无限次查询（组合定理导致隐私耗尽）；只对一次查询加噪却发布均值/分布等多统计量（组合泄露）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.Random;

public class DifferentialPrivacy {
    static final Random RANDOM = new Random(42);

    /** 拉普拉斯采样：scale = 敏感度 / ε */
    static double laplace(double sensitivity, double epsilon) {
        double u = RANDOM.nextDouble() - 0.5;
        return -sensitivity / epsilon * Math.signum(u)
                * Math.log(1 - 2 * Math.abs(u));
    }

    /** 计数查询（敏感度 = 1） */
    static long countQuery(List<Integer> ages, int minAge, double epsilon) {
        long real = ages.stream().filter(a -> a >= minAge).count();
        double noisy = real + laplace(1.0, epsilon);
        return Math.max(0, Math.round(noisy));
    }

    /** 求和查询（敏感度 = 单条最大值） */
    static double sumQuery(List<Double> incomes, double maxIncome, double epsilon) {
        double real = incomes.stream().mapToDouble(Double::doubleValue).sum();
        return real + laplace(maxIncome, epsilon);
    }

    /** 隐私预算管理：累计 ε 超限拒绝 */
    static class Budget {
        final double total;
        double used = 0;

        Budget(double total) {
            this.total = total;
        }

        boolean consume(double epsilon) {
            if (used + epsilon > total) {
                return false;
            }
            used += epsilon;
            return true;
        }
    }

    public static void main(String[] args) {
        List<Integer> ages = new ArrayList<>();
        for (int i = 0; i < 1000; i++) {
            ages.add(18 + i % 50);
        }
        System.out.println("【计数查询：年龄 >= 30 的人数】");
        System.out.printf("  真实值：%d%n", ages.stream().filter(a -> a >= 30).count());
        for (double eps : new double[]{0.1, 1.0, 10.0}) {
            List<Long> runs = new ArrayList<>();
            for (int i = 0; i < 5; i++) {
                runs.add(countQuery(ages, 30, eps));
            }
            System.out.printf("  ε=%-4.1f -> 5 次结果 %s（波动=%d）%n", eps, runs,
                    runs.stream().mapToLong(Long::longValue).max().orElse(0)
                            - runs.stream().mapToLong(Long::longValue).min().orElse(0));
        }
        System.out.println("  ε 越小噪声越大：隐私更强但可用性下降");

        System.out.println();
        System.out.println("【求和查询：收入总和（敏感度=单条最大 5 万）】");
        List<Double> incomes = new ArrayList<>();
        for (int i = 0; i < 100; i++) {
            incomes.add(8000.0 + i * 100);
        }
        double realSum = incomes.stream().mapToDouble(Double::doubleValue).sum();
        double noisySum = sumQuery(incomes, 50_000, 1.0);
        System.out.printf("  真实=%.0f 加噪=%.0f（相对误差 %.1f%%）%n",
                realSum, noisySum, Math.abs(noisySum - realSum) / realSum * 100);

        System.out.println();
        System.out.println("【隐私预算：组合定理】");
        Budget budget = new Budget(1.0);
        for (int i = 1; i <= 5; i++) {
            boolean ok = budget.consume(0.25);
            System.out.printf("  第%d次查询（ε=0.25）-> %s，已用 %.2f/%.2f%n", i,
                    ok ? "允许" : "拒绝（预算耗尽）", budget.used, budget.total);
        }

        System.out.println();
        System.out.println("【两种模式】");

        modes.put("本地 DP", "客户端加噪后上报，隐私最强，噪声大、结果粗");
```

### 68-08 隐私计算入门：联邦学习概念

**知识点**
- **联邦学习（Federated Learning）的核心思想：数据不动，模型动**——各方在本地用自己的数据训练，**只交换模型参数（梯度/权重）**，由聚合方合成全局模型——**原始数据永不离开本地**。
- **横向联邦 vs 纵向联邦**：**横向**（各方样本不同、特征相同——如多家医院同一套检查项）、**纵向**（各方样本相同、特征不同——如银行+电商同一批用户的不同维度）；**联合建模**需要样本对齐（隐私求交 PSI）。
- **FedAvg 聚合算法**：各方用本地数据训练若干轮 -> 上传参数 -> 服务端按样本量加权平均 -> 下发新参数 -> 重复——**简单有效，是联邦学习的基线**。
- **联邦学习不是万能药**：**梯度也可能泄露信息**（梯度反演攻击可重建训练样本）——需要**安全聚合（Secure Aggregation，加密后聚合）**、**差分隐私加噪**（68-07）、**可信执行环境**；**通信成本高**（多轮往返）；**非独立同分布数据**（Non-IID）导致收敛慢。
- **与 68-06 的关系**：跨境场景下"数据不出境、模型可共享"是合规路径之一——**但要注意：模型也可能记住数据（成员推断攻击）**。
- 易错点：以为"只传梯度就绝对安全"（梯度反演可还原样本）；忽略 Non-IID（各方数据分布差异大，全局模型效果差）；通信轮次无上限（成本失控）；不做安全聚合（明文梯度可被截获）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class FederatedLearning {
    /** 简化模型：一个线性参数（y = w * x），演示聚合语义 */
    record Client(String id, int samples, double w) {
    }

    /** FedAvg：按样本量加权平均 */
    static double fedAvg(List<Client> clients) {
        double total = 0;
        long samples = 0;
        for (Client c : clients) {
            total += c.w() * c.samples();
            samples += c.samples();
        }
        return samples == 0 ? 0 : total / samples;
    }

    /** 本地训练一步：用本地数据往真值方向走一小步 */
    static double localStep(double w, double target, double lr) {
        return w + lr * (target - w);
    }

    /** 联邦训练模拟：多轮 本地训练 -> 加权聚合 -> 下发 */
    static void federatedTraining(List<Client> clients, double globalTarget, int rounds,
                                  double lr) {
        List<Double> weights = new ArrayList<>();
        clients.forEach(c -> weights.add(0.0));
        double globalW = 0.0;
        for (int r = 1; r <= rounds; r++) {
            List<Client> updated = new ArrayList<>();
            for (int i = 0; i < clients.size(); i++) {
                Client c = clients.get(i);
                // 每方本地数据略有偏差（Non-IID）
                double localTarget = globalTarget + (i - 1) * 0.5;
                double localW = localStep(globalW, localTarget, lr);
                updated.add(new Client(c.id(), c.samples(), localW));
            }
            globalW = fedAvg(updated);
            System.out.printf("  第%d轮：各方本地参数=%s -> 聚合 globalW=%.3f%n", r,
                    updated.stream().map(c -> String.format("%.2f", c.w())).toList(), globalW);
        }
    }

    static void security() {
        System.out.println("【联邦学习的安全增强】");
        Map<String, String> measures = new LinkedHashMap<>();
        measures.put("安全聚合", "各方梯度加密后由聚合方求和（看不到明文梯度）");
        measures.put("差分隐私", "梯度上加噪（68-07），防梯度反演");
        measures.put("TEE", "聚合在可信执行环境中完成");
        measures.put("成员推断防护", "限制输出置信度/加噪，防判断某样本是否在训练集");
        measures.forEach((k, v) -> System.out.printf("  %-10s %s%n", k, v));
        System.out.println();
    }

    static void limits() {
        System.out.println("【适用边界】");
        String[][] rows = {
                {"数据不能出域", "多医院联合建模、跨境合规", "联邦是对的选择"},
                {"数据量小、通信便宜", "单机房少量参与方", "集中式更简单高效"},
                {"极度敏感", "金融风控、医疗", "需联邦 + 安全聚合 + DP + 审计"},
                {"要求极致精度", "离线分析", "联邦的噪声与非 IID 会损失精度"},
        };
        for (String[] r : rows) {
            System.out.printf("  %-16s %-22s %s%n", r[0], r[1], r[2]);
        }
    }

    public static void main(String[] args) {
        System.out.println("【横向联邦：3 家医院同一检查项】");
        List<Client> clients = List.of(
                new Client("医院A", 500, 0),
                new Client("医院B", 300, 0),
                new Client("医院C", 200, 0));
        System.out.println("  样本量：" + clients.stream().map(c -> c.id() + "=" + c.samples()).toList());
        System.out.println("  模拟目标参数 = 2.0");
        federatedTraining(clients, 2.0, 5, 0.5);
        System.out.println("  注意：样本量大的参与方对全局模型影响更大（加权聚合）");

        System.out.println();
        security();
        limits();
    }
}
```

**课后练习**

2. 构造 Non-IID 场景（各参与方目标参数差异很大），观察全局模型的次优性并说明缓解手段。

### 68-09 审计与可追溯

**知识点**
- **审计是隐私合规的"证据链"**：**谁（who）在何时（when）从哪（where）对什么数据（what）做了什么（action）**——每条记录不可篡改、可按主体/资源/时间检索。
- **审计的三类内容**：**访问审计**（查询/导出/查看详情）、**变更审计**（修改/删除/权限变更）、**管理审计**（授权/审批/配置变更）——**敏感数据的"读取"也要审计**（不止写）。
- **不可篡改的实现**：**append-only 表**（只插入，禁更新删除）、**哈希链**（每条记录含前一条的哈希，篡改一条则后续全部不匹配）、**WORM 存储/区块链**（高合规场景）。
- **审计的落地要点**：**异步写入**（不阻塞业务 42/66 章）、**脱敏存储**（审计里也不能存明文敏感数据）、**保留期**（通常 6 个月~3 年，按法规 68-10）、**可检索**（按用户/资源/时间/操作类型）。
- **与 51-10 的关系**：支付的操作审计是"资金证据"，本章的数据访问审计是"隐私证据"——**同一套 append-only + 哈希链思想**。
- 易错点：审计可被业务账号删除（等于没有）；审计不含"读"操作（只记写）；审计日志明文存敏感数据；审计无检索能力（出了事查不出来）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class AuditTrail {
    /** 审计记录：含前一条哈希，形成哈希链 */
    record Entry(long seq, long atMs, String who, String action, String resource,
                 String detail, String prevHash, String hash) {
    }

    static final List<Entry> ledger = new ArrayList<>();
    static long seq = 0;

    /** 简化哈希：真实系统用 SHA-256（36-06 同款） */
    static String hashOf(String content) {
        return Integer.toHexString(content.hashCode()) + "-"
                + Integer.toHexString((content + "#salt").hashCode());
    }

    static void record(String who, String action, String resource, String detail, long atMs) {
        String prev = ledger.isEmpty() ? "GENESIS" : ledger.get(ledger.size() - 1).hash();
        String content = (seq + 1) + "|" + atMs + "|" + who + "|" + action + "|"
                + resource + "|" + detail + "|" + prev;
        Entry e = new Entry(++seq, atMs, who, action, resource, detail, prev, hashOf(content));
        ledger.add(e);
        System.out.printf("  #%d %s %-8s %-16s %s%n", e.seq(), e.who(), e.action(),
                e.resource(), e.detail());
    }

    /** 完整性校验：重算哈希链 */
    static boolean verify() {
        String prev = "GENESIS";
        for (Entry e : ledger) {
            String content = e.seq() + "|" + e.atMs() + "|" + e.who() + "|" + e.action()
                    + "|" + e.resource() + "|" + e.detail() + "|" + prev;
            if (!e.prevHash().equals(prev) || !e.hash().equals(hashOf(content))) {
                System.out.println("  校验失败于 #" + e.seq() + "（链断裂或被篡改）");
                return false;
            }
            prev = e.hash();
        }
        return true;
    }

    static void query(String who, String resource) {
        System.out.println("  查询 who=" + who + " resource=" + resource + "：");
        ledger.stream()
                .filter(e -> (who == null || e.who().equals(who))
                        && (resource == null || e.resource().equals(resource)))
                .forEach(e -> System.out.printf("    #%d %s%n", e.seq(), e.action()));
    }

    public static void main(String[] args) {
        System.out.println("【写入审计（含读取操作）】");
        record("agent-01", "QUERY", "user:phone", "查看用户手机号（脱敏视图）", 1000);
        record("agent-01", "EXPORT", "order:2026-11", "导出 500 条订单（已审批 REQ-9）", 2000);
        record("dba-02", "ALTER", "user:id_card", "新增加密列", 3000);
        record("admin-03", "GRANT", "role:risk", "授予 L4 数据访问权限", 4000);
        record("agent-01", "QUERY", "user:phone", "再次查看（第 2 次）", 5000);

        System.out.println();
        System.out.println("【完整性校验】" + (verify() ? "通过（哈希链完整）" : "失败"));

        System.out.println();
        System.out.println("【篡改检测】把 #2 的 detail 改掉后重算");
        Entry original = ledger.get(1);
        ledger.set(1, new Entry(original.seq(), original.atMs(), original.who(),
                original.action(), original.resource(), "导出 5 条订单（已审批 REQ-9，已篡改）",
                original.prevHash(), original.hash()));
        System.out.println("  " + (verify() ? "未检测到（不应该）" : "检测到篡改（哈希不匹配）"));
        ledger.set(1, original);

        System.out.println();
        System.out.println("【检索】");
        query("agent-01", "user:phone");

        System.out.println();
        System.out.println("【审计要点】");
        Map<String, String> rules = new LinkedHashMap<>();
        rules.put("覆盖读操作", "敏感数据的查询/导出都要记");
        rules.put("不可篡改", "append-only + 哈希链");
        rules.put("脱敏存储", "审计日志本身也不放明文");
        rules.put("可检索", "按 who/resource/时间/动作");
        rules.put("保留期", "按法规（通常 6 个月~3 年）");
        rules.forEach((k, v) -> System.out.printf("  %-8s %s%n", k, v));
    }
}
```

**课后练习**
1. 实现审计链：append-only 写入 + 哈希链校验 + 按主体/资源检索，并演示篡改被检出。
2. 实现"审计异步写入"：业务线程只入队，后台批量落盘，验证业务耗时不受审计影响。
3. 思考题：为什么"读取操作"必须审计？从"内部人员批量查询导出"是最常见泄露渠道分析（36 章内部风险）。

### 68-10 数据删除与遗忘权

**知识点**
- **遗忘权（Right to be Forgotten）是法定义务**：用户有权要求删除其个人信息，企业需在合理期限内删除并**通知下游接收方**——**"删除"不是删一行数据，是全链路清除**。
- **删除的四个难点**：**分布式副本**（主库/从库/缓存/ES/数仓/备份）、**派生数据**（聚合结果、报表、模型训练样本）、**引用完整性**（订单需要保留但用户信息要删 -> **匿名化替代删除**）、**备份的不可删除性**（备份介质里的历史副本，通常用"加密擦除" 68-04 解决）。
- **三种删除策略**：**物理删除**（真删，最彻底但要处理引用）、**匿名化**（保留业务记录，抹掉个人标识——订单保留但用户变为 `deleted_user_hash`）、**加密擦除**（销毁密钥，数据不可解——用于备份/冷存储）。
- **删除的工程实现**：**删除清单**（该用户数据分布在哪些表/系统）+ **级联任务**（异步、可重试、可观测 61 章）+ **删除凭证**（记录删了什么、何时、由谁 68-09）+ **定期核验**（抽查是否还有残留）。
- 与 55-07 的关系：SaaS 退租的"数据清除"是同一问题（多系统清除 + 凭证），**本章是用户级的版本**。
- 易错点：只删业务库（缓存/ES/数仓仍有）；删除不留凭证（无法证明已删）；忽略派生数据（模型记住了用户数据）；备份永不清理（历史副本永久存在）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class RightToBeForgotten {
    /** 数据分布：系统 -> 存储的条目 */
    static final Map<String, List<String>> stores = new LinkedHashMap<>();

    static {
        stores.put("mysql.user", new ArrayList<>(List.of("u-1:phone:13800001234",
                "u-1:id_card:110101199001011234", "u-2:phone:13900005678")));
        stores.put("mysql.order", new ArrayList<>(List.of("u-1:order:o-1:address:杭州",
                "u-2:order:o-2:address:上海")));
        stores.put("redis.user_cache", new ArrayList<>(List.of("u-1:profile", "u-2:profile")));
        stores.put("es.user_index", new ArrayList<>(List.of("doc-u-1", "doc-u-2")));
        stores.put("dwh.user_dim", new ArrayList<>(List.of("u-1 维度行", "u-2 维度行")));
        stores.put("backup.daily", new ArrayList<>(List.of("u-1 备份副本（加密）",
                "u-2 备份副本（加密）")));
    }

    record DeletionResult(String store, String strategy, int affected, String note) {
    }

    /** 删除策略：按存储类型选择 */
    static DeletionResult deleteFrom(String store, String userId) {
        List<String> items = stores.get(store);
        int before = items.size();
        switch (store) {
            case "mysql.user" -> {
                items.removeIf(s -> s.startsWith(userId + ":"));
                return new DeletionResult(store, "物理删除", before - items.size(),
                        "用户主数据彻底删除");
            }
            case "mysql.order" -> {
                for (int i = 0; i < items.size(); i++) {
                    if (items.get(i).startsWith(userId + ":order:")) {
                        items.set(i, items.get(i).replace(":address:", ":address_anonymized:"));
                    }
                }
                return new DeletionResult(store, "匿名化", 1,
                        "订单保留（业务需要），地址字段匿名化");
            }
            case "redis.user_cache", "es.user_index" -> {
                items.removeIf(s -> s.contains(userId));
                return new DeletionResult(store, "物理删除", before - items.size(),
                        "缓存与索引立即失效");
            }
            case "dwh.user_dim" -> {
                items.removeIf(s -> s.startsWith(userId + " "));
                return new DeletionResult(store, "物理删除 + 重建", before - items.size(),
                        "维度表删除后需重建派生报表");
            }
            case "backup.daily" -> {
                return new DeletionResult(store, "加密擦除", 0,
                        "备份介质不可改，销毁该用户数据密钥 -> 不可解密");
            }
            default -> {
                return new DeletionResult(store, "未处理", 0, "未覆盖的存储（风险）");
            }
        }
    }

    static void execute(String userId) {
        System.out.println("【删除请求：用户 " + userId + "】");
        List<DeletionResult> results = new ArrayList<>();
        for (String store : stores.keySet()) {
            results.add(deleteFrom(store, userId));
        }
        results.forEach(r -> System.out.printf("  %-18s %-12s 影响=%-2d %s%n",
                r.store(), r.strategy(), r.affected(), r.note()));
        System.out.println();
        System.out.println("【删除后核验】");
        stores.forEach((store, items) -> {
            long remain = items.stream().filter(s -> s.contains(userId)).count();
            System.out.printf("  %-18s 残留 %d 条%s%n", store, remain,
                    remain == 0 ? "" : "（" + items.stream()
                            .filter(s -> s.contains(userId)).toList() + "）");
        });
        System.out.println();
        System.out.println("  凭证：本次删除记录已写入审计链（68-09），保留 3 年");
    }

    public static void main(String[] args) {
        execute("u-1");

        System.out.println();
        System.out.println("【删除策略选型】");
        Map<String, String> choice = new LinkedHashMap<>();
        choice.put("用户主数据", "物理删除（无业务依赖或可级联）");
        choice.put("业务单据", "匿名化（保留记录，抹除个人标识）");
        choice.put("缓存/索引", "物理删除 + 失效广播（65-05 同源）");
        choice.put("数仓/模型", "删除 + 重建派生数据（模型需重训，66-11）");
        choice.put("备份", "加密擦除（销毁密钥，备份不可改）");
        choice.forEach((k, v) -> System.out.printf("  %-10s %s%n", k, v));

        System.out.println();
        System.out.println("【难点清单】");
        List<String> hard = List.of(
                "派生数据：报表/聚合/模型样本都可能含个人信息",
                "备份：不可删除，只能加密擦除",
                "引用完整性：删用户但订单要留 -> 匿名化",
                "下游通知：共享过数据的第三方也要通知删除（68-06）");
        hard.forEach(h -> System.out.println("  - " + h));
    }
}
```

2. 设计"删除清单"模板（系统/表/字段/策略/责任人/凭证），并对你业务的一个用户跑一遍推演。

### 68-11 综合案例：用户数据全生命周期治理

**知识点**
- **把本章收口成一套完整治理方案**：**采集**（最小必要 + 分级 68-02）-> **传输**（TLS + 敏感字段加密 68-04）-> **存储**（加密 + 脱敏 68-03 + 保留期）-> **使用**（行列权限 68-05 + 审计 68-09）-> **共享**（出境评估 68-06 + 隐私计算 68-07/08）-> **销毁**（删除策略 68-10）。
- **治理的三个载体**：**数据字典**（字段级级别与控制，68-02）、**访问矩阵**（角色 × 数据 × 操作，68-05）、**审计链**（每次访问留痕，68-09）——**三者缺一不可**。
- **验收五条**：**可清点**（知道有哪些敏感数据）、**可控权**（知道谁能看）、**可脱敏**（非授权场景自动降级）、**可追溯**（每次访问有记录）、**可删除**（全链路清除 + 凭证）。
- **与全书的关系**：36 章防外部攻击、55-10 多租户合规、67-10 位置隐私、66-10 Agent 采集边界——**本章把它们统一为"数据治理框架"**。
- 易错点：只有制度没有技术控制（纸面合规）；只有技术没有制度（开发者不知道边界）；清单不定期更新（新系统绕过治理）；审计与删除各自为政（无统一证据链）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class DataGovernanceCase {
    enum Level {
        L1, L2, L3, L4
    }

    record FieldRule(String field, Level level, List<String> allowedRoles,
                     String mask, long retentionDays) {
    }

    static final List<FieldRule> rules = new ArrayList<>();
    static final List<String> audit = new ArrayList<>();

    static {
        rules.add(new FieldRule("phone", Level.L3, List.of("agent", "risk", "admin"),
                "138****1234", 365));
        rules.add(new FieldRule("id_card", Level.L4, List.of("risk", "admin"),
                "1101**********34", 180));
        rules.add(new FieldRule("address", Level.L3, List.of("agent", "admin"),
                "杭州市***", 365));
        rules.add(new FieldRule("amount", Level.L2, List.of("agent", "risk", "admin", "analyst"),
                "原值", 1095));
    }

    /** 访问：权限判定 + 脱敏 + 审计 */
    static String access(String role, String field, String rawValue, long nowMs) {
        FieldRule rule = rules.stream().filter(r -> r.field().equals(field))
                .findFirst().orElse(null);
        if (rule == null) {
            audit.add(role + " ACCESS " + field + " DENIED(未登记字段)");
            return "拒绝：字段未登记分级";
        }
        if (!rule.allowedRoles().contains(role)) {
            audit.add(role + " ACCESS " + field + " DENIED(无权限)");
            return "拒绝：" + role + " 无权访问 " + field;
        }
        audit.add(role + " ACCESS " + field + " ALLOWED");
        boolean privileged = role.equals("admin") || role.equals("risk");
        return privileged ? rawValue : rule.mask();
    }

    /** 保留期检查：超期需归档或删除 */
    static void retentionCheck(long nowMs) {
        System.out.println("【保留期检查】");
        rules.forEach(r -> {
            long expireAt = r.retentionDays() * 86_400_000L;
            String status = nowMs > expireAt ? "已超期 -> 归档/删除（68-10）" : "有效期内";
            System.out.printf("  %-10s 级别=%-3s 保留=%4d 天 -> %s%n",
                    r.field(), r.level(), r.retentionDays(), status);
        });
        System.out.println();
    }

    static void acceptance() {
        System.out.println();
        System.out.println("【治理验收五条】");
        Map<String, String> gates = new LinkedHashMap<>();
        gates.put("可清点", "数据字典覆盖全部字段（68-02）");
        gates.put("可控权", "角色×字段访问矩阵（68-05）");
        gates.put("可脱敏", "非特权角色自动降级（68-03）");
        gates.put("可追溯", "每次访问写入审计链（68-09）");
        gates.put("可删除", "全链路清除 + 凭证（68-10）");
        gates.forEach((k, v) -> System.out.printf("  %-6s %s%n", k, v));
        System.out.println();
        System.out.println("  三个载体：数据字典 + 访问矩阵 + 审计链 —— 缺一不可");
    }

    public static void main(String[] args) {
        System.out.println("【字段级规则】");
        rules.forEach(r -> System.out.printf("  %-10s 级别=%-3s 允许=%s%n",
                r.field(), r.level(), r.allowedRoles()));

        System.out.println();
        System.out.println("【访问模拟】");
        String phone = "13800001234";
        String idCard = "110101199001011234";
        System.out.println("  agent 读 phone  -> " + access("agent", "phone", phone, 0));
        System.out.println("  agent 读 id_card-> " + access("agent", "id_card", idCard, 0));
        System.out.println("  risk  读 id_card-> " + access("risk", "id_card", idCard, 0));
        System.out.println("  admin 读 phone  -> " + access("admin", "phone", phone, 0));
        System.out.println("  analyst 读未知  -> " + access("analyst", "salary", "10000", 0));

        System.out.println();
        System.out.println("【审计链】");
        audit.forEach(a -> System.out.println("  " + a));
        System.out.println("  （真实系统：append-only + 哈希链，68-09）");

        retentionCheck(200L * 86_400_000L);
        acceptance();
        System.out.println();
        System.out.println("  一句话：隐私工程 = 制度（清单/审批）+ 技术（分级/脱敏/权限/加密/审计）+ 运营（复核/演练）");
    }
}
```
