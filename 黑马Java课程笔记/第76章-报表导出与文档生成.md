# 第76章 报表导出与文档生成

导出是"数据平台的最后一公里"：查得再快，导不出来业务就用不上。难点不在格式，而在百万行下的内存、分页、任务与安全。本章按「导出全景 → 流式导出与内存控制 → 大数据量分页 → Excel 写入原理 → CSV 与编码 → PDF 排版 → 模板与动态报表 → 异步导出任务 → 下载中心与权限 → 导出安全与审计 → 百万行导出案例」的顺序讲。所有示例仍是纯 JDK：同步/异步决策、游标流式导出、id 区间分册与并发取消、手写 xlsx（ZIP+XML+共享字符串）、CSV 转义与 BOM、PDF 坐标系与最小 PDF、模板引擎与动态列、任务状态机与重试、下载中心三层鉴权、脱敏与配额审计全部真实运行。

### 76-01 报表导出全景

**知识点**
- **报表导出的四条链路**：**数据查询**（分页/流式 76-02）-> **格式生成**（CSV/Excel/PDF 76-04~76-06）-> **文件落地**（本地/对象存储 73 章）-> **通知下载**（下载中心 76-09）——**任何一环出错都会让用户拿到半个文件**。
- **同步 vs 异步的分界线**：**小报表（< 5 万行、< 10 秒）同步直出**；**大报表（百万行、分钟级）走异步任务**（76-08）——**按"用户能等多久"与"资源占用"选**。
- **导出的三个隐形要求**：**数据一致性**（导出的是某一时刻的快照，不是边导边变）、**可重入**（失败可重试，不产生重复文件）、**可审计**（谁在何时导了什么，76-10）。
- 与 73 章的关系：导出文件就是"大文件"，**分片/断点/签名 URL 的机制全部适用**——本章聚焦"怎么把数据变成文件"，73 章聚焦"文件怎么存怎么发"。
- 易错点：百万行全量load进内存（OOM）；导出过程数据在变（金额对不上）；无进度（用户以为卡死）；重复点击生成多份（76-08 幂等）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class ExportOverview {
    enum Mode { SYNC, ASYNC }

    record ExportRequest(String reportType, int estimatedRows, String format) {
    }

    record Decision(Mode mode, String reason) {
    }

    /** 决策：按行数 + 格式耗时估算 */
    static Decision decide(ExportRequest req) {
        long estimatedMs = switch (req.format()) {
            case "CSV" -> req.estimatedRows() / 50_000L;
            case "XLSX" -> req.estimatedRows() / 5_000L;
            case "PDF" -> req.estimatedRows() / 500L;
            default -> throw new IllegalArgumentException("不支持格式 " + req.format());
        };
        boolean tooBig = req.estimatedRows() > 50_000 || estimatedMs > 10_000;
        if (tooBig) {
            return new Decision(Mode.ASYNC,
                    "预计 " + req.estimatedRows() + " 行 / " + estimatedMs + "ms，超过同步阈值");
        }
        return new Decision(Mode.SYNC,
                "预计 " + req.estimatedRows() + " 行 / " + estimatedMs + "ms，同步直出");
    }

    static void pipeline() {
        System.out.println("【导出四段链路】");
        String[][] stages = {
                {"1. 数据查询", "分页或游标流式读取", "不能全量 load 进内存（76-02）"},
                {"2. 格式生成", "CSV/Excel/PDF 逐行写", "边查边写，内存恒定"},
                {"3. 文件落地", "本地临时文件 -> 对象存储", "73 章：分片/校验/生命周期"},
                {"4. 通知下载", "生成下载链接/站内信", "76-09 下载中心 + 签名 URL"},
        };
        for (String[] s : stages) {
            System.out.printf("  %-12s %-22s %s%n", s[0], s[1], s[2]);
        }
        System.out.println();
    }

    static void consistency() {
        System.out.println("【数据一致性：快照 vs 边导边变】");
        System.out.println("  反例：第 1 页查到 100 条，导出第 2 页时数据被删了 10 条");
        System.out.println("        -> 总行数对不上，用户投诉「报表不准」");
        System.out.println("  正解一：按主键游标（id > lastId），避免 offset 漂移");
        System.out.println("  正解二：固定快照（导出开始时记录 maxId / 时间点）");
        System.out.println("  正解三：读从库 + 一致性快照读（RC/RR 隔离级别）");
        System.out.println();
    }

    static void idempotent() {
        System.out.println("【可重入：同一请求只生成一份】");
        Map<String, String> jobByKey = new LinkedHashMap<>();
        String key = "user-1:order-report:2026-11-18";
        String first = jobByKey.computeIfAbsent(key, k -> "job-1001");
        String second = jobByKey.computeIfAbsent(key, k -> "job-1002");
        System.out.println("  第一次点击 -> " + first);
        System.out.println("  重复点击   -> " + second + "（复用同一任务，不重复生成）");
        System.out.println("  幂等键 = 用户 + 报表类型 + 参数摘要");
        System.out.println();
    }

    public static void main(String[] args) {
        pipeline();
        consistency();
        idempotent();

        System.out.println("【同步/异步决策】");
        List<ExportRequest> reqs = new ArrayList<>(List.of(
                new ExportRequest("订单明细", 1_000, "XLSX"),
                new ExportRequest("订单明细", 200_000, "XLSX"),
                new ExportRequest("对账单", 5_000_000, "CSV"),
                new ExportRequest("发票", 2_000, "PDF")));
        for (ExportRequest r : reqs) {
            Decision d = decide(r);
            System.out.printf("  %-6s %8d 行 %-5s -> %-5s（%s）%n",
                    r.reportType(), r.estimatedRows(), r.format(), d.mode(), d.reason());
        }

        System.out.println();
        System.out.println("【验收】内存恒定、快照一致、任务幂等、可审计（76-10）");
    }
}
```

### 76-02 流式导出与内存控制

**知识点**
- **流式导出的核心：边查边写，内存恒定**——**游标查询**（`id > lastId ORDER BY id LIMIT n`）逐批取数，**写出后立即丢弃**，内存里只有"一批"（如 1000 行）。
- **三种分页方式对比**：**offset/limit**（深分页越翻越慢，且有漂移 76-01）、**主键游标**（`WHERE id > ? ORDER BY id LIMIT n`，稳定高效）、**keyset/复合游标**（多列排序时用 `(create_time, id)` 元组）——**导出首选游标**。
- **写出端也要流式**：`BufferedWriter`/`OutputStream` 直接写文件，**不要先拼成 `List<String>` 再写**（那就是全量内存）——**查询流与写入流"背压"对齐**（快慢不匹配时用有界队列 43-04）。
- **JVM 视角**：**导出是"长事务 + 大对象"的高危场景**——控制批大小（1000~5000）、避免 `String` 拼接（用 `StringBuilder` 复用）、必要时 `-Xmx` 之外用堆外/临时文件。
- 与 54/46 章的关系：与"批量特征加载""列裁剪"同源——**"一次只处理一小片"是所有大数据处理的第一原则**。
- 易错点：`findAll()` 全量查（OOM 第一杀手）；offset 深分页（越翻越慢）；每行一次 DB 查询（N+1 的导出版）；不关流（文件句柄泄露）。

**示例代码**
```java
import java.io.BufferedWriter;
import java.io.IOException;
import java.io.StringWriter;
import java.util.ArrayList;
import java.util.List;

public class StreamingExport {
    record Order(long id, String customer, double amount, String createdAt) {
    }

    /** 模拟 20 万行订单数据（仅元信息，不真存） */
    static final int TOTAL_ROWS = 200_000;

    static Order fakeOrder(long id) {
        return new Order(id, "客户" + (id % 1000), 10.0 + (id % 500) / 10.0,
                "2026-11-" + String.format("%02d", (id % 28) + 1));
    }

    /** 模拟 DB：游标分页（id > lastId） */
    static List<Order> queryAfter(long lastId, int limit) {
        List<Order> out = new ArrayList<>(limit);
        long start = lastId + 1;
        long end = Math.min(TOTAL_ROWS, start + limit - 1);
        for (long id = start; id <= end; id++) {
            out.add(fakeOrder(id));
        }
        return out;
    }

    /** 流式导出：游标 + 边写边丢 */
    static String exportStreaming(int batchSize, int maxRows) throws IOException {
        StringWriter sink = new StringWriter();
        BufferedWriter writer = new BufferedWriter(sink);
        writer.write("id,customer,amount,createdAt\n");

        long lastId = 0;
        int written = 0;
        int batches = 0;
        int peakRowsInMemory = 0;
        while (written < maxRows) {
            int limit = Math.min(batchSize, maxRows - written);
            List<Order> batch = queryAfter(lastId, limit);
            if (batch.isEmpty()) {
                break;
            }
            for (Order o : batch) {
                writer.write(o.id() + "," + o.customer() + ","
                        + o.amount() + "," + o.createdAt() + "\n");
            }
            lastId = batch.get(batch.size() - 1).id();
            written += batch.size();
            batches++;
            peakRowsInMemory = Math.max(peakRowsInMemory, batch.size());
            // batch 出作用域即可被回收：内存里永远只有一批
        }
        writer.flush();
        System.out.printf("  流式：写入 %d 行，%d 批，内存峰值 %d 行，输出 %d 字节%n",
                written, batches, peakRowsInMemory, sink.toString().length());
        return sink.toString();
    }

    /** 反例：全量 load 再写（仅演示内存占用，不真跑 20 万） */
    static void naiveMemory() {
        System.out.println("【反例：全量 load】");
        System.out.println("  List<Order> all = orderMapper.findAll();  // 20 万行对象");
        System.out.println("  每行约 200 字节 -> 约 40MB，还要 + 字符串拼接的临时对象");
        System.out.println("  若 100 万行 / 字段更多 -> 数百 MB，直接 OOM");
        System.out.println("  正解：游标分批，内存 = 一批（1000 行 ≈ 200KB）");
        System.out.println();
    }

    static void cursorVsOffset() {
        System.out.println("【游标 vs offset】");
        String[][] rows = {
                {"第 1 页", "LIMIT 1000 OFFSET 0", "id > 0 LIMIT 1000"},
                {"第 100 页", "LIMIT 1000 OFFSET 99000（扫描 10 万行）", "id > 99000 LIMIT 1000"},
                {"第 1000 页", "LIMIT 1000 OFFSET 999000（扫描 100 万行）", "id > 999000 LIMIT 1000"},
                {"数据漂移", "导出中插入/删除会重合或漏行", "按 id 单调前进，不重不漏"},
        };
        for (String[] r : rows) {
            System.out.printf("  %-8s offset=%-34s 游标=%s%n", r[0], r[1], r[2]);
        }
        System.out.println();
    }

    public static void main(String[] args) throws IOException {
        cursorVsOffset();
        naiveMemory();
        System.out.println("【流式导出 20 万行】");
        long t0 = System.nanoTime();
        exportStreaming(1000, TOTAL_ROWS);
        System.out.printf("  耗时 %d ms%n", (System.nanoTime() - t0) / 1_000_000);
        System.out.println();
        System.out.println("  关键：查询流 -> 写入流，批间不累积；批大小 1000~5000 是常见甜点");
    }
}
```

### 76-03 大数据量分页导出

**知识点**
- **"分页导出"有两种含义**：**按页导出多个文件**（每页一个 Excel，适合"用户要分批看"）与**内部按页取数**（导出仍是单文件，76-02 的游标）——**先分清需求**，别把后者做成前者。
- **按页多文件的设计**：**页大小固定**（如每册 5 万行）、**文件名带页码**（`订单_1-50000.xlsx`）、**打包 ZIP**（73-09）——**单文件不超 2 万行是 Excel 的舒适区**（76-04 的流式写入也有内存收益）。
- **并发导出**：**多批并行查 + 顺序写**（保证行序）或**并行写各自分片再合并**——**并行度受 DB 连接池与下游限流约束**（44-08），**不是越高越好**。
- **进度与取消**：**记录已处理行数**（76-08 的任务状态）、**支持取消**（用户关页面/主动取消，任务可中断 61-03）——**长任务必须可观测可中断**。
- 与 39/61 章的关系：与"批量任务的分片并行"同构——**分片键、断点续传、幂等**三件套（61-08 的 DAG 编排）。
- 易错点：并发度 = 线程数（连接池打爆）；分页按 offset（越后越慢）；不让取消（用户等到崩溃）；单 Excel 百万行（打开即卡死）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.Future;
import java.util.concurrent.atomic.AtomicBoolean;
import java.util.concurrent.atomic.AtomicInteger;

public class PagedExport {
    record Chunk(int pageNo, long startId, long endId, int rows) {
    }

    static final long TOTAL = 1_000_000L;
    static final int ROWS_PER_PAGE = 50_000;

    /** 分片：按 id 区间切（避免 offset 漂移） */
    static List<Chunk> plan() {
        List<Chunk> chunks = new ArrayList<>();
        long start = 1;
        int page = 1;
        while (start <= TOTAL) {
            long end = Math.min(TOTAL, start + ROWS_PER_PAGE - 1);
            chunks.add(new Chunk(page++, start, end, (int) (end - start + 1)));
            start = end + 1;
        }
        return chunks;
    }

    static void sequentialPlan() {
        System.out.println("【分页方案】");
        List<Chunk> chunks = plan();
        System.out.printf("  总行数 %,d / 每页 %,d -> %d 个文件%n",
                TOTAL, ROWS_PER_PAGE, chunks.size());
        chunks.forEach(c -> System.out.printf("    第 %d 页：id %d~%d（%d 行）-> 订单_%d-%d.xlsx%n",
                c.pageNo(), c.startId(), c.endId(), c.rows(), c.startId(), c.endId()));
        System.out.println("  最后打包：订单导出_20261118.zip（73-09）");
        System.out.println();
    }

    /** 并发导出 + 进度 + 取消 */
    static void concurrent(boolean cancelAfterMs) throws Exception {
        System.out.println("【并发导出（4 线程）+ 进度 + 取消】");
        List<Chunk> chunks = plan();
        ExecutorService pool = Executors.newFixedThreadPool(4);
        AtomicInteger done = new AtomicInteger();
        AtomicInteger cancelled = new AtomicInteger();
        AtomicBoolean stop = new AtomicBoolean(false);
        Map<Integer, Long> pageCost = new LinkedHashMap<>();

        long t0 = System.currentTimeMillis();
        List<Future<String>> futures = new ArrayList<>();
        for (Chunk c : chunks) {
            futures.add(pool.submit(() -> {
                if (stop.get()) {
                    cancelled.incrementAndGet();
                    return "第 " + c.pageNo() + " 页：已取消";
                }
                long start = System.currentTimeMillis();
                // 模拟生成：每 1 万行约 40ms
                long work = Math.max(20, c.rows() / 250L);
                try {
                    Thread.sleep(work);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    return "第 " + c.pageNo() + " 页：中断";
                }
                long cost = System.currentTimeMillis() - start;
                pageCost.put(c.pageNo(), cost);
                int n = done.incrementAndGet();
                System.out.printf("  完成 %d/%d：第 %d 页（%d 行，%d ms）%n",
                        n, chunks.size(), c.pageNo(), c.rows(), cost);
                return "第 " + c.pageNo() + " 页：完成";
            }));
        }

        if (cancelAfterMs) {
            Thread.sleep(60);
            stop.set(true);
            System.out.println("  >>> 用户取消（正在执行的批次会跑完，未开始的跳过）");
        }

        int ok = 0;
        for (Future<String> f : futures) {
            String s = f.get();
            if (s.endsWith("完成")) {
                ok++;
            }
        }
        pool.shutdown();
        long total = System.currentTimeMillis() - t0;
        System.out.printf("  汇总：完成 %d 页，取消/跳过 %d 页，耗时 %d ms%n",
                ok, cancelled.get(), total);
        System.out.println("  注意：并发度受连接池限制（4 线程 = 4 连接），不是越高越好");
        System.out.println();
    }

    public static void main(String[] args) throws Exception {
        sequentialPlan();
        concurrent(false);
        concurrent(true);
        System.out.println("【要点】id 区间分片（不重不漏）/ 并发受连接池约束 / 进度可观测 / 可取消");
    }
}
```

### 76-04 Excel 写入原理（SXSSF 思想）

**知识点**
- **Excel 的两种写入模式**：**DOM 模式**（POI 的 `XSSF`，全建对象再写，10 万行即 OOM）与**流式模式**（`SXSSF`，**滑动窗口 + 临时文件**，只在内存保留 N 行）——**导出的唯一正确姿势是流式**。
- **xlsx 本质是 ZIP + XML**：`[Content_Types].xml` + `xl/workbook.xml` + `xl/worksheets/sheet1.xml`（行/单元格）+ `xl/sharedStrings.xml`（共享字符串）——**"写 Excel"就是"按格式拼 XML 再压 ZIP"**。
- **SXSSF 的滑动窗口**：`new SXSSFWorkbook(100)` 表示内存只保留 100 行，**超出的刷到磁盘临时文件**——**内存恒定，代价是临时磁盘 IO**（73-10 的存储治理也要管临时文件）。
- **单元格类型**：**字符串用共享字符串表**（同值只存一份，省空间）、**数字直接写**、**日期用序列号 + 格式**——**类型错了 Excel 会显示成文本**（`"00123"` 变文本、`1.0` 变日期）。
- 与 73-09 的关系：73-09 已手写过"最小 xlsx"（ZIP + XML），**本节把它用在"流式写入"上**——同一套原理，规模不同。
- 易错点：用 XSSF 写大文件（OOM）；全部用字符串类型（Excel 无法求和）；不设列宽/格式（打开是一堆 `####`）；临时文件不清理（磁盘打满）。

**示例代码**
```java
import java.io.ByteArrayOutputStream;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.util.LinkedHashMap;
import java.util.Map;
import java.util.zip.ZipEntry;
import java.util.zip.ZipOutputStream;

public class ExcelStreaming {
    /** 简化 xlsx 写入器：模拟 SXSSF 的滑动窗口（这里窗口只体现为"逐行写 XML"） */
    static class SheetWriter {
        final StringBuilder sheet = new StringBuilder();
        final Map<String, Integer> sharedStrings = new LinkedHashMap<>();
        int rows;

        SheetWriter() {
            sheet.append("<?xml version=\"1.0\" encoding=\"UTF-8\"?>\n");
            sheet.append("<worksheet xmlns=\"http://schemas.openxmlformats.org/spreadsheetml/2006/main\">");
            sheet.append("<sheetData>\n");
        }

        /** 写一行：字符串进共享表，数字直接写 */
        void writeRow(int rowNum, Object... cells) {
            sheet.append("<row r=\"").append(rowNum).append("\">");
            for (int i = 0; i < cells.length; i++) {
                String ref = colName(i) + rowNum;
                Object v = cells[i];
                if (v instanceof Number n) {
                    sheet.append("<c r=\"").append(ref).append("\"><v>")
                            .append(n).append("</v></c>");
                } else {
                    int idx = sharedStrings.computeIfAbsent(String.valueOf(v),
                            k -> sharedStrings.size());
                    sheet.append("<c r=\"").append(ref).append("\" t=\"s\"><v>")
                            .append(idx).append("</v></c>");
                }
            }
            sheet.append("</row>\n");
            rows++;
        }

        static String colName(int i) {
            return String.valueOf((char) ('A' + i));
        }

        String sheetXml() {
            return sheet + "</sheetData></worksheet>";
        }

        String sharedXml() {
            StringBuilder sb = new StringBuilder();
            sb.append("<?xml version=\"1.0\" encoding=\"UTF-8\"?>\n");
            sb.append("<sst xmlns=\"http://schemas.openxmlformats.org/spreadsheetml/2006/main\" count=\"")
                    .append(sharedStrings.size()).append("\">");
            for (String s : sharedStrings.keySet()) {
                sb.append("<si><t>").append(escape(s)).append("</t></si>");
            }
            return sb.append("</sst>").toString();
        }

        static String escape(String s) {
            return s.replace("&", "&amp;").replace("<", "&lt;").replace(">", "&gt;");
        }
    }

    static byte[] buildXlsx(SheetWriter w) throws IOException {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        try (ZipOutputStream zip = new ZipOutputStream(bos, StandardCharsets.UTF_8)) {
            put(zip, "[Content_Types].xml",
                    "<?xml version=\"1.0\"?><Types xmlns=\"http://schemas.openxmlformats.org/package/2006/content-types\">"
                            + "<Default Extension=\"xml\" ContentType=\"application/xml\"/>"
                            + "<Override PartName=\"/xl/workbook.xml\" ContentType=\"application/vnd.openxmlformats-officedocument.spreadsheetml.sheet.main+xml\"/>"
                            + "<Override PartName=\"/xl/worksheets/sheet1.xml\" ContentType=\"application/vnd.openxmlformats-officedocument.spreadsheetml.worksheet+xml\"/>"
                            + "<Override PartName=\"/xl/sharedStrings.xml\" ContentType=\"application/vnd.openxmlformats-officedocument.spreadsheetml.sharedStrings+xml\"/>"
                            + "</Types>");
            put(zip, "xl/workbook.xml",
                    "<?xml version=\"1.0\"?><workbook xmlns=\"http://schemas.openxmlformats.org/spreadsheetml/2006/main\" "
                            + "xmlns:r=\"http://schemas.openxmlformats.org/officeDocument/2006/relationships\">"
                            + "<sheets><sheet name=\"订单\" sheetId=\"1\" r:id=\"rId1\"/></sheets></workbook>");
            put(zip, "xl/worksheets/sheet1.xml", w.sheetXml());
            put(zip, "xl/sharedStrings.xml", w.sharedXml());
        }
        return bos.toByteArray();
    }

    static void put(ZipOutputStream zip, String name, String content) throws IOException {
        zip.putNextEntry(new ZipEntry(name));
        zip.write(content.getBytes(StandardCharsets.UTF_8));
        zip.closeEntry();
    }

    static void windowExplain() {
        System.out.println("【SXSSF 滑动窗口】");
        System.out.println("  new SXSSFWorkbook(100)  -> 内存保留 100 行");
        System.out.println("  第 101 行写入 -> 最早的行刷到临时文件（/tmp/poi-sxssf-xxx）");
        System.out.println("  内存占用与总行数无关（约 100 行 * 行大小）");
        System.out.println("  结束：workbook.dispose() 删除临时文件（否则磁盘打满）");
        System.out.println();
        System.out.println("【XSSF vs SXSSF】");
        String[][] rows = {
                {"内存", "全部行在堆", "固定窗口（100~1000 行）"},
                {"10 万行", "OOM 风险", "正常"},
                {"读", "支持读", "只写"},
                {"代价", "-", "临时磁盘 IO"},
        };
        for (String[] r : rows) {
            System.out.printf("  %-6s XSSF=%-16s SXSSF=%s%n", r[0], r[1], r[2]);
        }
        System.out.println();
    }

    public static void main(String[] args) throws IOException {
        windowExplain();

        SheetWriter w = new SheetWriter();
        w.writeRow(1, "订单号", "客户", "金额");
        for (int i = 1; i <= 5; i++) {

                w.rows, w.sharedStrings.size(), bytes.length);

        System.out.println();
```

### 76-05 CSV 与编码

**知识点**
- **CSV 是"最朴素也最容易出错"的格式**：**没有标准**（RFC 4180 只是参考），**转义规则**（字段含逗号/引号/换行要加双引号，内部双引号翻倍）、**编码**（UTF-8 vs GBK）、**BOM**（Excel 打开 UTF-8 CSV 乱码的根源）——**导出 CSV 的坑比 Excel 多**。
- **转义三规则**：**含 `,` `"` `\n` 的字段用双引号包裹**；**字段内的 `"` 写成 `""`**；**行尾用 `\r\n`**（Excel 兼容）——**少一条就会错列**。
- **编码选择**：**内部/接口用 UTF-8**；**给 Excel 用户的 CSV 加 UTF-8 BOM**（`\uFEFF`）——**没有 BOM 时 Excel 按系统编码（中文 Windows 是 GBK）解析，必乱码**。
- **CSV 注入（公式注入）**：字段以 `=` `+` `-` `@` 开头时，Excel 会当公式执行（`=cmd|...`）——**导出前转义/加单引号前缀**，这是**真实的安全漏洞**（36 章输入校验的变体）。
- 与 73-09 的关系：73-09 的"导出压缩"里有 CSV 生成，**本节把转义/编码/注入讲透**。
- 易错点：不转义逗号（错列）；不用 BOM（乱码）；`\n` 换行（Windows 打开错行）；不防公式注入（安全漏洞）。

**示例代码**
```java
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;

public class CsvExport {
    /** 规则一：含特殊字符加引号；规则二：内部引号翻倍；规则三：防公式注入 */
    static String escape(String field) {
        if (field == null) {
            return "";
        }
        String v = field;
        // 公式注入防护：以 = + - @ 开头时加单引号前缀
        if (!v.isEmpty() && "=+-@".indexOf(v.charAt(0)) >= 0) {
            v = "'" + v;
        }
        boolean needQuote = v.contains(",") || v.contains("\"")
                || v.contains("\n") || v.contains("\r");
        if (!needQuote) {
            return v;
        }
        return "\"" + v.replace("\"", "\"\"") + "\"";
    }

    static String toCsv(List<String[]> rows, boolean withBom) {
        StringBuilder sb = new StringBuilder();
        if (withBom) {
            sb.append('\uFEFF');
        }
        for (String[] row : rows) {
            for (int i = 0; i < row.length; i++) {
                if (i > 0) {
                    sb.append(',');
                }
                sb.append(escape(row[i]));
            }
            sb.append("\r\n");
        }
        return sb.toString();
    }

    static void escaping() {
        System.out.println("【转义演示】");
        String[] inputs = {
                "普通文本",
                "含,逗号",
                "含\"引号",
                "含\n换行",
                "=SUM(A1:A9)",
                "-1+1",
        };
        for (String in : inputs) {
            System.out.printf("  %-14s -> [%s]%n",
                    in.replace("\n", "\\n"), escape(in).replace("\n", "\\n"));
        }
        System.out.println();
    }

    static void roundTrip() {
        System.out.println("【生成 CSV（带 BOM）】");
        List<String[]> rows = new ArrayList<>();
        rows.add(new String[]{"订单号", "客户", "备注", "金额"});
        rows.add(new String[]{"1001", "张三", "含,逗号的备注", "69.00"});
        rows.add(new String[]{"1002", "李四", "说\"你好\"", "129.00"});
        rows.add(new String[]{"1003", "王五", "两行\n备注", "39.00"});
        rows.add(new String[]{"1004", "=cmd|calc", "正常", "0.00"});

        String csv = toCsv(rows, true);
        csv.lines().forEach(l -> System.out.println("  " + l.replace("\uFEFF", "<BOM>")));

        byte[] bytes = csv.getBytes(StandardCharsets.UTF_8);
        System.out.printf("  字节数 %d（BOM 占 3 字节），首字节 %02X %02X %02X%n",
                bytes.length, bytes[0] & 0xFF, bytes[1] & 0xFF, bytes[2] & 0xFF);
        System.out.println();
        System.out.println("  若去掉 BOM：Excel（中文 Windows）按 GBK 解码 -> 「订单号」变乱码");
        System.out.println();
    }

    static void bomTable() {
        System.out.println("【编码与 BOM 决策】");
        String[][] rows = {
                {"UTF-8 + BOM", "Excel 双击打开正常", "给业务人员的 CSV（推荐）"},
                {"UTF-8 无 BOM", "Excel 可能乱码", "程序消费 / 上传给系统"},
                {"GBK", "老系统兼容", "仅对接遗留系统"},
                {"UTF-16", "少见", "特定财务软件"},
        };
        for (String[] r : rows) {
            System.out.printf("  %-14s %-22s %s%n", r[0], r[1], r[2]);
        }
        System.out.println();
        System.out.println("  原则：内部一律 UTF-8；面向 Excel 的下载加 BOM；转码只在边界做");
    }

    public static void main(String[] args) {
        escaping();
        roundTrip();
        bomTable();
        System.out.println("【CSV 四坑】逗号/引号/换行未转义、无 BOM 乱码、\\n 换行错位、公式注入");
    }
}
```

### 76-06 PDF 排版基础

**知识点**
- **PDF 的本质**：**页面 + 内容流**（`BT /F1 12 Tf 72 720 Td (Hello) Tj ET`）+ **字体资源** + **xref 交叉引用表**——**"生成 PDF"就是"按坐标画字/线，再写 xref"**，并不神秘（与 PDF 1.4 语法对应）。
- **坐标系**：**原点在左下角**（不是左上），**单位是 point**（1/72 英寸），A4 = 595×842pt——**排版时 y 轴从大到小走**（从上往下），这是新手最容易搞反的地方。
- **中文的关键：字体嵌入**——标准 14 字体不含中文，**必须嵌入字体（Type0/CIDFont + ToUnicode）**，否则中文显示为空白/方框——**这是"PDF 中文乱码"的唯一根因**。
- **排版要素**：**分页**（内容超出页面高度就 `showPage` + 换页）、**表格**（画线 + 逐格写文本 + 列宽计算）、**页眉页脚/页码**——**报表 PDF = 这三样的组合**。
- 与 73 章的关系：PDF 是"不可编辑的交付物"，**通常配合签名 URL 下载**（73-06）——**发票/合同/对账单**是典型场景。
- 易错点：y 轴当左上（内容倒置/出界）；不嵌中文（乱码）；不处理分页（内容溢出丢失）；表格不换行（长文本撑破）。

**示例代码**
```java
import java.io.ByteArrayOutputStream;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;

public class PdfLayout {
    /** 极简 PDF 生成：页面 + 文本 + 线（不嵌入中文，演示排版坐标系） */
    static class PdfBuilder {
        final List<String> pages = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        final double pageWidth = 595;
        final double pageHeight = 842;

        void beginPage() {
            current = new StringBuilder();
        }

        /** 画文本：注意 y 轴从下往上，这里传"距顶部距离"自动换算 */
        void text(double x, double fromTop, double size, String s) {
            double y = pageHeight - fromTop;
            current.append("BT /F1 ").append(size).append(" Tf ")
                    .append(fmt(x)).append(' ').append(fmt(y)).append(" Td (")
                    .append(escapePdf(s)).append(") Tj ET\n");
        }

        void line(double x1, double fromTop1, double x2, double fromTop2) {
            current.append(fmt(x1)).append(' ').append(fmt(pageHeight - fromTop1)).append(" m ")
                    .append(fmt(x2)).append(' ').append(fmt(pageHeight - fromTop2)).append(" l S\n");
        }

        void endPage() {
            pages.add(current.toString());
        }

        static String fmt(double v) {
            return String.format("%.1f", v);
        }

        static String escapePdf(String s) {
            return s.replace("\\", "\\\\").replace("(", "\\(").replace(")", "\\)");
        }

        byte[] build() throws IOException {
            ByteArrayOutputStream out = new ByteArrayOutputStream();
            List<Integer> offsets = new ArrayList<>();
            StringBuilder pdf = new StringBuilder();
            pdf.append("%PDF-1.4\n");

            // 对象 1：Catalog；对象 2：Pages；对象 3：Font；对象 4..：Page/Content
            int obj1 = 1, obj2 = 2, obj3 = 3;
            int firstPage = 4;
            int objCount = 3 + pages.size() * 2;

            offsets.add(0);
            StringBuilder body = new StringBuilder();
            offsets.add(body.length());
            body.append(obj1).append(" 0 obj << /Type /Catalog /Pages ").append(obj2)
                    .append(" 0 R >> endobj\n");
            int pagesOffset = body.length();
            StringBuilder kids = new StringBuilder();
            for (int i = 0; i < pages.size(); i++) {
                kids.append(firstPage + i * 2).append(" 0 R ");
            }
            // 先占位记录 Pages 对象
            body.append(obj2).append(" 0 obj << /Type /Pages /Kids [")
                    .append(kids).append("] /Count ").append(pages.size()).append(" >> endobj\n");
            body.append(obj3).append(" 0 obj << /Type /Font /Subtype /Type1 /BaseFont /Helvetica >> endobj\n");

            for (int i = 0; i < pages.size(); i++) {
                int pageObj = firstPage + i * 2;
                int contentObj = pageObj + 1;
                body.append(pageObj).append(" 0 obj << /Type /Page /Parent ").append(obj2)
                        .append(" 0 R /MediaBox [0 0 ").append((int) pageWidth).append(' ')
                        .append((int) pageHeight).append("] /Contents ").append(contentObj)
                        .append(" 0 R /Resources << /Font << /F1 ").append(obj3)
                        .append(" 0 R >> >> >> endobj\n");
                String content = pages.get(i);
                body.append(contentObj).append(" 0 obj << /Length ")
                        .append(content.getBytes(StandardCharsets.ISO_8859_1).length)
                        .append(" >> stream\n").append(content).append("endstream endobj\n");
            }

            pdf.append(body);
            int xrefPos = pdf.length();
            pdf.append("xref\n0 ").append(objCount + 1).append("\n");
            pdf.append("0000000000 65535 f \n");
            for (int i = 1; i <= objCount; i++) {
                pdf.append(String.format("%010d 00000 n \n", 0));
            }
            pdf.append("trailer << /Size ").append(objCount + 1)
                    .append(" /Root ").append(obj1).append(" 0 R >>\nstartxref\n")
                    .append(xrefPos).append("\n%%EOF\n");
            out.write(pdf.toString().getBytes(StandardCharsets.ISO_8859_1));
            return out.toByteArray();
        }
    }

    static void coordinate() {
        System.out.println("【PDF 坐标系】");
        System.out.println("  A4：595 x 842 pt；原点在左下角");
        System.out.println("  距顶部 100pt 的文字 -> 实际 y = 842 - 100 = 742");
        System.out.println("  Td x y：把文本游标移到 (x, y)，然后 Tj 画文本");
        System.out.println("  常见错误：以为原点在左上 -> 内容倒置或跑出页面");
        System.out.println();
    }

    static void chineseIssue() {
        System.out.println("【中文必须嵌入字体】");
        System.out.println("  /BaseFont /Helvetica 只含西文 -> 中文显示空白/方框");
        System.out.println("  正解：Type0 复合字体 + CIDFont（如 STSong-Light）+ ToUnicode 映射");
        System.out.println("  结论：正式报表用成熟库（iText/OpenPDF），但要知道它在做什么");
        System.out.println();
    }

    public static void main(String[] args) throws IOException {
        coordinate();
        chineseIssue();

        PdfBuilder pdf = new PdfBuilder();
        pdf.beginPage();
        pdf.text(72, 72, 18, "Order Report");
        pdf.line(72, 90, 523, 90);
        pdf.text(72, 110, 11, "No.   Customer        Amount");
        pdf.text(72, 130, 11, "1001  Zhang San       69.00");
        pdf.text(72, 150, 11, "1002  Li Si          129.00");
        pdf.text(72, 800, 9, "Page 1 / 1");
        pdf.endPage();

        byte[] bytes = pdf.build();
        System.out.printf("【生成 PDF】%d 字节，%d 页%n", bytes.length, pdf.pages.size());
        System.out.println("  内容流示例（前 3 行）：");
        pdf.pages.get(0).lines().limit(3).forEach(l -> System.out.println("    " + l));
        System.out.println();
        System.out.println("【报表 PDF 三件套】分页（超高度换页）/ 表格（画线+逐格）/ 页眉页脚页码");
        System.out.println("  生产建议：用成熟库，但务必嵌入中文字体 + 显式处理分页");
    }
}
```

### 76-07 模板与动态报表

**知识点**
- **模板化是报表工程化的关键**：**版式与数据分离**——模板定义"哪里放什么"（占位符 + 循环区 + 表格区），数据只负责填充——**改版式不改代码，改数据不动模板**。
- **三类占位符**：**变量**（`${title}`）、**循环**（`{{#items}}...{{/items}}` 或表格行重复）、**条件**（`{{#if vip}}...{{/if}}`）——**与 37-04 的模板引擎同源**（Mustache/Thymeleaf 的最小模型）。
- **模板的两种落点**：**文档模板**（Word/Excel 模板 + 占位符替换，适合"格式复杂、变动少"的合同/发票）与**代码模板**（HTML/字符串拼接，适合"结构简单、变化多"的报表）——**按"改版频率"选**。
- **动态列是报表的难点**：列由数据决定（如"每月一列"）——**模板要支持"列集合"**，表头和数据行都按列集合渲染——**硬编码列名是动态报表的最大反模式**。
- 易错点：模板里写业务逻辑（不可维护）；占位符不转义（HTML 注入 36-02）；动态列硬编码；模板与数据版本不匹配（字段改名导致空白）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class ReportTemplate {
    /** 极简模板引擎：${var} 变量、{{#list}}...{{/list}} 循环、{{#if flag}}...{{/if}} 条件 */
    static class Template {
        final String src;

        Template(String src) {
            this.src = src;
        }

        String render(Map<String, Object> data) {
            return renderSection(src, data);
        }

        @SuppressWarnings("unchecked")
        String renderSection(String section, Map<String, Object> data) {
            // 1) 循环
            Pattern listPat = Pattern.compile("\\{\\{#([a-zA-Z_]+)}}(.*?)\\{\\{/\\1}}",
                    Pattern.DOTALL);
            Matcher lm = listPat.matcher(section);
            StringBuilder out = new StringBuilder();
            int last = 0;
            while (lm.find()) {
                out.append(section, last, lm.start());
                String key = lm.group(1);
                String body = lm.group(2);
                Object val = data.get(key);
                if (val instanceof List<?> list) {
                    for (Object item : list) {
                        Map<String, Object> scope = new LinkedHashMap<>(data);
                        if (item instanceof Map<?, ?> m) {
                            for (Map.Entry<?, ?> e : m.entrySet()) {
                                scope.put(String.valueOf(e.getKey()), e.getValue());
                            }
                        }
                        out.append(renderSection(body, scope));
                    }
                } else if (Boolean.TRUE.equals(val)) {
                    out.append(renderSection(body, data));       // if 语义
                }
                last = lm.end();
            }
            out.append(section.substring(last));

            // 2) 变量
            String result = out.toString();
            Matcher vm = Pattern.compile("\\$\\{([a-zA-Z_]+)}").matcher(result);
            StringBuilder sb = new StringBuilder();
            while (vm.find()) {
                Object v = data.get(vm.group(1));
                vm.appendReplacement(sb, Matcher.quoteReplacement(
                        v == null ? "" : escapeHtml(String.valueOf(v))));
            }
            vm.appendTail(sb);
            return sb.toString();
        }

        static String escapeHtml(String s) {
            return s.replace("&", "&amp;").replace("<", "&lt;").replace(">", "&gt;");
        }
    }

    /** 动态列：列集合来自数据，表头与行按列渲染 */

                }
                sb.append("</tr>");
```

### 76-08 异步导出任务

**知识点**
- **异步任务的完整生命周期**：**提交**（返回 taskId）-> **排队**（队列/线程池）-> **执行**（进度上报）-> **完成/失败**（结果落对象存储 73 章）-> **通知**（站内信/邮件/轮询）——**用户拿 taskId 查询进度，而不是等 HTTP 响应**。
- **任务状态机**：`PENDING -> RUNNING -> SUCCESS/FAILED/CANCELLED`——**状态流转要幂等**（重复提交返回同一 taskId 76-01），**失败可重试**（重试次数上限）。
- **进度上报**：**已处理行数/总行数**（或"当前阶段"）——**用户能看到"3 万/10 万"就不会以为卡死**；进度写 Redis/DB（不是内存，多实例可见）。
- **资源隔离**：**导出线程池独立于业务线程池**（大导出不拖垮在线接口 44-08）——**队列有界 + 拒绝策略**（满了返回"排队中"），**并发数受限**。
- 与 61 章的关系：与"分布式调度/工作流"同构——**任务编排、重试、超时、补偿**的完整套路（61-08）。
- 易错点：异步任务用主线程池（拖垮在线）；进度只在内存（多实例看不到）；无失败重试（一次失败就丢）；无过期清理（历史任务堆积 73-10）。

**示例代码**
```java
import java.util.LinkedHashMap;
import java.util.Map;
import java.util.concurrent.ArrayBlockingQueue;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.ThreadPoolExecutor;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicInteger;

public class AsyncExportJob {
    enum State { PENDING, RUNNING, SUCCESS, FAILED, CANCELLED }

    static class Job {
        final String taskId;
        final int totalRows;
        volatile State state = State.PENDING;
        volatile int processed;
        volatile String error;
        volatile String fileUrl;
        final AtomicInteger retries = new AtomicInteger();
        int plannedFailures;

        Job(String taskId, int totalRows) {
            this(taskId, totalRows, 0);
        }

        Job(String taskId, int totalRows, int plannedFailures) {
            this.taskId = taskId;
            this.totalRows = totalRows;
            this.plannedFailures = plannedFailures;
        }

        int percent() {
            return totalRows == 0 ? 0 : (int) (processed * 100L / totalRows);
        }

        Map<String, Object> snapshot() {
            Map<String, Object> m = new LinkedHashMap<>();
            m.put("taskId", taskId);
            m.put("state", state);
            m.put("processed", processed);
            m.put("total", totalRows);
            m.put("percent", percent() + "%");
            m.put("fileUrl", fileUrl);
            m.put("error", error);
            return m;
        }
    }

    /** 独立线程池：2 线程 + 有界队列（不拖垮业务） */
    static final ThreadPoolExecutor exportPool = new ThreadPoolExecutor(
            2, 2, 0, TimeUnit.SECONDS,
            new ArrayBlockingQueue<>(3),
            new ThreadPoolExecutor.AbortPolicy());

    static final Map<String, Job> jobs = new LinkedHashMap<>();

    /** 提交：幂等（同 taskId 复用） */
    static synchronized String submit(String taskId, int rows) {
        return submit(taskId, rows, 0);
    }

    /** plannedFailures：前 N 次执行模拟失败，用于演示重试 */
    static synchronized String submit(String taskId, int rows, int plannedFailures) {
        if (jobs.containsKey(taskId)) {
            System.out.println("  重复提交 -> 复用任务 " + taskId);
            return taskId;
        }
        Job job = new Job(taskId, rows, plannedFailures);
        jobs.put(taskId, job);
        try {
            exportPool.execute(() -> run(job));
            System.out.println("  提交成功 -> " + taskId + "（排队/执行中）");
        } catch (RuntimeException e) {
            job.state = State.FAILED;
            job.error = "QUEUE_FULL";
            System.out.println("  队列已满 -> 任务 " + taskId + " 被拒（应提示稍后重试）");
        }
        return taskId;
    }

    /** 执行：进度上报 + 失败重试（最多 2 次） */
    static void run(Job job) {
        job.state = State.RUNNING;
        try {
            if (job.plannedFailures > 0) {
                job.plannedFailures--;
                throw new IllegalStateException("模拟下游抖动");
            }
            int batch = 1000;
            while (job.processed < job.totalRows) {
                int step = Math.min(batch, job.totalRows - job.processed);
                Thread.sleep(20);                     // 模拟每批耗时
                job.processed += step;
                if (job.processed % 5000 == 0 || job.processed == job.totalRows) {
                    System.out.printf("    [%s] 进度 %d/%d（%d%%）%n",
                            job.taskId, job.processed, job.totalRows, job.percent());
                }
            }
            job.fileUrl = "https://cdn.example.com/export/" + job.taskId + ".xlsx";
            job.error = null;                     // 成功后清除上次失败信息
            job.state = State.SUCCESS;
            System.out.printf("    [%s] 完成 -> %s%n", job.taskId, job.fileUrl);
        } catch (Exception e) {
            job.error = e.getMessage();
            if (job.retries.incrementAndGet() <= 2) {
                System.out.printf("    [%s] 失败重试第 %d 次%n", job.taskId, job.retries.get());
                job.processed = 0;
                run(job);
            } else {
                job.state = State.FAILED;
                System.out.printf("    [%s] 最终失败：%s%n", job.taskId, job.error);
            }
        }
    }

    static void waitDone(String taskId, long timeoutMs) throws InterruptedException {
        long deadline = System.currentTimeMillis() + timeoutMs;
        while (System.currentTimeMillis() < deadline) {
            Job j = jobs.get(taskId);
            if (j.state == State.SUCCESS || j.state == State.FAILED) {
                return;
            }
            Thread.sleep(50);
        }
    }

    public static void main(String[] args) throws Exception {
        System.out.println("【提交导出任务】");
        submit("task-1", 5000);
        submit("task-1", 5000);
        submit("task-2", 3000, 1);
        waitDone("task-1", 5000);
        waitDone("task-2", 5000);

        System.out.println();
        System.out.println("【查询任务状态】");
        jobs.values().forEach(j -> System.out.println("  " + j.snapshot()));

        System.out.println();
        System.out.println("【队列满：拒绝而非无限堆积】");
        for (int i = 0; i < 12; i++) {
            submit("bulk-" + i, 200);
        }
        exportPool.shutdown();
        exportPool.awaitTermination(5, TimeUnit.SECONDS);

        System.out.println();
        System.out.println("【要点】独立线程池 / 幂等提交 / 进度可查 / 失败重试 / 队列有界");
        System.out.println("  生产：进度写 Redis（多实例可见），结果文件落对象存储（73 章），过期清理（73-10）");
    }
}
```

### 76-09 下载中心与权限

**知识点**
- **下载中心是"文件的统一入口"**：**列表**（历史导出/生成的文件）、**状态**（生成中/可下载/已过期）、**操作**（下载/删除/重新生成）——**用户不用再"点了等、等不到就重复点"**。
- **权限三层**：**能否看到该文件**（归属校验：只能看自己/本部门 74-05）、**能否下载**（下载动作单独鉴权，防"看到链接就能拿"）、**链接有效期**（签名 URL 73-06，如 15 分钟）——**三层缺一都可能泄露**。
- **文件归属与共享**：文件有 `ownerId + tenantId`（74-09），**共享要给"被共享人"单独授权**（不是把 URL 发出去）——**URL 即权限是最大的反模式**。
- **过期与清理**：导出文件是"临时产物"（**保留 7 天**），到期删除（73-10 的生命周期）——**下载中心要显示"剩余有效期"**。
- 与 73 章的关系：73 章讲"文件怎么存/怎么发"，**本节讲"谁能在下载中心看到并下载什么"**——**权限与生命周期是治理的两面**。
- 易错点：只校验"登录"不校验"归属"（越权下载）；URL 永久有效（泄露即永久）；下载不记审计（76-10 无法追溯）；不清理（存储无限增长）。

**示例代码**
```java
import java.time.Duration;
import java.time.LocalDateTime;
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class DownloadCenter {
    record ExportFile(String fileId, String ownerId, String tenantId, String name,
                      LocalDateTime createdAt, Duration ttl, boolean shared) {
        boolean expired(LocalDateTime now) {
            return now.isAfter(createdAt.plus(ttl));
        }
    }

    record User(String userId, String tenantId, String deptId, boolean admin) {
    }

    record AccessResult(boolean allowed, String reason) {
    }

    static final Map<String, List<String>> shares = new LinkedHashMap<>();
    static final List<String> auditLog = new ArrayList<>();

    /** 三层校验：归属 -> 下载权限 -> 链接有效期 */
    static AccessResult canDownload(User user, ExportFile f, LocalDateTime now,
                                    String action) {
        if (!user.tenantId().equals(f.tenantId())) {
            return new AccessResult(false, "跨租户拒绝（74-09）");
        }
        boolean owner = user.userId().equals(f.ownerId());
        boolean sharedToMe = shares.getOrDefault(f.fileId(), List.of())
                .contains(user.userId());
        if (!owner && !sharedToMe && !user.admin()) {
            return new AccessResult(false, "无归属/未共享（越权）");
        }
        if (action.equals("download") && f.expired(now)) {
            return new AccessResult(false, "文件已过期（" + f.ttl().toDays() + " 天）");
        }
        return new AccessResult(true, owner ? "所有者" : sharedToMe ? "被共享" : "管理员");
    }

    /** 生成签名 URL：短有效期 + 绑定 fileId */
    static String signedUrl(ExportFile f, User user, LocalDateTime now) {
        if (!canDownload(user, f, now, "download").allowed()) {
            return null;
        }
        long expiresAt = now.plus(Duration.ofMinutes(15))
                .atZone(java.time.ZoneId.systemDefault()).toEpochSecond();
        String sig = Integer.toHexString((f.fileId() + ":" + expiresAt).hashCode());
        return "https://cdn.example.com/" + f.fileId() + "?expires=" + expiresAt
                + "&sig=" + sig;
    }

    static void record(User user, ExportFile f, String action, AccessResult r) {
        auditLog.add(String.format("%s %s %s %s -> %s",
                LocalDateTime.now().withNano(0), user.userId(), action, f.fileId(),
                r.allowed() ? "OK(" + r.reason() + ")" : "DENY(" + r.reason() + ")"));
    }

    public static void main(String[] args) {
        LocalDateTime now = LocalDateTime.of(2026, 11, 18, 10, 0);
        ExportFile mine = new ExportFile("f-1", "u-1", "t-1", "我的订单.xlsx",
                now.minusDays(1), Duration.ofDays(7), false);
        ExportFile others = new ExportFile("f-2", "u-2", "t-1", "别人的订单.xlsx",
                now.minusDays(1), Duration.ofDays(7), false);
        ExportFile shared = new ExportFile("f-3", "u-2", "t-1", "共享报表.xlsx",
                now.minusDays(2), Duration.ofDays(7), true);
        ExportFile old = new ExportFile("f-4", "u-1", "t-1", "过期导出.xlsx",
                now.minusDays(10), Duration.ofDays(7), false);
        shares.put("f-3", List.of("u-1"));

        User u1 = new User("u-1", "t-1", "d-1", false);
        User u2 = new User("u-2", "t-1", "d-1", false);
        User cross = new User("u-9", "t-2", "d-9", false);
        User admin = new User("admin", "t-1", "d-0", true);

        System.out.println("【下载中心列表（u-1 视角）】");
        for (ExportFile f : List.of(mine, others, shared, old)) {
            AccessResult r = canDownload(u1, f, now, "list");
            String state = f.expired(now) ? "已过期" : "可下载";
            System.out.printf("  %-14s owner=%-4s 共享=%-5s %-6s -> %s%n",
                    f.name(), f.ownerId(), f.shared(), state,
                    r.allowed() ? "可见" : "不可见（" + r.reason() + "）");
        }

        System.out.println();
        System.out.println("【下载鉴权】");
        record(u1, mine, "download", canDownload(u1, mine, now, "download"));
        record(u1, others, "download", canDownload(u1, others, now, "download"));
        record(u1, shared, "download", canDownload(u1, shared, now, "download"));
        record(u1, old, "download", canDownload(u1, old, now, "download"));
        record(cross, mine, "download", canDownload(cross, mine, now, "download"));
        record(admin, others, "download", canDownload(admin, others, now, "download"));
        auditLog.forEach(l -> System.out.println("  " + l));

        System.out.println();
        System.out.println("【签名 URL（15 分钟）】");
        System.out.println("  u-1 下载 mine：" + signedUrl(mine, u1, now));
        System.out.println("  u-1 下载 others：" + signedUrl(others, u1, now) + "（拒绝，返回 null）");

        System.out.println();
        String[][] rules = {
                {"归属校验", "只能看自己/被共享/管理员", "防越权"},
                {"下载鉴权", "list 与 download 分开校验", "防看到就能拿"},
                {"链接有效期", "签名 URL 15 分钟", "防链接泄露"},
                {"保留期", "导出文件 7 天清理", "73-10 生命周期"},
        };
        for (String[] r : rules) {
            System.out.printf("  %-10s %-30s %s%n", r[0], r[1], r[2]);
        }
    }
}
```

### 76-10 导出安全与审计

**知识点**
- **导出的四类风险**：**越权导出**（导出全量而非自己可见的数据 74-05）、**敏感字段泄露**（手机号/身份证未脱敏 68-04）、**大批量拉取**（内部人员一次导 100 万条，44-08 的配额）、**文件外泄**（下载链接被转发 73-06）——**导出是数据泄露的高发口**，必须专项治理。
- **导出前必须做的三件事**：**行级权限**（只能导出"你能看到的"）、**列级脱敏**（敏感列按角色遮蔽）、**数量配额**（每人每日导出上限，超限拦截）——**与 68 章隐私工程同源**。
- **审计要记全**：**谁**（userId）、**何时**（时间）、**导了什么**（报表类型 + 筛选条件）、**多少行**（数量）、**结果**（成功/失败/被拒）、**文件 ID**（可追溯）——**审计日志不可篡改**（68-09）。
- **水印与追溯**：导出文件加**隐形水印**（含 userId/时间），泄露后可溯源——**"防不住就追得到"**是数据安全的基本策略。
- 与 36/68 章的关系：导出安全 = **输入校验（条件注入）+ 权限（行/列）+ 脱敏 + 配额 + 审计**——**是全书安全能力的汇总演练**。
- 易错点：导出不分权限（全量导出）；敏感列不脱敏（手机号明文）；无配额（内部人批量拉取）；审计只记"导出成功"（不记条件和行数）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

public class ExportSecurity {
    record Order(long id, String customer, String phone, String idCard, double amount,
                 String deptId) {
    }

    record Operator(String userId, String role, Set<String> deptScope, int dailyQuota) {
    }

    static final List<Order> allOrders = new ArrayList<>();

    static {
        allOrders.add(new Order(1, "张三", "13800001111", "110101199001011234", 69.0, "d-1"));
        allOrders.add(new Order(2, "李四", "13900002222", "310101199202022345", 129.0, "d-1"));
        allOrders.add(new Order(3, "王五", "13700003333", "440101199303033456", 39.0, "d-2"));
        allOrders.add(new Order(4, "赵六", "13600004444", "510101199404044567", 199.0, "d-2"));
        allOrders.add(new Order(5, "钱七", "13500005555", "330101199505055678", 88.0, "d-3"));
    }

    static String maskPhone(String p) {
        return p.substring(0, 3) + "****" + p.substring(7);
    }

    static String maskIdCard(String id) {
        return id.substring(0, 6) + "********" + id.substring(14);
    }

    /** 列级脱敏：按角色决定敏感列是否可见 */
    static Map<String, Object> project(Order o, String role) {
        Map<String, Object> row = new LinkedHashMap<>();
        row.put("id", o.id());
        row.put("customer", o.customer());
        row.put("amount", o.amount());
        if (role.equals("admin") || role.equals("auditor")) {
            row.put("phone", o.phone());
            row.put("idCard", o.idCard());
        } else {
            row.put("phone", maskPhone(o.phone()));
            row.put("idCard", maskIdCard(o.idCard()));
        }
        return row;
    }

    /** 行级权限：只能导出 deptScope 内的数据 */
    static List<Order> filterRows(Operator op) {
        List<Order> out = new ArrayList<>();
        for (Order o : allOrders) {
            if (op.role().equals("admin") || op.deptScope().contains(o.deptId())) {
                out.add(o);
            }
        }
        return out;
    }

    /** 配额：每日导出上限（生产用 Redis 计数） */
    static final Map<String, Integer> usedToday = new LinkedHashMap<>();

    static String checkQuota(Operator op, int requested) {
        int used = usedToday.getOrDefault(op.userId(), 0);
        if (used + requested > op.dailyQuota()) {
            return "拒绝：超出每日配额（已用 " + used + " / 上限 " + op.dailyQuota() + "）";
        }
        usedToday.put(op.userId(), used + requested);
        return "通过：已用 " + (used + requested) + " / " + op.dailyQuota();
    }

    record Audit(String userId, String report, int rows, String result, String fileId) {
    }

    static final List<Audit> audits = new ArrayList<>();

    public static void main(String[] args) {
        Operator staff = new Operator("u-1", "staff", Set.of("d-1"), 100);
        Operator manager = new Operator("u-2", "admin", Set.of(), 10_000);

        System.out.println("【行级权限】");

        System.out.println("【配额】");

        System.out.println("  staff 再申请 60 行：" + checkQuota(staff, 60));
        System.out.println("  admin 申请 5000 行：" + checkQuota(manager, 5000));

        System.out.println();
        System.out.println("【审计】");
        audits.add(new Audit("u-1", "订单明细", 2, "SUCCESS", "f-100"));
        audits.add(new Audit("u-1", "订单明细", 0, "DENY(quota)", "-"));
        audits.add(new Audit("u-2", "全量订单", 5, "SUCCESS", "f-101"));

        String watermark = "u-1|2026-11-18T10:00|f-100";

        String[][] defenses = {
```

### 76-11 综合案例：百万行导出

**知识点**
- **把本章收口成一条完整链路**：**配额校验**（76-10）-> **异步任务**（76-08）-> **游标流式查询**（76-02）-> **分册生成 xlsx**（76-03/76-04）-> **ZIP 打包**（73-09）-> **落对象存储 + 签名 URL**（73 章）-> **审计**（76-10）——**每一环都可独立验证**。
- **百万行的验收指标**：**内存峰值恒定**（不随行数增长）、**耗时线性**（不因翻页变慢）、**可取消**、**可重试**、**文件可下载**（分册 + 总 ZIP）。
- **关键权衡**：**单文件 vs 分册**（Excel 单文件超 10 万行打开困难 -> 按 5 万行分册）、**CSV vs XLSX**（百万行 CSV 更合适）、**实时 vs 异步**（必然异步）。
- 与全书的关系：本章是"数据处理 + 文件 + 任务 + 权限 + 安全"的**终章级综合**——**它把 54（数据）、61（任务）、73（文件）、74（权限）、76（导出）串成一条线**。
- 易错点：全量 load；单文件百万行；无配额；无审计；不可取消。

**示例代码**
```java
import java.io.ByteArrayOutputStream;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.zip.ZipEntry;
import java.util.zip.ZipOutputStream;

public class MillionRowExportCase {
    record Order(long id, String customer, double amount, String deptId) {
    }

    static final long TOTAL = 1_000_000L;
    static final int PAGE_ROWS = 50_000;
    static final int BATCH = 2_000;

    /** 游标查询（只生成元数据，不真存百万对象） */
    static List<Order> queryAfter(long lastId, int limit) {
        List<Order> rows = new ArrayList<>(limit);
        long end = Math.min(TOTAL, lastId + limit);
        for (long id = lastId + 1; id <= end; id++) {
            rows.add(new Order(id, "客户" + (id % 5000), 10.0 + (id % 300) / 3.0,
                    "d-" + (id % 20)));
        }
        return rows;
    }

    /** 一册的 CSV 内容（演示流式：逐批写，不持有全册） */
    static String buildPageCsv(long startId, long endId, String deptFilter) throws IOException {
        StringBuilder sb = new StringBuilder();
        sb.append("id,customer,amount,dept\n");
        long cursor = startId - 1;
        while (cursor < endId) {
            List<Order> batch = queryAfter(cursor, BATCH);
            for (Order o : batch) {
                if (o.id() > endId) {
                    break;
                }
                if (deptFilter != null && !o.deptId().equals(deptFilter)) {
                    continue;
                }
                sb.append(o.id()).append(',').append(o.customer()).append(',')
                        .append(o.amount()).append(',').append(o.deptId()).append('\n');
            }
            cursor = batch.get(batch.size() - 1).id();
        }
        return sb.toString();
    }

    static byte[] zip(Map<String, byte[]> files) throws IOException {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        try (ZipOutputStream z = new ZipOutputStream(bos, StandardCharsets.UTF_8)) {
            for (Map.Entry<String, byte[]> e : files.entrySet()) {
                z.putNextEntry(new ZipEntry(e.getKey()));
                z.write(e.getValue());
                z.closeEntry();
            }
        }
        return bos.toByteArray();
    }

    record JobState(String taskId, int totalPages, int donePages, long rowsWritten,
                    String state, String url, boolean cancelled) {
    }

    /** 主流程：配额 -> 任务 -> 逐册 -> 打包 -> URL -> 审计 */
    static void run(String taskId, String deptFilter, int quota, boolean cancelAfterPage)
            throws IOException {
        System.out.printf("【任务 %s】筛选=%s 配额=%d 行%n", taskId, deptFilter, quota);

        long estimated = deptFilter == null ? TOTAL : TOTAL / 20;
        if (estimated > quota) {
            System.out.println("  拒绝：预计 " + estimated + " 行 > 配额 " + quota);
            return;
        }
        System.out.println("  配额通过（预计筛选后 " + estimated + " 行）");

        List<String> pageNames = new ArrayList<>();
        Map<String, byte[]> files = new LinkedHashMap<>();
        // 分册始终按 id 区间切（不因筛选而改变区间，避免重复/遗漏）
        int pages = (int) ((TOTAL + PAGE_ROWS - 1) / PAGE_ROWS);
        int done = 0;
        long written = 0;
        boolean cancelled = false;

        for (int p = 0; p < pages; p++) {
            if (cancelAfterPage && p == 1) {
                cancelled = true;
                System.out.println("  用户取消：已完成 " + done + " 册，停止");
                break;
            }
            long startId = (long) p * PAGE_ROWS + 1;
            long endId = Math.min(TOTAL, startId + PAGE_ROWS - 1);
            String name = String.format("订单_%d-%d.csv", startId, endId);
            String csv = buildPageCsv(startId, endId, deptFilter);
            files.put(name, csv.getBytes(StandardCharsets.UTF_8));
            pageNames.add(name);
            done++;
            int lines = (int) csv.lines().count() - 1;
            written += lines;
            System.out.printf("    第 %d/%d 册 %s -> %,d 行%n", done, pages, name, lines);
        }

        byte[] zipBytes = zip(files);
        String url = cancelled ? null
                : "https://cdn.example.com/export/" + taskId + ".zip?expires=1800&sig=abc";
        System.out.println();
        System.out.println("【结果】");
        System.out.println("  册数 " + done + "/" + pages + "，总行数 " + written
                + "，ZIP " + zipBytes.length + " 字节");
        System.out.println("  下载 URL：" + (url == null ? "（已取消，无）" : url));
        System.out.println("  审计：task=" + taskId + " user=u-1 rows=" + written
                + " filter=" + deptFilter + " state=" + (cancelled ? "CANCELLED" : "SUCCESS"));
        System.out.println("  内存：每批 " + BATCH + " 行（约 "
                + (BATCH * 200 / 1024) + "KB），与总行数无关");
        System.out.println();
    }

    public static void main(String[] args) throws IOException {
        System.out.println("【百万行导出：全量（配额 200 万）】");
        run("task-full", null, 2_000_000, false);

        System.out.println("【部门筛选（d-3）+ 取消】");
        run("task-dept", "d-3", 100_000, true);

        System.out.println("【配额不足】");
        run("task-over", null, 500_000, false);

        System.out.println("【验收清单】");
        String[][] checks = {
                {"内存恒定", "每批 2000 行，不随总行数增长", "76-02"},
                {"耗时线性", "游标分页，不因翻页变慢", "76-03"},
                {"可取消", "取消后停止生成，返回已完成的册", "76-08"},
                {"可重试", "任务幂等，重试不重复", "76-01"},
                {"可下载", "分册 + ZIP + 签名 URL", "73-06"},
                {"可审计", "谁/条件/行数/结果", "76-10"},
        };
        for (String[] c : checks) {
            System.out.printf("  %-8s %-32s %s%n", c[0], c[1], c[2]);
        }
    }
}
```
