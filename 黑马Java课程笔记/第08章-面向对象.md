# 第8章 面向对象

本章正式迈入面向对象编程：从"面向过程"的思想转变开始，学习类与对象的定义和使用、成员变量默认值等细节、private 封装与数据安全、this 关键字与构造方法，最终掌握标准 JavaBean 的完整写法。

### 8-01 什么是面向对象？（面向过程 vs 面向对象思想）

**知识点**
- 面向过程：关注"怎么做"，把问题拆成一个个步骤，自己一步一步实现，代表语言是 C。
- 面向对象：关注"谁来做"，把数据和功能打包成对象，让对象之间协作完成任务，Java 就是面向对象的语言。
- 面向对象是一种思想，不是某种语法：拿到需求后先找"对象"（参与者），再让对象做事，最后拿到结果。
- 生活例子：洗衣服，面向过程是自己按"脱衣、泡水、揉搓、拧干、晾晒"一步步做；面向对象是把衣服交给洗衣机这个"对象"，让洗衣机完成。
- 好处：把复杂问题简单化，更符合人类思考习惯，让程序员从"实现者"变成"指挥者"。
- Java 中一切都是围绕类和对象展开的：JDK 提供的大量现成类（如 Arrays、Scanner）都可以直接拿来用。

**示例代码**
```java
// 文件名: ObjectOrientedDemo.java
// 对比：面向过程 vs 面向对象（任务：把数组排序并打印）
public class ObjectOrientedDemo {
    public static void main(String[] args) {
        int[] arr = {5, 2, 8, 1};

        // 面向过程：每一步都自己写，关注"怎么做"
        // 步骤1：冒泡排序
        for (int i = 0; i < arr.length - 1; i++) {
            for (int j = 0; j < arr.length - 1 - i; j++) {
                if (arr[j] > arr[j + 1]) {
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }
        // 步骤2：自己遍历打印
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + " ");
        }
        System.out.println();

        // 面向对象：找 JDK 现成的"对象"帮忙，关注"谁来帮我做"
        // Arrays 是 JDK 提供的数组工具类，排序和转字符串都让它来做
        int[] arr2 = {5, 2, 8, 1};
        java.util.Arrays.sort(arr2);
        System.out.println(java.util.Arrays.toString(arr2));
    }
}
```

### 8-02 类和对象

**知识点**
- 类：是对事物共同特征的描述（模板、图纸），确定对象将会拥有的属性（成员变量）和行为（成员方法）。
- 对象：是类的具体实例，是真实存在的具体事物；类是模板，对象是根据模板造出来的具体东西。
- 定义类的格式：`public class 类名 { 成员变量; 成员方法; }`，类名使用英文大驼峰。
- 创建对象：`类名 对象名 = new 类名();`，new 负责在内存中开辟空间创建对象。
- 使用成员：访问成员变量用 `对象名.成员变量`；调用成员方法用 `对象名.方法名()`。
- 一个 .java 文件中通常一个类，main 方法写在单独的测试类中，让"描述类"和"测试类"分开。

**示例代码**
```java
// 文件名: Phone.java
// 类：描述手机这一类事物共同的特征（属性 + 行为）
public class Phone {
    // 成员变量（属性）
    String brand; // 品牌
    double price; // 价格

    // 成员方法（行为）
    public void call() {
        System.out.println("用" + brand + "手机打电话");
    }

    public void playGame() {
        System.out.println("用" + brand + "手机玩游戏");
    }
}
```

```java
// 文件名: PhoneTest.java
// 测试类：创建对象并使用
public class PhoneTest {
    public static void main(String[] args) {
        // 创建对象：类名 对象名 = new 类名();
        Phone p = new Phone();

        // 给成员变量赋值：对象名.成员变量
        p.brand = "华为";
        p.price = 6999.0;

        // 使用成员变量
        System.out.println(p.brand); // 华为
        System.out.println(p.price); // 6999.0

        // 调用成员方法：对象名.方法名()
        p.call();
        p.playGame();
    }
}
```

### 8-03 面向对象中的小细节

**知识点**
- 成员变量有默认值：整数 0、小数 0.0、布尔 false、字符 '\u0000'（空字符）、引用类型 null，不赋值也能直接使用。
- 局部变量没有默认值，必须先赋值再使用，这一点和成员变量不同。
- 类名命名规范：英文大驼峰（每个单词首字母大写）、见名知意，如 Student、GoodPhone，不能与关键字冲突。
- 一个 .java 文件中可以写多个类，但只能有一个类被 public 修饰，且文件名必须与 public 类名一致；实际开发建议一个文件只写一个类。
- 成员方法与 main 方法是平级的，成员方法不能写在 main 方法里面，也不能写在类的大括号外面。
- 成员方法必须通过"对象名.方法名()"调用（同一个类中直接写方法名调用的是另一种场景，本阶段统一用对象调用）。

**示例代码**
```java
// 文件名: Student.java
// 描述类：学生
public class Student {
    String name;  // 不赋值时默认值是 null
    int age;      // 不赋值时默认值是 0
    double score; // 不赋值时默认值是 0.0
    boolean male; // 不赋值时默认值是 false

    public void study() {
        System.out.println(name + "正在学习");
    }
}
```

```java
// 文件名: StudentTest.java
// 测试类
public class StudentTest {
    public static void main(String[] args) {
        Student stu = new Student();
        // 没有赋值，直接打印成员变量，输出各自的默认值
        System.out.println(stu.name);  // null
        System.out.println(stu.age);   // 0
        System.out.println(stu.score); // 0.0
        System.out.println(stu.male);  // false

        // 赋值后再调用方法
        stu.name = "阿玮";
        stu.study();
    }
}
```

### 8-04 面向对象中数据安全的问题

**知识点**
- 问题：属性不加限制时，外界可以随意赋值，甚至赋不合理的值（如 age = -100），程序不报错但数据不合理。
- 原因：成员变量直接暴露给了外界，任何地方都能通过"对象名.属性"读取和修改。
- 解决：用 private 关键字把成员变量私有化，让它只能在当前类内部被访问。
- private 之后外界无法直接访问，需要在本类中提供 public 的 getter（取值）和 setter（赋值）方法作为公共入口。
- 校验逻辑可以写在 setter 中，只有合法的数据才允许赋给成员变量，非法数据被拦截。
- 封装：隐藏实现细节，仅对外提供公共访问方式；private 是封装最直接的体现，好处是提高安全性、复用性，降低使用成本。

**示例代码**
```java
// 文件名: SafeStudent.java
public class SafeStudent {
    // 用 private 私有化，外界不能直接访问
    private String name;
    private int age;

    // setter：给外界提供设置 age 的入口，可以在里面做校验
    public void setAge(int a) {
        if (a >= 0 && a <= 120) {
            age = a;
        } else {
            System.out.println("年龄不合理，赋值失败");
        }
    }

    // getter：给外界提供读取 age 的入口
    public int getAge() {
        return age;
    }

    public void setName(String n) {
        name = n;
    }

    public String getName() {
        return name;
    }
}
```

```java
// 文件名: SafeStudentTest.java
public class SafeStudentTest {
    public static void main(String[] args) {
        SafeStudent stu = new SafeStudent();

        // stu.age = -100;  // private 之后这行报错，无法直接访问
        stu.setAge(-100);   // 走 setter，非法值被校验拦下
        stu.setName("小黑");

        System.out.println(stu.getName()); // 小黑
        System.out.println(stu.getAge());  // 0（非法值没有被赋进去）
    }
}
```

### 8-05 数据安全的练习：学生

**知识点**
- 题面：定义 Student 类，属性 name、age 全部用 private 修饰；提供 getName/setName、getAge/setAge；setAge 中校验年龄必须在 0~120 之间，非法则打印提示且不修改；再提供 study() 方法打印学习信息；最后写测试类验证。
- 思路：第一步属性私有化，第二步在 setter 方法内用 if 校验参数，第三步提供 getter 返回属性值，第四步在测试类中只通过方法访问属性。
- 易错点：校验不通过时不要给 age 赋值，保持原值即可；setter 的参数名如果与成员变量重名，需要用 this 区分（下一课详细讲解）。

**示例代码**
```java
// 文件名: Student.java
public class Student {
    private String name; // 姓名
    private int age;     // 年龄

    // 设置年龄，带合法性校验
    public void setAge(int a) {
        if (a >= 0 && a <= 120) {
            age = a;
        } else {
            System.out.println("输入的年龄有误，赋值失败，年龄保持默认值0");
        }
    }

    // 获取年龄
    public int getAge() {
        return age;
    }

    // 设置姓名
    public void setName(String n) {
        name = n;
    }

    // 获取姓名
    public String getName() {
        return name;
    }

    // 行为方法
    public void study() {
        System.out.println("名为" + name + "的学生正在学习Java");
    }
}
```

```java
// 文件名: StudentTest.java
public class StudentTest {
    public static void main(String[] args) {
        Student stu = new Student();

        stu.setName("阿玮");
        stu.setAge(18); // 合法，成功赋值
        System.out.println(stu.getName() + "：" + stu.getAge());
        stu.study();

        stu.setAge(200); // 非法，被校验拦下
        System.out.println("再次获取年龄：" + stu.getAge()); // 仍然是18
    }
}
```

### 8-06 就近原则和this关键字

**知识点**
- 就近原则：方法中使用某个变量名时，先在方法内部（局部变量）找，找到了就用局部的；找不到才去成员位置找。
- 问题：当成员变量与局部变量（比如 setter 的形参）重名时，就近原则会让方法内的名字代表局部变量，出现"name = name 自己赋给自己"的情况，成员变量赋值失败。
- this 的作用：代表当前对象（谁调用这个方法，this 就是谁），用 `this.成员变量` 明确访问成员位置的同名变量。
- 标准写法：`this.成员变量 = 形参;`，这是 setter 方法中的固定套路。
- 没有重名问题时 this 可以省略，省略后仍然遵循"就近原则"找到成员变量。
- 开发中即使不重名也建议养成习惯：涉及成员变量的地方尽量写清楚，避免歧义。

**示例代码**
```java
// 文件名: ThisStudent.java
public class ThisStudent {
    private String name;
    private int age;

    // this.name 是成员变量，等号右边的 name 是形参（局部变量）
    public void setName(String name) {
        this.name = name;
    }

    public String getName() {
        return name; // 没有重名，this 可以省略
    }

    public void setAge(int age) {
        this.age = age;
    }

    public int getAge() {
        return age;
    }

    public void show() {
        // 局部变量与成员变量重名时的对比
        int age = 99; // 局部变量
        System.out.println("局部变量age：" + age);      // 99（就近原则）
        System.out.println("成员变量age：" + this.age); // this 明确指向成员变量
    }
}
```

```java
// 文件名: ThisStudentTest.java
public class ThisStudentTest {
    public static void main(String[] args) {
        ThisStudent stu = new ThisStudent();
        stu.setName("阿玮");
        stu.setAge(18);
        stu.show();
        System.out.println(stu.getName() + " " + stu.getAge());
    }
}
```

### 8-07 构造方法

**知识点**
- 构造方法是在创建对象（new 的过程中）由虚拟机自动调用的方法，作用是给成员变量初始化赋值。
- 定义格式：方法名与类名完全相同、没有返回值类型（连 void 都不能写）、没有具体返回值。
- 无参构造：参数列表为空，创建对象时成员变量使用默认值；有参构造：通过参数把值传进来，在创建对象的同时完成赋值。
- 调用方式：new 类名() 走空参构造；new 类名(参数) 走与之匹配的有参构造。
- 构造方法不负责"创建对象"本身，创建对象是 new 干的事，构造方法只负责初始化。
- 构造方法里也可以写打印语句，方便观察它被自动执行的过程。

**示例代码**
```java
// 文件名: Person.java
public class Person {
    private String name;
    private int age;

    // 无参构造方法：new Person() 时被自动调用
    public Person() {
        System.out.println("无参构造方法执行了");
    }

    // 有参构造方法：new Person("阿玮", 18) 时被自动调用，用于初始化
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
        System.out.println("有参构造方法执行了");
    }

    public void show() {
        System.out.println("姓名：" + name + "，年龄：" + age);
    }
}
```

```java
// 文件名: PersonTest.java
public class PersonTest {
    public static void main(String[] args) {
        // 调用无参构造，属性是默认值
        Person p1 = new Person();
        p1.show();

        // 调用有参构造，创建对象的同时就完成赋值
        Person p2 = new Person("阿玮", 18);
        p2.show();
    }
}
```

### 8-08 构造方法的注意事项

**知识点**
- 如果一个类中一个构造方法都没写，编译器会自动赠送一个空参构造（方法体为空）。
- 一旦手动写了有参构造，系统就不再赠送空参构造，此时再写"new 类名()"会编译报错。
- 解决办法：想要两种创建方式都可用，就必须把空参构造和有参构造都手动写出来。
- 构造方法可以重载：参数个数、类型、顺序不同即构成重载，创建对象时按传入的参数自动匹配。
- 标准 JavaBean：属性私有化 + 空参构造 + 全参构造 + getter/setter，是实际开发中实体类的标准写法。
- IDEA 快捷键：Alt+Insert 可以自动生成构造方法和 getter/setter，没必要手敲。

**示例代码**
```java
// 文件名: User.java
// 标准 JavaBean（标准实体类）写法
public class User {
    private String username; // 用户名
    private String password; // 密码

    // 注意：只写下面那个有参构造后，系统就不再赠送空参构造
    // 想让两种 new 方式都可用，必须手动补上空参构造（构造方法可以重载）
    public User() {
    }

    // 有参构造（全参构造）
    public User(String username, String password) {
        this.username = username;
        this.password = password;
    }

    public String getUsername() {
        return username;
    }

    public void setUsername(String username) {
        this.username = username;
    }

    public String getPassword() {
        return password;
    }

    public void setPassword(String password) {
        this.password = password;
    }
}
```

```java
// 文件名: UserTest.java
public class UserTest {
    public static void main(String[] args) {
        // 方式1：空参构造 + setter 赋值
        User u1 = new User();
        u1.setUsername("admin");
        u1.setPassword("123456");
        System.out.println(u1.getUsername() + " " + u1.getPassword());

        // 方式2：有参构造，创建的同时赋值
        User u2 = new User("阿玮", "888888");
        System.out.println(u2.getUsername() + " " + u2.getPassword());
    }
}
```

### 8-09 面向对象小结

**知识点**
- 封装完整步骤：属性 private 私有化 → 手写空参构造 + 全参构造 → 提供 getter/setter → 需要校验的逻辑写在 setter 中。
- 类与对象：类是描述共同特征的模板，对象是类的具体实例；用 new 在内存中创建对象，用"对象名.成员"访问属性和方法。
- this：在成员变量与局部变量重名时区分二者，this 代表当前对象。
- 构造方法：与类同名、无返回值类型，new 时自动执行、用于初始化成员变量，且可以重载。
- 标准 JavaBean 模板必须练到形成肌肉记忆，后续章节（继承、集合、IO）中的实体类全部沿用这套写法。

**示例代码**
```java
// 文件名: Phone.java
// 本章小结模板：标准封装的完整步骤
public class Phone {
    // 步骤1：属性私有化
    private String brand;
    private double price;

    // 步骤2：空参构造
    public Phone() {
    }

    // 步骤3：全参构造
    public Phone(String brand, double price) {
        this.brand = brand;
        this.price = price;
    }

    // 步骤4：getter/setter（需要校验的逻辑写在 setter 里）
    public String getBrand() {
        return brand;
    }

    public void setBrand(String brand) {
        this.brand = brand;
    }

    public double getPrice() {
        return price;
    }

    public void setPrice(double price) {
        if (price >= 0) {
            this.price = price;
        } else {
            System.out.println("价格不能为负数");
        }
    }

    public void call() {
        System.out.println(brand + "手机正在打电话");
    }
}
```

```java
// 文件名: PhoneTest.java
public class PhoneTest {
    public static void main(String[] args) {
        Phone p1 = new Phone("华为", 6999.0);
        p1.call();

        Phone p2 = new Phone();
        p2.setBrand("小米");
        p2.setPrice(-100); // 触发校验，赋值失败
        System.out.println(p2.getBrand() + " " + p2.getPrice());
    }
}
```
