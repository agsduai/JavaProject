# 第13章 阶段项目实战

本章是一个综合实战项目：在控制台实现"用户注册登录 + 回合制格斗小游戏"，把前面所学的语法基础、面向对象、集合与常用 API 全部串起来，完整体验从需求分析、类设计到功能实现与扩展的开发流程。

### 13-01 项目介绍和主页面搭建

**知识点**
- 项目分两大模块：用户模块（注册、验证码、登录）+ 游戏模块（角色创建、回合制战斗、结算），先跑通主流程骨架，再逐个填充功能。
- 主页面用 while(true) 死循环包住菜单，每次操作完自动回到主菜单，只有选"退出"才结束程序。
- 菜单分发用 Scanner 录入 + switch 分发到不同功能；建议用 String 接收选项，避免录入非数字导致程序崩溃。
- 未实现的功能先用打印占位（"开发中..."），保证主流程先通，这就是"自顶向下、逐步求精"的开发思路。
- Scanner 对象定义为类的静态成员变量，让多个方法共用同一个输入源。

**示例代码**
```java
// 文件名: GameApp.java
import java.util.Scanner;

public class GameApp {
    static Scanner sc = new Scanner(System.in);

    public static void main(String[] args) {
        // 死循环保证每次操作后都回到主菜单
        while (true) {
            System.out.println("欢迎来到黑马格斗小游戏");
            System.out.println("1. 登录");
            System.out.println("2. 注册");
            System.out.println("3. 退出");
            System.out.println("请输入您的选择：");
            // 用 String 接收选项，避免录入非数字导致程序报错
            String choice = sc.next();
            switch (choice) {
                case "1":
                    System.out.println("登录功能开发中...");
                    break;
                case "2":
                    System.out.println("注册功能开发中...");
                    break;
                case "3":
                    System.out.println("感谢使用，再见！");
                    // 结束 main 方法，程序退出
                    return;
                default:
                    System.out.println("输入有误，请重新输入");
                    break;
            }
        }
    }
}
```

**课后练习**
1. 在主菜单增加"4. 游戏说明"选项，选择后打印完整玩法介绍，然后回到主菜单。
2. 增加一个"是否已登录"的状态标记：未登录时选择登录、注册、退出之外的选项，统一提示"请先登录或注册"。
3. 把主菜单的打印封装成 showMenu 方法，把选项分发封装成 dispatch 方法，让 main 方法只保留循环骨架。

### 13-02 用户类和注册的业务

**知识点**
- JavaBean 标准写法：属性全部 private，提供无参构造和全参构造，给每个属性提供 getter/setter。
- User 类只需要两个属性：username、password；注册的本质就是把录入的数据变成 User 对象存起来。
- 格式校验：用户名、密码长度要求 3~15 位，不合法要循环重新录入，校验通过才能继续往下走。
- 唯一性校验：注册前遍历 ArrayList<User> 比对用户名是否已存在，存在则提示重新录入。
- 用集合充当"数据库"：ArrayList<User> 定义为静态成员变量，注册成功就 add 进去。

**示例代码**
```java
// 文件名: User.java
public class User {
    private String username;
    private String password;

    public User() {
    }

    public User(String username, String password) {
        this.username = username;
        this.password = password;
    }

    public String getUsername() {
        return username;
    }

    public void setUsername(String username) {
        this.username = username;
    }

    public String getPassword() {
        return password;
    }

    public void setPassword(String password) {
        this.password = password;
    }
}
```

```java
// 文件名: RegisterDemo.java（依赖同目录的 User.java）
import java.util.ArrayList;
import java.util.Scanner;

public class RegisterDemo {
    static Scanner sc = new Scanner(System.in);
    // 用集合模拟数据库，存放所有已注册的用户
    static ArrayList<User> userList = new ArrayList<>();

    public static void main(String[] args) {
        userList.add(new User("zhangsan", "123456"));
        register();
        System.out.println("当前已注册用户数：" + userList.size());
    }

    // 注册业务：用户名校验 + 唯一性校验 + 密码校验 + 存入集合
    public static void register() {
        String username;
        while (true) {
            System.out.println("请输入用户名（3~15 位）：");
            username = sc.next();
            if (username.length() < 3 || username.length() > 15) {
                System.out.println("用户名长度不合法，请重新录入");
                continue;
            }
            if (isExists(username)) {
                System.out.println("用户名已被占用，请重新录入");
            } else {
                break;
            }
        }
        String password;
        while (true) {
            System.out.println("请输入密码（3~15 位）：");
            password = sc.next();
            if (password.length() >= 3 && password.length() <= 15) {
                break;
            }
            System.out.println("密码长度不合法，请重新录入");
        }
        // 校验全部通过，注册信息存入集合
        userList.add(new User(username, password));
        System.out.println("注册成功！");
    }

    // 判断用户名是否已存在
    public static boolean isExists(String username) {
        for (User u : userList) {
            if (u.getUsername().equals(username)) {
                return true;
            }
        }
        return false;
    }
}
```

**课后练习**
1. 注册时要求输入两次密码，两次不一致时提示"两次密码不一致"并重新录入。
2. 用户名校验升级：只允许出现字母和数字，包含其他字符时提示"用户名包含非法字符"并重新录入。
3. 注册成功后打印当前已注册的用户总数，并思考：当用户量非常大时，"遍历查重"这种方式会有什么问题？

### 13-03 验证码和登录业务的完整实现

**知识点**
- 验证码：5 位字符，从"大小写字母 + 数字"共 62 个字符中随机取；把字符池写成字符串，用随机下标取字符再拼接最简单。
- 登录三步校验：先验证码（忽略大小写用 equalsIgnoreCase）→ 再用户名 → 再密码，验证码不对就不用往后比了。
- 用户名要在集合中查询：没查到提示"用户名未注册"；查到了再比对密码，不一致提示"密码错误"。
- 提示信息要模糊化（如统一提示"用户名或密码错误"），避免暴露"该用户名存在"这类信息，这是真实项目的安全习惯。
- 登录成功后打印欢迎语，后续从这里衔接进入游戏模块。

**示例代码**
```java
// 文件名: CaptchaLoginDemo.java
import java.util.Random;
import java.util.Scanner;

public class CaptchaLoginDemo {
    static Scanner sc = new Scanner(System.in);

    public static void main(String[] args) {
        // 模拟已注册用户（真实项目应来自用户集合）
        String rightUsername = "zhangsan";
        String rightPassword = "123456";

        // 第一步：生成并校验验证码
        String code = getCode();
        System.out.println("验证码：" + code);
        System.out.println("请输入验证码：");
        String inputCode = sc.next();
        // 验证码比较忽略大小写
        if (!code.equalsIgnoreCase(inputCode)) {
            System.out.println("验证码错误，登录失败");
            return;
        }

        // 第二步：校验用户名和密码
        System.out.println("请输入用户名：");
        String username = sc.next();
        System.out.println("请输入密码：");
        String password = sc.next();
        if (username.equals(rightUsername) && password.equals(rightPassword)) {
            System.out.println("登录成功，欢迎 " + username + " 进入游戏！");
        } else {
            System.out.println("用户名或密码错误，登录失败");
        }
    }

    // 生成 5 位验证码：大小写字母 + 数字
    public static String getCode() {
        String pool = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789";
        Random r = new Random();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 5; i++) {
            int index = r.nextInt(pool.length());
            sb.append(pool.charAt(index));
        }
        return sb.toString();
    }
}
```

**课后练习**
1. 生成验证码时保证 5 位中至少包含一个数字，不满足就重新生成。
2. 登录失败时给用户 3 次机会，3 次全部失败则提示"账户已被锁定"并结束程序。
3. 注册成功后自动进入登录环节，登录成功后打印"欢迎进入游戏"，把注册和登录串成一条完整流程。

### 13-04 准备工作（编写游戏角色的继承结构）

**知识点**
- 战斗角色之间有大量公共内容（名字、血量、攻击力），把公共属性和公共方法抽取到父类 Role，避免重复代码。
- 继承语法：`class Hero extends Role`，子类可以直接使用父类的非私有成员，私有属性通过 getter/setter 访问。
- 子类构造方法里用 super(...) 调用父类构造，先完成公共属性赋值，再给子类独有属性赋值。
- 公共行为封装在父类：如 hurt(伤害) 负责扣血并保底为 0，我方和敌方通用。
- 设计思想：先找同类事物的共性抽父类，再让子类按需扩展自己的独有属性和方法。

**示例代码**
```java
// 文件名: Role.java
public class Role {
    private String name; // 名字
    private int hp;      // 血量
    private int attack;  // 攻击力

    public Role() {
    }

    public Role(String name, int hp, int attack) {
        this.name = name;
        this.hp = hp;
        this.attack = attack;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getHp() {
        return hp;
    }

    public void setHp(int hp) {
        this.hp = hp;
    }

    public int getAttack() {
        return attack;
    }

    public void setAttack(int attack) {
        this.attack = attack;
    }

    // 公共行为：受击扣血，血量最低降到 0
    public void hurt(int damage) {
        this.hp -= damage;
        if (this.hp < 0) {
            this.hp = 0;
        }
    }
}
```

### 13-05 准备工作（创建敌我双方的角色）

**知识点**
- 用集合管理角色：ArrayList<Hero> 存我方出战池、ArrayList<Enemy> 存敌人池，战斗时遍历集合行动。
- 敌人随机生成：名字从字符串数组按随机下标取，血量、攻击力在设定区间内随机。
- 任意区间 [min, max] 的随机数公式：r.nextInt(max - min + 1) + min。
- 把"创建角色"封装成方法并返回集合，main 方法里只做调用和测试打印。
- 创建完立刻遍历打印集合，先验证数据正确，再进入下一阶段的开发。

**示例代码**
```java
// 文件名: RoleFactory.java（依赖 13-04 的 Hero、Enemy 类）
import java.util.ArrayList;
import java.util.Random;

public class RoleFactory {
    static Random r = new Random();

    public static void main(String[] args) {
        ArrayList<Hero> heroes = createHeroes();
        ArrayList<Enemy> enemies = createEnemies();

        System.out.println("我方角色：");
        for (Hero h : heroes) {
            System.out.println(h.getName() + " 血量" + h.getHp() + " 攻击" + h.getAttack());
        }
        System.out.println("敌方角色：");
        for (Enemy e : enemies) {
            System.out.println(e.getName() + " 血量" + e.getHp() + " 攻击" + e.getAttack());
        }
    }

    // 创建我方出战池
    public static ArrayList<Hero> createHeroes() {
        ArrayList<Hero> list = new ArrayList<>();
        list.add(new Hero("阿玮", 100, 20, 0));
        list.add(new Hero("小波", 90, 25, 0));
        list.add(new Hero("皮皮", 110, 15, 0));
        return list;
    }

    // 随机创建敌方角色
    public static ArrayList<Enemy> createEnemies() {
        String[] names = {"史莱姆", "哥布林", "骷髅兵", "蝙蝠怪", "石头人"};
        ArrayList<Enemy> list = new ArrayList<>();
        for (int i = 0; i < 3; i++) {
            // 随机名字：从数组中按随机下标取
            String name = names[r.nextInt(names.length)];
            // 血量区间 [40, 80]，攻击力区间 [8, 15]
            int hp = r.nextInt(80 - 40 + 1) + 40;
            int attack = r.nextInt(15 - 8 + 1) + 8;
            list.add(new Enemy(i + 1, name, hp, attack));
        }
        return list;
    }
}
```

**课后练习**
1. 敌人数量改为随机 3~5 个，并保证同一波敌人名字互不重复。
2. 给 Enemy 增加难度星级（1~3 星），打印敌人信息时用 ★ 展示星级。
3. 我方出战角色改为从 5 个预设名单中随机抽取 2 名，要求多次运行时抽到的组合可以不同。

### 13-06 战斗前（增强属性，选择敌人，打印血条）

**知识点**
- 战前增强：给每个我方角色随机提升攻击力或血量，本质是 get 出旧值、算好新值再 set 回去。
- 选择敌人：打印敌人编号列表，让玩家录入编号，先校验合法性再锁定出战目标。
- 血条：用循环把 '█' 拼接若干次得到字符串，填充格数 = 当前血量 / 最大血量 × 总格数。
- 血条后面跟上"当前血量/最大血量"的数值，信息更直观。
- System.out.printf 配合 %s、%d 占位符排版，可以让多行信息上下对齐。

**示例代码**
```java
// 文件名: BattlePreDemo.java（依赖 13-04 的 Hero、Enemy 类）
import java.util.ArrayList;
import java.util.Random;
import java.util.Scanner;

public class BattlePreDemo {
    static Scanner sc = new Scanner(System.in);
    static Random r = new Random();

    public static void main(String[] args) {
        ArrayList<Hero> heroes = new ArrayList<>();
        heroes.add(new Hero("阿玮", 100, 20, 0));
        heroes.add(new Hero("小波", 90, 25, 0));
        ArrayList<Enemy> enemies = new ArrayList<>();
        enemies.add(new Enemy(1, "史莱姆", 60, 10));
        enemies.add(new Enemy(2, "哥布林", 80, 12));

        // 战前增强：每个角色随机提升攻击力或血量
        for (Hero h : heroes) {
            if (r.nextBoolean()) {
                int buff = r.nextInt(10) + 5;
                h.setAttack(h.getAttack() + buff);
                System.out.println(h.getName() + " 攻击力提升了 " + buff);
            } else {
                int buff = r.nextInt(30) + 10;
                h.setHp(h.getHp() + buff);
                System.out.println(h.getName() + " 血量提升了 " + buff);
            }
        }

        // 打印双方血条（我方血量上限假设为 150）
        System.out.println("===== 战斗前状态 =====");
        for (Hero h : heroes) {
            System.out.printf("%-6s %s %d/%d%n", h.getName(),
                    getHpBar(h.getHp(), 150, 10), h.getHp(), 150);
        }
        for (Enemy e : enemies) {
            System.out.printf("%-6s %s %d/%d%n", e.getName(),
                    getHpBar(e.getHp(), e.getHp(), 10), e.getHp(), e.getHp());
        }
    }

    // 根据当前血量和最大血量生成血条字符串
    public static String getHpBar(int cur, int max, int cells) {
        int fill = cur * cells / max;
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < fill; i++) {
            sb.append('█');
        }
        // 用空格补齐剩余格子，保证各行血条宽度一致
        for (int i = fill; i < cells; i++) {
            sb.append(' ');
        }
        return "[" + sb + "]";
    }
}
```

**课后练习**
1. 根据血量百分比在血条后追加状态文字：高于 60% 显示"良好"，30%~60% 显示"受伤"，低于 30% 显示"危险"。
2. 选择敌人时做好校验：编号不存在时提示重新选择，录入非数字时程序不能崩溃。
3. 战前增强改为玩家手动选择：打印选项让玩家决定每个角色是提升攻击力还是提升血量。

### 13-07 战斗中（我方回合）

**知识点**
- 回合制的最小闭环：我方行动 → 敌方行动 → 判断胜负 → 进入下一回合。
- 伤害计算：基础伤害 = 攻击力，再加随机波动（如 ±5），最低保底 1 点，避免出现 0 伤害。
- 暴击：随机一个 0~99 的数，小于暴击率（如 30）判定暴击，伤害翻倍。
- 敌人掉血调用父类封装好的 hurt 方法；血量小于等于 0 就从敌人集合中移除，表示阵亡。
- 每次攻击都打印战斗日志（谁对谁造成多少伤害、剩余血量），回合制游戏的体验感靠日志撑起来。

**示例代码**
```java
// 文件名: MyTurnDemo.java（依赖 13-04 的 Hero、Enemy 类）
import java.util.ArrayList;
import java.util.Random;

public class MyTurnDemo {
    static Random r = new Random();

    public static void main(String[] args) {
        Hero hero = new Hero("阿玮", 100, 30, 0);
        ArrayList<Enemy> enemies = new ArrayList<>();
        enemies.add(new Enemy(1, "史莱姆", 80, 10));
        enemies.add(new Enemy(2, "哥布林", 50, 12));

        // 我方回合：攻击第一个存活的敌人
        Enemy target = enemies.get(0);
        attack(hero, target);

        // 敌人血量为 0 时移出集合
        if (target.getHp() <= 0) {
            System.out.println(target.getName() + " 被击败了！");
            enemies.remove(target);
        }
        System.out.println("剩余敌人数：" + enemies.size());
    }

    // 我方攻击逻辑：计算伤害、判定暴击、敌方掉血
    public static void attack(Hero hero, Enemy enemy) {
        int damage = hero.getAttack();
        // 暴击判定：0~99 的随机数小于 30 视为暴击（30% 概率），伤害翻倍
        boolean isCrit = r.nextInt(100) < 30;
        if (isCrit) {
            damage *= 2;
        }
        // 伤害在 ±5 内随机波动
        damage += r.nextInt(11) - 5;
        if (damage < 1) {
            damage = 1;
        }
        // 敌方掉血
        enemy.hurt(damage);
        if (isCrit) {
            System.out.println(hero.getName() + " 打出了暴击！对 "
                    + enemy.getName() + " 造成 " + damage + " 点伤害");
        } else {
            System.out.println(hero.getName() + " 对 " + enemy.getName()
                    + " 造成 " + damage + " 点伤害");
        }
        System.out.println(enemy.getName() + " 剩余血量：" + enemy.getHp());
    }
}
```

**课后练习**
1. 我方多名角色依次行动，每名角色由玩家选择攻击目标，也可以选择跳过本回合。
2. 增加连击机制：20% 概率追加一次半价伤害的攻击，并把每次攻击记录成战斗日志字符串。
3. 暴击伤害改为攻击力的 1.5~2.5 倍之间的随机值（伤害取整数），并统计本回合的总输出伤害。

### 13-08 战斗中（敌方回合）

**知识点**
- 敌方回合：遍历敌人集合，每个存活的敌人随机攻击一名我方角色。
- 随机目标：r.nextInt(heroes.size()) 得到下标，注意先保证我方集合不为空。
- 敌人行动前先判断自己是否存活（可能上一手已被打死），用 continue 跳过阵亡敌人。
- 敌方伤害逻辑可以与我方对称：随机波动 ±2、保底 1 点，需要暴击时复用同样套路。
- 我方角色被打死后要从集合移除或做标记，否则后续回合还会被敌人选中攻击。

**示例代码**
```java
// 文件名: EnemyTurnDemo.java（依赖 13-04 的 Hero、Enemy 类）
import java.util.ArrayList;
import java.util.Random;

public class EnemyTurnDemo {
    static Random r = new Random();

    public static void main(String[] args) {
        ArrayList<Hero> heroes = new ArrayList<>();
        heroes.add(new Hero("阿玮", 100, 30, 0));
        heroes.add(new Hero("小波", 80, 25, 0));

        ArrayList<Enemy> enemies = new ArrayList<>();
        enemies.add(new Enemy(1, "史莱姆", 60, 15));
        enemies.add(new Enemy(2, "哥布林", 70, 12));

        // 敌方回合：每个存活的敌人随机攻击一名我方角色
        for (int i = 0; i < enemies.size(); i++) {
            Enemy enemy = enemies.get(i);
            // 阵亡的敌人跳过行动
            if (enemy.getHp() <= 0) {
                continue;
            }
            // 随机挑选一名我方角色作为目标
            Hero target = heroes.get(r.nextInt(heroes.size()));
            int damage = enemy.getAttack() + r.nextInt(6) - 2;
            if (damage < 1) {
                damage = 1;
            }
            target.hurt(damage);
            System.out.println(enemy.getName() + " 攻击了 " + target.getName()
                    + "，造成 " + damage + " 点伤害，"
                    + target.getName() + " 剩余血量 " + target.getHp());
        }
    }
}
```

**课后练习**
1. 敌人增加集火策略：30% 概率所有敌人攻击同一个我方目标。
2. 敌方 Boss 每回合自动回复 5 点血量，并打印回复日志。
3. 已阵亡的我方角色不能再被敌人选中；当全员阵亡时直接跳转到失败结算。

### 13-09 战斗结算（恢复血量，增加属性，是否继续）

**知识点**
- 一波敌人清空后进入结算，结算不等于游戏结束：回血、涨属性、询问是否继续。
- 回血规则：每个存活角色回复最大血量的 20%，回血后不能超过上限，需要 if 判断截断。
- 属性成长：胜利后攻击力 +5（或血量上限提升），游戏才有"越打越强"的正反馈。
- 是否继续用循环 + 分支：选 1 生成新一波敌人再战，选 2 进入最终结算。
- 把"一波战斗"封装成方法，用返回值把结果（如是否全灭）带回主流程，主流程才好判断走向。

**示例代码**
```java
// 文件名: SettlementDemo.java（依赖 13-04 的 Hero 类）
import java.util.ArrayList;
import java.util.Scanner;

public class SettlementDemo {
    static Scanner sc = new Scanner(System.in);

    public static void main(String[] args) {
        ArrayList<Hero> heroes = new ArrayList<>();
        heroes.add(new Hero("阿玮", 60, 30, 0));
        heroes.add(new Hero("小波", 45, 25, 0));
        // 假设我方血量上限都是 100
        int maxHp = 100;

        // 模拟一轮战斗胜利后的结算
        for (Hero h : heroes) {
            // 恢复血量：回复最大血量的 20%，但不能超过上限
            int heal = maxHp * 20 / 100;
            if (h.getHp() + heal > maxHp) {
                h.setHp(maxHp);
            } else {
                h.setHp(h.getHp() + heal);
            }
            // 增加属性：攻击力 +5
            h.setAttack(h.getAttack() + 5);
            System.out.println(h.getName() + " 恢复到 " + h.getHp()
                    + " 点血量，攻击力提升到 " + h.getAttack());
        }

        // 询问玩家是否继续战斗
        while (true) {
            System.out.println("是否继续挑战下一波敌人？1. 继续 2. 结束");
            String choice = sc.next();
            if ("1".equals(choice)) {
                System.out.println("准备生成下一波敌人...");
                break;
            } else if ("2".equals(choice)) {
                System.out.println("结束本次冒险");
                break;
            } else {
                System.out.println("输入有误，请重新选择");
            }
        }
    }
}
```

**课后练习**
1. 结算时统计本轮每个角色受到的总伤害，并按伤害发放金币奖励，金币数存入 Hero 类。
2. 回血比例与连胜场次挂钩：每连胜一场，回血比例提升 5%。
3. 结算界面增加撤退选项：撤退保留当前属性但连胜清零，然后返回主菜单。

### 13-10 游戏最终结算

**知识点**
- 游戏结束的两种情况：我方全员阵亡 → 失败结算；玩家主动选择结束 → 按当前战绩结算。
- 战绩数据（总轮数、击败敌人数、累计伤害）要在战斗过程中随时累加，不能等到结算时才算。
- 判断全灭：遍历我方集合，所有角色血量都小于等于 0 即为失败。
- 结算界面逐行打印胜负 + 各项战绩，再根据数值给一句评价，增加游戏成就感。
- 收尾习惯：关闭 Scanner、打印"程序结束"，让程序有头有尾。

**示例代码**
```java
// 文件名: FinalSettlementDemo.java（依赖 13-04 的 Hero 类）
import java.util.ArrayList;
import java.util.Scanner;

public class FinalSettlementDemo {
    static Scanner sc = new Scanner(System.in);

    public static void main(String[] args) {
        ArrayList<Hero> heroes = new ArrayList<>();
        heroes.add(new Hero("阿玮", 0, 35, 0));
        heroes.add(new Hero("小波", 20, 28, 0));

        // 战绩数据：真实项目中应在战斗过程中累加
        int roundCount = 3;    // 已战斗的轮数
        int killCount = 5;     // 击败的敌人数
        int totalDamage = 380; // 累计造成的伤害

        // 判断我方是否还有存活角色
        boolean allDead = true;
        for (Hero h : heroes) {
            if (h.getHp() > 0) {
                allDead = false;
                break;
            }
        }

        System.out.println("========= 游戏结束 =========");
        if (allDead) {
            System.out.println("我方全员阵亡，挑战失败！");
        } else {
            System.out.println("恭喜通关！你战胜了所有敌人！");
        }
        System.out.println("总轮数：" + roundCount);
        System.out.println("击败敌人：" + killCount + " 名");
        System.out.println("累计伤害：" + totalDamage);

        // 根据战绩给出一句评价
        if (totalDamage > 500) {
            System.out.println("评价：真乃一代战神！");
        } else {
            System.out.println("评价：路虽远，行则将至，再接再厉！");
        }
        sc.close();
    }
}
```

**课后练习**
1. 输出每名角色的个人战绩：造成的伤害、击杀数、当前存活状态。
2. 按总伤害与击杀数综合计算评级（S、A、B、C 四档），不同评级打印不同的通关标语。
3. 把每一轮的战斗记录拼接成完整战报字符串，游戏结束时逐行回放整场战斗。
