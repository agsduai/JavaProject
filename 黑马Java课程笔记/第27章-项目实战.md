# 第27章 项目实战

前 26 章把 Java 基础、集合、IO、并发、数据库、Web、框架这些零件一个个讲完了，但真正交付一个项目，难点往往不在"某个知识点会不会"，而在"这些东西怎么拼在一起才不出事"：接口怎么设计前端才好用、代码分几层才不会越写越乱、参数在哪一层校验、异常怎么统一成一种格式、分页和排序怎么防注入、扣库存怎么防超卖、用户连点两下怎么防重复下单、上线之后日志怎么查、jar 怎么打包怎么启动。本章就用一个"商品 + 订单"的迷你项目把这些串起来。所有示例仍然是纯 JDK 可运行：Web 层用方法调用模拟，数据库用内存表模拟，事务用"操作日志 + 回滚"模拟，部署部分用真实的 `jar`/启动脚本/健康检查来演示，不需要装 MySQL、Redis、Nginx。

### 27-01 接口设计：URL、方法、状态码

**知识点**
- RESTful 的核心是"用名词表示资源，用 HTTP 方法表示动作"：`GET /api/items` 查列表、`GET /api/items/1` 查单个、`POST /api/items` 新增、`PUT /api/items/1` 全量更新、`PATCH /api/items/1` 局部更新、`DELETE /api/items/1` 删除。
- URL 里不要出现动词：`/api/getItemList`、`/api/deleteItem?id=1` 都是反例。动作实在表达不了才用子资源，例如 `POST /api/orders/1/cancel`。
- 层级表达归属：订单里的一条明细是 `/api/orders/1/items/3`，不要写成 `/api/orderItem?orderId=1&itemId=3`。
- 状态码要"说到做到"：200 成功、201 创建成功、204 删除成功无返回体、400 参数错、401 未登录、403 无权限、404 不存在、409 冲突（用户名重复）、422 业务校验失败、500 服务端异常。
- 统一响应体：`{code, msg, data}`。HTTP 状态码表达"协议层结果"，`code` 表达"业务层结果"，两者不要混用（全部返回 200 然后靠 code 判断，会让网关、监控、重试策略全部失效）。
- 分页参数统一：`page`（从 1 开始）、`size`（默认 10，上限 100）、`sort`（字段+方向）。排序字段必须走白名单，否则就是 SQL 注入入口。
- 易错：`GET` 请求带请求体（很多网关会丢掉）；`PUT` 当成 `PATCH` 用（前端只传一个字段，结果其它字段被置空）；URL 用驼峰（`/api/itemList`），服务器和 CDN 对大小写敏感容易踩坑。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class RestApiDesign {
    /** 一条路由：方法 + 路径模板 + 说明 */
    record Route(String method, String pattern, String desc, int okStatus) { }

    static final List<Route> ROUTES = new ArrayList<>();

    public static void main(String[] args) {
        ROUTES.add(new Route("GET", "/api/items", "分页查询商品", 200));
        ROUTES.add(new Route("GET", "/api/items/{id}", "查询商品详情", 200));
        ROUTES.add(new Route("POST", "/api/items", "新增商品", 201));
        ROUTES.add(new Route("PUT", "/api/items/{id}", "全量更新商品", 200));
        ROUTES.add(new Route("PATCH", "/api/items/{id}", "局部更新商品", 200));
        ROUTES.add(new Route("DELETE", "/api/items/{id}", "删除商品", 204));
        ROUTES.add(new Route("POST", "/api/orders", "创建订单", 201));
        ROUTES.add(new Route("POST", "/api/orders/{id}/cancel", "取消订单", 200));
        ROUTES.add(new Route("GET", "/api/orders/{id}/items/{itemId}", "查询订单明细", 200));

        System.out.println("=== 接口清单 ===");
        System.out.printf("%-7s %-34s %-12s %s%n", "方法", "路径", "成功状态码", "说明");
        for (Route r : ROUTES) {
            System.out.printf("%-7s %-34s %-12d %s%n", r.method(), r.pattern(), r.okStatus(), r.desc());
        }

        System.out.println();
        System.out.println("=== 路由匹配（含路径变量）===");
        String[][] requests = {
                {"GET", "/api/items"},
                {"GET", "/api/items/42"},
                {"POST", "/api/items"},
                {"DELETE", "/api/items/42"},
                {"GET", "/api/orders/7/items/3"},
                {"POST", "/api/orders/7/cancel"},
                {"GET", "/api/getItemList"},
                {"PUT", "/api/items/42"},
        };
        for (String[] req : requests) {
            System.out.printf("  %-6s %-30s -> %s%n", req[0], req[1], dispatch(req[0], req[1]));
        }

        System.out.println();
        System.out.println("=== 统一响应体 ===");
        System.out.println("  成功: " + result(200, "ok", Map.of("id", 42, "name", "机械键盘")));
        System.out.println("  参数错: " + result(400, "size 必须在 1~100 之间", null));
        System.out.println("  未登录: " + result(401, "请先登录", null));
        System.out.println("  冲突: " + result(409, "商品名称已存在", null));
        System.out.println("  服务错: " + result(500, "服务器繁忙，请稍后重试", null));
    }

    /** 极简路由：先比方法，再比路径模板 */
    static String dispatch(String method, String path) {
        for (Route r : ROUTES) {
            if (!r.method().equals(method)) {
                continue;
            }
            Map<String, String> vars = match(r.pattern(), path);
            if (vars != null) {
                String extra = vars.isEmpty() ? "" : " 参数=" + vars;
                return r.okStatus() + " " + r.desc() + extra;
            }
        }
        return "404 无此接口（或方法不匹配）: " + method + " " + path;
    }

    /** 把 /api/items/{id} 和 /api/items/42 对上，取出 id=42 */
    static Map<String, String> match(String pattern, String path) {
        String[] p = pattern.split("/");
        String[] a = path.split("/");
        if (p.length != a.length) {
            return null;
        }
        Map<String, String> vars = new LinkedHashMap<>();
        for (int i = 0; i < p.length; i++) {
            if (p[i].startsWith("{") && p[i].endsWith("}")) {
                if (a[i].isEmpty()) {
                    return null;
                }
                vars.put(p[i].substring(1, p[i].length() - 1), a[i]);
            } else if (!p[i].equals(a[i])) {
                return null;
            }
        }
        return vars;
    }

    static Map<String, Object> result(int code, String msg, Object data) {
        Map<String, Object> body = new LinkedHashMap<>();
        body.put("code", code);
        body.put("msg", msg);
        body.put("data", data);
        return body;
    }
}
```

### 27-02 分层架构：Controller、Service、Repository

**知识点**
- 四层职责：`Controller` 只做"收参数、调 Service、包响应"，不写业务；`Service` 只写业务规则与事务边界；`Repository/Mapper` 只做数据访问；`Entity/DTO/VO` 只做数据载体。
- 依赖方向必须单向：Controller -> Service -> Repository -> 数据库。反向依赖（Repository 调 Service）会形成环，编译能过但运行期难测。
- 面向接口编程：Service 依赖 `ItemRepository` 接口而不是 `MemoryItemRepository` 实现，这样换存储、加缓存、写单测替换成假实现都不用改业务代码。
- 装饰器模式加缓存：写一个 `CachingItemRepository` 实现同一个接口，内部包一层真实实现，Service 完全不知道缓存的存在。
- 事务边界在 Service：一个业务用例可能调多个 Repository 方法，只有 Service 知道"这几步必须一起成功"。
- Controller 不要直接返回 Entity：Entity 跟着表结构变，接口契约会跟着抖；用 VO 隔离。
- 易错：Service 之间互相注入形成环（A 依赖 B，B 依赖 A），Spring 启动直接报循环依赖；把 `HttpServletRequest` 传进 Service，业务层被 Web 容器绑死，单测跑不起来。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.Optional;

public class LayeredArchitecture {
    public static void main(String[] args) {
        // 组装依赖：像 Spring 容器那样在最外层把实现塞进去
        ItemRepository real = new MemoryItemRepository();
        ItemRepository withCache = new CachingItemRepository(real);
        ItemService service = new ItemService(withCache);
        ItemController controller = new ItemController(service);

        System.out.println("=== 新增 ===");
        System.out.println("  " + controller.create("机械键盘", 39900));
        System.out.println("  " + controller.create("显示器", 129900));

        System.out.println();
        System.out.println("=== 查询（第一次走库，第二次走缓存）===");
        System.out.println("  " + controller.detail(1L));
        System.out.println("  " + controller.detail(1L));
        System.out.println("  " + controller.detail(999L));

        System.out.println();
        System.out.println("=== 列表 ===");
        System.out.println("  " + controller.list());

        System.out.println();
        System.out.println("=== 改价：Service 负责清缓存 ===");
        System.out.println("  " + controller.updatePrice(1L, 35900));
        System.out.println("  " + controller.detail(1L));

        System.out.println();
        System.out.println("=== 底层换了实现，上层一行没改 ===");
        ItemRepository another = new MemoryItemRepository();
        another.save(new Item(1L, "机械键盘", 39900));
        System.out.println("  " + new ItemController(new ItemService(another)).detail(1L));

        System.out.println();
        System.out.println("=== 各层职责 ===");
        Map<String, String> duties = new LinkedHashMap<>();
        duties.put("Controller", "收参数、校验格式、调 Service、包统一响应");
        duties.put("Service", "业务规则、事务边界、编排多个 Repository");
        duties.put("Repository", "只做增删改查，不含业务判断");
        duties.put("Entity/VO", "数据载体，Entity 对表，VO 对接口");
        duties.forEach((k, v) -> System.out.printf("  %-12s %s%n", k, v));
    }

    /** 数据载体 */
    static class Item {
        Long id;
        String name;
        int priceCent;

        Item(Long id, String name, int priceCent) {
            this.id = id;
            this.name = name;
            this.priceCent = priceCent;
        }

        Item copy() {
            return new Item(id, name, priceCent);
        }
    }

    /** 数据访问接口：Service 只认这个 */
    interface ItemRepository {
        Item save(Item item);

        Optional<Item> findById(Long id);

        List<Item> findAll();

        boolean updatePrice(Long id, int priceCent);
    }

    /** 内存实现，模拟 MySQL */
    static class MemoryItemRepository implements ItemRepository {
        private final Map<Long, Item> table = new LinkedHashMap<>();
        private long seq = 0;

        @Override
        public Item save(Item item) {
            Item stored = item.copy();
            stored.id = ++seq;
            table.put(stored.id, stored);
            return stored.copy();
        }

        @Override
        public Optional<Item> findById(Long id) {
            return Optional.ofNullable(table.get(id)).map(Item::copy);
        }

        @Override
        public List<Item> findAll() {
            List<Item> list = new ArrayList<>();
            for (Item i : table.values()) {
                list.add(i.copy());
            }
            return list;
        }

        @Override
        public boolean updatePrice(Long id, int priceCent) {
            Item i = table.get(id);
            if (i == null) {
                return false;
            }
            i.priceCent = priceCent;
            return true;
        }
    }

    /** 装饰器：加缓存，不侵入业务 */
    static class CachingItemRepository implements ItemRepository {
        private final ItemRepository delegate;
        private final Map<Long, Item> cache = new LinkedHashMap<>();
        int hits;
        int misses;

        CachingItemRepository(ItemRepository delegate) {
            this.delegate = delegate;
        }

        @Override
        public Item save(Item item) {
            return delegate.save(item);
        }

        @Override
        public Optional<Item> findById(Long id) {
            Item cached = cache.get(id);
            if (cached != null) {
                hits++;
                System.out.println("    [cache] hit id=" + id + " 命中次数=" + hits);
                return Optional.of(cached.copy());
            }
            misses++;
            Optional<Item> fromDb = delegate.findById(id);
            fromDb.ifPresent(i -> {
                cache.put(i.id, i.copy());
                System.out.println("    [cache] miss id=" + id + "，已回填，未命中次数=" + misses);
            });
            return fromDb;
        }

        @Override
        public List<Item> findAll() {
            return delegate.findAll();
        }

        @Override
        public boolean updatePrice(Long id, int priceCent) {
            cache.remove(id);
            return delegate.updatePrice(id, priceCent);
        }
    }

    /** 业务层：只写规则，不碰 HTTP，也不碰 SQL */
    static class ItemService {
        private final ItemRepository repository;

        ItemService(ItemRepository repository) {
            this.repository = repository;
        }

        Item create(String name, int priceCent) {
            if (name == null || name.isBlank()) {
                throw new IllegalArgumentException("商品名不能为空");
            }
            if (priceCent <= 0) {
                throw new IllegalArgumentException("价格必须大于 0");
            }
            return repository.save(new Item(null, name.trim(), priceCent));
        }

        Item detail(Long id) {
            return repository.findById(id)
                    .orElseThrow(() -> new IllegalStateException("商品不存在: " + id));
        }

        List<Item> list() {
            return repository.findAll();
        }

        Item updatePrice(Long id, int priceCent) {
            if (priceCent <= 0) {
                throw new IllegalArgumentException("价格必须大于 0");
            }
            if (!repository.updatePrice(id, priceCent)) {
                throw new IllegalStateException("商品不存在: " + id);
            }
            return detail(id);
        }
    }

    /** 接口层：只负责参数和响应 */
    static class ItemController {
        private final ItemService service;

        ItemController(ItemService service) {
            this.service = service;
        }

        String create(String name, int priceCent) {
            try {
                Item item = service.create(name, priceCent);
                return "201 " + toVo(item);
            } catch (RuntimeException e) {
                return "400 " + e.getMessage();
            }
        }

        String detail(Long id) {
            try {
                return "200 " + toVo(service.detail(id));
            } catch (RuntimeException e) {
                return "404 " + e.getMessage();
            }
        }

        String list() {
            List<Map<String, Object>> vos = new ArrayList<>();
            for (Item i : service.list()) {
                vos.add(toVo(i));
            }
            return "200 " + vos;
        }

        String updatePrice(Long id, int priceCent) {
            try {
                return "200 " + toVo(service.updatePrice(id, priceCent));
            } catch (IllegalArgumentException e) {
                return "400 " + e.getMessage();
            } catch (RuntimeException e) {
                return "404 " + e.getMessage();
            }
        }

        /** Entity -> VO：价格按元显示，不暴露内部字段 */
        static Map<String, Object> toVo(Item item) {
            Map<String, Object> vo = new LinkedHashMap<>();
            vo.put("id", item.id);
            vo.put("name", item.name);
            vo.put("price", String.format("%.2f", item.priceCent / 100.0));
            return vo;
        }
    }
}
```

### 27-03 DTO、VO 与参数校验

**知识点**
- 三种对象的边界：`DTO` 接收前端入参（只包含允许前端传的字段），`Entity` 对应数据库表，`VO` 返回给前端（去掉密码、内部状态，加上格式化字段）。
- 为什么不能直接用 Entity 收参：前端只要多传一个 `role=admin` 或 `balance=999999`，`BeanUtils.copyProperties` 一拷就变成提权漏洞。
- 校验分层：格式校验（非空、长度、范围、正则）在入口做；业务校验（用户名是否重复、库存是否足够）在 Service 做。两者的区别是"不查库就能判断" vs "必须查库才能判断"。
- 一次返回全部错误，而不是遇到第一个就抛：前端能一次性提示所有问题，用户不用改一个提交一次。
- 校验规则要用常量/注解集中管理，别散落在 if 里。真实项目用 `jakarta.validation` 的 `@NotBlank`、`@Size`、`@Pattern`、`@Min`。
- 金额用 `long` 存分或 `BigDecimal`，绝不用 `double`；`0.1 + 0.2 != 0.3` 在金额上是事故。
- 易错：`@Valid` 只对 `@RequestBody` 生效，`@RequestParam` 上的校验要类上加 `@Validated`；嵌套对象要加 `@Valid` 才会级联校验。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class DtoValidation {
    /** 前端能传的字段，一个不多 */
    static class ItemCreateDTO {
        String name;
        Integer priceCent;
        Integer stock;
        String description;

        ItemCreateDTO(String name, Integer priceCent, Integer stock, String description) {
            this.name = name;
            this.priceCent = priceCent;
            this.stock = stock;
            this.description = description;
        }
    }

    /** 数据库实体，含前端不该碰的字段 */
    static class ItemEntity {
        Long id;
        String name;
        int priceCent;
        int stock;
        String description;
        String status = "OFF_SHELF";
        String ownerId = "system";
    }

    public static void main(String[] args) {
        System.out.println("=== 合法请求 ===");
        ItemCreateDTO ok = new ItemCreateDTO("机械键盘", 39900, 100, "87 键 红轴");
        System.out.println("  " + create(ok));

        System.out.println();
        System.out.println("=== 一次返回全部错误 ===");
        ItemCreateDTO bad = new ItemCreateDTO("", -1, 0, null);
        System.out.println("  " + create(bad));

        System.out.println();
        System.out.println("=== 名称超长 + 描述超长 ===");
        StringBuilder longName = new StringBuilder();
        for (int i = 0; i < 70; i++) {
            longName.append('键');
        }
        StringBuilder longDesc = new StringBuilder();
        for (int i = 0; i < 600; i++) {
            longDesc.append('描');
        }
        System.out.println("  " + create(new ItemCreateDTO(longName.toString(), 100, 1, longDesc.toString())));

        System.out.println();
        System.out.println("=== 前端偷偷传了 status/ownerId 会怎样 ===");
        Map<String, Object> raw = new LinkedHashMap<>();
        raw.put("name", "鼠标");
        raw.put("priceCent", 9900);
        raw.put("stock", 10);
        raw.put("status", "ON_SHELF");
        raw.put("ownerId", "admin");
        System.out.println("  DTO 只认白名单字段，status/ownerId 被丢弃");
        System.out.println("  " + create(fromRaw(raw)));

        System.out.println();
        System.out.println("=== 金额为什么不能用 double ===");
        System.out.println("  0.1 + 0.2 = " + (0.1 + 0.2));
        System.out.println("  用分做整数：10 + 20 = " + (10 + 20) + " 分 = 0.30 元");

        System.out.println();
        System.out.println("=== 校验规则表 ===");
        Map<String, String> rules = new LinkedHashMap<>();
        rules.put("name", "非空，2~64 字符");
        rules.put("priceCent", "必填，> 0，单位分");
        rules.put("stock", "必填，0~999999");
        rules.put("description", "可选，<= 500 字符");
        rules.forEach((k, v) -> System.out.printf("  %-12s %s%n", k, v));
    }

    /** 只把白名单字段搬进 DTO，等价于 Jackson 绑定到固定字段 */
    static ItemCreateDTO fromRaw(Map<String, Object> raw) {
        return new ItemCreateDTO(
                (String) raw.get("name"),
                (Integer) raw.get("priceCent"),
                (Integer) raw.get("stock"),
                (String) raw.get("description"));
    }

    /** 格式校验：不查库就能判断的都在这里 */
    static List<String> validate(ItemCreateDTO dto) {
        List<String> errors = new ArrayList<>();
        if (dto.name == null || dto.name.isBlank()) {
            errors.add("name 不能为空");
        } else if (dto.name.trim().length() < 2 || dto.name.trim().length() > 64) {
            errors.add("name 长度必须在 2~64 之间，当前 " + dto.name.trim().length());
        }
        if (dto.priceCent == null) {
            errors.add("priceCent 不能为空");
        } else if (dto.priceCent <= 0) {
            errors.add("priceCent 必须大于 0，当前 " + dto.priceCent);
        } else if (dto.priceCent > 100_000_000) {
            errors.add("priceCent 超出上限（100 万元）");
        }
        if (dto.stock == null) {
            errors.add("stock 不能为空");
        } else if (dto.stock < 0 || dto.stock > 999_999) {
            errors.add("stock 必须在 0~999999 之间，当前 " + dto.stock);
        }
        if (dto.description != null && dto.description.length() > 500) {
            errors.add("description 不能超过 500 字符，当前 " + dto.description.length());
        }
        return errors;
    }

    /** 接口入口：校验 -> DTO 转 Entity -> Entity 转 VO */
    static String create(ItemCreateDTO dto) {
        List<String> errors = validate(dto);
        if (!errors.isEmpty()) {
            Map<String, Object> body = new LinkedHashMap<>();
            body.put("code", 400);
            body.put("msg", "参数校验失败");
            body.put("data", errors);
            return body.toString();
        }
        ItemEntity entity = toEntity(dto);
        entity.id = 1L;
        return "201 " + toVo(entity);
    }

    static ItemEntity toEntity(ItemCreateDTO dto) {
        ItemEntity e = new ItemEntity();
        e.name = dto.name.trim();
        e.priceCent = dto.priceCent;
        e.stock = dto.stock;
        e.description = dto.description == null ? "" : dto.description;
        return e;                     // status/ownerId 用默认值，前端无权指定
    }

    static Map<String, Object> toVo(ItemEntity e) {
        Map<String, Object> vo = new LinkedHashMap<>();
        vo.put("id", e.id);
        vo.put("name", e.name);
        vo.put("price", String.format("%.2f", e.priceCent / 100.0));
        vo.put("stock", e.stock);
        vo.put("status", e.status);
        return vo;
    }
}
```

### 27-04 统一异常处理与错误码

**知识点**
- 三类异常分开：`BusinessException`（可预期，带业务码，比如"库存不足"）、参数校验异常（400）、未预期异常（500，必须打完整堆栈但不返回给前端）。
- 统一出口：Spring 里用 `@RestControllerAdvice` + `@ExceptionHandler`，一处把异常转成 `{code,msg,data}`，Controller 里就不用到处 `try-catch`。
- 错误码要稳定：`1001 用户不存在`、`2001 库存不足`、`2002 重复下单`，前端可以按码做不同交互（弹窗 / 跳转 / 静默重试），文案改了不影响前端。
- 不要吞异常：`catch (Exception e) { }` 会让线上问题彻底消失；至少 `log.error("...", e)`。
- 区分"给用户看的消息"和"给开发看的消息"：`msg` 面向用户要友好（"库存不足，仅剩 2 件"），日志里要有 traceId、参数、堆栈。
- 包装第三方异常：`catch (SQLException e) { throw new BusinessException(5001, "数据访问失败", e); }`，保留 cause 链，否则排查时只剩一句"系统错误"。
- 易错：把 `e.printStackTrace()` 当日志（生产环境进不了日志文件）；把堆栈信息直接返回给前端（泄露表名、路径）；`finally` 里 return 覆盖掉异常。

**示例代码**
```java
import java.util.LinkedHashMap;
import java.util.Map;

public class GlobalExceptionHandler {
    /** 业务异常：带稳定错误码，可预期 */
    static class BusinessException extends RuntimeException {
        private static final long serialVersionUID = 1L;
        final int code;

        BusinessException(int code, String message) {
            super(message);
            this.code = code;
        }

        BusinessException(int code, String message, Throwable cause) {
            super(message, cause);
            this.code = code;
        }
    }

    /** 参数校验异常 */
    static class ValidationException extends RuntimeException {
        private static final long serialVersionUID = 1L;

        ValidationException(String message) {
            super(message);
        }
    }

    public static void main(String[] args) {
        System.out.println("=== 业务异常：库存不足 ===");
        System.out.println("  " + call(() -> buy(1L, 5)));

        System.out.println();
        System.out.println("=== 业务异常：商品不存在 ===");
        System.out.println("  " + call(() -> buy(999L, 1)));

        System.out.println();
        System.out.println("=== 参数校验异常 ===");
        System.out.println("  " + call(() -> buy(1L, 0)));

        System.out.println();
        System.out.println("=== 未预期异常：不泄露细节 ===");
        System.out.println("  " + call(() -> {
            throw new NullPointerException("item.name 为 null");
        }));

        System.out.println();
        System.out.println("=== 第三方异常被包装，cause 链保留 ===");
        try {
            wrapAndThrow();
        } catch (BusinessException e) {
            System.out.println("  对外: code=" + e.code + " msg=" + e.getMessage());
            System.out.println("  对内: cause=" + e.getCause());
        }

        System.out.println();
        System.out.println("=== 错误码表 ===");
        Map<Integer, String> codes = new LinkedHashMap<>();
        codes.put(400, "参数格式错误");
        codes.put(401, "未登录");
        codes.put(403, "无权限");
        codes.put(1001, "用户不存在");
        codes.put(2001, "库存不足");
        codes.put(2002, "重复下单");
        codes.put(500, "服务器内部错误");
        codes.forEach((k, v) -> System.out.printf("  %-6d %s%n", k, v));
    }

    /** 模拟 Controller 外层：异常统一在这里转成响应 */
    static Map<String, Object> call(Runnable action) {
        try {
            action.run();
            return result(200, "ok");
        } catch (BusinessException e) {
            log("WARN", "业务异常 code=" + e.code + " msg=" + e.getMessage());
            return result(e.code, e.getMessage());
        } catch (ValidationException e) {
            log("WARN", "参数校验失败: " + e.getMessage());
            return result(400, e.getMessage());
        } catch (RuntimeException e) {
            // 未预期异常：日志留全量堆栈，响应只给通用文案
            log("ERROR", "未预期异常: " + e);
            return result(500, "服务器繁忙，请稍后重试");
        }
    }

    /** 模拟业务：库存只有 2 件 */
    static void buy(Long itemId, int count) {
        if (count <= 0) {
            throw new ValidationException("购买数量必须大于 0");
        }
        if (itemId != 1L) {
            throw new BusinessException(1001, "商品不存在");
        }
        int stock = 2;
        if (count > stock) {
            throw new BusinessException(2001, "库存不足，仅剩 " + stock + " 件");
        }
    }

    static void wrapAndThrow() {
        try {
            throw new IllegalStateException("Connection refused: 127.0.0.1:3306");
        } catch (RuntimeException e) {
            throw new BusinessException(5001, "数据访问失败，请稍后重试", e);
        }
    }

    static void log(String level, String msg) {
        System.out.println("    [" + level + "] " + msg);
    }

    static Map<String, Object> result(int code, String msg) {
        Map<String, Object> body = new LinkedHashMap<>();
        body.put("code", code);
        body.put("msg", msg);
        body.put("data", null);
        return body;
    }
}
```

### 27-05 分页查询：参数、排序与总数

**知识点**
- 分页三要素：`page`（页码，从 1 开始）、`size`（每页条数，必须有上限）、`sort`（排序字段 + 方向）。
- SQL 本质：`LIMIT size OFFSET (page-1)*size`。深分页（`page=10000`）会扫描大量行，优化手段是"游标分页"（`WHERE id > lastId LIMIT size`）。
- `size` 不设上限的后果：前端传 `size=1000000`，一次查全表，内存和带宽直接打满，等于给自己做了个 DoS。
- 排序字段必须白名单：`ORDER BY ${sort}` 拼接字符串就是注入点，`sort=id;DROP TABLE item` 直接删库。正确做法是映射 `"price" -> "price_cent"`。
- 返回结构：`{list, total, page, size, pages}`。`total` 单独查一次 `COUNT(*)`，或者用"查 size+1 条判断有没有下一页"省掉 count。
- 页码越界：`page` 超过总页数返回空列表而不是报错；`page < 1` 归一化成 1。
- 易错：`OFFSET` 从 0 开始但页码从 1 开始，少减 1 导致第一页数据丢失；`total=0` 时算 `pages` 除零。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class PageQuery {
    /** 通用分页结果 */
    static class Page<T> {
        List<T> list;
        long total;
        int page;
        int size;
        int pages;

        Page(List<T> list, long total, int page, int size) {
            this.list = list;
            this.total = total;
            this.page = page;
            this.size = size;
            this.pages = size == 0 ? 0 : (int) ((total + size - 1) / size);
        }

        @Override
        public String toString() {
            return "Page{page=" + page + ", size=" + size + ", total=" + total
                    + ", pages=" + pages + ", list=" + list + "}";
        }
    }

    /** 排序白名单：前端传的 key -> 数据库列名 */
    static final Map<String, String> SORT_WHITELIST = new LinkedHashMap<>();

    static {
        SORT_WHITELIST.put("id", "id");
        SORT_WHITELIST.put("price", "price_cent");
        SORT_WHITELIST.put("stock", "stock");
        SORT_WHITELIST.put("createdAt", "created_at");
    }

    /** 模拟商品表 */
    static final List<Map<String, Object>> TABLE = new ArrayList<>();

    public static void main(String[] args) {
        for (int i = 1; i <= 23; i++) {
            Map<String, Object> row = new LinkedHashMap<>();
            row.put("id", (long) i);
            row.put("name", "商品" + i);
            row.put("price_cent", 1000 * ((i * 37) % 50 + 1));
            row.put("stock", (i * 13) % 100);
            row.put("created_at", 1700000000L + i * 3600L);
            TABLE.add(row);
        }
        System.out.println("表里共 " + TABLE.size() + " 条");

        System.out.println();
        System.out.println("=== 第 1 页，每页 5 条 ===");
        System.out.println("  " + query(1, 5, "id", true));

        System.out.println();
        System.out.println("=== 第 3 页，按价格降序 ===");
        System.out.println("  " + query(3, 5, "price", false));

        System.out.println();
        System.out.println("=== 最后一页不满 ===");
        System.out.println("  " + query(5, 5, "id", true));

        System.out.println();
        System.out.println("=== 页码越界：返回空列表，不报错 ===");
        System.out.println("  " + query(99, 5, "id", true));

        System.out.println();
        System.out.println("=== page < 1 归一化成 1 ===");
        System.out.println("  " + query(0, 5, "id", true));

        System.out.println();
        System.out.println("=== size 超上限被截断到 100 ===");
        Page<Map<String, Object>> capped = query(1, 1000000, "id", true);
        System.out.println("  实际 size=" + capped.size + "，返回 " + capped.list.size() + " 条");

        System.out.println();
        System.out.println("=== 非法排序字段：拒绝，不拼接 ===");
        try {
            System.out.println("  " + query(1, 5, "id; DROP TABLE item", true));
        } catch (IllegalArgumentException e) {
            System.out.println("  400 " + e.getMessage() + "（没有拼进 SQL）");
        }

        System.out.println();
        System.out.println("=== 空表：pages 不能除零 ===");
        TABLE.clear();
        System.out.println("  " + query(1, 5, "id", true));

        System.out.println();
        System.out.println("=== 深分页的代价 ===");
        System.out.println("  LIMIT 5 OFFSET 0      -> 读 5 行");
        System.out.println("  LIMIT 5 OFFSET 50000  -> 先读 50005 行再丢掉前 50000 行");
        System.out.println("  游标分页: WHERE id > 50000 ORDER BY id LIMIT 5 -> 走主键索引，只读 5 行");
    }

    static Page<Map<String, Object>> query(int page, int size, String sortKey, boolean asc) {
        String column = SORT_WHITELIST.get(sortKey);
        if (column == null) {
            throw new IllegalArgumentException("不支持的排序字段: " + sortKey
                    + "，可选: " + SORT_WHITELIST.keySet());
        }
        int safePage = Math.max(page, 1);
        int safeSize = Math.min(Math.max(size, 1), 100);

        List<Map<String, Object>> sorted = new ArrayList<>(TABLE);
        sorted.sort((a, b) -> {
            long va = ((Number) a.get(column)).longValue();
            long vb = ((Number) b.get(column)).longValue();
            int cmp = Long.compare(va, vb);
            return asc ? cmp : -cmp;
        });

        int from = (safePage - 1) * safeSize;
        int to = Math.min(from + safeSize, sorted.size());
        List<Map<String, Object>> slice = from >= sorted.size()
                ? new ArrayList<>()
                : new ArrayList<>(sorted.subList(from, to));

        List<Map<String, Object>> rows = new ArrayList<>();
        for (Map<String, Object> r : slice) {
            rows.add(new LinkedHashMap<>(r));
        }
        return new Page<>(rows, sorted.size(), safePage, safeSize);
    }
}
```

### 27-06 事务与并发扣库存

**知识点**
- 事务的四个特性：原子性（要么全成功要么全回滚）、一致性（约束不被破坏）、隔离性（并发互不干扰）、持久性（提交后不丢）。
- 事务边界放在 Service：`@Transactional` 标在"一个完整业务用例"的方法上，不要标在 Repository 的单条 SQL 上（那样多步操作就不在同一个事务里了）。
- 超卖的根因是"读-改-写"三步不原子：两个线程同时读到 `stock=1`，都判断"够"，都写回 `0`，结果卖出 2 件。加 `synchronized` 只在单机有效，多实例部署立刻失效。
- 三种正确做法：
  - 数据库原子更新：`UPDATE item SET stock = stock - ? WHERE id = ? AND stock >= ?`，看影响行数判断是否成功。最简单、最推荐。
  - 乐观锁：表加 `version` 字段，`UPDATE ... SET stock=?, version=version+1 WHERE id=? AND version=?`，影响 0 行说明被别人改过，重试。
  - 悲观锁：`SELECT ... FOR UPDATE`，锁住行再改。适合冲突激烈的场景，但容易锁等待、死锁。
- 隔离级别：读未提交 / 读已提交 / 可重复读（MySQL 默认）/ 串行化。级别越高并发越差；`可重复读` 靠 MVCC + 间隙锁解决大部分幻读。
- 死锁预防：多个资源按固定顺序加锁（永远先锁 id 小的）；事务尽量短；`UPDATE` 走主键或索引，避免锁全表。
- 长事务的代价：持有行锁时间长、undo log 膨胀、连接池被占满。远程调用、发消息、写文件绝不能放在事务里。
- 易错：同类内部 `this.method()` 调用带 `@Transactional` 的方法，事务不生效（没走代理）；异常被 `catch` 住没重新抛出，事务不回滚（默认只回滚 `RuntimeException`）。

**示例代码**
```java
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.atomic.AtomicReference;

public class StockConcurrency {
    static final int STOCK = 100;
    static final int THREADS = 20;
    static final int PER_THREAD = 10;

    public static void main(String[] args) throws Exception {
        System.out.println("库存 " + STOCK + "，线程 " + THREADS + "，每人请求 " + PER_THREAD
                + " 次，总请求 " + (THREADS * PER_THREAD));

        System.out.println();
        System.out.println("=== 方案一：先查库存再扣（错误写法）===");
        int[] naive = runNaive();
        System.out.println("  卖出=" + naive[0] + " 剩余=" + naive[1]
                + (naive[0] > STOCK ? "  <-- 超卖 " + (naive[0] - STOCK) + " 件" : "  <-- 恰好没超卖，纯属运气"));

        System.out.println();
        System.out.println("=== 方案二：数据库原子更新（推荐）===");
        int[] atomic = runAtomic();
        System.out.println("  卖出=" + atomic[0] + " 剩余=" + atomic[1]
                + (atomic[0] == STOCK ? "  <-- 正确" : "  <-- 有问题"));

        System.out.println();
        System.out.println("=== 方案三：乐观锁 version + 重试 ===");
        int[] opt = runOptimistic();
        System.out.println("  卖出=" + opt[0] + " 剩余=" + opt[1] + " 版本冲突次数=" + opt[2]
                + (opt[0] == STOCK ? "  <-- 正确" : "  <-- 有问题"));

        System.out.println();
        System.out.println("=== 为什么 synchronized 不够 ===");
        System.out.println("  单机 20 线程：synchronized 有效");
        System.out.println("  两台机器各 20 线程：两把锁互不相干，照样超卖");
        System.out.println("  所以并发控制要落到数据库（行锁/CAS）或 Redis 上");

        System.out.println();
        System.out.println("=== 事务回滚演示：扣库存成功但建订单失败 ===");
        TransactionDemo.run();
    }

    /** 模拟"读出来 -> 处理一会儿 -> 写回去"，拉大竞态窗口 */
    static void busyWait(long nanos) {
        long end = System.nanoTime() + nanos;
        while (System.nanoTime() < end) {
            Thread.onSpinWait();
        }
    }

    static int[] runNaive() throws Exception {
        AtomicInteger stock = new AtomicInteger(STOCK);
        AtomicInteger sold = new AtomicInteger();
        runAll(() -> {
            if (stock.get() > 0) {
                busyWait(50_000);          // 查完到写回之间的空档
                stock.decrementAndGet();
                sold.incrementAndGet();
            }
        });
        return new int[]{sold.get(), stock.get()};
    }

    static int[] runAtomic() throws Exception {
        AtomicInteger stock = new AtomicInteger(STOCK);
        AtomicInteger sold = new AtomicInteger();
        runAll(() -> {
            if (tryDeduct(stock)) {
                sold.incrementAndGet();
            }
        });
        return new int[]{sold.get(), stock.get()};
    }

    /** 等价于 UPDATE item SET stock = stock - 1 WHERE id = ? AND stock >= 1 */
    static boolean tryDeduct(AtomicInteger stock) {
        while (true) {
            int cur = stock.get();
            if (cur <= 0) {
                return false;
            }
            if (stock.compareAndSet(cur, cur - 1)) {
                return true;
            }
        }
    }

    static int[] runOptimistic() throws Exception {
        OptimisticRow row = new OptimisticRow(STOCK);
        AtomicInteger sold = new AtomicInteger();
        runAll(() -> {
            if (row.deduct()) {
                sold.incrementAndGet();
            }
        });
        return new int[]{sold.get(), row.stock(), row.conflicts()};
    }

    /** 一行记录：stock + version 打包成一个不可变数组，CAS 整体替换 */
    static class OptimisticRow {
        private final AtomicReference<int[]> state;
        private final AtomicInteger conflicts = new AtomicInteger();

        OptimisticRow(int stock) {
            state = new AtomicReference<>(new int[]{stock, 0});
        }

        boolean deduct() {
            while (true) {
                int[] cur = state.get();
                if (cur[0] <= 0) {
                    return false;
                }
                int[] next = new int[]{cur[0] - 1, cur[1] + 1};
                if (state.compareAndSet(cur, next)) {
                    return true;
                }
                conflicts.incrementAndGet();
            }
        }

        int stock() {
            return state.get()[0];
        }

        int conflicts() {
            return conflicts.get();
        }
    }

    interface Task {
        void run();
    }

    static void runAll(Task task) throws Exception {
        ExecutorService pool = Executors.newFixedThreadPool(THREADS);
        CountDownLatch gate = new CountDownLatch(1);
        CountDownLatch done = new CountDownLatch(THREADS * PER_THREAD);
        for (int i = 0; i < THREADS * PER_THREAD; i++) {
            pool.execute(() -> {
                try {
                    gate.await();
                    task.run();
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                } finally {
                    done.countDown();
                }
            });
        }
        gate.countDown();
        done.await(30, TimeUnit.SECONDS);
        pool.shutdown();
        pool.awaitTermination(5, TimeUnit.SECONDS);
    }

    /** 事务：记录 undo 日志，失败时倒序回滚 */
    static class TransactionDemo {
        static void run() {
            int[] stock = {10};                 // 用数组装，才能被 lambda 捕获
            java.util.List<Runnable> undo = new java.util.ArrayList<>();
            try {
                // 1. 扣库存
                stock[0]--;
                undo.add(() -> {
                    stock[0]++;
                    System.out.println("    rollback: stock 恢复为 " + stock[0]);
                });
                System.out.println("  扣库存后 stock=" + stock[0]);

                // 2. 建订单（这里故意抛异常，模拟唯一索引冲突）
                undo.add(() -> System.out.println("    rollback: delete order ORD20261117001"));
                throw new IllegalStateException("Duplicate entry 'ORD20261117001' for key 'uk_order_no'");
            } catch (RuntimeException e) {
                System.out.println("  捕获异常: " + e.getMessage());
                for (int i = undo.size() - 1; i >= 0; i--) {
                    undo.get(i).run();
                }
                System.out.println("  事务已回滚，stock=" + stock[0] + "，订单未创建");
            }
        }
    }
}
```

### 27-07 幂等与防重复提交

**知识点**
- 幂等：同一个请求执行一次和执行 N 次，结果一样。`GET`/`PUT`/`DELETE` 天然幂等，`POST` 不幂等（下单、支付、发券）。
- 重复提交的三个来源：用户连点、网络超时后客户端重试、消息队列重复投递。前端置灰按钮只是体验优化，不是防护。
- 主流方案：
  - 幂等键（idempotency-key）：客户端生成唯一 key 随请求带上，服务端用 `SETNX` 或唯一索引占位，占不到直接返回上次结果。
  - 数据库唯一索引：`uk_order_no`，重复插入报 `DuplicateKeyException`，捕获后当作"已处理"返回。最可靠，作为最后一道防线。
  - 状态机：订单只能从 `PENDING` 流转到 `PAID`，已支付的再收到支付回调直接返回成功，不重复加钱。
  - 分布式锁：同一业务 key 只允许一个请求进入，其它等待或快速失败。
- 幂等表设计：`idempotency_key`（唯一）、`biz_type`、`result`（缓存首次结果）、`status`（PROCESSING / DONE）、`expire_at`。处理中重复请求要返回"处理中，请稍后"而不是重复执行。
- 幂等键的选取：不能用"用户 id + 时间戳"（同一秒重复），要用客户端生成的 UUID 或"业务号"（订单号天然唯一）。
- 易错：先查后插（并发下两个请求都查到"不存在"）；幂等记录和业务数据不在同一个事务里；幂等 key 永不过期导致表无限膨胀。

**示例代码**
```java
import java.util.LinkedHashMap;
import java.util.Map;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicInteger;

public class IdempotentSubmit {
    /** 幂等记录表：key -> 记录 */
    static final Map<String, IdemRecord> IDEM_TABLE = new ConcurrentHashMap<>();
    /** 订单表：orderNo -> 金额 */
    static final Map<String, Integer> ORDER_TABLE = new ConcurrentHashMap<>();
    static final AtomicInteger CREATE_COUNT = new AtomicInteger();

    static class IdemRecord {
        String status;      // PROCESSING / DONE
        String result;

        IdemRecord(String status, String result) {
            this.status = status;
            this.result = result;
        }
    }

    public static void main(String[] args) throws Exception {
        System.out.println("=== 场景一：用户连点 5 次（同一幂等键）===");
        String key = UUID.randomUUID().toString();
        for (int i = 1; i <= 5; i++) {
            System.out.println("  第 " + i + " 次: " + submit(key, "ITEM-1", 1));
        }
        System.out.println("  实际创建订单数=" + CREATE_COUNT.get() + "（期望 1）");

        System.out.println();
        System.out.println("=== 场景二：10 个线程并发提交同一个键 ===");
        CREATE_COUNT.set(0);
        ORDER_TABLE.clear();
        IDEM_TABLE.clear();
        String sameKey = "client-uuid-0001";
        ExecutorService pool = Executors.newFixedThreadPool(10);
        CountDownLatch gate = new CountDownLatch(1);
        CountDownLatch done = new CountDownLatch(10);
        for (int i = 0; i < 10; i++) {
            pool.execute(() -> {
                try {
                    gate.await();
                    String r = submit(sameKey, "ITEM-2", 1);
                    System.out.println("  " + Thread.currentThread().getName() + " -> " + r);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                } finally {
                    done.countDown();
                }
            });
        }
        gate.countDown();
        done.await(10, TimeUnit.SECONDS);
        pool.shutdown();
        System.out.println("  实际创建订单数=" + CREATE_COUNT.get() + "（期望 1）");

        System.out.println();
        System.out.println("=== 场景三：不同幂等键，正常下两单 ===");
        CREATE_COUNT.set(0);
        ORDER_TABLE.clear();
        IDEM_TABLE.clear();
        System.out.println("  " + submit(UUID.randomUUID().toString(), "ITEM-3", 1));
        System.out.println("  " + submit(UUID.randomUUID().toString(), "ITEM-3", 1));
        System.out.println("  实际创建订单数=" + CREATE_COUNT.get() + "（期望 2）");

        System.out.println();
        System.out.println("=== 场景四：唯一索引兜底（幂等表被绕过时）===");
        ORDER_TABLE.clear();
        String orderNo = "ORD202611170001";
        System.out.println("  " + insertOrder(orderNo, 9900));
        System.out.println("  " + insertOrder(orderNo, 9900));

        System.out.println();
        System.out.println("=== 场景五：状态机幂等（重复支付回调）===");
        Map<String, String> orderStatus = new LinkedHashMap<>();
        orderStatus.put("ORD-1", "PENDING");
        System.out.println("  " + payCallback(orderStatus, "ORD-1", 9900));
        System.out.println("  " + payCallback(orderStatus, "ORD-1", 9900));
        System.out.println("  最终状态=" + orderStatus.get("ORD-1") + "，只加了一次钱");

        System.out.println();
        System.out.println("=== 幂等表结构 ===");
        System.out.println("  idempotency_key VARCHAR(64) PRIMARY KEY  -- 客户端 UUID 或业务号");
        System.out.println("  biz_type        VARCHAR(32)              -- ORDER / PAY / COUPON");
        System.out.println("  status          VARCHAR(16)              -- PROCESSING / DONE");
        System.out.println("  result          TEXT                     -- 首次执行结果，重复请求直接返回");
        System.out.println("  expire_at       DATETIME                 -- 定时任务清理，避免表无限膨胀");
    }

    /** 幂等提交：占位 -> 执行 -> 回填结果 */
    static String submit(String idemKey, String itemId, int count) {
        IdemRecord existing = IDEM_TABLE.putIfAbsent(idemKey, new IdemRecord("PROCESSING", null));
        if (existing != null) {
            if ("DONE".equals(existing.status)) {
                return "幂等命中，返回首次结果: " + existing.result;
            }
            return "处理中，请稍后查询（key=" + idemKey.substring(0, 8) + "...）";
        }
        try {
            String orderNo = "ORD" + System.nanoTime();
            CREATE_COUNT.incrementAndGet();
            ORDER_TABLE.put(orderNo, 9900 * count);
            String result = "下单成功 orderNo=" + orderNo;
            IDEM_TABLE.put(idemKey, new IdemRecord("DONE", result));
            return result;
        } catch (RuntimeException e) {
            IDEM_TABLE.remove(idemKey);        // 执行失败要释放占位，允许重试
            return "下单失败: " + e.getMessage();
        }
    }

    /** 数据库唯一索引：重复插入抛异常，捕获后视为已处理 */
    static String insertOrder(String orderNo, int amountCent) {
        if (ORDER_TABLE.putIfAbsent(orderNo, amountCent) != null) {
            return "DuplicateKeyException(uk_order_no) -> 视为重复请求，返回成功";
        }
        return "插入成功 " + orderNo;
    }

    /** 状态机：只有 PENDING 才能变 PAID */
    static String payCallback(Map<String, String> orderStatus, String orderNo, int amountCent) {
        String status = orderStatus.get(orderNo);
        if (status == null) {
            return "订单不存在";
        }
        if ("PAID".equals(status)) {
            return "已是 PAID，重复回调直接返回成功（不重复加钱）";
        }
        if (!"PENDING".equals(status)) {
            return "状态 " + status + " 不允许支付";
        }
        orderStatus.put(orderNo, "PAID");
        return "支付成功，金额 " + amountCent + " 分";
    }
}
```

### 27-08 日志、监控与链路追踪

**知识点**
- 日志级别怎么用：`ERROR` 需要人介入（异常、资损）、`WARN` 可自愈但要关注（重试成功、降级）、`INFO` 关键业务节点（下单成功、支付回调）、`DEBUG` 排查用（入参出参，生产默认关闭）。
- 结构化日志：`时间 级别 traceId 线程 类名 消息 key=value`。别用字符串拼接把关键字段埋在句子里，否则没法检索和统计。
- traceId：一次外部请求生成一个，通过 `MDC.put("traceId", ...)` 或 `ThreadLocal` 贯穿全链路，跨服务通过 HTTP 头 / MQ 属性传递。没有 traceId，一个并发 500 的服务日志基本没法看。
- 三个绝不：绝不打密码/令牌/身份证/银行卡；绝不 `printStackTrace()`；绝不 `catch` 住异常什么都不做。
- 日志切割：按天 + 按大小滚动，保留 7~30 天，总量设上限。单文件几百 MB 会导致排查时打不开。
- 可观测性三支柱：日志（发生了什么）、指标（整体健康度：QPS、P99 延迟、错误率、连接池占用）、链路追踪（一次请求经过了哪些服务，哪一段慢）。
- 黄金指标：延迟、流量、错误、饱和度。告警要基于"错误率 > 1% 持续 5 分钟"这类组合条件，而不是单次异常。
- 健康检查分两种：`liveness`（进程活着吗，失败就重启）和 `readiness`（能接流量吗，失败就从负载均衡摘掉）。数据库连不上应该 `readiness` 失败而不是 `liveness` 失败，否则会陷入无限重启。
- 易错：在循环里打 `INFO` 日志（日志量爆炸）；日志里打大对象 `toString()`（一次几百 KB）；异步线程里丢了 MDC 上下文。

**示例代码**
```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.concurrent.atomic.AtomicLong;

public class Observability {
    enum Level {
        DEBUG(0), INFO(1), WARN(2), ERROR(3);
        final int weight;

        Level(int weight) {
            this.weight = weight;
        }
    }

    /** 等价于 MDC：每个请求一个 traceId */
    static final ThreadLocal<String> TRACE_ID = new ThreadLocal<>();
    static Level threshold = Level.INFO;
    static final List<Long> LATENCIES = Collections.synchronizedList(new ArrayList<>());
    static final AtomicLong TOTAL = new AtomicLong();
    static final AtomicLong ERRORS = new AtomicLong();

    public static void main(String[] args) {
        System.out.println("=== 结构化日志：带 traceId ===");
        TRACE_ID.set("a1b2c3d4");
        log(Level.INFO, "OrderController", "收到下单请求 userId=1001 itemId=42 count=2");
        log(Level.DEBUG, "ItemService", "查询商品缓存未命中 id=42");       // 生产不开 DEBUG
        log(Level.INFO, "OrderService", "扣库存成功 itemId=42 before=100 after=98");
        log(Level.WARN, "PayClient", "支付网关超时，准备重试 attempt=1 cost=3021ms");
        log(Level.ERROR, "OrderService", "下单失败 orderNo=ORD20261117001 reason=库存不足");
        TRACE_ID.remove();

        System.out.println();
        System.out.println("=== 没有 traceId 的日志基本没法排查 ===");
        log(Level.INFO, "OrderService", "另一个请求的日志（traceId=null）");

        System.out.println();
        System.out.println("=== 敏感信息必须脱敏 ===");
        String phone = "13812345678";
        String token = "eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJ6aGFuZ3NhbiJ9.abc";
        log(Level.INFO, "UserService", "登录 phone=" + maskPhone(phone)
                + " token=" + maskToken(token));
        System.out.println("  反例（绝不能出现在日志里）: phone=" + phone + " token=" + token);

        System.out.println();
        System.out.println("=== 指标：QPS / 错误率 / P99 ===");
        for (int i = 0; i < 100; i++) {
            long cost = 20 + (i % 10) * 5;
            if (i == 87) {
                cost = 1800;                 // 一个长尾请求
            }
            record(cost, i % 50 == 0);
        }
        System.out.printf("  总请求=%d 错误数=%d 错误率=%.2f%%%n",
                TOTAL.get(), ERRORS.get(), ERRORS.get() * 100.0 / TOTAL.get());
        System.out.printf("  P50=%dms P95=%dms P99=%dms MAX=%dms%n",
                percentile(50), percentile(95), percentile(99), percentile(100));
        System.out.println("  平均值会掩盖长尾：平均只有 "
                + String.format("%.1f", avg()) + "ms，但 P99 已经到 " + percentile(99) + "ms");

        System.out.println();
        System.out.println("=== 告警规则示例 ===");
        Map<String, String> alerts = new LinkedHashMap<>();
        alerts.put("错误率", "rate(error[5m]) / rate(total[5m]) > 0.01 持续 5m");
        alerts.put("P99 延迟", "histogram_quantile(0.99, latency) > 500ms 持续 5m");
        alerts.put("连接池", "hikari_active / hikari_max > 0.9 持续 2m");
        alerts.put("磁盘", "disk_free < 10%");
        alerts.forEach((k, v) -> System.out.printf("  %-10s %s%n", k, v));

        System.out.println();
        System.out.println("=== 健康检查两种探针 ===");
        System.out.println("  /actuator/health/liveness  -> 进程能响应就行，失败 -> 重启容器");
        System.out.println("  /actuator/health/readiness -> 依赖（DB/Redis）都通才返回 UP，失败 -> 摘流量");
        System.out.println("  DB 挂了让 liveness 失败 = 无限重启，问题永远好不了");
    }

    /** 一条结构化日志 */
    static void log(Level level, String logger, String msg) {
        if (level.weight < threshold.weight) {
            return;
        }
        String trace = TRACE_ID.get() == null ? "-" : TRACE_ID.get();
        System.out.printf("  2026-11-17T10:23:45.123+08:00 %-5s [%s] [%s] %s - %s%n",
                level, trace, Thread.currentThread().getName(), logger, msg);
    }

    static void record(long costMs, boolean error) {
        LATENCIES.add(costMs);
        TOTAL.incrementAndGet();
        if (error) {
            ERRORS.incrementAndGet();
        }
    }

    static long percentile(int p) {
        List<Long> copy;
        synchronized (LATENCIES) {
            copy = new ArrayList<>(LATENCIES);
        }
        if (copy.isEmpty()) {
            return 0;
        }
        Collections.sort(copy);
        int idx = (int) Math.ceil(p / 100.0 * copy.size()) - 1;
        return copy.get(Math.max(0, Math.min(idx, copy.size() - 1)));
    }

    static double avg() {
        synchronized (LATENCIES) {
            long sum = 0;
            for (long v : LATENCIES) {
                sum += v;
            }
            return LATENCIES.isEmpty() ? 0 : (double) sum / LATENCIES.size();
        }
    }

    static String maskPhone(String phone) {
        return phone.substring(0, 3) + "****" + phone.substring(7);
    }

    static String maskToken(String token) {
        return token.length() <= 10 ? "***" : token.substring(0, 6) + "..." + token.substring(token.length() - 4);
    }
}
```

### 27-09 打包与部署

**知识点**
- 打包：`mvn clean package` 产出 `app.jar`。Spring Boot 的 fat jar 把依赖一起打进去，`java -jar app.jar` 直接跑；thin jar 需要配合 `lib/` 目录和 `-Dloader.path`。
- 配置外部化优先级（从高到低）：命令行参数 > 环境变量 > `application-{profile}.yml` > `application.yml` > 代码默认值。生产环境用环境变量注入密码，绝不写进 jar。
- `profile` 隔离：`application-dev.yml` / `application-test.yml` / `application-prod.yml`，启动时 `--spring.profiles.active=prod`。
- JVM 参数：`-Xms` 与 `-Xmx` 设成一样避免堆反复扩缩；容器里用 `-XX:MaxRAMPercentage=75` 而不是写死 `-Xmx2g`（否则容器限制 1G、JVM 却按 2G 算，直接被 OOMKill）。
- 优雅停机：`server.shutdown=graceful` + `spring.lifecycle.timeout-per-shutdown-phase=30s`，先停止接收新请求，等在处理的请求完成再退出。没有优雅停机，发版时正在下单的用户会收到 502。
- 启动脚本要做的：切到 jar 目录、设置 JVM 参数、`nohup` 后台运行、写 pid 文件、日志重定向、`start/stop/restart/status` 四个子命令。
- 部署顺序：先起新实例 -> 等健康检查通过 -> 从负载均衡摘旧实例 -> 停旧实例（滚动发布），而不是"先停后起"。
- 时区与端口：容器默认 UTC，`-Duser.timezone=Asia/Shanghai` 否则时间差 8 小时；端口冲突时用 `--server.port`。
- 易错：jar 里的 `application-prod.yml` 存着数据库密码（能直接被 `unzip` 出来）；`nohup` 没重定向导致 `nohup.out` 撑爆磁盘；健康检查路径被鉴权拦截器挡住，导致探针永远失败。

### 27-10 接口文档与联调

**知识点**
- 文档即契约：接口一旦发布，字段名、类型、是否必填、错误码就是承诺。改字段名等于破坏契约，要么加版本（`/api/v2/items`），要么新老字段并存一段时间。
- 必写的六项：URL + 方法、请求头（是否需要 token）、请求参数（类型/必填/范围/示例）、响应结构（含错误码）、错误码表、幂等性说明。
- `OpenAPI`/`Swagger` 的价值：文档从代码生成，不会和实现脱节；还能生成前端 SDK、做契约测试。手写 Word 文档三天就过期。
- 联调顺序：先定契约 -> 后端出 mock（返回假数据）-> 前端并行开发 -> 后端实现完切真实接口 -> 契约测试兜底。
- Mock 的意义不是"造假数据"，而是把"前端等后端"的串行变成并行。
- 契约测试：用同一份 schema 校验请求和响应，字段少一个、类型变一个立刻失败。
- 常见坑：`null` 和"字段不存在"混用（前端无法区分"没查"和"查了是空"）；分页返回 `list` 有时叫 `records` 有时叫 `rows`；时间格式一会时间戳一会 `yyyy-MM-dd`；枚举传中文。
- 易错：文档写了 `size` 最大 100，代码里没校验；文档说 401 返回 `{code,msg}`，实际返回了 HTML 错误页（被网关拦了）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class ApiContract {
    /** 字段定义 */

    /** 接口定义 */

               List<Field> response, List<String> errors) { }

        List<Api> apis = new ArrayList<>();
        apis.add(new Api("POST", "/api/items", "新增商品",

                        new Field("msg", "string", true, "-", "ok"),
                        new Field("data.id", "integer", true, "-", "42"),
                        new Field("data.name", "string", true, "-", "机械键盘"),

                List.of("400 参数格式错误", "409 商品名重复", "401 未登录")));

        apis.add(new Api("GET", "/api/items", "分页查询商品",
                List.of(
                        new Field("page", "integer", false, ">= 1，默认 1", "1"),
                        new Field("size", "integer", false, "1~100，默认 10", "10"),

                List.of(
                        new Field("code", "integer", true, "-", "200"),
                        new Field("data.list", "array", true, "-", "[{...}]"),
                        new Field("data.total", "integer", true, ">= 0", "23"),
                        new Field("data.page", "integer", true, ">= 1", "1"),

                        new Field("data.pages", "integer", true, ">= 0", "3")),

        breaks.forEach((k, v) -> System.out.printf("  %-8s %s%n", k, v));
        System.out.println("  正确做法：加新字段并保留旧字段一个版本周期，前端迁移完再删");

        System.out.println();
        System.out.println("=== 联调流程 ===");
        String[] steps = {

    static void printApi(Api api) {
        System.out.println("=== " + api.method() + " " + api.path() + "  " + api.summary() + " ===");
        System.out.println("  请求参数:");
        if (api.request().isEmpty()) {
            System.out.println("    （无）");
        }
        for (Field f : api.request()) {
            System.out.printf("    %-14s %-8s %-8s %-18s 例: %s%n",
                    f.name(), f.type(), f.required() ? "必填" : "可选", f.rule(), f.example());
        }
        System.out.println("  响应字段:");
        for (Field f : api.response()) {
            System.out.printf("    %-14s %-8s %-8s %s%n", f.name(), f.type(),
                    f.required() ? "必有" : "可空", f.rule());
        }
        System.out.println("  错误码: " + api.errors());
        System.out.println();
    }

    /** 契约测试：逐个检查必填字段是否存在 */
    static List<String> checkResponse(Api api, Map<String, Object> actual) {
        List<String> missing = new ArrayList<>();
        for (Field f : api.response()) {
            if (!f.required()) {
                continue;
            }
            if (!hasPath(actual, f.name())) {
                missing.add(f.name());
            }
        }
        return missing;
    }

    /** 支持 data.list 这种点号路径 */
    static boolean hasPath(Map<String, Object> root, String path) {
        Object cur = root;
        for (String part : path.split("\\.")) {
            if (!(cur instanceof Map)) {
                return false;
            }
            Map<?, ?> map = (Map<?, ?>) cur;
            if (!map.containsKey(part)) {
                return false;
            }
            cur = map.get(part);
        }
        return true;
    }
}
```

### 27-11 综合案例：下单全流程

**知识点**
- 一个下单请求串起前面所有内容：参数校验（27-03）-> 查商品（27-02 分层）-> 扣库存（27-06 原子更新）-> 建订单（27-07 幂等）-> 统一异常（27-04）-> 日志与 traceId（27-08）-> 返回统一响应（27-01）。
- 关键顺序：先校验后扣减，先扣库存后建订单（库存是稀缺资源，早点失败）；扣库存失败立即返回，不要建"待支付但没货"的订单。
- 金额计算全部用分：`总价 = 单价 * 数量`，优惠单独算，最后一次性汇总，避免多次浮点累加。
- 订单号生成：`业务前缀 + 日期 + 序列`（`ORD20261117` + 6 位），唯一索引兜底；不要用"当前时间戳"（同毫秒并发会撞）。
- 状态机：`CREATED -> PAID -> SHIPPED -> COMPLETED`，`CREATED -> CANCELLED`。每次流转校验前置状态，非法流转直接拒绝。
- 全链路一个 traceId：入口生成，日志、响应头（`X-Trace-Id`）都带上，用户报障时让他提供这个 id 就能定位。
- 易错：把"扣库存"和"建订单"放在两个事务里（扣了库存但订单没建成，库存永久丢失）；订单号用 `System.currentTimeMillis()`；返回体里带上内部字段（成本价、库存表 id）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.atomic.AtomicLong;

public class OrderFlowCase {
    static final ThreadLocal<String> TRACE = new ThreadLocal<>();
    static final Map<Long, Item> ITEM_TABLE = new ConcurrentHashMap<>();
    static final Map<String, Order> ORDER_TABLE = new ConcurrentHashMap<>();
    static final Map<String, String> IDEM = new ConcurrentHashMap<>();
    static final AtomicLong ORDER_SEQ = new AtomicLong(0);
    static final List<String> LOGS = new ArrayList<>();

    static class Item {
        Long id;
        String name;
        int priceCent;
        final AtomicInteger stock;

        Item(Long id, String name, int priceCent, int stock) {
            this.id = id;
            this.name = name;
            this.priceCent = priceCent;
            this.stock = new AtomicInteger(stock);
        }
    }

    static class Order {
        String orderNo;
        Long itemId;
        int count;
        int amountCent;
        String status = "CREATED";

        Order(String orderNo, Long itemId, int count, int amountCent) {
            this.orderNo = orderNo;
            this.itemId = itemId;
            this.count = count;
            this.amountCent = amountCent;
        }

        Map<String, Object> toVo() {
            Map<String, Object> vo = new LinkedHashMap<>();
            vo.put("orderNo", orderNo);
            vo.put("itemId", itemId);
            vo.put("count", count);
            vo.put("amount", String.format("%.2f", amountCent / 100.0));
            vo.put("status", status);
            return vo;
        }
    }

    public static void main(String[] args) {
        ITEM_TABLE.put(1L, new Item(1L, "机械键盘", 39900, 3));
        ITEM_TABLE.put(2L, new Item(2L, "显示器", 129900, 0));

        System.out.println("=== 正常下单 ===");
        System.out.println("  " + place("req-" + UUID.randomUUID(), 1L, 2));

        System.out.println();
        System.out.println("=== 库存不足（只剩 1 件，要 2 件）===");
        System.out.println("  " + place("req-" + UUID.randomUUID(), 1L, 2));

        System.out.println();
        System.out.println("=== 完全没货 ===");
        System.out.println("  " + place("req-" + UUID.randomUUID(), 2L, 1));

        System.out.println();
        System.out.println("=== 重复提交（同一幂等键）===");
        String sameReq = "req-fixed-key-001";
        System.out.println("  第1次: " + place(sameReq, 1L, 1));
        System.out.println("  第2次: " + place(sameReq, 1L, 1));
        System.out.println("  剩余库存=" + ITEM_TABLE.get(1L).stock.get() + "（期望 0）");

        System.out.println();
        System.out.println("=== 参数校验 ===");
        System.out.println("  " + place("req-" + UUID.randomUUID(), 1L, 0));
        System.out.println("  " + place("req-" + UUID.randomUUID(), 999L, 1));

        System.out.println();
        System.out.println("=== 状态流转 ===");
        String orderNo = ORDER_TABLE.keySet().iterator().next();
        System.out.println("  " + transit(orderNo, "PAID"));
        System.out.println("  " + transit(orderNo, "PAID"));
        System.out.println("  " + transit(orderNo, "SHIPPED"));
        System.out.println("  " + transit(orderNo, "CANCELLED"));

        System.out.println();
        System.out.println("=== 全链路日志（同一 traceId）===");
        for (String line : LOGS) {
            System.out.println("  " + line);
        }
    }

    /** 下单：校验 -> 扣库存 -> 建订单 -> 响应 */
    static Map<String, Object> place(String idemKey, Long itemId, int count) {
        TRACE.set(UUID.randomUUID().toString().substring(0, 8));
        try {
            log("INFO", "OrderController", "收到下单 itemId=" + itemId + " count=" + count);

            if (count <= 0) {
                return fail(400, "购买数量必须大于 0");
            }
            if (count > 99) {
                return fail(400, "单次最多购买 99 件");
            }

            String done = IDEM.get(idemKey);
            if (done != null) {
                log("INFO", "OrderService", "幂等命中 key=" + idemKey + " orderNo=" + done);
                return ok("重复请求，返回首次订单 " + done);
            }

            Item item = ITEM_TABLE.get(itemId);
            if (item == null) {
                log("WARN", "ItemRepository", "商品不存在 id=" + itemId);
                return fail(1001, "商品不存在");
            }
            log("INFO", "ItemRepository", "查询商品 " + item.name + " 单价=" + item.priceCent + "分");

            if (!deduct(item, count)) {
                log("WARN", "OrderService", "库存不足 itemId=" + itemId + " 剩余=" + item.stock.get());
                return fail(2001, "库存不足，仅剩 " + item.stock.get() + " 件");
            }
            log("INFO", "OrderService", "扣库存成功 itemId=" + itemId + " 剩余=" + item.stock.get());

            String orderNo = nextOrderNo();
            int amount = item.priceCent * count;
            ORDER_TABLE.put(orderNo, new Order(orderNo, itemId, count, amount));
            IDEM.put(idemKey, orderNo);
            log("INFO", "OrderService", "创建订单 orderNo=" + orderNo + " amount=" + amount + "分");

            Map<String, Object> resp = ok("下单成功");
            @SuppressWarnings("unchecked")
            Map<String, Object> data = (Map<String, Object>) resp.get("data");
            data.putAll(ORDER_TABLE.get(orderNo).toVo());
            data.put("traceId", TRACE.get());
            return resp;
        } catch (RuntimeException e) {
            log("ERROR", "OrderService", "下单异常 " + e);
            return fail(500, "系统繁忙，请稍后重试");
        } finally {
            TRACE.remove();
        }
    }

    /** 等价于 UPDATE item SET stock = stock - ? WHERE id = ? AND stock >= ? */
    static boolean deduct(Item item, int count) {
        while (true) {
            int cur = item.stock.get();
            if (cur < count) {
                return false;
            }
            if (item.stock.compareAndSet(cur, cur - count)) {
                return true;
            }
        }
    }

    static String nextOrderNo() {
        return "ORD20261117" + String.format("%06d", ORDER_SEQ.incrementAndGet());
    }

    static Map<String, Object> transit(String orderNo, String target) {
        Order order = ORDER_TABLE.get(orderNo);
        if (order == null) {
            return fail(1001, "订单不存在");
        }
        boolean legal = switch (order.status + "->" + target) {
            case "CREATED->PAID", "CREATED->CANCELLED", "PAID->SHIPPED",
                 "SHIPPED->COMPLETED" -> true;
            default -> false;
        };
        if (!legal) {
            return fail(2002, "非法状态流转 " + order.status + " -> " + target);
        }
        order.status = target;
        return ok("订单 " + orderNo + " 状态变为 " + target);
    }

    static Map<String, Object> ok(String msg) {
        Map<String, Object> body = new LinkedHashMap<>();
        body.put("code", 200);
        body.put("msg", msg);
        body.put("data", new LinkedHashMap<String, Object>());
        return body;
    }

    static Map<String, Object> fail(int code, String msg) {
        Map<String, Object> body = new LinkedHashMap<>();
        body.put("code", code);
        body.put("msg", msg);
        body.put("data", null);
        return body;
    }

    static void log(String level, String logger, String msg) {
        String line = "2026-11-17T10:23:45 " + level + " [" + TRACE.get() + "] " + logger + " - " + msg;
        synchronized (LOGS) {
            if (LOGS.size() < 40) {
                LOGS.add(line);
            }
        }
    }
}
```

## 本章综合练习

### 综合题：下单全流程接口

**场景**

把前几章的能力拼成一条下单链路：接口设计 → 分层 → DTO/VO 转换 → 参数校验 → 事务扣库存 → 幂等防重 → 统一异常 → 日志追踪 → 打包部署。这是第一个「完整业务闭环」的综合题。

**任务**
1. 设计下单接口：URL、方法、状态码、请求体、响应体各写清楚，说明为什么下单用 POST 而不是 GET、为什么创建成功返回 201。
2. 实现 Service 层下单事务：校验商品与库存 → 扣库存（用 update ... where stock >= n 防超卖）→ 写订单与明细 → 清购物车，任一步失败整体回滚。
3. 实现幂等：客户端传 requestId，服务端用唯一索引或 Redis setnx 保证同一 requestId 只成功一次，重复请求返回首次结果。
4. 用 MDC 给每次请求生成 traceId 并打进日志，串联 Controller 与 Service 的日志；最后打成 jar 用 java -jar 启动验证。

**验收清单**
- [ ] 并发 100 次抢 10 件库存，成功订单恰好 10 笔，库存不为负。
- [ ] 同一 requestId 重复提交 10 次只产生 1 笔订单。
- [ ] 库存不足、商品下架、参数非法三种失败场景都返回明确错误码且数据无脏写。
- [ ] 同一请求的日志能靠 traceId 串起来，jar 包在干净环境可启动。
