### 实操 37-01 镜像构建缓存评估器

**知识点注释**
- 【题目要求】给定 Dockerfile 指令序列（FROM/COPY/RUN/EXPOSE 等）与两次构建间“哪些文件变了”的描述，输出第二次构建每一层是 CACHED 还是重算，并统计重算层数与预估耗时（每层固定开销 5s，COPY 层重算另加 8s）。
- 【考核点】构建缓存判定规则（父层相同且指令未变才命中；COPY 按文件内容校验和）、指令顺序即缓存策略、层不可变。
- 【易错点】一条失配其后全部重算；EXPOSE 等元数据层也依赖父层；把“文件没变”当成“层命中”而忽略父层失效。
- 【提示】把每条指令建模为 (类型, 内容指纹, 依赖父层指纹)，自底向上传播“失效”标记。

**示例代码**（技术示范：失效传播，另一套场景）
```java
import java.util.ArrayList;
import java.util.List;

public class CachePropagateDemo {
    record Step(String cmd, String fingerprint, boolean changed) {
    }

    static void evaluate(List<Step> steps) {
        boolean broken = false;
        int recompute = 0, cached = 0;
        for (Step s : steps) {
            if (s.changed()) {
                broken = true;
            }
            if (broken) {
                recompute++;
                System.out.printf("  %-10s -> 重算（%s）%n", s.cmd(),
                        s.changed() ? "内容变更" : "父层失效");
            } else {
                cached++;
                System.out.printf("  %-10s -> CACHED%n", s.cmd());
            }
        }
        System.out.printf("  结果：命中 %d 层 / 重算 %d 层%n%n", cached, recompute);
    }

    public static void main(String[] args) {
        List<Step> steps = List.of(
                new Step("FROM base", "base-v1", false),
                new Step("COPY pom.xml", "pom-a1", false),
                new Step("RUN mvn dep", "deps-a1", false),
                new Step("COPY src", "src-b2", true),
                new Step("RUN mvn pkg", "pkg-c3", false));
        evaluate(steps);
    }
}
```

**课后练习题**
1. 实现完整评估器：输入 Dockerfile 文本（自己定义紧凑格式）与变更文件清单，输出逐层判定与总耗时；用“改 pom.xml”与“只改 src”两组输入对比命中差异。
2. 在真实 Docker（或虚拟机演示）验证评估器：同一项目两次构建，`docker build` 输出与你的推演逐层比对。

### 实操 38-01 倒排索引布尔检索器

**知识点注释**
- 【题目要求】给定 10 篇文档（自行设计），分词（空格+小写）建倒排索引；实现布尔检索 `term1 AND term2 NOT term3` 与短语查询（两词相邻）；输出每个查询的命中文档与交集过程。
- 【考核点】倒排索引构建、布尔集合运算（交/并/差）、最短表驱动求交、位置信息与短语查询。
- 【易错点】未排序的倒排表无法双指针求交；NOT 误用 removeAll 前未复制集合；短语查询忽略位置。
- 【提示】倒排表存 ArrayList 并在插入时保持有序；短语查询额外存每词在各文档中的位置列表。

**示例代码**（技术示范：集合求交，另一套场景）
```java
import java.util.ArrayList;
import java.util.List;

public class SetOpsDemo {
    static List<Integer> intersect(List<Integer> a, List<Integer> b) {
        List<Integer> r = new ArrayList<>();
        int i = 0, j = 0;
        while (i < a.size() && j < b.size()) {
            if (a.get(i).equals(b.get(j))) {
                r.add(a.get(i));
                i++;
                j++;
            } else if (a.get(i) < b.get(j)) {
                i++;
            } else {
                j++;
            }
        }
        return r;
    }

    public static void main(String[] args) {
        List<Integer> vip = List.of(1, 3, 5, 9);
        List<Integer> active = List.of(3, 5, 7);
        System.out.println("  VIP ∩ 活跃 = " + intersect(vip, active));
    }
}
```

**课后练习题**
1. 实现完整倒排检索器：含 AND/OR/NOT 三种组合与短语查询，用 5 个查询验证并输出求交步数。
2. 统计“用最短表驱动 vs 固定用第一张表”的比较次数差异，量化驱动表选择的收益。
3. 思考题：为什么倒排表要保持有序？从跳表加速与双指针求交两个用途分析。

### 实操 38-02 BM25 排序器

**知识点注释**
- 【题目要求】给定 8 篇文档与查询词，实现 BM25 评分（IDF×词频项，含字段长度归一，k1=1.2、b=0.75），输出全部文档按分排序的结果，并用 `explain` 风格输出每篇文档的 IDF、TF 项、长度归一三项明细。
- 【考核点】BM25 公式、字段长度归一的方向、TF 饱和效应、多词查询的分数合成。
- 【易错点】IDF 公式用错方向（稀有词应高分）；忘记除以（tf + k1）饱和项；长度归一 b 参数含义颠倒。
- 【提示】先算每词 IDF，再逐文档累加各词贡献；explain 输出每一项便于人工核对。

**示例代码**（技术示范：评分分解，另一套场景）
```java
import java.util.LinkedHashMap;
import java.util.Map;

public class ScoreExplainDemo {
    record Explain(String item, double value, String note) {
    }

    public static void main(String[] args) {
        Map<String, Double> factors = new LinkedHashMap<>();
        factors.put("流行度加成", 1.2);
        factors.put("新鲜度衰减", 0.85);
        factors.put("库存惩罚", 0.95);
        double score = 10;
        for (Map.Entry<String, Double> e : factors.entrySet()) {
            score *= e.getValue();
            System.out.printf("  %-8s ×%.2f -> 累计 %.3f%n", e.getKey(), e.getValue(), score);
        }
        System.out.println("  explain 思想：每一项可单独核对，排序争议不再靠猜");
    }
}
```

### 实操 39-01 基因法分片路由器

**知识点注释**
- 【题目要求】实现基因法路由：从 user_id 提取低 10 位基因生成 order_id（时间戳|基因|序列 位段），验证“按 user_id 查列表”与“按 order_id 查详情”路由到同一分片；再用 1000 条模拟订单统计 8 分片的分布均匀度（最大/最小分片行数比）。
- 【考核点】位段设计（41+10+12 位）、基因提取与反解、哈希均匀度评估、路由公式 shard=hash%N。
- 【易错点】位段溢出（超 64 位）；用 userId 直接取模与基因路由混用（两维度路由不一致）；均匀度只看平均值不看极差。
- 【提示】先画位段图再写代码；均匀度用“最大分片/平均分片”比值评估（<1.1 为健康）。

**示例代码**（技术示范：位段编码，另一套场景）
```java
public class BitLayoutDemo {
    // 32 位：8 位类型 | 12 位序号 | 12 位哈希
    static long encode(int type, int seq, int hash) {
        return ((long) (type & 0xFF) << 24) | ((seq & 0xFFF) << 12) | (hash & 0xFFF);
    }

    static int type(long v) {
        return (int) ((v >>> 24) & 0xFF);
    }

    public static void main(String[] args) {
        long v = encode(7, 3000, 0xAB1);
        System.out.printf("  编码=%d 反解类型=%d（应为 7）%n", v, type(v));
    }
}
```

**示例代码**（技术示范：单调时钟，另一套场景）

```java
public class MonotonicClockDemo {
    static long last = 1000;

    static long next(long wallNow) {
        long now = Math.max(wallNow, last);   // 回拨吸收：永不后退
        last = now + 1;
        return now;
    }

    public static void main(String[] args) {
        System.out.println("  正常推进：" + next(1005) + " " + next(1006));
        System.out.println("  时钟回拨到 1003：" + next(1003) + "（仍单调递增）");
    }
}
```

**示例代码**（技术示范：校验重试环，另一套场景）

```java
import java.util.ArrayList;
import java.util.List;

public class ValidateRetryDemo {
    record Attempt(int no, String output, List<String> errors) {
    }

    static List<String> validate(String output) {
        List<String> errors = new ArrayList<>();
        if (!output.startsWith("{")) {
            errors.add("输出必须是 JSON");
        }
        if (!output.contains("\"city\"")) {
            errors.add("缺少 city 字段");
        }
        return errors;
    }

    public static void main(String[] args) {
        String[] outputs = {"not-json", "{\"name\":\"x\"}", "{\"name\":\"x\",\"city\":\"杭州\"}"};

        for (String o : outputs) {
            round++;
            List<String> errs = validate(o);
            System.out.printf("  第%d轮：%s -> %s%n", round, o, errs.isEmpty() ? "通过" : errs);
            if (errs.isEmpty()) {
                break;
            }
        }
    }
}
```

### 实操 40-02 语义缓存层

**知识点注释**
- 【题目要求】实现语义缓存：输入规范化（去标点/小写/去空格）做精确缓存键 + “向量相似度”简化为关键词重合率（≥0.9 视为相同问题）；缓存命中返回缓存值并计数，未命中调“模拟模型”并写缓存；统计 20 条请求（含 8 条语义重复）的命中率与节省的 token 数。
- 【考核点】缓存键设计、相似阈值与误答风险的平衡（40-10）、命中统计与成本节省量化。
- 【易错点】阈值过低（不同问题被误命中，返回错误答案）；缓存无 TTL（知识更新后旧答案残留）；命中率只算次数不算 token 节省。
- 【提示】重合率 = 交集词数 / 并集词数（Jaccard 简化版）；阈值定 0.9 并在测试中验证边界样本。

**示例代码**（技术示范：规范化键，另一套场景）
```java
import java.util.HashSet;
import java.util.Set;

public class NormalizeDemo {
    static String normalize(String s) {
        return s.replace("？", "").replace("?", "").replace(" ", "").toLowerCase();
    }

    static double jaccard(String a, String b) {
        Set<Character> sa = new HashSet<>(), sb = new HashSet<>();
        for (char c : a.toCharArray()) {
            sa.add(c);
        }
        for (char c : b.toCharArray()) {
            sb.add(c);
        }
        long inter = sa.stream().filter(sb::contains).count();
        long union = sa.size() + sb.size() - inter;
        return union == 0 ? 0 : (double) inter / union;
    }

    public static void main(String[] args) {
        System.out.printf("  「退货运费谁出」 vs 「退货运费谁出？」 规范化相等：%b%n",
                normalize("退货运费谁出").equals(normalize("退货运费谁出？")));
        System.out.printf("  与「退货运费谁承担」 字符重合率=%.2f%n",
                jaccard(normalize("退货运费谁出"), normalize("退货运费谁承担")));
    }
}
```

1. 实现完整语义缓存：规范化 + Jaccard 相似 + TTL，用 20 条请求统计命中率与节省 token 数。
2. 构造 3 个“阈值过低导致误命中”的反例（如“退款政策”vs“退款进度”），验证 0.9 阈值的必要性。

```java
    record Stage(String name, int costSec, boolean parallel) {
    }

    public static void main(String[] args) {
        List<Stage> stages = List.of(
                new Stage("build", 60, false),
                new Stage("test-a", 120, true),
                new Stage("test-b", 180, true),
                new Stage("deploy", 45, false));
        int path = 0;
        int i = 0;
        while (i < stages.size()) {
            Stage s = stages.get(i);
            if (s.parallel()) {
                int groupMax = 0;
                while (i < stages.size() && stages.get(i).parallel()) {
                    groupMax = Math.max(groupMax, stages.get(i).costSec());
                    i++;
                }
                path += groupMax;
            } else {
                path += s.costSec();
                i++;
            }
        }
        System.out.println("  关键路径 = " + path + "s");
    }
}
```

### 实操 41-02 金丝雀自动判据器

**知识点注释**
- 【题目要求】实现金丝雀自动判据：输入逐分钟的金丝雀错误率序列与旧版本基线（同期值），按相对基线阈值决策——偏差 ≤2% 继续、>2% 暂停一轮观察、>5% 告警停止放量、>10% 自动回退；输出每分钟的决策日志与最终放量进度。
- 【考核点】相对基线判据、分级阈值（继续/暂停/告警/回退）、自动回退与放量进度状态机。
- 【易错点】用绝对错误率阈值（高峰期误判）；回退后没有清零放量进度（下次从 5% 重来）；暂停轮次无上限（无限暂停）。
- 【提示】状态机：WAITING->PROGRESSING->PAUSED->ROLLBACK；连续暂停 3 次自动回退。

**示例代码**（技术示范：分级阈值，另一套场景）
```java
public class ThresholdJudgeDemo {
    static String judge(double baseline, double current) {
        double delta = current - baseline;
        if (delta > 0.10) {
            return "ROLLBACK";
        }
        if (delta > 0.05) {
            return "ALERT-STOP";
        }
        if (delta > 0.02) {
            return "PAUSE";
        }
        return "PROCEED";
    }

    public static void main(String[] args) {
        double base = 0.10;
        for (double cur : new double[]{0.11, 0.13, 0.16, 0.22}) {
            System.out.printf("  基线%.2f 当前%.2f -> %s%n", base, cur, judge(base, cur));
        }
    }
}
```
