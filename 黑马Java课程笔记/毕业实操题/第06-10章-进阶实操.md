### 实操 6-01 数组引用共享实验报告

**知识点注释**
- 【题目要求】编写程序完成三组实验并写出结论：① `arr1 = arr2` 后修改 `arr2[0]`，观察 `arr1`；② 用 `new` + 循环逐元素复制后修改副本，观察原数组；③ 把数组传入方法，在方法内修改元素，观察调用者数组。输出每组实验结果，并画出 main 栈帧与堆中数组对象的内存示意图。
- 【考核点】栈与堆、引用类型、引用赋值只复制地址、`new` 创建独立对象、方法传参是“地址值的副本”。
- 【易错点】“传引用”不等于“引用本身被传递”，形参是实参地址的副本；副本数组必须 `new`。
- 【提示】可用 `System.identityHashCode(arr)` 辅助判断两个引用是否指向同一对象（仅用于观察，不能当业务逻辑）。

**示例代码**（技术示范：基本类型的值传递）
```java
// 技术示范（非本题答案）：基本类型参数是值传递
public class PassByValueDemo {
    public static void main(String[] args) {
        int x = 10;
        change(x);
        System.out.println("main 中的 x = " + x);
    }

    public static void change(int num) {
        num = 99;
        System.out.println("方法中的 num = " + num);
    }
}
```

**课后练习题**
1. 预测以下场景的输出并说明原因：`int[] a = {1,2,3}; int[] b = a; b[0] = 100;` 之后 `a[0]` 是多少？
2. 用 `java.util.Arrays.copyOf` 改写实验②，比较它与 `arr1 = arr2` 的本质区别。
3. 画出实验③方法调用前、调用中、调用后的栈与堆变化图，并标注形参和实参的引用关系。

### 实操 6-02 方法内数组操作的三种结果分析

**知识点注释**
- 【题目要求】编写三个方法：`modifyElement(int[] arr)` 修改第一个元素；`reassign(int[] arr)` 在方法内让形参指向新数组并修改；`createAndReturn(int[] arr)` 返回一个新数组。主方法依次调用并打印原数组，分析三种操作对原数组的影响，写出结论。
- 【考核点】引用传递的实际效果、形参重新赋值不影响实参、返回值的作用、方法副作用。
- 【易错点】在方法内 `arr = new int[]{...}` 后，后续操作只影响新数组，调用者完全看不到。
- 【提示】每个实验后立即打印原数组，避免多次调用互相干扰；可先复制一份对照组。

**示例代码**（技术示范：观察对象身份）
```java
// 技术示范（非本题答案）：用 == 与标识值观察引用
public class IdentityDemo {
    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        int[] b = a;
        int[] c = new int[]{1, 2, 3};
        System.out.println("a 与 b 是否同一对象：" + (a == b));
        System.out.println("a 与 c 是否同一对象：" + (a == c));
        System.out.println("a 的标识：" + System.identityHashCode(a));
    }
}
```

**课后练习题**
1. 写一个方法 `void fillZero(int[] arr)` 把数组全部置 0，验证调用者数组是否改变。
2. 写一个方法 `int[] doubled(int[] arr)` 返回每项翻倍的新数组，验证原数组不变。
3. 结合两题结论，总结“什么时候方法能修改调用者的数组，什么时候不能”，写成 5 行以内的说明。

### 实操 7-01 拼手气红包分配器

**知识点注释**
- 【题目要求】输入总金额（元，最多两位小数）与人数，按“二倍均值法”生成每人金额：当前剩余金额为 m、剩余人数为 n 时，本次随机区间为 `[0.01, m / n × 2]`（分为单位取整）。要求每人至少 0.01 元，总额精确等于总金额（最后一人拿剩余），输出每人金额与“手气王”，并校验总额。
- 【考核点】随机区间、整数“分”避免浮点误差、边界处理、循环与累加、最大值追踪。
- 【易错点】用 double 累加会导致总额差几分钱，必须转成 int 分计算；最后一人不能参与随机，直接拿剩余。
- 【提示】金额转分：`(int) Math.round(amount * 100)`；输出时再除以 100.0 并 `printf("%.2f")`。

**示例代码**（技术示范：随机区间公式）
```java
import java.util.Random;

// 技术示范（非本题答案）：生成 [5, 15] 的随机整数
public class RandomRangeDemo {
    public static void main(String[] args) {
        Random r = new Random();
        int n = r.nextInt(11) + 5;
        System.out.println(n);
    }
}
```

**课后练习题**
1. 输出现金分配明细后，标记“手气王”（金额最高者，并列则都标记）。
2. 增加固定红包模式：每人金额相同，除不尽的分给最后一人，输出两种模式的对比。
3. 模拟 1000 次分配（人数固定为 10），统计平均每人金额、最大单笔与最小单笔，并输出“最大/最小”比值。

### 实操 7-02 接雨水（双指针）

**知识点注释**
- 【题目要求】给定非负整数数组 `height` 表示柱高（宽度均为 1），计算下雨后能接多少雨水。要求用双指针 O(n) 实现，并输出每个位置的水量数组与总水量。
- 【考核点】双指针、左右最大值、贪心思想、下标边界、复杂度分析。
- 【易错点】某个位置的水量由“左右两侧最高柱子的较小值”决定；双指针移动的是较矮一侧。
- 【提示】维护 `leftMax` 与 `rightMax`；每次移动前先更新当前侧最大值，再累加水量。

**示例代码**（技术示范：双指针移动模板）
```java
// 技术示范（非本题答案）：双指针相向移动
public class TwoPointerDemo {
    public static void main(String[] args) {
        int[] arr = {1, 3, 2, 5, 4};
        int left = 0;
        int right = arr.length - 1;
        while (left < right) {
            if (arr[left] < arr[right]) {
                left++;
            } else {
                right--;
            }
        }
        System.out.println("相遇位置：" + left);
    }
}
```

**课后练习题**
1. 用“前缀最大值 + 后缀最大值”数组实现接雨水，并与双指针版本比较时间/空间复杂度。
2. 求“盛最多水的容器”（LeetCode 11）：两条竖线与 x 轴构成的最大面积。
3. 若每根柱子宽度为 2，接水量如何变化？给出通用公式并验证一组数据。

### 实操 7-03 大乐透号码生成器

**知识点注释**
- 【题目要求】前区从 1~35 选 5 个不重复号码并升序输出；后区从 1~12 选 2 个不重复号码并升序输出。支持生成 n 注，要求任意两注号码不完全相同，输出格式如 `01 07 12 23 35 + 03 11`。
- 【考核点】Random、标记数组去重、排序、多注去重、格式化补零。
- 【易错点】`nextInt(35) + 1` 才是 1~35；补零要用 `%02d`；多注去重需比较两组号码而不是单个数。
- 【提示】可用 `boolean[] used` 标记已选号码；排序可用 `Arrays.sort`；两注比较可拼接成字符串后 `equals`。

**示例代码**（技术示范：标记数组去重）
```java
import java.util.Random;

// 技术示范（非本题答案）：标记数组生成不重复号码
public class LotteryDemo {
    public static void main(String[] args) {
        boolean[] used = new boolean[36];
        Random r = new Random();
        int count = 0;
        while (count < 5) {
            int num = r.nextInt(35) + 1;
            if (!used[num]) {
                used[num] = true;
                System.out.print(num + " ");
                count++;
            }
        }
    }
}
```

**课后练习题**
1. 输出 5 注号码，要求任意两注前区+后区不完全相同。
2. 生成 100 注后，统计前区 1~35 每个号码出现的次数，输出出现最多和最少的号码。
3. 增加“机选 + 自选”模式：自选时校验号码范围、个数与重复，非法则提示重新输入。

### 实操 8-01 学生档案类

**知识点注释**
- 【题目要求】设计 `Student` 类：私有属性 `id`、`name`、`age`、`score`；提供空参构造、全参构造、getter/setter。要求 age 必须在 6~30，score 必须在 0~100，非法值给出提示且不修改原值；提供 `String getLevel()` 返回优秀/良好/及格/不及格。主方法创建 3 个学生并输出全部信息与等级。
- 【考核点】封装、private、构造方法、this、数据校验、JavaBean 规范、成员方法。
- 【易错点】setter 校验失败应 `return`，不能先赋值再判断；全参构造也应走校验逻辑或至少保证数据合法。
- 【提示】`getLevel()` 内部用 if-else 链返回字符串，不要打印。

**示例代码**（技术示范：封装与构造，另一个类）
```java
// 技术示范（非本题答案）：封装、构造方法与 setter 校验
public class Book {
    private String name;
    private double price;

    public Book() {
    }

    public Book(String name, double price) {
        this.name = name;
        setPrice(price);
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public double getPrice() {
        return price;
    }

    public void setPrice(double price) {
        if (price < 0) {
            System.out.println("价格不能为负数");
            return;
        }
        this.price = price;
    }
}
```

### 实操 8-02 银行账户类

**知识点注释**
- 【题目要求】设计 `Account`：账号、户主、余额（private，余额不能为负）。提供 `deposit(double)`、`withdraw(double)`（余额不足提示并拒绝）、`transfer(Account target, double amount)`（从当前账户转到目标账户，余额不足则失败）。主方法创建两个账户，演示存款、取款、转账，并打印双方余额。
- 【考核点】封装、对象作参数、方法间调用、数据安全、返回值设计。
- 【易错点】转账应先校验再扣款，避免“扣了钱没到账”；余额比较不要用 `==`。
- 【提示】`transfer` 内部可复用 `withdraw` 与 `deposit`，但要注意失败时的一致性。

**示例代码**（技术示范：对象作参数）
```java
// 技术示范（非本题答案）：对象作为方法参数
public class Wallet {
    private double money;

    public Wallet(double money) {
        this.money = money;
    }

    public void add(double amount) {
        money += amount;
    }

    public double getMoney() {
        return money;
    }

    public static void main(String[] args) {
        Wallet a = new Wallet(100);
        Wallet b = new Wallet(50);
        a.add(b.getMoney() / 2);
        System.out.println(a.getMoney());
    }
}
```

**课后练习题**
1. 增加交易流水记录（用 `String[]` 或 `ArrayList` 保存），每次操作后追加，主方法输出最近 5 条。
2. 把 `transfer` 改为返回 `boolean`，失败时输出具体原因（余额不足/金额非法/目标账户为空）。
3. 设计 `AccountTest` 模拟 10 次随机存取款（金额 1~200），输出最终余额、成功次数与失败次数。


### 实操 10-01 静态数组工具类与常量类

**知识点注释**
- 【题目要求】设计 `ArrayUtil` 工具类：私有构造方法，全部方法为 `public static`（sum、max、avg、toString）；设计 `Constants` 类，用 `public static final` 定义 `MAX_SIZE = 100`、`DEFAULT_PAGE_SIZE = 10`。主方法调用工具方法，并在注释中说明“为什么工具类不能实例化”。
- 【考核点】static 成员、工具类设计、private 构造、final 常量、命名规范、类名调用。
- 【易错点】静态方法不能直接访问非静态成员；常量命名全大写；工具类不应被 new。
- 【提示】可给工具类加 `final` 修饰，配合私有构造彻底阻止继承与实例化。

**示例代码**（技术示范：静态工具类）
```java
// 技术示范（非本题答案）：私有构造 + 静态方法
public final class MathUtil {
    private MathUtil() {
    }

    public static int pow2(int n) {
        return n * n;
    }

    public static void main(String[] args) {
        System.out.println(MathUtil.pow2(5));
    }
}
```

**课后练习题**

### 实操 10-02 订单状态枚举与流转

**知识点注释**
- 【题目要求】定义 `OrderStatus` 枚举：`CREATED("已创建")`、`PAID("已支付")`、`SHIPPED("已发货")`、`FINISHED("已完成")`、`CANCELED("已取消")`，包含中文描述属性与 getter。编写 `boolean canTransfer(OrderStatus from, OrderStatus to)` 判断合法流转：创建→支付/取消；支付→发货；发货→完成；终态不可再流转。主方法测试全部合法与非法组合并输出结果。
- 【考核点】enum 定义、枚举属性与构造、枚举比较用 `==`、switch 配合枚举、values/valueOf。
- 【易错点】枚举构造方法默认私有，不能加 public；枚举项必须写在最前面；`==` 比 `equals` 更安全。
- 【提示】可用 `switch (from)` 分支 + `switch (to)` 判断合法目标状态，或直接写 `if` 组合。

**示例代码**（技术示范：带属性的枚举）
```java
// 技术示范（非本题答案）：枚举的属性、构造与遍历
public enum Season {
    SPRING("春天"), SUMMER("夏天");

    private final String desc;

    Season(String desc) {
        this.desc = desc;
    }

    public String getDesc() {
        return desc;
    }

    public static void main(String[] args) {
        for (Season s : Season.values()) {
            System.out.println(s + "：" + s.getDesc());
        }
    }
}
```

**课后练习题**
