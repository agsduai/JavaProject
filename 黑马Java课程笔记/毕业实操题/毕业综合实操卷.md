## 卷一 校园二手交易平台（控制台版）

**知识点注释**
- 【项目背景】为校园学生提供二手物品发布与交易的控制台系统，买家与卖家为同一套用户体系。
- 【功能要求】
  1. 用户注册/登录：用户名唯一、密码 6~16 位且含字母和数字、5 位验证码（忽略大小写）、登录失败 3 次锁定。
  2. 商品发布：名称、价格（BigDecimal）、描述、分类、状态（在售/已售/下架，用枚举）。
  3. 商品浏览：全部列表、关键字搜索（名称/描述）、按价格升序/降序排序。
  4. 购买流程：校验余额、扣款、商品置为已售、生成订单（订单号、买家、卖家、金额、时间戳）。
  5. 订单查询：我买到的、我卖出的，支持按状态筛选。
  6. 统计报表：成交总额、成交笔数、最贵成交商品、发布商品最多的用户。
- 【技术要求】至少 6 个类；实体类私有属性 + getter/setter；业务逻辑放 Service 类；使用集合、枚举、String API、BigDecimal；菜单循环；非法输入不得导致程序崩溃。
- 【考核点】第2~14章综合：语法、流程控制、数组/集合、方法、面向对象、继承/接口（可选）、字符串、常用类。
- 【评分锚点】功能完整可演示（40）、分层与封装（20）、边界与健壮性（20）、代码规范与注释（10）、README 与演示（10）。

## 卷二 健身房会员与课程预约系统

**知识点注释**
- 【项目背景】健身房需要管理会员、课程与预约，控制台版本完成核心业务闭环。
- 【功能要求】
  1. 会员管理：注册（姓名、手机号、会员等级枚举：普通/银卡/金卡/钻石）、充值、查看余额与等级。
  2. 课程管理：课程名称、教练、容量、已预约人数、开课时间（时间戳）。
  3. 预约/取消：容量未满方可预约；同一会员同一课程不可重复预约；开课前 2 小时内不可取消（用时间戳判断）。
  4. 签到：预约后可签到，记录签到状态；未预约不可签到。
  5. 统计：各课程预约率、会员出勤率、最受欢迎课程 Top3、按等级统计会员人数。
  6. 等级权益：金卡及以上可提前 24 小时预约（普通/银卡只能预约 24 小时内的课程）。
- 【技术要求】至少 7 个类；使用枚举、集合、时间戳、String 处理、方法封装；业务校验失败必须给出明确提示；统计结果格式化输出。
- 【考核点】面向对象建模、集合操作、枚举、条件分支、时间比较、数据一致性。
- 【评分锚点】预约/取消/签到闭环（40）、等级权益与时间规则（20）、统计报表（20）、健壮性与提示（10）、文档与演示（10）。

## 卷三 回合制卡牌对战游戏（毕业设计）

**知识点注释**
- 【项目背景】实现一个可玩的控制台回合制卡牌对战游戏，综合运用继承、接口、多态、集合、枚举、随机数与字符串处理。
- 【功能要求】
  1. 角色体系：抽象类 `Role`（名称、血量、攻击、防御、速度、存活判断）；子类 `Warrior`（高防）、`Mage`（技能伤害）、`Archer`（暴击）。
  2. 技能体系：接口 `Skill`（名称、消耗能量、`void cast(Role caster, Role target)`）；每个角色至少 2 个技能，用实现类或匿名内部类注册。
  3. 战斗流程：回合制，按速度决定出手顺序；每回合可选择“普通攻击/技能/防御”；能量每回合恢复；血量 ≤ 0 判负。
  4. 状态系统：枚举 `BuffType`（中毒/护盾/加速），持续回合数，回合结束结算。
  5. 战报：逐回合输出双方血量、伤害、技能、状态；战斗结束输出胜者与总回合数。
  6. 战后结算：胜利获得金币与经验，经验满升级（属性成长），支持连续挑战 3 场，血量继承并每场恢复 30%。
- 【技术要求】至少 8 个类/接口；禁止把战斗逻辑写在一个方法里；随机数使用 `Random`；所有输入做合法性校验；代码分层（角色、技能、战斗、入口）。
- 【考核点】继承与多态、接口与匿名内部类、枚举、集合、随机、循环与分支、封装与数据校验、整体设计。
- 【评分锚点】战斗闭环可玩（40）、技能/状态系统（20）、角色体系与多态（15）、战报与结算（15）、代码质量与文档（10）。

**示例代码**（工程骨架，仅战斗循环伪骨架，不是实现）
```java
// 技术示范（非本题答案）：回合制战斗主循环骨架
import java.util.Random;

public class BattleApp {
    public static void main(String[] args) {
        Random r = new Random();
        int round = 1;
        boolean gameOver = false;
        while (!gameOver && round <= 30) {
            System.out.println("----- 第 " + round + " 回合 -----");
            // TODO: 按速度排序、处理玩家选择、释放技能、结算 Buff、判断胜负
            if (r.nextInt(100) < 0) { // 占位，实际由血量判断
                gameOver = true;
            }
            round++;
        }
        System.out.println("=== 战斗结束 ===");
    }
}
```

**课后练习题**
1. 增加“装备系统”：武器/护甲提升攻击/防御，支持穿戴与卸下，战斗中实时生效。
2. 增加“技能冷却”：每个技能有冷却回合数，冷却中不可释放，战报中显示剩余冷却。
3. 增加“排行榜”：把多场战斗的胜者、剩余血量、回合数存入集合，按胜场与血量排序输出。
4. 增加“存档/读档”：定义存档接口并给出内存实现（为后续 IO 课程预留文件实现）。
