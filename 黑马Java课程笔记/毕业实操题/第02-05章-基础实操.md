### 实操 2-01 智能点餐结算单

**知识点注释**
- 【题目要求】从键盘录入：菜品单价（double）、数量（int）、会员等级（char，'A'/'B'/'C'）。折扣规则：A 级 8 折、B 级 9 折、C 级无折扣。输出小计、优惠金额、实付金额（均保留两位小数）。
- 【考核点】Scanner 录入、算术运算、if 多分支或三元运算符、`printf` 格式化、double 与 int 混合运算。
- 【易错点】`nextInt()` 后直接 `nextLine()` 会读到残留换行，本题用 `next().charAt(0)` 规避；金额不要用 `==` 比较。
- 【提示】格式化输出用 `System.out.printf("%.2f%n", value);`。

**示例代码**（技术示范：录入与折扣骨架，数据规则与本题不同）

```java
import java.util.Scanner;

// 技术示范（非本题答案）：录入单价与数量，按固定 9 折结算

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("请输入单价：");

        System.out.printf("小计：%.2f 元%n", total);
        System.out.printf("实付：%.2f 元%n", pay);
        sc.close();
    }
}
```

### 实操 2-02 运动配速与时间换算器

**知识点注释**

- 【考核点】整数除法与取模、数值拆分、类型转换、三元运算符、关系运算。
- 【易错点】`1000 / 4210` 是整数除法结果为 0，应先乘后除或转成 double；秒数拆分顺序必须是“先取小时、再取分钟、最后取秒”。
- 【提示】配速秒数 = 总秒数 × 1000 ÷ 距离，结果用 double；分钟 = `(int) paceSeconds / 60`，秒 = `(int) paceSeconds % 60`。

**示例代码**（技术示范：总秒数拆分为时/分/秒）
```java
// 技术示范（非本题答案）：把总秒数转换为时分秒
public class TimeConvertDemo {
    public static void main(String[] args) {
        int totalSeconds = 3725;
        int hour = totalSeconds / 3600;
        int minute = totalSeconds % 3600 / 60;
        int second = totalSeconds % 60;
        System.out.println(hour + " 小时 " + minute + " 分 " + second + " 秒");
    }
}
```

**课后练习题**

### 实操 3-01 三回合战斗模拟器

**知识点注释**
- 【题目要求】玩家血量 100、攻击 15~25 随机；敌人血量 80、攻击 10~20 随机。每回合玩家先手，输出双方剩余血量；任一方血量 ≤ 0 立即结束并输出胜负；最多 3 回合，3 回合后按剩余血量百分比高者获胜。
- 【考核点】`Random` 的区间公式、while 循环、if-else、break、循环计数。
- 【易错点】`nextInt(n)` 生成的是 `[0, n)`；血量不能显示为负数（用 `Math.max(hp, 0)`）。
- 【提示】区间 [a, b] 的随机数写法：`r.nextInt(b - a + 1) + a`。

**示例代码**（技术示范：随机伤害与循环骨架）
```java
import java.util.Random;

// 技术示范（非本题答案）：随机伤害 + 循环扣血骨架
public class BattleSkeleton {
    public static void main(String[] args) {
        Random r = new Random();
        int playerHp = 100;
        int round = 1;
        while (playerHp > 0 && round <= 3) {
            int damage = r.nextInt(10) + 5; // 5~14
            System.out.println("第 " + round + " 回合，受到伤害：" + damage);
            playerHp -= damage;
            round++;
        }
        System.out.println("剩余血量：" + Math.max(playerHp, 0));
    }
}
```

**课后练习题**
1. 加入 20% 概率暴击（伤害翻倍），并输出“暴击！”提示。
2. 加入 10% 概率闪避（本次伤害为 0），输出“闪避”提示。
3. 改为由速度属性决定出手顺序（速度高者先手，相同则玩家先手），并输出完整战斗日志。

### 实操 3-02 成绩等级统计器

**知识点注释**
- 【题目要求】循环录入成绩（输入 -1 结束），自动跳过大于 100 或小于 0 的无效成绩；统计优秀（90+）、良好（80~89）、及格（60~79）、不及格人数，并计算平均分；有效成绩不足 3 个时提示“样本不足”。
- 【考核点】`while (true)`、break、continue、计数器与累加器、多分支判断、整数除法陷阱。
- 【易错点】平均分必须用 `sum * 1.0 / count`，否则整数除法丢小数；无效成绩不能计入人数。
- 【提示】先判断结束条件，再判断合法性，最后才统计。

**示例代码**（技术示范：break 与 continue 的用法）
```java
import java.util.Scanner;

// 技术示范（非本题答案）：-1 结束，非法成绩跳过
public class ScoreLoopDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int validCount = 0;
        int sum = 0;
        while (true) {
            System.out.print("请输入成绩（-1 结束）：");
            int score = sc.nextInt();
            if (score == -1) {
                break;
            }
            if (score < 0 || score > 100) {
                System.out.println("无效成绩，已跳过");
                continue;
            }
            validCount++;
            sum += score;
        }
        System.out.println("有效人数：" + validCount + "，总分：" + sum);
        sc.close();
    }
}
```

**课后练习题**
1. 输出各等级人数及占比（百分比保留一位小数）。
2. 统计最高分与最低分，并输出它们分别是第几个录入的有效成绩。
3. 把等级判定封装为方法 `String levelOf(int score)`，主流程调用该方法输出结果。

### 实操 4-02 会员卡号洗牌与去重

**知识点注释**
- 【题目要求】给定会员卡号数组 `{1001, 1003, 1003, 1007, 1009, 1007, 1011}`：① 输出去重后的数组（保持首次出现顺序）；② 随机打乱顺序后输出；③ 检查并输出所有重复出现的卡号（每个只输出一次）。
- 【考核点】双指针去重、随机交换（Fisher-Yates）、嵌套循环查重、数组长度与有效长度区分。
- 【易错点】去重后数组尾部残留旧值，遍历时只能用“有效长度”；随机交换应倒序遍历。
- 【提示】可先用 `int[] result = new int[arr.length]` 存放去重结果并记录有效个数。

**示例代码**（技术示范：随机打乱数组）
```java
import java.util.Random;

// 技术示范（非本题答案）：Fisher-Yates 洗牌
public class ShuffleDemo {
    public static void main(String[] args) {
        int[] cards = {1, 2, 3, 4, 5};
        Random r = new Random();
        for (int i = cards.length - 1; i > 0; i--) {
            int j = r.nextInt(i + 1);
            int temp = cards[i];
            cards[i] = cards[j];
            cards[j] = temp;
        }
        for (int card : cards) {
            System.out.print(card + " ");
        }
    }
}
```

**课后练习题**
1. 用双指针法完成去重，输出去重后的有效长度及内容。
2. 输出去重后数组中出现次数最多的卡号（假设唯一）。
3. 实现“卡号合法性检查”：卡号必须是 4 位且首位不为 0，将合法卡号与非法卡号分别输出。

- 【考核点】方法定义与调用、形参与实参、返回值、方法重载、数组作参数、边界校验。
- 【易错点】重载要求“同名不同参”，与返回值无关；区间求和要求 `from <= to` 且下标合法。
- 【提示】工具类方法建议全部 `public static`，便于直接 `类名.方法名()` 调用。

**示例代码**（技术示范：方法定义与重载）
```java
// 技术示范（非本题答案）：同名方法的重载
public class MethodDemo {
    public static void main(String[] args) {
        double[] data = {100, 200, 300};
        System.out.println(sum(data));
        System.out.println(sum(data, 0, 2));
    }

    public static double sum(double[] arr) {
        double s = 0;
        for (double v : arr) {
            s += v;
        }
        return s;
    }

    public static double sum(double[] arr, int from, int to) {
        double s = 0;
        for (int i = from; i <= to; i++) {
            s += arr[i];
        }
        return s;
    }
}
```

### 实操 5-02 数组工具方法包

**知识点注释**
- 【题目要求】实现 `ArrayTool` 工具类：`int[] copyOf(int[] arr)` 返回副本；`int[] reverse(int[] arr)` 返回逆序新数组；`int indexOf(int[] arr, int value)` 找不到返回 -1；`String join(int[] arr, String sep)` 用分隔符拼接。要求除特别说明外不得修改原数组，主方法逐一演示并打印结果。
- 【考核点】数组作为参数与返回值、副本创建、方法职责单一、边界处理、方法设计诀窍（要不要返回值/要不要参数）。
- 【易错点】`int[] b = a` 只是复制地址，不是副本；`join` 拼接不要产生末尾多余分隔符。
- 【提示】返回值是新数组时，先在方法内 `new int[arr.length]`，再逐个赋值。

**示例代码**（技术示范：创建真正的数组副本）
```java
import java.util.Arrays;

// 技术示范（非本题答案）：逐元素复制得到独立副本
public class ArrayCopyDemo {
    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        int[] b = new int[a.length];
        for (int i = 0; i < a.length; i++) {
            b[i] = a[i];
        }
        b[0] = 99;
        System.out.println("a = " + Arrays.toString(a));
        System.out.println("b = " + Arrays.toString(b));
    }
}
```
