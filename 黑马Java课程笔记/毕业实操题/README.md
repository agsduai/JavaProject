> 定位：完成第2~52章课程学习后，用“场景化实操题”检验能否独立写出可运行、可讲清设计的程序。

## 做题规范

1. **独立建目录**：每题单独一个包（如 `practice/p201`），不要把所有题写在同一个文件里。
2. **先注释后代码**：先用中文注释写出需求拆解与步骤，再实现；方法职责保持单一。
3. **必须自测**：至少覆盖“正常数据 + 边界数据 + 非法输入”三类用例，记录在 README 中。
4. **禁止抄袭示例**：示例代码只演示技术点，且通常换了场景与数据；直接复制视为未完成。
5. **算法题写复杂度**：第7章题目需在注释中写明时间/空间复杂度及推导。
6. **原理题画图**：第6、9章题目需提交手绘或文本版内存示意图。

## 单题评分标准

| 维度 | 分值 | 说明 |
