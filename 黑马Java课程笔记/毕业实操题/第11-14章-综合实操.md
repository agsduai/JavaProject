## 第11章 面向对象高级

### 实操 11-01 员工薪资体系（继承 + 多态 + 抽象类）

**知识点注释**
- 【题目要求】定义抽象类 `Employee`：属性 name、baseSalary，抽象方法 `double calcSalary()`，普通方法 `void printInfo()` 输出姓名与薪资。子类：`Manager`（奖金 bonus）、`Salesman`（销售额 sales，提成 5%）、`Intern`（日薪 dayRate × 出勤天数）。用 `Employee[]` 统一遍历输出薪资；对 `Salesman` 额外输出销售额（`instanceof` + 强转）。
- 【考核点】继承、抽象类与抽象方法、方法重写、多态、向上转型、instanceof、父类引用调用子类重写方法。
- 【易错点】抽象类不能 new；子类必须重写全部抽象方法；强转前必须用 instanceof 判断。
- 【提示】`printInfo` 放在父类中调用 `calcSalary()`，即可自动呈现多态效果。

**示例代码**（技术示范：抽象类与多态，另一套体系）
```java
// 技术示范（非本题答案）：抽象类 + 多态数组
abstract class Shape {
    abstract double area();
}

class Circle extends Shape {
    private double r;

    Circle(double r) {
        this.r = r;
    }

    @Override
    double area() {
        return Math.PI * r * r;
    }
}

public class PolymorphismDemo {
    public static void main(String[] args) {
        Shape[] shapes = {new Circle(2)};
        for (Shape s : shapes) {
            System.out.printf("%.2f%n", s.area());
        }
    }
}
```

**课后练习题**
1. 增加 `Director` 子类（基础工资 + 股份分红），加入数组并统计公司总薪资。
2. 定义 `Payable` 接口（`double calcSalary()`），让 `Employee` 实现该接口，比较“抽象类 + 接口”的设计差异。
3. 统计各类员工人数与平均薪资（按 `instanceof` 分组），输出格式化的薪资报表。

### 实操 11-02 支付接口体系（接口 + 默认方法 + 多态参数）

**知识点注释**
- 【题目要求】定义接口 `Payment`：`boolean pay(double amount)`、`String channel()`、默认方法 `default void printReceipt(double amount)` 输出小票。实现 `AliPay`（手续费 0.6%）、`WeChatPay`（手续费 0.6%）、`BankCardPay`（手续费 0.1%，最低 0.1 元）。编写 `checkout(Payment p, double amount)` 统一收银并打印渠道、手续费、实付金额。用数组存放三种支付方式逐一结算。
- 【考核点】接口定义与实现、默认方法、接口作为参数类型（多态）、方法重写、金额精度处理。
- 【易错点】接口方法默认 `public abstract`，实现类重写时不能降低可见性；默认方法可被实现类覆盖。
- 【提示】手续费可用 `Math.round(x * 100) / 100.0` 保留两位；`checkout` 只依赖 `Payment` 接口，不依赖具体类。

**示例代码**（技术示范：接口 + 默认方法）
```java
// 技术示范（非本题答案）：接口默认方法
interface Printable {
    String content();

    default void print() {
        System.out.println("打印内容：" + content());
    }
}

class Ticket implements Printable {
    @Override
    public String content() {
        return "电影票";
    }
}

public class InterfaceDemo {
    public static void main(String[] args) {
        new Ticket().print();
    }
}
```

**课后练习题**
1. 增加 `Refundable` 接口（退款方法），只让部分支付方式实现，并在结算后判断该渠道是否支持退款。
2. 给 `Payment` 增加静态工厂方法 `static Payment of(String type)`，根据字符串返回对应实现，未知类型返回 null。
3. 设计 `Discountable` 接口（折扣方法），让部分支付方式实现，与 `Payment` 组合完成“折扣 + 手续费”的结算。

### 实操 11-03 匿名内部类实现事件回调

**知识点注释**
- 【题目要求】定义接口 `ClickListener { void onClick(String msg); }`，编写 `Button` 类（`setOnClickListener(ClickListener l)`、`click()` 触发回调）。要求：① 用匿名内部类注册监听器；② 用 lambda 改写同一逻辑；③ 用成员内部类再实现一种监听。主方法分别演示三种写法。
- 【考核点】成员内部类、匿名内部类、接口回调、lambda 与函数式接口的关系、外部类成员访问。
- 【易错点】匿名内部类访问局部变量必须是 effectively final；lambda 只能用于函数式接口（仅一个抽象方法）。
- 【提示】`Button.click()` 中判空后再调用 `listener.onClick("按钮被点击")`。

**示例代码**（技术示范：匿名内部类）
```java
// 技术示范（非本题答案）：匿名内部类实现接口
public class AnonymousDemo {
    interface Greeting {
        void say(String name);
    }

    public static void main(String[] args) {
        Greeting g = new Greeting() {
            @Override
            public void say(String name) {
                System.out.println("你好，" + name);
            }
        };
        g.say("阿玮");
    }
}
```

**课后练习题**
1. 给 `Button` 增加 `setOnLongClickListener`，用匿名内部类实现长按逻辑（长按 3 秒触发）。
2. 用 lambda 改写全部监听器，比较两种写法的代码量与可读性。
3. 设计 `Timer` 类，循环 3 次、每次 `Thread.sleep(1000)` 后触发回调，用匿名内部类注册并在回调中打印第几次触发。

### 实操 12-01 用户注册校验器

**知识点注释**
- 【题目要求】录入用户名、密码、确认密码、手机号。校验规则：用户名 4~12 位，只能包含字母、数字、下划线；密码 6~16 位，必须同时包含字母和数字；两次密码一致；手机号 11 位、全数字且以 1 开头。所有错误信息收集后一次性输出；全部通过输出“注册成功”。
- 【考核点】String 的 length/charAt/equals、字符范围判断、StringBuilder 拼接错误信息、循环遍历字符串。
- 【易错点】字符串比较必须用 `equals`；`charAt` 越界；错误信息不要发现一条就 return，要全部收集。
- 【提示】可写私有静态方法 `boolean isLetterOrDigitOrUnderscore(char c)` 复用判断逻辑。

**示例代码**（技术示范：遍历字符判断类型）
```java
// 技术示范（非本题答案）：统计字符串中的字母与数字
public class CharCheckDemo {
    public static void main(String[] args) {
        String s = "abc123";
        boolean hasDigit = false;
        boolean hasLetter = false;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c >= '0' && c <= '9') {
                hasDigit = true;
            }
            if ((c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z')) {
                hasLetter = true;
            }
        }
        System.out.println("含数字：" + hasDigit + "，含字母：" + hasLetter);
    }
}
```

**课后练习题**
1. 增加“密码不能包含用户名”的校验规则（忽略大小写）。
2. 把所有错误信息用 StringBuilder 拼接，用换行分隔后一次性输出。
3. 实现手机号打码方法 `String mask(String phone)`，输出如 `138****8888`。

### 实操 12-02 文本敏感词过滤与统计

**知识点注释**
- 【题目要求】给定一段文本和敏感词数组：① 把敏感词替换为等长的 `*`；② 统计每个敏感词出现次数（用 `indexOf` 循环，不区分大小写）；③ 统计文本中英文字母、数字、空格、其他字符的数量；④ 输出处理后的文本。
- 【考核点】indexOf/substring/replace、StringBuilder、字符分类、循环统计、大小写转换。
- 【易错点】`index += word.length()` 防止重叠死循环；替换时注意大小写与长度一致。
- 【提示】统计子串出现次数可统一转小写后再查找；中文字符属于“其他字符”。

**示例代码**（技术示范：indexOf 统计子串）
```java
// 技术示范（非本题答案）：统计子串出现次数
public class CountWordDemo {
    public static void main(String[] args) {
        String text = "java 和 Java 都是 JAVA";
        String word = "Java";
        int count = 0;
        int index = 0;
        while ((index = text.indexOf(word, index)) != -1) {
            count++;
            index += word.length();
        }
        System.out.println(word + " 出现次数：" + count);
    }
}
```

**课后练习题**
1. 忽略大小写统计敏感词出现次数，并输出每个敏感词的位置下标。
2. 把文本按空格拆分，输出每个单词及其长度（跳过空串）。
3. 实现“敏感词高亮”：用【】包裹敏感词，输出高亮后的文本（注意替换后长度变化）。

### 实操 12-03 通讯录管理（ArrayList CRUD）

**知识点注释**
- 【题目要求】设计 `Contact`（name、phone），`ContactManager` 用 `ArrayList<Contact>` 实现：添加、按姓名删除、按姓名查找、修改电话、显示全部、按姓名排序。用菜单循环驱动，所有操作给出成功/失败提示。
- 【考核点】ArrayList 增删改查、泛型、对象集合、遍历、删除时的下标陷阱、排序。
- 【易错点】正序遍历删除会漏删，应倒序遍历或使用迭代器；按姓名查找可能重名，要明确返回第一条还是全部。
- 【提示】排序可用 `Collections.sort(list, (a, b) -> a.getName().compareTo(b.getName()))`。

**示例代码**（技术示范：ArrayList 基础操作）
```java
import java.util.ArrayList;

// 技术示范（非本题答案）：ArrayList 的增删遍历
public class ListDemo {
    public static void main(String[] args) {
        ArrayList<String> names = new ArrayList<>();
        names.add("张三");
        names.add("李四");
        names.add("王五");
        names.remove("李四");
        for (String name : names) {
            System.out.println(name);
        }
        System.out.println("大小：" + names.size());
    }
}
```

**课后练习题**

2. 实现“删除所有姓张的联系人”，用倒序遍历避免漏删，并说明原因。
3. 统计通讯录中每个姓氏（姓名字符串第一个字）的人数，按人数从高到低输出。

### 实操 13-01 控制台图书管理系统（综合项目）

**知识点注释**
- 【题目要求】实现图书管理系统：① 用户注册/登录（用户名唯一、密码 6 位以上、5 位验证码）；② 图书管理（添加、查询、修改库存、删除）；③ 借阅/归还（库存校验、借阅记录）；④ 菜单循环；⑤ 统计（在借数量、库存不足提醒）。要求至少 4 个类（`Book`、`User`、`BookService`、`Main`），使用面向对象 + 集合 + 字符串处理，方法职责单一。
- 【考核点】类与对象、封装、集合、字符串、循环与分支、简单分层（实体类/业务类/入口类）、数据一致性。
- 【易错点】借阅要先判断库存再扣减；删除图书前要检查是否在借；验证码比较忽略大小写。
- 【提示】`BookService` 只负责业务，`Main` 只负责菜单与输入输出，避免所有代码堆在 main 中。

**示例代码**（技术示范：分层骨架，不含业务实现）
```java
import java.util.ArrayList;

// 技术示范（非本题答案）：实体类 + 业务类 + 入口类的分层骨架
class Book {
    private String id;
    private String name;
    private int stock;

    public Book(String id, String name, int stock) {
        this.id = id;
        this.name = name;
        this.stock = stock;
    }

    public String getName() {
        return name;
    }

    public int getStock() {
        return stock;
    }
}

class BookService {
    private ArrayList<Book> books = new ArrayList<>();

    public void add(Book book) {
        books.add(book);
    }

    public void showAll() {
        for (Book b : books) {
            System.out.println(b.getName() + " 库存：" + b.getStock());
        }
    }
}

public class LibrarySkeleton {
    public static void main(String[] args) {
        BookService service = new BookService();
        service.add(new Book("B001", "Java 入门", 5));
        service.showAll();
    }
}
```

**课后练习题**
1. 增加借阅记录类 `BorrowRecord`（用户、图书、借出时间戳），输出指定用户的借阅历史。
2. 增加权限控制：管理员可增删图书，普通用户只能查询与借阅（用 `isAdmin` 字段判断）。
3. 增加库存不足自动提醒：遍历全部图书，库存 ≤ 2 时输出提醒列表，并统计种类数。

### 实操 14-01 金融分期计算器

**知识点注释**
- 【题目要求】输入贷款本金（元）、年利率（%）、期数：① 用 BigDecimal 计算等额本息每月还款额（月供 = 本金 × 月利率 × (1 + 月利率)^n ÷ ((1 + 月利率)^n − 1)），保留 2 位四舍五入；② 输出总利息；③ 计算若提前 3 期还清可节省的利息；④ 用 `System.currentTimeMillis()` 统计计算耗时并输出。
- 【考核点】BigDecimal 精度、divide 必须指定精度与 RoundingMode、Math.pow、包装类、System 计时、金额格式化。
- 【易错点】BigDecimal 除法不指定精度会抛 ArithmeticException；不要用 `new BigDecimal(0.1)`（用字符串构造）。
- 【提示】`Math.pow` 返回 double，转 BigDecimal 用 `BigDecimal.valueOf(...)`；月利率 = 年利率 ÷ 12 ÷ 100。

**示例代码**（技术示范：BigDecimal 精度与除法）
```java
import java.math.BigDecimal;
import java.math.RoundingMode;

// 技术示范（非本题答案）：BigDecimal 加减与带精度除法
public class BigDecimalDemo {
    public static void main(String[] args) {
        BigDecimal a = new BigDecimal("0.1");
        BigDecimal b = new BigDecimal("0.2");
        System.out.println(a.add(b));
        System.out.println(new BigDecimal("10").divide(new BigDecimal("3"), 4, RoundingMode.HALF_UP));
    }
}
```

**课后练习题**
1. 用 BigInteger 计算 100! 的结果并输出其位数（不转 double）。
2. 实现“等额本金”月供计算，与等额本息对比总利息差额。
3. 处理年利率为 0 的边界情况（直接本金 ÷ 期数），并校验期数必须为正整数。
