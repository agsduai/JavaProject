# 第17章 多线程

本章进入并发世界：先弄清进程与线程、并发与并行的区别，再掌握三种创建线程的方式；随后学习线程的常用方法、线程安全问题的根源与三种加锁方案，最后了解死锁、线程池与并发工具类。多线程是"程序跑得快"和"能同时处理多个请求"的基础。

### 17-01 进程、线程、并发与并行

**知识点**
- 进程是操作系统分配资源的最小单位，一个进程可以包含多个线程；线程是 CPU 调度的最小单位。
- 并发：多个任务在**同一时间段**内交替执行（单核也能并发，靠快速切换）。
- 并行：多个任务在**同一时刻**同时执行（需要多核 CPU）。
- Java 程序天生多线程：`main` 是主线程，还有 GC 线程、异常处理线程等在后台运行。
- 多线程的好处：充分利用多核 CPU、提高响应速度；代价：线程安全问题、上下文切换开销。
- 易错：线程越多越快是错误认知，线程数超过核心数后频繁切换反而降低性能。

**示例代码**
```java
public class ThreadConceptDemo {
    public static void main(String[] args) {
        // 主线程：每个 Java 程序启动时自动创建
        Thread main = Thread.currentThread();
        System.out.println("主线程名称：" + main.getName());      // main
        System.out.println("主线程优先级：" + main.getPriority()); // 5
        System.out.println("可用处理器核心数：" + Runtime.getRuntime().availableProcessors());

        // 查看 JVM 中正在运行的线程
        System.out.println("JVM 启动时包含的线程：");
        Thread.getAllStackTraces().keySet().stream()
                .map(Thread::getName)
                .sorted()
                .forEach(name -> System.out.println("  - " + name));

        // 并发演示：单线程顺序执行两个任务
        long start = System.currentTimeMillis();
        task("任务A");
        task("任务B");
        System.out.println("顺序执行耗时：" + (System.currentTimeMillis() - start) + " ms");
    }

    public static void task(String name) {
        long sum = 0;
        for (int i = 0; i < 10_000_000; i++) {
            sum += i;
        }
        System.out.println(name + " 计算完成，结果：" + sum);
    }
}
```

### 17-02 继承Thread类创建线程

**知识点**
- 创建线程方式一：定义类继承 `Thread`，重写 `run()` 方法，创建对象后调用 `start()` 启动。
- `start()` 的作用：启动新线程，由 JVM 调用 `run()`；直接调用 `run()` 只是普通方法调用，仍在当前线程执行。
- 线程执行顺序由 CPU 调度决定，每次运行结果可能不同，这是多线程的"随机性"。
- `Thread.sleep(long millis)` 让当前线程休眠指定毫秒，需要处理 `InterruptedException`。
- 缺点：Java 单继承，继承了 `Thread` 就不能再继承其他类，扩展性差。
- 易错：同一个 `Thread` 对象不能 `start()` 两次，第二次会抛 `IllegalThreadStateException`。

**示例代码**
```java
class MyThread extends Thread {
    public MyThread(String name) {
        super(name); // 设置线程名
    }

    @Override
    public void run() {
        for (int i = 1; i <= 3; i++) {
            System.out.println(getName() + " 执行第 " + i + " 次");
            try {
                Thread.sleep(100); // 休眠 100ms，让出 CPU
            } catch (InterruptedException e) {
                System.out.println(getName() + " 被中断");
                return;
            }
        }
    }
}

public class ThreadExtendDemo {
    public static void main(String[] args) {
        MyThread t1 = new MyThread("线程A");
        MyThread t2 = new MyThread("线程B");

        t1.start(); // 启动新线程，JVM 内部调用 run
        t2.start();

        // 主线程继续执行，与 t1/t2 并发
        for (int i = 1; i <= 3; i++) {
            System.out.println("main 执行第 " + i + " 次");
            try {
                Thread.sleep(100);
            } catch (InterruptedException e) {
                return;
            }
        }

        System.out.println("main 结束，但线程A/B 可能还在运行");
    }
}
```

### 17-03 实现Runnable接口创建线程

**知识点**
- 创建线程方式二：定义类实现 `Runnable` 接口，重写 `run()`，再交给 `Thread` 执行：`new Thread(runnable).start()`。
- 优点：只实现接口，还能继承其他类；多个线程可以共享同一个 `Runnable` 对象的数据。
- `Thread` 构造方法可同时传入 `Runnable` 和线程名：`new Thread(r, "线程名")`。
- 匿名内部类/Lambda 写法：`new Thread(() -> {...}).start()`，代码最简洁。
- 方式三 `Callable` + `FutureTask` 可以拿到返回值，后面线程池会用到。
- 易错：`Runnable` 的 `run()` 没有返回值、不能抛受检异常，需要返回结果时选 `Callable`。

**示例代码**
```java
class TicketTask implements Runnable {
    // 共享数据：多个线程共用同一个 Runnable 对象时，这份数据是共享的
    private int tickets = 10;

    @Override
    public void run() {
        while (true) {
            if (tickets <= 0) {
                break;
            }
            System.out.println(Thread.currentThread().getName() + " 卖出第 " + tickets + " 张票");
            tickets--;
            try {
                Thread.sleep(10); // 模拟出票耗时
            } catch (InterruptedException e) {
                return;
            }
        }
    }
}

public class RunnableDemo {
    public static void main(String[] args) {
        // 方式二：实现 Runnable 接口
        TicketTask task = new TicketTask();
        Thread t1 = new Thread(task, "窗口1");
        Thread t2 = new Thread(task, "窗口2");
        t1.start();
        t2.start();

        // Lambda 写法：适合简单的任务
        Thread lambdaThread = new Thread(() -> {
            for (int i = 1; i <= 3; i++) {
                System.out.println("Lambda 线程：" + i);
            }
        }, "Lambda线程");
        lambdaThread.start();
    }
}
```

### 17-04 线程的常用方法

**知识点**
- `getName()`/`setName()` 获取和设置线程名；`currentThread()` 获取当前线程对象。
- `getPriority()`/`setPriority(int)` 设置优先级（1~10，默认 5），只是"建议"，不保证生效。
- `sleep(long)` 休眠；`join()` 让调用线程等待该线程执行完毕；`join(long)` 最多等待指定毫秒。
- `setDaemon(true)` 设为守护线程：主线程结束时守护线程自动结束，GC 线程就是守护线程。
- `interrupt()` 中断线程：会让 `sleep`/`wait` 抛 `InterruptedException`，并清除中断标记。
- 易错：`join` 是"谁调用谁等待"，`t.join()` 写在主线程里表示主线程等 t 结束。

**示例代码**
```java
public class ThreadMethodDemo {
    public static void main(String[] args) throws InterruptedException {
        Thread worker = new Thread(() -> {
            for (int i = 1; i <= 3; i++) {
                System.out.println(Thread.currentThread().getName() + " 工作中 " + i);
                try {
                    Thread.sleep(200);
                } catch (InterruptedException e) {
                    System.out.println("工作线程被中断，提前结束");
                    return;
                }
            }
            System.out.println("工作线程执行完毕");
        }, "工作线程");

        worker.setPriority(Thread.MAX_PRIORITY); // 10
        worker.start();

        // join：主线程等待 worker 结束
        worker.join();
        System.out.println("主线程在 worker 结束后才继续");

        // 守护线程：主线程结束它就结束
        Thread daemon = new Thread(() -> {
            while (true) {
                System.out.println("守护线程运行中...");
                try {
                    Thread.sleep(300);
                } catch (InterruptedException e) {
                    return;
                }
            }
        });
        daemon.setDaemon(true);
        daemon.start();

        // 中断演示
        Thread sleeper = new Thread(() -> {
            try {
                Thread.sleep(5000);
                System.out.println("睡满了 5 秒");
            } catch (InterruptedException e) {
                System.out.println("sleep 被打断：" + e.getMessage());
            }
        });
        sleeper.start();
        Thread.sleep(300);
        sleeper.interrupt(); // 打断 sleep

        Thread.sleep(500);
        System.out.println("main 即将结束，守护线程也会随之结束");
    }
}
```

### 17-05 线程安全问题与synchronized

**知识点**
- 线程安全问题：多个线程同时操作同一份共享数据，导致结果与预期不符（如超卖、少卖）。
- 产生条件：多线程 + 共享数据 + 至少有一个线程在修改数据。
- `synchronized` 同步代码块：`synchronized (锁对象) { ... }`，同一时刻只允许一个线程进入。
- `synchronized` 修饰方法：锁对象是 `this`；修饰静态方法：锁对象是当前类的 `Class` 对象。
- 锁对象必须是所有线程共享的同一个对象，`new Object()` 写在方法内部会失效。
- 易错：锁的范围过大影响性能，过小起不到保护作用；用 `String` 常量当锁容易与别处冲突。

**示例代码**
```java
class TicketSeller implements Runnable {
    private int tickets = 20;
    private final Object lock = new Object(); // 锁对象必须共享

    @Override
    public void run() {
        while (true) {
            // 同步代码块：同一时刻只有一个线程能进入
            synchronized (lock) {
                if (tickets <= 0) {
                    System.out.println("票已售完");
                    return;
                }
                try {
                    Thread.sleep(5); // 模拟检查余量的耗时
                } catch (InterruptedException e) {
                    return;
                }
                tickets--;
                System.out.println(Thread.currentThread().getName()
                        + " 卖出一张，剩余：" + tickets);
            }
        }
    }
}

public class SyncDemo {
    public static void main(String[] args) throws InterruptedException {
        TicketSeller seller = new TicketSeller();
        Thread[] threads = new Thread[3];
        for (int i = 0; i < threads.length; i++) {
            threads[i] = new Thread(seller, "窗口" + (i + 1));
            threads[i].start();
        }
        for (Thread t : threads) {
            t.join();
        }
        System.out.println("售票结束，剩余票数应为 0");
    }
}
```

### 17-06 同步方法与Lock锁

**知识点**
- 同步方法：把 `synchronized` 写在方法声明上，锁对象是 `this`（静态方法则是类对象）。
- `Lock` 是 JDK5 引入的接口，`ReentrantLock` 是最常用实现，比 `synchronized` 更灵活。
- `lock()` 加锁、`unlock()` 解锁；解锁必须放在 `finally` 中，保证异常时也能释放锁。
- `tryLock()` 尝试加锁，立即返回 `boolean`，可避免无限等待；`tryLock(timeout, unit)` 可设置等待时间。
- 相比 `synchronized`，`Lock` 支持公平锁（`new ReentrantLock(true)`）、可中断、可超时。
- 易错：忘记 `unlock()` 会导致死锁；`lock()` 与 `unlock()` 次数必须配对。

**示例代码**
```java
import java.util.concurrent.locks.Lock;
import java.util.concurrent.locks.ReentrantLock;

class Account {
    private int balance = 1000;
    private final Lock lock = new ReentrantLock();

    // 同步方法：锁对象是 this
    public synchronized void withdrawSync(int amount) {
        if (balance >= amount) {
            balance -= amount;
            System.out.println(Thread.currentThread().getName()
                    + " 取款 " + amount + "，余额：" + balance);
        } else {
            System.out.println(Thread.currentThread().getName() + " 余额不足");
        }
    }

    // Lock 锁：更灵活，必须在 finally 中解锁
    public void withdrawLock(int amount) {
        lock.lock();
        try {
            if (balance >= amount) {
                balance -= amount;
                System.out.println(Thread.currentThread().getName()
                        + " 取款 " + amount + "，余额：" + balance);
            } else {
                System.out.println(Thread.currentThread().getName() + " 余额不足");
            }
        } finally {
            lock.unlock(); // 无论是否异常都要解锁
        }
    }

    // tryLock：拿不到锁就放弃，避免死等
    public boolean tryWithdraw(int amount) {
        if (lock.tryLock()) {
            try {
                if (balance >= amount) {
                    balance -= amount;
                    return true;
                }
                return false;
            } finally {
                lock.unlock();
            }
        }
        System.out.println(Thread.currentThread().getName() + " 没抢到锁，稍后再试");
        return false;
    }

    public int getBalance() {
        return balance;
    }
}

public class LockDemo {
    public static void main(String[] args) throws InterruptedException {
        Account account = new Account();
        Thread t1 = new Thread(() -> account.withdrawLock(300), "张三");
        Thread t2 = new Thread(() -> account.withdrawLock(300), "李四");
        Thread t3 = new Thread(() -> account.withdrawLock(600), "王五");

        t1.start();
        t2.start();
        t3.start();
        t1.join();
        t2.join();
        t3.join();

        System.out.println("最终余额：" + account.getBalance());
    }
}
```

### 17-07 死锁、wait与notify

**知识点**
- 死锁：两个或多个线程互相持有对方需要的锁，并且都不释放，程序永久阻塞。
- 产生死锁的四个必要条件：互斥、持有并等待、不可抢占、循环等待；破坏任意一个即可避免。
- 避免死锁的实用做法：所有线程按同一顺序获取锁、设置锁超时（`tryLock`）、减少锁的嵌套。
- `wait()` 让当前线程释放锁并等待，`notify()` 唤醒一个等待线程，`notifyAll()` 唤醒全部。
- 这三个方法必须写在 `synchronized` 块中，且调用者必须是锁对象，否则抛 `IllegalMonitorStateException`。
- 易错：`wait` 应该放在 `while` 循环里判断条件，用 `if` 可能被"虚假唤醒"导致逻辑错误。

**示例代码**
```java
class SharedResource {
    private int data = 0;
    private boolean hasData = false;

    // 生产者：有数据就等待，没有就生产并通知
    public synchronized void produce(int value) throws InterruptedException {
        while (hasData) {           // 用 while 防止虚假唤醒
            wait();                 // 释放锁并等待
        }
        data = value;
        hasData = true;
        System.out.println("生产：" + data);
        notifyAll();                // 唤醒等待的消费者
    }

    // 消费者：没数据就等待，有就消费并通知
    public synchronized int consume() throws InterruptedException {
        while (!hasData) {
            wait();
        }
        hasData = false;
        System.out.println("消费：" + data);
        notifyAll();
        return data;
    }
}

public class WaitNotifyDemo {
    public static void main(String[] args) throws InterruptedException {
        SharedResource resource = new SharedResource();

        Thread producer = new Thread(() -> {
            for (int i = 1; i <= 3; i++) {
                try {
                    resource.produce(i);
                } catch (InterruptedException e) {
                    return;
                }
            }
        }, "生产者");

        Thread consumer = new Thread(() -> {
            for (int i = 1; i <= 3; i++) {
                try {
                    resource.consume();
                } catch (InterruptedException e) {
                    return;
                }
            }
        }, "消费者");

        producer.start();
        consumer.start();
        producer.join();
        consumer.join();
        System.out.println("生产消费完成");
    }
}
```

### 17-08 线程池

**知识点**
- 线程池复用已创建的线程，避免频繁创建销毁的开销，同时能控制并发数量。
- `Executors` 工厂方法：`newFixedThreadPool(n)` 固定数量、`newCachedThreadPool()` 按需扩容、`newSingleThreadExecutor()` 单线程。
- `ExecutorService.submit(Callable)` 提交任务并返回 `Future`，`future.get()` 阻塞获取结果。
- `execute(Runnable)` 无返回值；`shutdown()` 不再接受新任务但执行完已提交的，`shutdownNow()` 立即中断。
- 底层是 `ThreadPoolExecutor`：核心线程数、最大线程数、空闲存活时间、任务队列、拒绝策略。
- 易错：`newFixedThreadPool` 的任务队列无界，任务积压可能 OOM；生产环境推荐手动 `new ThreadPoolExecutor` 指定队列容量。

**示例代码**
```java
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.Callable;
import java.util.concurrent.ExecutionException;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.Future;
import java.util.concurrent.TimeUnit;

public class ThreadPoolDemo {
    public static void main(String[] args) throws InterruptedException, ExecutionException {
        // 固定 3 个线程的线程池
        ExecutorService pool = Executors.newFixedThreadPool(3);

        // execute：提交无返回值的任务
        for (int i = 1; i <= 5; i++) {
            final int taskId = i;
            pool.execute(() -> {
                System.out.println(Thread.currentThread().getName()
                        + " 执行任务 " + taskId);
                try {
                    Thread.sleep(100);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            });
        }

        // submit + Callable：提交有返回值的任务
        List<Future<Integer>> futures = new ArrayList<>();
        for (int i = 1; i <= 3; i++) {
            final int n = i;
            Callable<Integer> task = () -> {
                int sum = 0;
                for (int j = 1; j <= n * 10; j++) {
                    sum += j;
                }
                return sum;
            };
            futures.add(pool.submit(task));
        }
        for (Future<Integer> future : futures) {
            System.out.println("计算结果：" + future.get()); // 阻塞等待结果
        }

        // 关闭线程池
        pool.shutdown();
        if (!pool.awaitTermination(2, TimeUnit.SECONDS)) {
            pool.shutdownNow();
        }
        System.out.println("线程池已关闭：" + pool.isShutdown());
    }
}
```

### 17-09 并发工具类与原子类

**知识点**
- `AtomicInteger`/`AtomicLong` 基于 CAS（比较并交换）实现无锁线程安全，`incrementAndGet()` 是原子自增。
- `ConcurrentHashMap` 是线程安全的 Map，采用分段/CAS 优化，读操作几乎无锁，性能远高于 `Collections.synchronizedMap`。
- `CopyOnWriteArrayList` 写时复制：写操作加锁复制新数组，读操作无锁，适合读多写少。
- `CountDownLatch` 倒计时门闩：`countDown()` 减一，`await()` 等计数归零。
- `Semaphore` 信号量控制同时访问的线程数；`CyclicBarrier` 让一组线程互相等待到齐。
- 易错：`i++` 不是原子操作（读-改-写三步），多线程下必须用原子类或加锁。

**示例代码**
```java
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.CopyOnWriteArrayList;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.atomic.AtomicInteger;

public class ConcurrentUtilDemo {
    public static void main(String[] args) throws InterruptedException {
        int threadCount = 10;
        int loop = 1000;

        // 普通 int：多线程累加结果不对
        int[] normal = {0};
        // 原子类：CAS 保证原子性
        AtomicInteger atomic = new AtomicInteger(0);

        ExecutorService pool = Executors.newFixedThreadPool(threadCount);
        CountDownLatch latch = new CountDownLatch(threadCount);

        for (int i = 0; i < threadCount; i++) {
            pool.execute(() -> {
                for (int j = 0; j < loop; j++) {
                    normal[0]++;
                    atomic.incrementAndGet();
                }
                latch.countDown(); // 计数减一
            });
        }

        latch.await(); // 等待所有线程执行完
        System.out.println("普通 int 结果：" + normal[0] + "（期望 " + threadCount * loop + "）");
        System.out.println("AtomicInteger 结果：" + atomic.get());

        // ConcurrentHashMap：并发安全的 Map
        ConcurrentHashMap<String, Integer> map = new ConcurrentHashMap<>();
        map.put("a", 1);
        map.merge("a", 1, Integer::sum);
        System.out.println("ConcurrentHashMap：" + map);

        // CopyOnWriteArrayList：读多写少场景
        CopyOnWriteArrayList<String> cowList = new CopyOnWriteArrayList<>();
        cowList.add("A");
        cowList.add("B");
        System.out.println("CopyOnWriteArrayList：" + cowList);

        // 对照：普通 ArrayList 在多线程写入下会丢数据
        List<Integer> unsafeList = new ArrayList<>();
        for (int i = 0; i < threadCount; i++) {
            pool.execute(() -> {
                for (int j = 0; j < 100; j++) {
                    unsafeList.add(j);
                }
            });
        }

        pool.shutdown();
        pool.awaitTermination(3, java.util.concurrent.TimeUnit.SECONDS);
        System.out.println("普通 ArrayList 大小：" + unsafeList.size() + "（期望 1000，可能更小）");
    }
}
```
