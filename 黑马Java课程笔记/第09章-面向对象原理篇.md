# 第9章 面向对象原理篇

本章把目光投向内存内部：用一张张中文注释的内存图，搞清楚 new 出来的对象在堆、栈、方法区中如何分配、对象传入方法后引用传递的真实效果，以及 this 关键字的底层本质。

### 9-01 Java中对象的内存分配

**知识点**
- 栈内存：方法运行时进栈，存放局部变量（包括引用类型的变量），方法执行完毕就弹栈消失。
- 堆内存：所有 new 出来的东西都在堆中，对象在堆中有唯一的地址值；成员变量跟随对象一起存放在堆中。
- 成员方法不需要 new：类加载时方法的信息就已经进入方法区，调用方法时才把方法压入栈中执行。
- 引用类型的变量（如 Phone p）中存的是对象的地址值，不是对象本身。
- 两次 new 创建两个独立对象，堆中有两块空间，修改互不影响；把一个变量赋值给另一个变量，是复制地址值，二者指向同一个对象。
- 画图顺序：类加载 → main 进栈 → new 开辟堆空间 → 地址值赋给栈中变量 → 成员变量赋值。

**示例代码**
```java
// 文件名: ObjectMemoryDemo.java
// 演示对象的内存分配（结合注释画出内存图）
public class ObjectMemoryDemo {
    public static void main(String[] args) {
        // 内存变化：
        // 1. ObjectPhone.class 加载进方法区
        // 2. new 在堆中开辟空间，成员变量 brand、price 跟随对象进堆，值为默认值
        // 3. 把堆中对象的地址值 0x0011 赋给栈中的局部变量 p
        ObjectPhone p = new ObjectPhone();
        p.brand = "华为";
        p.price = 6999.0;
        // 此刻：栈中 p 存的是 0x0011；堆 0x0011 里 brand=华为，price=6999.0

        // 再次 new：堆中开辟一块全新空间，地址 0x0022，与 p 互不影响
        ObjectPhone p2 = new ObjectPhone();
        p2.brand = "小米";
        System.out.println(p.brand);  // 华为
        System.out.println(p2.brand); // 小米

        // 把 p 的地址值复制给 p3：p 和 p3 存的都是 0x0011，指向同一个对象
        ObjectPhone p3 = p;
        p3.price = 8888.0;
        // 通过任何一个变量修改，改的都是堆中同一块内存
        System.out.println(p.price); // 8888.0
    }
}
```

```java
// 文件名: ObjectPhone.java
public class ObjectPhone {
    String brand;  // 成员变量随对象一起存放在堆中
    double price;  // 方法不 new，类加载时已在方法区，调用时才进栈
}
```

### 9-02 对象在方法中进行传递

**知识点**
- 基本类型作为方法参数传递时，传的是"实际的值"，方法内修改的是副本，不影响外面的变量。
- 引用类型（对象）作为方法参数传递时，传的是"地址值"，方法内通过地址修改对象属性，会影响原对象。
- 原因：方法进栈后，形参变量中存的地址和实参一样，二者指向堆中同一个对象，操作的是同一块内存。
- 注意：如果方法内部让形参指向了一个新对象（形参 = new ...），那么之后的修改就与原对象无关了。
- 本质：Java 中只有值传递，引用类型传的那个"值"是地址值。
- 画图要点：方法进栈时，栈中会多出一个形参变量，形参与实参的箭头都指向同一个堆对象。

**示例代码**
```java
// 文件名: PassObjectDemo.java
// 演示对象在方法中的传递（结合注释画出内存图）
public class PassObjectDemo {
    public static void main(String[] args) {
        PassPhone p = new PassPhone();
        p.brand = "华为";

        // 调用方法，把 p 中存的地址值 0x0011 传给形参 phone
        // 方法进栈后：main 的 p -> 0x0011，形参 phone -> 0x0011（同一个对象）
        change(p);
        // 方法内通过地址修改了堆中对象的属性，原对象受影响
        System.out.println(p.brand); // 小米

        int a = 10;
        changeInt(a);
        // 基本类型传的是值本身，方法内改的只是自己的副本
        System.out.println(a); // 10
    }

    // 形参 phone 中存的是对象的地址值
    public static void change(PassPhone phone) {
        // phone.brand = "小米" 实际修改的是堆中 0x0011 那块内存
        phone.brand = "小米";
    }

    public static void changeInt(int num) {
        // 只修改栈中 changeInt 方法自己的局部变量 num，与 main 的 a 无关
        num = 100;
    }
}
```

### 9-03 this关键字的本质

**知识点**
- 本质：this 就是"当前调用该方法的对象"的地址值，方法被谁调用，方法内的 this 就代表谁。
- 例如 stu1.show() 执行时，方法内的 this 是 stu1 的地址；改成 stu2.show()，this 就变成 stu2 的地址。
- this 不是变量声明出来的，它是成员方法隐含的一部分，随方法被哪个对象调用而动态确定。
- this.成员变量 = 形参 的执行过程：先用 this 拿到当前对象的地址，再去堆中找到该对象的成员变量并赋值。
- 直接打印 this 可以看到"类名@十六进制地址"形式的输出，与打印对象本身的结果一致。
- static 方法中没有 this（静态与对象无关，下一章展开），this 只存在于非静态的成员方法中。

**示例代码**
```java
// 文件名: ThisEssenceDemo.java
// 演示 this 的本质（结合注释画出内存图）
public class ThisEssenceDemo {
    public static void main(String[] args) {
        // 堆中创建两个对象：0x0011 和 0x0022
        ThisCat c1 = new ThisCat();
        c1.name = "阿玮";

        ThisCat c2 = new ThisCat();
        c2.name = "小黑";

        // c1 调用 say：say 方法进栈，方法内的 this 就是 0x0011
        c1.say();
        // c2 调用 say：say 再次进栈，这次方法内的 this 就是 0x0022
        c2.say();

        // 打印对象本身，输出"类名@地址值"，可与 say 中打印的 this 对比
        System.out.println(c1);
        System.out.println(c2);
    }
}
```

```java
// 文件名: ThisCat.java
public class ThisCat {
    String name;

    public void say() {
        // this 代表当前调用该方法的对象的地址值
        // c1 调用时，下面这行等价于打印 c1 的 name 和地址
        System.out.println("我是" + this.name + "，我的地址是" + this);
    }
}
```
