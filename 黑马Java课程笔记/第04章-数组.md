# 第4章 数组

本章从"容器"的视角认识数组，学习静态与动态初始化、元素访问与遍历等基础操作，并通过查找、求最值、洗牌、去重、快慢指针五个练习，逐步建立用数组解决问题的算法思维。

### 4-01 什么是数组？

**知识点**
- 数组是一种容器，用来存储同一种数据类型的多个值，元素在内存中的地址是连续的。
- 定义格式（推荐）：`数据类型[] 数组名`，如 `int[] arr`；也可写成 `int arr[]`，但不推荐。
- 数组一旦创建，长度固定，不能自动扩容。
- 数组中的每个数据叫"元素"，元素的编号叫"索引（下标）"，索引从 0 开始。
- 存储的数据类型必须与数组类型匹配，`int[]` 只能存 int 类型的数据。

**示例代码**
```java
public class ArrayDemo {
    public static void main(String[] args) {
        // 数组就是一个容器，把多个同类型数据放在一起管理
        int[] scores = {100, 95, 88, 76, 60};

        // 通过索引访问元素，索引从 0 开始
        System.out.println("第一个成绩：" + scores[0]);
        System.out.println("最后一个成绩：" + scores[4]);

        // length 表示数组长度，即元素的个数
        System.out.println("共保存了 " + scores.length + " 个成绩");
    }
}
```

1. 模仿示例代码定义一个数组，保存 3 个水果名称，打印其中第二个元素。
2. 定义一个 double 数组保存 5 个身高值，打印数组的长度和第一个元素。
3. 定义一个数组保存一周 7 天的气温，分别打印第一天和最后一天的气温。

### 4-02 数组的学习内容

**知识点**
- 本章学习路线：数组概念 → 静态初始化 → 元素访问 → 遍历 → 动态初始化 → 常见异常 → 综合练习 → 作业。
- 核心操作只有两件事：把数据放进数组（初始化、赋值），把数据取出来用（访问、遍历）。
- 练习环节由易到难：查找 → 求最值 → 随机打乱 → 去重 → 快慢指针，为力扣、牛客的算法题打底。
- 学数组要养成习惯：先想清楚长度和索引范围，再动手写循环。

**示例代码**
```java
public class ArrayRoadmapDemo {
    public static void main(String[] args) {
        // 本章路线：初始化 -> 访问 -> 遍历 -> 综合练习
        int[] arr = {5, 12, 8, 20, 3};

        // 第一站：按索引访问元素
        System.out.println("第 3 个元素：" + arr[2]);

        // 第二站：用 for 循环遍历数组
        for (int i = 0; i < arr.length; i++) {
            System.out.println("索引 " + i + " -> " + arr[i]);
        }

        // 第三站：综合练习中会实现的功能（求最大值）先睹为快
        int max = arr[0];
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > max) {
                max = arr[i];
            }
        }
        System.out.println("最大值：" + max);
    }
}
```

### 4-03 数组的静态初始化

**知识点**
- 静态初始化：定义数组时直接写明所有元素，长度由系统自动计算。
- 推荐写法：`int[] arr = {11, 22, 33};`，简洁直观。
- 完整写法：`int[] arr = new int[]{11, 22, 33};`，与推荐写法效果完全一样。
- 易错点：简写 `{...}` 只能在定义的同时赋值，分两步时必须写完整格式 `arr = new int[]{...}`。
- 静态初始化指定的是"元素"，动态初始化（4-06 会学）指定的是"长度"。

**示例代码**
```java
public class StaticInitDemo {
    public static void main(String[] args) {
        // 推荐写法：直接写出所有元素，长度由系统计算
        int[] arr1 = {11, 22, 33, 44};

        // 完整写法：new int[]{...}，效果一样
        double[] arr2 = new double[]{1.5, 2.5, 3.5};

        System.out.println(arr1.length); // 4
        System.out.println(arr2[1]);     // 2.5

        // 分两步时，简写 {} 是非法的，必须用完整格式
        int[] arr3;
        arr3 = new int[]{1, 2, 3};
        System.out.println(arr3[0]); // 1
    }
}
```

### 4-04 数组中元素的访问

**知识点**
- 通过 `数组名[索引]` 访问元素，合法索引范围是 `0 ~ length-1`。
- 读元素：`int x = arr[0];`；改元素：`arr[0] = 100;`。
- `arr.length` 是数组的长度属性，注意没有括号（不是方法）。
- 负数索引或超出 `length-1` 的索引会抛出 `ArrayIndexOutOfBoundsException`（越界异常）。
- 访问不确定的索引前，先判断 `index >= 0 && index < arr.length` 更安全。

**示例代码**
```java
public class ArrayAccessDemo {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30, 40};

        // 索引范围：0 ~ length - 1
        System.out.println(arr[0]); // 10
        System.out.println(arr[3]); // 40

        // 通过索引修改元素
        arr[1] = 200;
        System.out.println(arr[1]); // 200

        // length 是属性，直接使用，不加括号
        System.out.println("长度：" + arr.length);

        // 下面这行越界了，取消注释会报 ArrayIndexOutOfBoundsException
        // System.out.println(arr[4]);
    }
}
```

### 4-05 数组的遍历

**知识点**
- 遍历：把数组中每个元素从头到尾逐个访问一遍。
- 固定套路：`for (int i = 0; i < arr.length; i++)`，用 `arr.length` 当循环终点，数组长度变了代码也不用改。
- 循环变量 i 恰好就是每个元素的索引，`arr[i]` 就是当前元素。
- 易错点：循环条件写成 `i <= arr.length` 会造成越界。
- 遍历时可以边访问边统计：求和、计数、找最值都建立在遍历之上。

**示例代码**
```java
public class ArrayTraversalDemo {
    public static void main(String[] args) {
        int[] arr = {55, 66, 77, 88, 99};

        // 遍历套路：i 依次是 0、1、2、3、4
        for (int i = 0; i < arr.length; i++) {
            System.out.println(arr[i]);
        }

        // 遍历的同时累加求和
        int sum = 0;
        for (int i = 0; i < arr.length; i++) {
            sum += arr[i];
        }
        System.out.println("总和：" + sum);
    }
}
```

**课后练习**
1. 遍历打印数组 `{3, 6, 9, 12, 15, 18}`，要求每行输出"索引: 元素"的格式。

3. 遍历数组 `{5, 8, 2, 9, 1}`，只打印索引为偶数（0、2、4）位置上的元素。

### 4-06 数组的动态初始化

**知识点**
- 动态初始化：只指定长度，元素先由系统赋默认值，之后再手动填充，如 `int[] arr = new int[5];`。
- 默认值规则：整数 `0`、小数 `0.0`、布尔 `false`、字符 `'\u0000'`、引用类型（如 String）`null`。
- 静态与动态的选择：元素数据已知用静态，只知道"要存几个"用动态。
- 动态初始化后依然可以用索引逐个赋值，也可以配合遍历批量赋值。
- 易错点：`new int[5]` 中的 5 是长度不是最大索引，合法索引是 0~4。

**示例代码**
```java
public class DynamicInitDemo {
    public static void main(String[] args) {
        // 只指定长度，元素是默认值
        int[] arr1 = new int[3];
        System.out.println(arr1[0]); // 0

        double[] arr2 = new double[2];
        System.out.println(arr2[0]); // 0.0

        boolean[] arr3 = new boolean[2];
        System.out.println(arr3[0]); // false

        String[] arr4 = new String[2];
        System.out.println(arr4[0]); // null

        // 动态初始化后可以再手动赋值
        arr1[1] = 66;
        System.out.println(arr1[1]); // 66
    }
}
```

**课后练习**
1. 动态初始化一个长度为 5 的 int 数组，遍历打印所有默认值，再通过遍历把元素改成 1~5。
2. 动态初始化长度为 3 的 String 数组，打印第一个元素观察默认值，再赋值成 3 个姓名。
3. 定义一个长度为 100 的数组，用遍历把索引 i 的元素赋值为 i * 2，打印前 10 个元素验证。

### 4-07 数组的常见问题

**知识点**
- `NullPointerException`（空指针异常）：数组引用为 `null` 时还去访问元素或 length，如 `int[] arr = null; arr[0]`。
- `ArrayIndexOutOfBoundsException`（索引越界异常）：访问了 `0 ~ length-1` 之外的索引，包括负数。
- null 表示"引用没有指向任何数组对象"，与"长度为 0 的数组"不是一回事。
- 防御写法：使用前判断 `arr != null`，访问前核对索引是否在合法范围内。
- 看报错技巧：异常信息第一行是异常类名，随后括号里是出错的类名和行号，按行号排查。

**示例代码**
```java
public class ArrayProblemDemo {
    public static void main(String[] args) {
        // 问题一：空指针异常
        int[] arr1 = null;
        // System.out.println(arr1[0]); // NullPointerException

        // 问题二：索引越界异常
        int[] arr2 = {1, 2, 3};
        // System.out.println(arr2[3]); // ArrayIndexOutOfBoundsException

        // 正确姿势：先判断引用是否为 null
        if (arr1 != null) {
            System.out.println(arr1[0]);
        } else {
            System.out.println("arr1 没有指向任何数组");
        }

        // 正确姿势：访问前核对索引范围
        int index = 2;
        if (index >= 0 && index < arr2.length) {
            System.out.println(arr2[index]);
        }
    }
}
```

**课后练习**
1. 分别写出一段会产生空指针异常和一段会产生越界异常的代码，注释掉并用文字标注错误原因。

### 4-08 练习1：查找数据

**知识点**
- 题面：给定数组 `{19, 28, 37, 46, 50}`，查找数字 46 的索引并打印；如果元素不存在，打印 -1。
- 思路：遍历数组，用 `arr[i] == target` 逐个比较，相等就记录索引。
- 用变量 index 先初始化为 -1，找到后覆盖成真实索引，"没找到输出 -1"就自然成立。
- 找到后用 `break` 结束循环，避免不必要的继续比较。
- 这就是"顺序查找"，是力扣、牛客中查找类题目的最基础模型。

**示例代码**
```java
public class ArraySearchDemo {
    public static void main(String[] args) {
        // 需求：查找 46 在数组中的索引，不存在则输出 -1
        int[] arr = {19, 28, 37, 46, 50};
        int target = 46;

        // index 初始为 -1，表示"还没找到"
        int index = -1;
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == target) {
                index = i;
                break; // 找到就结束，无需继续比较
            }
        }

        if (index == -1) {
            System.out.println(target + " 不存在于数组中，返回 " + index);
        } else {
            System.out.println(target + " 的索引是：" + index);
        }
    }
}
```

### 4-09 练习2：数组中的最大值

**知识点**
- 题面：给定数组 `{33, 5, 22, 44, 55}`，找出其中的最大值并打印。
- 思路：先假设第 0 个元素是最大值，从索引 1 开始逐个比较，谁更大谁当"擂主"。
- 这种思路叫"打擂台"：擂主变量 max 不停被更强的元素替换，遍历结束剩下的就是答案。
- 求最小值只需把比较符号反过来，套路完全相同。
- 易错点：假设值不能写死为 0，要用数组元素做初值，否则数组全是负数时会出错。

**示例代码**
```java
public class ArrayMaxDemo {
    public static void main(String[] args) {
        // 需求：找出数组中的最大值
        int[] arr = {33, 5, 22, 44, 55};

        // 先假设第 0 个元素是最大值（擂主）
        int max = arr[0];

        // 从索引 1 开始逐个挑战擂主
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > max) {
                max = arr[i]; // 更大的元素成为新擂主
            }
        }

        System.out.println("最大值是：" + max); // 55
    }
}
```

**课后练习**
1. 修改示例，求数组中的最小值。
2. 求出最大值的同时，打印最大值所在的索引。
3. 求数组中最大值与最小值的差，注意数组元素可能全是负数的情况。

### 4-10 练习3：打乱数组中的数据

**知识点**
- 题面：给定数组 `{1, 2, 3, 4, 5}`，把里面的数据随机打乱后打印（洗牌效果）。
- 思路：借助 `Random` 随机生成索引，让当前元素与随机位置的元素交换。
- 交换两个元素必须借助第三个临时变量 temp，先把一边的数据暂存再交换。
- 随机索引范围：`r.nextInt(arr.length)` 生成 0 ~ length-1，正好是合法索引。
- 交换若干轮后数据的位置就被打乱了，这是洗牌算法的雏形。

**示例代码**
```java
import java.util.Random;

public class ShuffleDemo {
    public static void main(String[] args) {
        // 需求：把数组中的数据随机打乱（洗牌）
        int[] arr = {1, 2, 3, 4, 5};
        Random r = new Random();

        // 每一轮：随机选一个索引，与当前位置交换
        for (int i = 0; i < arr.length; i++) {
            int randomIndex = r.nextInt(arr.length);
            int temp = arr[i];           // 先把 arr[i] 暂存
            arr[i] = arr[randomIndex];
            arr[randomIndex] = temp;     // 交换完成
        }

        // 打印打乱后的数组
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + " ");
        }
    }
}
```

### 4-11 练习4：去除重复元素

**知识点**
- 题面：给定数组 `{1, 1, 2, 3, 3, 4}`，去掉重复元素，得到每个元素只保留一份的结果 `{1, 2, 3, 4}`。
- 思路：准备一个等长的新数组，遍历原数组，判断当前元素是否已经存入新数组，不存在才存入。
- 判断"是否已存在"需要再用一层循环检查新数组，用计数变量 count 记录已存入的个数。
- 最后只打印新数组前 count 个元素，其余位置是多余的默认值。
- 双层循环是去重的基础写法，下一课会学习用双指针优化有序数组的去重。

**示例代码**
```java
public class RemoveDuplicateDemo {
    public static void main(String[] args) {
        // 需求：去掉重复元素，每个元素只保留一份
        int[] arr = {1, 1, 2, 3, 3, 4};

        // 新数组接收去重结果，count 记录已存入的个数
        int[] newArr = new int[arr.length];
        int count = 0;

        for (int i = 0; i < arr.length; i++) {
            boolean repeated = false; // 标记当前元素是否已存在
            for (int j = 0; j < count; j++) {
                if (newArr[j] == arr[i]) {
                    repeated = true;
                    break;
                }
            }
            if (!repeated) {
                newArr[count] = arr[i]; // 不重复才存入
                count++;
            }
        }

        // 打印前 count 个有效元素
        for (int i = 0; i < count; i++) {
            System.out.print(newArr[i] + " ");
        }
    }
}
```

### 4-12 练习5：快慢指针

**知识点**
- 题面（力扣 26. 删除有序数组中的重复项）：有序数组 `{1, 1, 2, 2, 3, 4, 4}` 原地去重，输出去重后的长度和前若干个元素。
- 思路：慢指针 slow 指向"不重复区域"的最后一个元素，快指针 fast 向右扫描寻找新数据。
- 当 `nums[fast] != nums[slow]` 时说明发现新数据：slow 先前进一格，再把新数据覆盖到 slow 位置。
- 原地操作：不开辟新数组，直接修改原数组，空间复杂度为 O(1)。
- 快慢双指针是算法题高频套路，还常用于移除元素、移动零等原地操作题。

**示例代码**
```java
public class FastSlowPointerDemo {
    public static void main(String[] args) {
        // 需求：有序数组原地去重（力扣 26 题）
        int[] nums = {1, 1, 2, 2, 3, 4, 4};

        // 慢指针：不重复区域的最后一个元素
        int slow = 0;

        // 快指针：扫描整个数组
        for (int fast = 1; fast < nums.length; fast++) {
            if (nums[fast] != nums[slow]) {
                slow++;                  // 不重复区域扩大一格
                nums[slow] = nums[fast]; // 覆盖新数据
            }
        }

        // 前 slow + 1 个元素就是去重后的结果
        System.out.println("去重后的长度：" + (slow + 1));
        for (int i = 0; i <= slow; i++) {
            System.out.print(nums[i] + " ");
        }
    }
}
```

```java
import java.util.Arrays;

public class ArrayPrintTool {
    public static void main(String[] args) {
        // 作业调试技巧：把数组打印出来观察中间结果
        int[] arr = {11, 22, 33, 44};

        // 写法一：自己拼字符串，格式 [元素1, 元素2, ...]
        System.out.print("自定义打印：[");
        for (int i = 0; i < arr.length; i++) {
            if (i != arr.length - 1) {
                System.out.print(arr[i] + ", ");
            } else {
                System.out.print(arr[i]);
            }
        }
        System.out.println("]");

        // 写法二：Arrays 工具类的 toString 方法，一行搞定
        System.out.println("Arrays.toString：" + Arrays.toString(arr));
    }
}
```
