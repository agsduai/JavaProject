## 统一格式

每一课均按以下固定格式整理，便于对照视频复习与自测：

1. **课号 + 知识点注释** —— 该课核心概念、语法格式与易错点
2. **示例代码** —— 完整可运行、带中文注释的示例程序
3. **课后练习** —— 2~4 道练习题（不附参考答案，独立完成后可对照视频或提问验证）

每章末尾另有一节 `## 本章综合练习`，把整章知识点串成一个业务场景：

- **场景** —— 一段业务背景，说明要解决的问题与约束条件；
- **任务** —— 3~5 个递进小问，从「跑通」到「优化」再到「说清为什么」；
- **验收清单** —— 可勾选的自检项，逐条对照即可判断是否真的掌握。

综合练习同样不附参考答案，并同步以注释块形式写在每章最后一课的 `.java` 文件末尾，读笔记与写代码时看到的是同一道题。
