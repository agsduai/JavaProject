# 第5章 方法

本章学习方法的定义与调用，理解形参、实参与返回值的传递过程，掌握"要不要返回值、要不要形参"的设计诀窍与重载规则，让代码可以复用、更易维护，为后面面向对象的学习铺路。

### 5-01 什么是方法？

**知识点**
- 方法是一段组织好、可以被反复调用的代码，目的：提高代码的复用性和可读性。
- 定义格式：`public static 返回值类型 方法名(形参列表) { 方法体; return 结果; }`，定义在类中、与 main 方法平级。
- 形参：方法定义时声明的参数，相当于"占位"；实参：调用方法时真正传入的值。
- 返回值类型写 void 表示没有返回值；写了具体类型就必须 return 一个对应类型的结果。
- 调用过程：实参传给形参 → 执行方法体 → return 把结果带回调用处；方法不调用就不会执行。
- return 之后方法立即结束，return 下面不能再写任何代码。

**示例代码**
```java
public class MethodDemo {
    public static void main(String[] args) {
        // 调用方法：实参 10、20 会传给形参 a、b
        int result = getSum(10, 20);
        System.out.println("求和结果：" + result);

        // 无返回值的方法单独调用
        sayHello("阿玮");
    }

    // 定义方法：有参数、有返回值
    public static int getSum(int a, int b) {
        int sum = a + b;
        return sum; // 把结果带回调用处
    }

    // void 表示没有返回值
    public static void sayHello(String name) {
        System.out.println("你好，" + name + "！");
    }
}
```

**课后练习**
1. 定义一个无参无返回值的方法 printWelcome，调用它打印一句欢迎语。
2. 定义方法 getDiff(int a, int b)，返回 a - b 的结果，并在 main 中调用后打印。
3. 定义方法 getCircleArea(double r)，返回圆的面积（圆周率用 3.14），调用并验证结果。

### 5-02 三道方法练习

**知识点**
- 练习一（判断素数）：定义方法 `isPrime(int num)`，num 是素数返回 true，否则返回 false。思路：小于 2 直接返回 false；从 2 开始试除，存在约数就不是素数（试到平方根即可提前结束）。
- 练习二（求较大值）：定义方法 `getMax(int a, int b)`，返回两个整数中较大的一个。思路：用 if 判断，或用三元运算符 `a >= b ? a : b`。
- 练习三（数组求和）：定义方法 `getSum(int[] arr)`，返回数组所有元素的总和。思路：遍历累加，循环终点用 `arr.length`。
- 共同方法：先按"要不要返回值、要不要形参"确定方法签名，再填方法体，最后在 main 中调用验证。

**示例代码**
```java
public class MethodPractice {
    public static void main(String[] args) {
        System.out.println("17 是否为素数：" + isPrime(17)); // true
        System.out.println("较大值：" + getMax(10, 23));     // 23
        int[] arr = {1, 2, 3, 4, 5};
        System.out.println("数组总和：" + getSum(arr));      // 15
    }

    // 练习一：判断 num 是否为素数
    public static boolean isPrime(int num) {
        if (num < 2) {
            return false;
        }
        for (int i = 2; i * i <= num; i++) {
            if (num % i == 0) {
                return false; // 找到约数就不是素数
            }
        }
        return true;
    }

    // 练习二：返回两个整数中的较大值
    public static int getMax(int a, int b) {
        return a >= b ? a : b;
    }

    // 练习三：返回整数数组的总和
    public static int getSum(int[] arr) {
        int sum = 0;
        for (int i = 0; i < arr.length; i++) {
            sum += arr[i];
        }
        return sum;
    }
}
```

**课后练习**
1. 定义方法 `countEven(int[] arr)`，统计并返回数组中偶数的个数。
2. 定义方法 `getMaxOfThree(int a, int b, int c)`，返回三个整数中的最大值。
3. 定义方法 `contains(int[] arr, int data)`，判断数组中是否包含 data，包含返回 true，否则返回 false。

### 5-03 定义方法的小诀窍

**知识点**
- 方法只是执行一段代码：把重复或独立的逻辑抽出来，调用处一行即可完成。
- 诀窍一（要不要返回值）：看调用处是否需要结果——需要就定义返回值类型并 return；只是做动作（如打印）就用 void。
- 诀窍二（要不要形参）：看方法干活时缺不缺数据——缺什么就声明什么形参，什么都不缺就把形参列表留空。
- 两个判断独立进行，组合出四种方法形态：有参有返回、有参无返回、无参有返回、无参无返回。
- 方法内部的变量与方法外互不影响，形参是实参的拷贝，方法内修改形参不会影响调用处的变量。
- void 方法中可以写 `return;` 提前结束方法，其后同样不能再有代码。

**示例代码**
```java
public class MethodTipsDemo {
    public static void main(String[] args) {
        // 调用处需要结果 -> 定义返回值
        int area = getRectangleArea(4, 5);
        System.out.println("面积：" + area);

        // 调用处只要打印 -> 用 void 即可
        printRectangleArea(3, 6);

        // 方法干活不缺数据 -> 形参留空
        printLine();
    }

    // 有参有返回：形参是干活用的数据，返回值是调用处要的结果
    public static int getRectangleArea(int width, int height) {
        return width * height;
    }

    // 有参无返回：只负责打印，不需要带回结果
    public static void printRectangleArea(int width, int height) {
        System.out.println("面积：" + width * height);
    }

    // 无参无返回：不缺数据，也不需要结果
    public static void printLine() {
        System.out.println("--------------------");
    }
}
```

**课后练习**
1. 需求"打印 10 行星号"，按诀窍分析它应该带不带走参、需不需要返回值，然后实现并调用。
2. 把本课的 `printRectangleArea`（打印面积）改造成返回面积的方法，在 main 中接收返回值后自己打印。
3. 分析方法设计 `public static int printSum(int a, int b)`（方法体内只打印 a+b，没有 return）是否合理，说明理由。

### 5-04 方法的重载和总结

**知识点**
- 重载（Overload）：同一个类中，方法名相同、参数列表不同的多个方法。
- 参数不同指的是：参数个数不同、参数类型不同、参数顺序不同，满足其一即可。
- 判断要点：重载与返回值无关，只看方法名和参数列表。
- 调用时 Java 会根据实参的个数和类型自动匹配最合适的方法。
- 好处：功能相似的方法共用一个名字，调用者无需记忆多个名字，如 println 就有多个重载。
- 本章总结：方法定义格式、形参与实参、返回值与 void、调用过程、重载规则。

**示例代码**
```java
public class OverloadDemo {
    public static void main(String[] args) {
        // 方法名相同，按实参自动匹配不同的方法
        System.out.println(sum(1, 2));     // 匹配两个 int
        System.out.println(sum(1, 2, 3));  // 匹配三个 int
        System.out.println(sum(1.5, 2.5)); // 匹配两个 double
    }

    // 两个 int 求和
    public static int sum(int a, int b) {
        return a + b;
    }

    // 参数个数不同，构成重载
    public static int sum(int a, int b, int c) {
        return a + b + c;
    }

    // 参数类型不同，也构成重载
    public static double sum(double a, double b) {
        return a + b;
    }
}
```

**课后练习**
1. 定义三个重载的 print 方法：分别接收 int、double、String 参数并打印不同格式的提示，调用验证。
2. 定义重载方法 getMax：一个版本求两个 int 的较大值，另一个版本求两个 double 的较大值。
3. 判断每组方法是否构成重载，先写判断再写代码验证：`f(int, double)` 与 `f(double, int)`；`f(int)` 与 `f(double)`。

### 5-05 方法的作业

**知识点**
- 作业一（判断闰年）：方法签名 `public static boolean isLeapYear(int year)`，是闰年返回 true。闰年条件：能被 4 整除且不能被 100 整除，或能被 400 整除。
- 作业二（复制数组）：方法签名 `public static int[] copyArray(int[] arr)`，返回一个内容与 arr 完全相同的新数组，要求修改新数组不影响原数组。
- 作业三（拼接字符串）：方法签名 `public static String arrayToString(int[] arr)`，把数组拼成 `[1, 2, 3]` 这种格式的字符串并返回。
- 作业四（平均分）：方法签名 `public static double getAverage(int[] arr)`，返回数组所有元素的平均分，结果保留两位小数。
- 统一要求：每个方法补上 `/** */` 文档注释（说明功能、@param、@return）；在 main 中调用并验证；每个作业独立成一个类完成。

**示例代码**
```java
public class MethodDocDemo {
    public static void main(String[] args) {
        // 作业规范：每个方法都要有文档注释，示例写法如下
        System.out.println(getGreeting("同学"));
        System.out.println("8 是偶数：" + isEven(8));
    }

    /**
     * 获取一句问候语（演示方法文档注释的规范写法）
     * @param name 要问候的人名
     * @return 拼接好的问候语
     */
    public static String getGreeting(String name) {
        return "你好，" + name + "，欢迎学习 Java！";
    }

    /**
     * 判断一个整数是否为偶数
     * @param num 被判断的整数
     * @return 偶数返回 true，奇数返回 false
     */
    public static boolean isEven(int num) {
        return num % 2 == 0;
    }
}
```

**课后练习**
1. 作业一：定义方法 `public static boolean isLeapYear(int year)` 判断闰年，用 2024、1900、2000 三组数据验证。
2. 作业二：定义方法 `public static int[] copyArray(int[] arr)` 复制数组，并验证修改新数组不影响原数组。
3. 作业三：定义方法 `public static String arrayToString(int[] arr)`，把数组拼成 `[1, 2, 3]` 格式的字符串返回。
4. 作业四：定义方法 `public static double getAverage(int[] arr)`，返回数组所有元素的平均分并保留两位小数。
