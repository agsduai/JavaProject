# 第11章 面向对象高级

本章是 Java 面向对象的进阶篇章，从继承出发，依次学习继承中的成员规则与权限修饰符、多态、抽象类、接口、内部类与匿名内部类，并通过多个综合案例与练习完成从“会写类”到“会设计类”的跨越。

### 11-01 什么是继承？

**知识点**
- 继承是面向对象三大特征（封装、继承、多态）之一，用关键字 `extends` 实现，语法：`public class 子类 extends 父类 {}`
- 父类（也叫基类、超类）存放多个子类共有的属性和方法；子类（也叫派生类）只写自己独有的内容
- 核心好处：代码复用，把重复代码抽到父类，子类直接拿来用；同时让类与类之间产生关系，为后面学多态打基础
- 子类可以像使用自己的成员一样使用父类中非私有的成员
- Java 中一个类只能有一个直接父类（单继承）
- 使用场景判断：当多个类出现大量相同的属性和方法时，就该把共同点抽取到一个父类中

**示例代码**
```java
// 文件名: ExtendsDemo1.java
public class ExtendsDemo1 {
    public static void main(String[] args) {
        // 创建父类对象
        Animal a = new Animal();
        a.eat();

        // 创建子类对象：eat 是从父类继承来的，lookHome 是子类自己的
        Dog d = new Dog();
        d.eat();
        d.lookHome();
    }
}

// 父类：存放共有的属性和方法
class Animal {
    public void eat() {
        System.out.println("动物都要吃东西");
    }
}

// 子类：通过 extends 继承父类，不用再重复写 eat 方法
class Dog extends Animal {
    public void lookHome() {
        System.out.println("狗在看家");
    }
}
```

### 11-02 如何设计一个复杂的继承结构

**知识点**
- 设计套路：先看需求 → 列出每个类的属性和方法 → 找出共同点 → 把共同点抽取到父类 → 子类 `extends` 父类
- 典型例子：学生有姓名、年龄、学号、学习方法；老师有姓名、年龄、工号、讲课方法 → 把姓名、年龄、吃饭、睡觉抽到父类 Person
- 抽取原则：所有子类都有的内容放父类；只有部分子类有的内容留在子类
- 父类中的成员要让子类能直接使用，一般用 public（或 protected）修饰，暂时不要用 private
- 抽象成父类的过程就是“从具体到一般”的归纳思维，这也是面向对象设计的基本功
- 设计完成后要写测试类验证：子类对象既能调父类方法，也能调自己的方法

**示例代码**
```java
// 文件名: Person.java
// 父类：从需求中抽取出来的共同属性和方法
public class Person {
    String name; // 姓名
    int age;     // 年龄

    public void eat() {
        System.out.println(name + "正在吃饭");
    }

    public void sleep() {
        System.out.println(name + "正在睡觉");
    }
}
```
```java
// 文件名: Student.java
// 子类：学生，继承 Person 后只写自己独有的内容
public class Student extends Person {
    String studentId; // 独有属性：学号

    public void study() {
        System.out.println(name + "正在学习");
    }
}
```
```java
// 文件名: Teacher.java
// 子类：老师
public class Teacher extends Person {
    String workId; // 独有属性：工号

    public void teach() {
        System.out.println(name + "正在讲课");
    }
}
```

### 11-03 继承的特点

**知识点**
- Java 只支持单继承：一个子类只能有一个直接父类，`class A extends B, C` 这种写法是非法的
- Java 支持多层继承：A 继承 B，B 又继承 C，子类可以把“爷爷类”的公有成员也一并继承过来使用
- 每种继承关系只能有一个直接父类；但一个父类可以同时被多个子类继承（如 Person 可以被 Student、Teacher 共同继承）
- 不支持多继承的原因：如果两个父类中有同名方法，子类不知道该用哪一个，会产生二义性
- 所有类的顶级父类是 Object：任何一个类不写 extends，默认直接继承 Object
- 记忆：直接父类只能有一个，间接父类（各级祖先类）的公有成员照常继承

**示例代码**
```java
// 文件名: ExtendsFeature.java
public class ExtendsFeature {
    public static void main(String[] args) {
        Student s = new Student();
        s.study();                        // 自己的方法
        s.eat();                          // 间接父类 Animal 的方法（多层继承而来）
        s.sleep();                        // 直接父类 Person 的方法
        System.out.println(s.toString()); // 顶级父类 Object 的方法
    }
}

// 间接父类（爷爷类）
class Animal {
    public void eat() {
        System.out.println("吃东西");
    }
}

// 直接父类：Person 继承 Animal；同时可以被多个子类继承
class Person extends Animal {
    public void sleep() {
        System.out.println("睡觉");
    }
}

// 子类：只能写一个直接父类，不能写成 class Student extends Person, Animal
class Student extends Person {
    public void study() {
        System.out.println("学习");
    }
}
```

### 11-04 继承中成员变量的特点

**知识点**
- 变量的访问遵循就近原则：先找局部范围（方法内部），再找本类成员位置，找不到才逐级向上去父类找
- 子类成员变量与父类成员变量同名时，子类对象默认访问到的是子类的那个变量
- 想访问父类的同名变量，用 `super.变量名`；想明确访问本类成员变量，用 `this.变量名`
- `this` 代表本类对象的引用；`super` 代表父类的存储空间（对象中父类那一部分）
- 局部变量、子类成员变量、父类成员变量三者同名时：直接写变量名取局部，`this.` 取本类，`super.` 取父类
- 易错点：就近原则只发生在“找不到才向上找”，一旦本类有同名变量，就不会再往父类找

**示例代码**
```java
// 文件名: VariableDemo.java
public class VariableDemo {
    public static void main(String[] args) {
        Zi z = new Zi();
        z.show();
    }
}

class Fu {
    String name = "父类的name";
}

class Zi extends Fu {
    String name = "子类的name";

    public void show() {
        String name = "局部变量name";
        System.out.println(name);        // 就近原则：先取局部变量
        System.out.println(this.name);   // this.：取子类成员变量
        System.out.println(super.name);  // super.：取父类成员变量
    }
}
```

### 11-05 继承中成员方法的特点

**知识点**
- 方法同样遵循就近原则：调用方法时先在本类找，本类没有才去父类找
- 方法重写（Override）：子类中出现与父类方法声明完全相同的方法（方法名相同、参数列表相同），会覆盖从父类继承来的方法
- 重写的规则：方法名、形参列表必须与父类一致；返回值类型相同或更小；子类方法的访问权限必须大于等于父类
- `@Override` 注解写在重写方法上方，是重写的“校验器”：如果下面的方法不是合法的重写，编译直接报错，建议永远加上
- 重写的典型场景：父类的方法满足不了子类的需求时，子类对方法进行升级改造
- 区分两个概念：重写 Override（发生在继承关系中）与重载 Overload（同一个类中方法名相同、参数不同）

**示例代码**
```java
// 文件名: OverrideDemo.java
public class OverrideDemo {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.eat(); // 子类重写了父类方法，就近原则执行子类的版本
    }
}

class Animal {
    public void eat() {
        System.out.println("吃东西");
    }
}

class Dog extends Animal {
    // 方法重写：方法声明与父类完全一致，方法体改成子类需要的逻辑
    @Override
    public void eat() {
        System.out.println("狗吃骨头");
    }
}
```

### 11-06 继承中构造方法的特点

**知识点**
- 构造方法不能被继承，但子类构造方法中默认会先执行父类的构造方法
- 子类构造方法的第一行默认隐藏了一句 `super()`：先调用父类的空参构造，再执行子类构造自己的内容
- 原因：父类的属性要先初始化完成，子类才能安全地使用
- 如果父类没有空参构造（例如只写了有参构造），子类就必须在构造第一行手动用 `super(实参)` 调用父类的有参构造
- `super(...)` 和 `this(...)` 都必须写在构造方法的第一行，所以二者不能同时出现
- 分析技巧：看到“new 子类对象”，就先沿着 super 链条找到最顶层的父类构造开始执行，再一层层回到子类

**示例代码**
```java
// 文件名: ConstructorDemo.java
public class ConstructorDemo {
    public static void main(String[] args) {
        // 创建子类对象：先执行父类构造，再执行子类构造
        Student s1 = new Student();
        System.out.println("----------");
        // 子类有参构造通过 super(实参) 把父类属性交给父类构造赋值
        Student s2 = new Student("阿玮", 18);
        System.out.println(s2.getName() + "..." + s2.getAge());
    }
}

// 父类：手动写了有参构造，默认的空参构造就不存在了
class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
        System.out.println("父类的有参构造");
    }

    public String getName() { return name; }
    public int getAge() { return age; }
}

// 子类
class Student extends Person {
    public Student() {
        // 隐藏的 super() 会报错，因为父类没有空参构造
        // 所以必须手动调用父类的有参构造
        super("小黑", 20);
        System.out.println("子类的空参构造");
    }

    public Student(String name, int age) {
        super(name, age); // 必须写在第一行，借用父类构造给父类属性赋值
        System.out.println("子类的有参构造");
    }
}
```

### 11-07 带有继承结构的标准javabean类

**知识点**
- 标准 JavaBean 四件套：类名见名知意、成员变量私有化、空参构造 + 全参构造、每个属性配套 getter/setter
- 带继承结构时，父类和子类各自封装自己的属性：父类的属性在父类私有并提供 getter/setter，子类独有属性同样处理
- 子类全参构造的写法：父类部分的属性用 `super(父类属性值)` 交给父类构造，子类独有的属性用 `this.xxx = xxx` 自己赋值
- 子类空参构造中隐藏着 `super()`，会先执行父类的空参构造
- 模板书写顺序建议：成员变量 → 空参构造 → 全参构造 → getter/setter
- 使用方式：先 new 对象（空参 + set 逐个赋值，或全参构造一步到位），再通过 get 方法取值

**示例代码**
```java
// 文件名: Person.java
// 父类：标准 JavaBean
public class Person {
    private String name; // 姓名
    private int age;     // 年龄

    public Person() {
    }

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }
}
```
```java
// 文件名: Student.java
// 子类：标准 JavaBean，父类属性通过 super 传递
public class Student extends Person {
    private String studentId; // 子类独有属性：学号

    public Student() {
        // 隐藏着 super()，会先执行父类的空参构造
    }

    // 全参构造：父类属性交给 super，子类属性自己赋值
    public Student(String name, int age, String studentId) {
        super(name, age);
        this.studentId = studentId;
    }

    public String getStudentId() { return studentId; }
    public void setStudentId(String studentId) { this.studentId = studentId; }
}
```
```java
// 文件名: JavaBeanTest.java
public class JavaBeanTest {
    public static void main(String[] args) {
        // 方式一：空参构造 + set 逐个赋值
        Student s1 = new Student();
        s1.setName("阿玮");
        s1.setAge(18);
        s1.setStudentId("S001");
        System.out.println(s1.getName() + "..." + s1.getAge() + "..." + s1.getStudentId());

        // 方式二：全参构造一步到位
        Student s2 = new Student("小黑", 20, "S002");
        System.out.println(s2.getName() + "..." + s2.getAge() + "..." + s2.getStudentId());
    }
}
```

### 11-09 子类到底能继承父类的哪些内容？

**知识点**
- 构造方法：不能被继承。子类构造里只是默认调用了 `super()`，“调用”不等于“继承”
- 私有成员：子类实际上会继承（拥有），但因为 private 的限制无法直接访问，即“有但拿不到”，只能通过父类提供的公共 getter/setter 等方法间接使用
- 公有成员：完全继承，子类在任何地方都可以直接使用
- protected 成员：归属父类，但专门给子类开“绿色通道”，子类可以直接访问
- 记忆口诀：构造不继承；私有“有但拿不到”；公共和 protected 随意用
- 验证手段：可以用 javap 等反编译工具查看子类字节码，确认哪些成员真的属于子类

**示例代码**
```java
// 文件名: InheritScopeTest.java
public class InheritScopeTest {
    public static void main(String[] args) {
        Zi z = new Zi();
        z.publicMethod(); // 公有方法：直接继承使用
        z.usePrivate();   // 通过父类提供的公有方法，间接使用父类私有成员

        // z.money = 100;      // 编译报错：私有成员“有但拿不到”
        // z.privateMethod();  // 编译报错：私有方法同理

        new Zi(100); // 构造方法不能继承，只能由子类构造通过 super(...) 借用
    }
}

class Fu {
    private int money = 100; // 私有成员变量

    public void publicMethod() { // 公有成员
        System.out.println("公有方法");
    }

    private void privateMethod() { // 私有成员
        System.out.println("私有方法");
    }

    // 父类主动提供公有方法，让外界间接使用私有成员
    public void usePrivate() {
        System.out.println("父类私有money的值：" + money);
        privateMethod(); // 父类自己内部可以访问自己的私有成员
    }

    public Fu(int x) {
        System.out.println("父类有参构造：" + x);
    }
}

class Zi extends Fu {
    public Zi() {
        super(1); // 父类没有空参构造，必须手动调用有参构造
    }

    public Zi(int x) {
        super(x);
    }
}
```

### 11-10 Java中的权限修饰符

**知识点**
- 四种权限修饰符由小到大：private < 缺省（不写） < protected < public，范围越大越开放
- private：只有本类可以访问
- 缺省（什么都不写）：本类 + 同一个包中的其他类可以访问（也叫包权限）
- protected：本类 + 同一个包中的其他类 + 不同包中的子类可以访问
- public：任何位置都可以访问
- 实际开发经验：成员变量一般用 private，方法一般用 public，构造方法一般用 public；只想给子类用的成员用 protected
- 补充规则：修饰外部类时只能用 public 或缺省，不能写 private、protected

作用范围速记表：

| 修饰符 | 本类 | 同一个包中的其他类 | 不同包中的子类 | 不同包中的其他类 |
| --- | --- | --- | --- | --- |
| private | 可访问 | 不可访问 | 不可访问 | 不可访问 |
| 缺省 | 可访问 | 可访问 | 不可访问 | 不可访问 |
| protected | 可访问 | 可访问 | 可访问 | 不可访问 |
| public | 可访问 | 可访问 | 可访问 | 可访问 |

**示例代码**
```java
// 文件名: ModifierDemo.java
// 演示本类中四种权限修饰符的访问情况
public class ModifierDemo {
    private int a = 1;   // 私有：只有本类能用
    int b = 2;           // 缺省：本类 + 同一个包
    protected int c = 3; // 受保护：本类 + 同一个包 + 不同包的子类
    public int d = 4;    // 公有：任何位置都能用

    public void test() {
        // 本类内部：四种修饰的成员全部可以访问
        System.out.println(a);
        System.out.println(b);
        System.out.println(c);
        System.out.println(d);
    }
}
```
```java

    public static void main(String[] args) {
        ModifierDemo m = new ModifierDemo();
        // System.out.println(m.a); // 编译报错：private 只有本类能访问
        System.out.println(m.b); // 同一个包：缺省可以访问
        System.out.println(m.c); // 同一个包：protected 可以访问
```

### 11-11 什么是多态？

**知识点**
- 多态：同一种类型的对象，执行同一个行为时表现出不同的状态；代码层面就是“父类引用指向子类对象”
- 语法格式：`父类类型 变量名 = new 子类类型();`，例如 `Person p = new Student();`
- 多态的三个前提，缺一不可：① 有继承（或实现）关系 ② 有方法重写 ③ 父类引用指向子类对象
- 多态的好处：提高程序的扩展性和灵活性，配合“父类类型做方法参数”可以实现统一入口、多种行为
- 记忆口诀（针对成员方法）：编译看左边，运行看右边 —— 编译时检查父类中有没有这个方法，运行时执行子类重写后的逻辑
- 多态是继承、方法重写结合在一起的自然结果，是面向对象三大特征中最灵活的一个

**示例代码**
```java
// 文件名: PolymorphismDemo.java
public class PolymorphismDemo {
    public static void main(String[] args) {
        // 多态：父类引用指向子类对象
        Person p = new Student();
        p.sayHello(); // 编译看左边（Person 有 sayHello），运行看右边（执行 Student 重写的版本）

        p = new Teacher();
        p.sayHello(); // 同一个变量指向不同对象，行为不同 —— 这就是多态
    }
}

class Person {
    public void sayHello() {
        System.out.println("你好，我是人");
    }
}

class Student extends Person {
    @Override
    public void sayHello() {
        System.out.println("你好，我是学生，正在上课");
    }
}

class Teacher extends Person {
    @Override
    public void sayHello() {
        System.out.println("你好，我是老师，正在讲课");
    }
}
```

### 11-12 多态调用成员的特点和弊端以及解决方案

**知识点**
- 成员变量：编译看左边，运行看左边 —— 变量没有“运行看右边”一说；父类中没有该变量直接编译报错，父子同名变量取的是父类的值
- 成员方法：编译看左边，运行看右边 —— 编译检查父类是否有声明，运行执行子类重写后的方法体
- 弊端：多态下父类引用无法直接调用子类特有的方法，因为编译阶段只看父类，父类中没有就报错
- 解决方案：向下转型（强制类型转换）—— `子类类型 变量名 = (子类类型) 父类引用;`，转换后即可调用子类特有成员
- 强转有风险：如果对象的真实类型与目标类型不匹配，运行时会抛出 ClassCastException，所以强转前必须用 instanceof 判断
- instanceof 用法：`对象 instanceof 类型` 返回 boolean；JDK14+ 支持判断并转型一步到位：`if (p instanceof Student s) { s.xxx(); }`

**示例代码**
```java
// 文件名: PolyMemberDemo.java
public class PolyMemberDemo {
    public static void main(String[] args) {
        Person p = new Student();

        // 成员变量：编译看左边，运行看左边
        // System.out.println(p.score); // 编译报错：Person 中没有 score
        System.out.println(p.name); // 输出“父类Person的name”：变量永远取父类的

        // 成员方法：编译看左边，运行看右边
        p.show(); // 执行的是子类重写后的方法

        // 弊端演示：study 是子类特有方法，父类中没有，直接调用编译报错
        // p.study();

        // 解决方案：instanceof 判断 + 向下转型
        if (p instanceof Student) {
            Student s = (Student) p;
            s.study(); // 强转后即可调用子类特有方法
        }

        // JDK14+ 新写法：判断与转型一步到位
        if (p instanceof Student stu) {
            stu.study();
        }
    }
}

class Person {
    String name = "父类Person的name";

    public void show() {
        System.out.println("Person 的 show");
    }
}

class Student extends Person {
    String name = "子类Student的name"; // 与父类同名
    int score = 100;                  // 子类特有变量

    @Override
    public void show() {
        System.out.println("Student 重写后的 show");
    }

    // 子类特有方法
    public void study() {
        System.out.println("学生在学习");
    }
}
```

### 11-14 抽象类和抽象方法

**知识点**
- 抽象方法：用 `abstract` 修饰、没有方法体、直接以分号结束的方法，格式：`public abstract void eat();`
- 抽象类：含有抽象方法的类必须用 `abstract` 修饰，格式：`public abstract class 类名 {}`
- 抽象类不能创建对象（不能 new），它存在的意义就是被继承，由子类创建对象
- 子类继承抽象类后必须重写父类的全部抽象方法；如果不重写全部，子类自己也只能声明为抽象类
- 抽象类中可以有构造方法（供子类 `super()` 调用完成父类属性初始化）、成员变量和普通方法
- 意义：抽象类是“规则制定者”——强制要求子类必须具备哪些行为，同时把共性代码抽取出来复用

**示例代码**
```java
// 文件名: AbstractDemo.java
public class AbstractDemo {
    public static void main(String[] args) {
        // Animal a = new Animal(); // 编译报错：抽象类不能创建对象

        Animal a = new Cat("汤姆"); // 多态：父类引用指向子类对象
        a.eat();   // 运行看右边，执行子类重写的方法
        a.sleep(); // 调用抽象类中的普通方法
    }
}

// 抽象类：含抽象方法的类必须用 abstract 修饰
abstract class Animal {
    private String name;

    // 抽象类可以有构造方法，供子类 super() 调用
    public Animal() {
    }

    public Animal(String name) {
        this.name = name;
    }

    public String getName() { return name; }

    // 抽象方法：没有方法体，只定规则，强制子类重写
    public abstract void eat();

    // 抽象类中也可以写普通方法，给子类直接复用
    public void sleep() {
        System.out.println(getName() + "在睡觉");
    }
}

// 子类：必须重写父类的全部抽象方法
class Cat extends Animal {
    public Cat() {
    }

    public Cat(String name) {
        super(name);
    }

    @Override
    public void eat() {
        System.out.println(getName() + "吃鱼");
    }
}
```

### 11-15 接口和接口中的成员？

**知识点**
- 接口用 `interface` 定义：`public interface 接口名 {}`；实现用 `implements`：`public class 类名 implements 接口名 {}`
- 接口是一种行为的抽象规范，代表“某种能力/规则”；类实现接口表示它具备这种能力
- JDK7 前（含 JDK7）接口中只有两种成员：常量（默认 public static final，可省略不写）和抽象方法（默认 public abstract，可省略不写）
- 接口不能创建对象（不能 new），接口也没有构造方法，必须通过实现类来使用
- 实现类必须重写接口中的全部抽象方法；如果不想重写全部，实现类只能声明为抽象类
- 一个类可以实现多个接口（用逗号隔开），也可以在继承一个父类的同时实现接口，写法顺序：extends 在前，implements 在后

**示例代码**
```java
// 文件名: Swim.java
// 接口：定义“会游泳”这个规则
public interface Swim {
    // 常量：public static final 可省略不写
```

### 11-17 接口在JDK8和9的新特性

**知识点**
- JDK8 之前接口只能是“常量 + 抽象方法”；从 JDK8 开始，接口中还可以定义默认方法和静态方法
- 默认方法：`public default 返回值类型 方法名() {}`，实现类可以选择重写，也可以不重写直接继承使用
- 默认方法的意义：给接口“打补丁”，向已经写好的接口新增方法时，不强制所有实现类都去重写
- 静态方法：`public static 返回值类型 方法名() {}`，只能用 `接口名.方法名()` 调用，不能用实现类对象调用
- JDK9 开始接口可以有私有方法：普通私有方法 `private xxx()` 给默认方法复用代码；静态私有方法 `private static xxx()` 给静态方法复用代码
- 记忆总结：默认方法实现类可重写可不重写；静态方法只能接口名调用；私有方法是接口内部“自己人”用的，外界访问不到

**示例代码**
```java
// 文件名: Inter.java
// 演示 JDK8 / JDK9 接口新特性
public interface Inter {
    // 抽象方法：实现类必须重写
    void abstractMethod();

    // JDK8：默认方法，实现类可重写也可不重写
    public default void defaultMethod() {
        System.out.println("接口的默认方法");
        show(); // JDK9 私有方法：给默认方法复用
    }

    // JDK8：静态方法，只能通过 接口名.方法名 调用
    public static void staticMethod() {
        System.out.println("接口的静态方法");
        staticShow(); // JDK9 静态私有方法：给静态方法复用
    }

    // JDK9：普通私有方法，供默认方法复用重复代码
    private void show() {
        System.out.println("接口的私有方法");
    }

    // JDK9：静态私有方法，供静态方法复用重复代码
    private static void staticShow() {
        System.out.println("接口的静态私有方法");
    }
}
```
```java

    @Override
    public void abstractMethod() {
        System.out.println("实现类重写抽象方法");
    }

    // 默认方法可以不重写直接用；需要改造时也可以重写，写法如下：
    // @Override
    // public void defaultMethod() {
    //     System.out.println("实现类重写后的默认方法");
    // }
}
```
```java

    public static void main(String[] args) {
        Inter i = new InterImpl();
        i.abstractMethod(); // 抽象方法：执行实现类重写的版本
        i.defaultMethod();  // 默认方法：实现类没重写，直接使用接口里的默认实现

        // 静态方法只能用接口名调用；写成 i.staticMethod() 会编译报错
```

### 11-18 内部类

**知识点**
- 内部类：定义在另一个类里面的类；外面的类叫外部类，里面的类叫内部类
- 内部类的分类：成员内部类（写在成员位置，又分为非静态成员内部类和静态内部类）、局部内部类（写在方法里面）、匿名内部类（特殊的局部内部类）
- 内部类的核心特点：可以直接访问外部类的所有成员，包括私有成员
- 反过来，外部类想访问内部类的成员，必须先创建内部类对象，通过对象去访问
- 好处：把“只跟外部类配合的逻辑”隐藏在外部类内部，封装性更好，也避免污染包结构
- 本课先建立整体概念框架，后面课程再分别细讲成员内部类、静态内部类与匿名内部类

**示例代码**
```java
// 文件名: Outer.java
// 外部类
public class Outer {
    private int num = 10; // 外部类私有成员

    // 成员内部类：定义在外部类的成员位置
    public class Inner {
        public void show() {
            // 内部类可以直接访问外部类的成员，包括私有的
            System.out.println("内部类访问外部类私有变量 num：" + num);
        }
    }

    // 外部类方法：访问内部类成员，必须先创建内部类对象
    public void method() {
        Inner i = new Inner();
        i.show();
    }
}
```
```java
// 文件名: InnerClassDemo.java

    public static void main(String[] args) {
        Outer o = new Outer();
        o.method(); // 通过外部类的方法间接使用内部类

        // 测试类中也可以直接创建内部类对象（格式后面课程细讲）
        Outer.Inner i = new Outer().new Inner();
        i.show();
    }
}
```

### 11-19 成员内部类

**知识点**
- 非静态成员内部类：定义在外部类的成员位置、不加 static 修饰的类，它是外部类对象的一部分
- 访问规则：内部类访问外部类成员直接访问（含私有）；外部类访问内部类成员必须创建内部类对象
- 在测试类中创建非静态成员内部类对象的格式：`外部类名.内部类名 对象名 = new 外部类名().new 内部类名();`
- 内部类本质也是类，可以被四种权限修饰符修饰（private、缺省、protected、public 都可以）
- 如果内部类被 private 修饰，外界无法直接创建其对象，只能通过外部类提供的公有方法间接使用
- 版本注意：JDK16 之前内部类中不能定义静态变量（final 常量除外），JDK16 及以后才允许内部类定义静态成员

**示例代码**
```java
// 文件名: Outer.java
public class Outer {
    private int num = 10;           // 外部类私有成员
    private Inner in = new Inner(); // 外部类的成员：内部类对象

    // 非静态成员内部类
    public class Inner {
        public void show() {
            // 直接访问外部类的私有成员
            System.out.println("内部类访问外部类私有变量：" + num);
        }
    }

    // 外部类公有方法：把内部类的功能对外暴露
    public void useInner() {
        System.out.println("外部类使用内部类对象：");
        in.show(); // 内部类对象已经是外部类的成员，直接使用
    }
}
```
```java
// 文件名: MemberInnerTest.java
public class MemberInnerTest {
    public static void main(String[] args) {
        // 创建内部类对象的格式：new 外部类名().new 内部类名()
        Outer.Inner oi = new Outer().new Inner();
        oi.show();

        // 通过外部类方法间接使用内部类
        new Outer().useInner();
    }
}
```

### 11-20 静态内部类和匿名内部类

**知识点**
- 静态内部类：写在成员位置上并用 static 修饰的类，属于外部类本身，随外部类加载
- 静态内部类访问外部类的限制：只能访问外部类的静态成员，因为非静态成员属于对象，而静态内部类创建时可能还没有外部类对象
- 创建静态内部类对象的格式：`外部类名.内部类名 对象名 = new 外部类名.内部类名();`（注意中间没有 new 外部类）
- 匿名内部类：没有名字的特殊局部内部类，本质是一个“继承了该父类 / 实现了该接口”的子类对象
- 匿名内部类的三种使用场景：① 继承父类重写方法 ② 实现接口重写方法 ③ 作为方法参数直接传递
- 匿名内部类基本格式：`new 类名/接口名() { 重写方法 }`，适合只需要使用一次的场合，用完即弃

**示例代码**
```java
// 文件名: Outer.java
public class Outer {
    static int staticNum = 10; // 外部类静态成员
    int num = 20;              // 外部类非静态成员

    // 静态内部类
    static class Inner {
        public void show() {
            // 只能访问外部类的静态成员；访问 num 会编译报错
            System.out.println("访问外部类静态变量：" + staticNum);
        }
    }
}
```
```java
// 文件名: AnonymousDemo.java
public class AnonymousDemo {
    public static void main(String[] args) {
        // 静态内部类对象的创建：new 外部类名.内部类名()
        Outer.Inner oi = new Outer.Inner();
        oi.show();

        // 匿名内部类场景一：继承父类，重写方法
        Animal a = new Animal() {
            @Override
            public void eat() {
                System.out.println("匿名子类对象：狗吃骨头");
            }
        };
        a.eat();

        // 匿名内部类场景二：实现接口，重写方法
        Swim s = new Swim() {
            @Override
            public void swim() {
                System.out.println("匿名实现类对象：正在游泳");
            }
        };
        s.swim();

        // 匿名内部类场景三：作为方法参数直接传递
        go(new Swim() {
            @Override
            public void swim() {
                System.out.println("匿名对象作为参数：参加游泳比赛");
            }
        });
    }

    // 参数是接口类型：只要能实现该接口的对象都能传进来
    public static void go(Swim s) {
        System.out.println("比赛开始：");
        s.swim();
    }
}

// 父类
class Animal {
    public void eat() {
        System.out.println("吃东西");
    }
}

// 接口
interface Swim {
    void swim();
}
```

### 11-21 匿名内部类

**知识点**
- 匿名内部类格式：`new 父类名/接口名() { 方法重写 }`，整体是一个表达式，最后必须以分号结束
- 本质：一个匿名的子类/实现类对象 —— new 的瞬间类被定义、对象被创建；“类没有名字，对象有引用”
- 使用时机：某个类只需要使用一次时用匿名内部类最省事；如果需要反复使用，应该老老实实定义独立的实现类
- 接口作为方法参数时，可以在调用处直接传匿名内部类对象，这是开发中最常见的用法（如回调、监听器场景）
- 匿名内部类可以直接访问所在方法中的局部变量（JDK8 起该变量默认是事实最终变量，不能被修改）
- 使用建议：匿名内部类内部代码不宜过长；逻辑复杂时应抽取成独立类，保证可读性

**示例代码**

```java
        s.swim();

        // 三、接口作为方法参数：调用处直接传匿名内部类对象
        start(new Swim() {
            @Override
            public void swim() {
                System.out.println("蛙泳，速度 1.5 米/秒");
            }
        });
    }

    // 方法形参是接口类型：调用时必须传入“接口实现类对象”
    // 匿名内部类就是最省事的实现类对象
    public static void start(Swim s) {
        System.out.println("游泳比赛开始：");
        s.swim();
    }
}
```

**课后练习**
1. 用匿名内部类的两种方式分别“继承抽象类 Bird（抽象方法 fly()）”和“实现接口 Flyable（方法 fly()）”，各创建对象并调用重写后的方法。
2. 编写方法 `public static void calc(Compute c, int a, int b)`（接口 Compute 含方法 getResult(int a, int b)），在调用处用匿名内部类分别传入“求和”和“求乘积”两种实现并打印结果。
3. 对比“每次调用都重新 new 一个匿名内部类对象”和“先用引用变量把匿名对象保存起来再多次调用”两种写法，用文字说明各自适合的场景。

### 综合题：支付渠道体系

**场景**

设计一套支付渠道：抽象类定义公共流程，接口定义可插拔的支付能力，子类实现微信、支付宝、银行卡三种渠道，再用多态统一调用、用内部类做回调。

**任务**
1. 定义抽象类 AbstractPayChannel，含 final 的 pay(long amount) 模板方法（先校验再扣款再打印回执），以及抽象方法 doPay(long amount)。
2. 定义接口 Refundable 含 refund(long amount)，让微信与银行卡实现、支付宝不实现，用 instanceof 判断并处理不可退款的情况。
3. 用父类引用指向三种子类，放进数组遍历调用 pay，验证多态调用的是子类重写的方法而不是父类。
4. 用匿名内部类实现 PayCallback 接口作为支付完成回调，在 pay 结束后触发并打印结果。

**验收清单**

- [ ] 对不支持的渠道调用退款时给出友好提示，不抛 ClassCastException。
- [ ] 匿名内部类能访问并打印外部方法的局部变量。
