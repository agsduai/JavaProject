# 第83章 营销活动与促销引擎设计

营销是电商里最容易被低估的一块：看起来只是「打个折、发张券」，真做起来要同时管住价格算得对、优惠不叠加错、库存不超卖、预算不超发、黄牛刷不走。一次大促的价格链路要经过六七个阶段，任何一个阶段顺序错了、取整错了、并发扣减写错了，最后都是真金白银的资损和客诉。本章按「营销系统全景与价格链路 → 四类优惠的算法与取整 → 叠加互斥与最优组合 → 价格分摊与退款分摊 → 券状态机与并发核销 → 库存扣减与防超卖 → 限购与防刷 → 活动时间窗口与时区 → 预算控制与熔断 → 营销归因与增量 ROI → 大促券全链路案例」的顺序讲。所有示例仍是纯 JDK：价格链路顺序敏感性、四种优惠的精确取整、穷举求最优券组合与贪心反例、最大余额法分摊与守恒校验、券状态机非法迁移拒绝、CAS 扣减防超卖与分段库存、用户/设备双维度限购与幂等、时区导致的提前开抢、预扣预算与超发复现、增量 ROI 与表面 ROI 的差距全部真实运行。

### 83-01 营销系统全景与价格链路

**知识点**
- **一笔订单的价格不是「原价减优惠」，而是一条链路**：**原价小计 → 单品折扣 → 满减 → 券 → 积分抵扣 → 运费 → 应付**，**每一步都要落库留痕**，否则财务对不上账、客诉说不清。
- **只有「乘法型」和「减法型」的相对顺序会改变结果**：折扣是乘法、满减/券是减法，**先乘后减比先减后乘更便宜**（乘法作用在更大的基数上）；**两个减法之间可交换**，谁先谁后都一样。
- **门槛必须钉死在「原价小计」上**：如果用「减完之后的金额」判门槛，**一笔折扣就会把订单打下门槛，后面的满减直接失效**，这是最容易被漏掉的资损点。
- **取整位置决定谁吃亏**：**按行取整**每行都可能多进 1 分，行数越多偏差越大；**整单取整**只有一次误差。**规则要写死并公示**，不能让不同服务各自四舍五入。
- **运费与积分是链路的最后两环**：**包邮门槛通常按「优惠后金额」判**，而**积分抵扣一般有上限（如应付的 50%）**，两处都能被刷。
- 易错点：把价格计算散落在订单、结算、支付三个服务里各算一遍；折扣用 double 累加出现 0.01 误差；优惠后金额为负却直接落库。

**示例代码**
```java
import java.util.ArrayList;
import java.util.List;

public class PriceChain {
    record Item(String sku, long unitFen, int qty) {
        long subtotal() {
            return unitFen * qty;
        }
    }

    // 链路的每一环都留痕：财务对账要能从应付一路回放到原价
    record Stage(String name, long deltaFen, long amountFen) {
    }

    static String yuan(long fen) {
        return String.format("%.2f", fen / 100.0);
    }

    // 折扣按「分」四舍五入：permille=900 表示 9 折
    static long discount(long fen, int permille) {
        return Math.round(fen * permille / 1000.0);
    }

    static void print(String title, List<Stage> stages) {
        System.out.println(title);
        for (Stage s : stages) {
            String d = s.deltaFen() == 0 ? "  " : (s.deltaFen() > 0 ? "+" : "-");
            System.out.printf("  %-22s %s%8s  -> %10s%n", s.name(), d,
                    yuan(Math.abs(s.deltaFen())), yuan(s.amountFen()));
        }
    }

    static long subtotal(List<Item> items) {
        long s = 0;
        for (Item it : items) {
            s += it.subtotal();
        }
        return s;
    }

    // 顺序一：先折扣，后满减，再券，最后积分
    static List<Stage> discountFirst(List<Item> items) {
        List<Stage> st = new ArrayList<>();
        long base = subtotal(items);
        st.add(new Stage("原价小计", 0, base));

        long afterDiscount = discount(base, 900);
        st.add(new Stage("9 折", afterDiscount - base, afterDiscount));

        long afterReduce = afterDiscount >= 40000 ? afterDiscount - 5000 : afterDiscount;
        st.add(new Stage("满 400 减 50", afterReduce - afterDiscount, afterReduce));

        long afterCoupon = afterReduce >= 30000 ? afterReduce - 3000 : afterReduce;
        st.add(new Stage("券 满 300 减 30", afterCoupon - afterReduce, afterCoupon));

        long afterPoints = Math.max(0, afterCoupon - 1000);
        st.add(new Stage("积分抵扣 1000 分", afterPoints - afterCoupon, afterPoints));

        long shipping = afterPoints >= 9900 ? 0 : 800;
        st.add(new Stage("运费（满 99 包邮）", shipping, afterPoints + shipping));
        return st;
    }

    // 顺序二：先满减，后折扣，再券，最后积分
    static List<Stage> reduceFirst(List<Item> items) {
        List<Stage> st = new ArrayList<>();
        long base = subtotal(items);
        st.add(new Stage("原价小计", 0, base));

        long afterReduce = base >= 40000 ? base - 5000 : base;
        st.add(new Stage("满 400 减 50", afterReduce - base, afterReduce));

        long afterDiscount = discount(afterReduce, 900);
        st.add(new Stage("9 折", afterDiscount - afterReduce, afterDiscount));

        long afterCoupon = afterDiscount >= 30000 ? afterDiscount - 3000 : afterDiscount;
        st.add(new Stage("券 满 300 减 30", afterCoupon - afterDiscount, afterCoupon));

        long afterPoints = Math.max(0, afterCoupon - 1000);
        st.add(new Stage("积分抵扣 1000 分", afterPoints - afterCoupon, afterPoints));

        long shipping = afterPoints >= 9900 ? 0 : 800;
        st.add(new Stage("运费（满 99 包邮）", shipping, afterPoints + shipping));
        return st;
    }

    static long payable(List<Stage> st) {
        return st.get(st.size() - 1).amountFen();
    }

    public static void main(String[] args) {
        List<Item> items = new ArrayList<>();
        items.add(new Item("SKU-A", 19900, 2));
        items.add(new Item("SKU-B", 8990, 1));

        System.out.println("【1. 一笔订单的完整价格链路】");
        for (Item it : items) {
            System.out.printf("  行 %-6s %8s x %d = %8s%n",
                    it.sku(), yuan(it.unitFen()), it.qty(), yuan(it.subtotal()));
        }
        print("  顺序A：折扣 -> 满减 -> 券 -> 积分", discountFirst(items));
        print("  顺序B：满减 -> 折扣 -> 券 -> 积分", reduceFirst(items));

        long a = payable(discountFirst(items));
        long b = payable(reduceFirst(items));
        System.out.printf("%n【2. 顺序敏感性】顺序A 应付 %s，顺序B 应付 %s，差 %s 元%n",
                yuan(a), yuan(b), yuan(Math.abs(a - b)));
        System.out.println("  原因：折扣是乘法、满减是减法，先乘后减让乘法作用在更大的基数上，所以更便宜。");
        System.out.println("  注意两个减法之间可交换：满减与券互换顺序，应付完全不变。");

        System.out.println();
        System.out.println("【3. 两个减法型优惠互换顺序】");
        long x = 43911 - 5000 - 3000;
        long y = 43911 - 3000 - 5000;
        System.out.printf("  满减先：%s    券先：%s    差 %d 分%n", yuan(x), yuan(y), Math.abs(x - y));

        System.out.println();
        System.out.println("【4. 按行取整 vs 整单取整（8 折，每行 10.01 元）】");
        long unit = 1001;
        for (int rows : new int[]{3, 10, 30}) {
            long perRow = 0;
            for (int i = 0; i < rows; i++) {
                perRow += discount(unit, 800);
            }
            long whole = discount(unit * rows, 800);
            System.out.printf("  %2d 行：按行合计 %8s  整单 %8s  差 %3d 分%n",
                    rows, yuan(perRow), yuan(whole), perRow - whole);
        }
        System.out.println("  行数越多，按行取整多进的分越多；所以分摊必须用「总额守恒」的算法，而不是各行独立取整。");

        System.out.println();
        System.out.println("【5. 门槛必须钉在原价上】");
        long base = 30000;
        long afterDiscount = discount(base, 880);
        System.out.printf("  原价 %s，先打 88 折 -> %s%n", yuan(base), yuan(afterDiscount));
        System.out.println("  若用「折扣后金额」判「满 300 减 70」：" + (afterDiscount >= 30000 ? "仍命中" : "不命中，满减直接失效"));
        System.out.printf("  用「原价」判：命中，减 70 后应付 %s%n", yuan(afterDiscount - 7000));
    }
}
```

### 83-02 四类优惠的算法与取整

**知识点**
- **满减**：**达到门槛就减固定金额，多档取最高可命中档**——**门槛按原价小计判，不按件数**，**多档之间是「取最优」不是「累加」**。
- **阶梯优惠**：**按件数或金额分档**（满 2 件 9 折、满 3 件 85 折）——**档位要连续可算**，**不能出现「买 4 件比买 3 件还贵」的断档**。
- **折扣（带上限）**：**按比例减，但必须封顶**——**不封顶的折扣在大额订单上会直接击穿毛利**，**封顶值要与预算联动**。
- **立减**：**每件减固定额或整单减固定额**——**最容易做，也最容易被刷**（凑单后整单退），**必须配合限购与退款回收**。
- **三种取整方式的差异只在小数位上，但方向不同**：**四舍五入**对用户友好、**向下取整**对商家有利、**银行家舍入（四舍六入五成双）**在大量结算时偏差最小——**同一系统内只能选一种**。
- 易错点：用 `double` 存金额导致 0.1+0.2 类误差；折扣上限按「优惠额」封顶却忘了同步改分摊；阶梯档位写成 `if` 链漏了等于号，恰好 3 件时不打折。

**示例代码**
```java
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.ArrayList;
import java.util.List;

public class DiscountRounding {
    record Cart(long subtotalFen, int qty) {
    }

    // 满减：多档取「最高可命中档」，不是逐档累加
    record Tier(long thresholdFen, long reduceFen) {
    }

    static long fullReduce(long subtotal, List<Tier> tiers) {
        long best = 0;
        for (Tier t : tiers) {
            if (subtotal >= t.thresholdFen()) {
                best = Math.max(best, t.reduceFen());
            }
        }
        return best;
    }

    // 阶梯：按件数分档，档位必须单调，不能出现断档
    static int ladderPermille(int qty) {
        if (qty >= 5) {
            return 800;
        }
        if (qty >= 3) {
            return 850;
        }
        if (qty >= 2) {
            return 900;
        }
        return 1000;
    }

    // 折扣带上限：先按比例算，再与上限取小
    static long discountWithCap(long subtotal, int permille, long capFen) {
        long raw = Math.round(subtotal * permille / 1000.0);
        long cut = subtotal - raw;
        return Math.min(cut, capFen);
    }

    static long halfUp(double v) {
        return Math.round(v);
    }

    static long floor(double v) {
        return (long) Math.floor(v);
    }

    static long banker(double v) {
        return BigDecimal.valueOf(v).setScale(0, RoundingMode.HALF_EVEN).longValue();
    }

    static String yuan(long fen) {
        return String.format("%.2f", fen / 100.0);
    }

    public static void main(String[] args) {
        List<Tier> tiers = new ArrayList<>();
        tiers.add(new Tier(30000, 5000));
        tiers.add(new Tier(50000, 10000));
        tiers.add(new Tier(80000, 18000));

        System.out.println("【1. 满减：多档取最优，不是累加】");
        for (long s : new long[]{29999, 30000, 49999, 50000, 80000, 120000}) {
            System.out.printf("  原价 %9s  ->  减 %7s  ->  应付 %9s%n",
                    yuan(s), yuan(fullReduce(s, tiers)), yuan(s - fullReduce(s, tiers)));
        }
        System.out.println("  500 元订单命中「满 500 减 100」，不会同时叠加「满 300 减 50」。");

        System.out.println();
        System.out.println("【2. 阶梯：按件数分档，档位要单调】");
        long unit = 9900;
        for (int q = 1; q <= 6; q++) {
            int pm = ladderPermille(q);
            long total = Math.round(unit * q * pm / 1000.0);
            System.out.printf("  %d 件  折扣 %3d‰  应付 %9s  折合单价 %7s%n",
                    q, pm, yuan(total), yuan(total / q));
        }
        System.out.println("  折合单价随件数单调下降，说明档位没有断档。");

        System.out.println();
        System.out.println("【3. 折扣带上限：不封顶会击穿毛利】");
        for (long s : new long[]{10000, 50000, 100000, 500000}) {
            long noCap = s - Math.round(s * 900 / 1000.0);
            long capped = discountWithCap(s, 900, 10000);
            System.out.printf("  原价 %9s  不封顶减 %8s  封顶 100 元减 %8s  差额 %9s%n",
                    yuan(s), yuan(noCap), yuan(capped), yuan(noCap - capped));
        }

        System.out.println();
        System.out.println("【4. 三种取整方式：只在恰好 .5 上分歧】");
        System.out.printf("  %-10s %-10s %-10s %-10s %s%n", "金额(分)", "半值", "四舍五入", "银行家", "两者是否不同");
        for (long fen : new long[]{1001, 1002, 1003, 1005, 1007}) {
            double v = fen * 0.5;
            long h = halfUp(v);
            long b = banker(v);
            System.out.printf("  %-10d %-10s %-10d %-10d %s%n",
                    fen, String.format("%.1f", v), h, b, h != b ? "是" : "否");
        }
        System.out.println("  恰好 .5 才分歧：500.5 向上进成 501，银行家进成 500（取偶）；501.5 两者都是 502。");
        System.out.println("  向下取整则不参与比较：它永远比四舍五入少，是商家有利、用户吃亏的单边规则。");

        long hSum = 0;
        long bSum = 0;
        for (long fen = 1; fen <= 200; fen++) {
            hSum += halfUp(fen * 0.5);
            bSum += banker(fen * 0.5);
        }
        System.out.printf("  1~200 分各取一半：四舍五入合计 %d 分，银行家合计 %d 分，差 %d 分%n",
                hSum, bSum, hSum - bSum);
        System.out.println("  银行家把「逢 5 必进」的系统性偏差抵掉一半，大量结算时总额更接近真实值。");

        System.out.println();
        System.out.println("【5. 四类优惠各算一遍：同一笔 600 元 3 件的订单】");
        long s = 60000;
        int q = 3;
        System.out.printf("  满减（满 500 减 100）      -%s%n", yuan(fullReduce(s, tiers)));
        System.out.printf("  阶梯（3 件 85 折）         -%s%n", yuan(s - Math.round(s * ladderPermille(q) / 1000.0)));
        System.out.printf("  折扣（9 折上限 100 元）    -%s%n", yuan(discountWithCap(s, 900, 10000)));
        System.out.printf("  立减（整单减 20 元）       -%s%n", yuan(2000));
    }
}
```

### 83-03 叠加互斥与最优组合

**知识点**
- **券不是「越多越便宜」，而是「有约束的组合优化」**：**互斥组（同组只能选一张）+ 门槛（原价判定）+ 叠加顺序**，三者一起决定最终优惠。
- **互斥要按「组」而不是按「张」**：**全场券与品类券常常同组互斥**，**但运费券、积分、会员折扣通常是独立维度**，混在一起配就会出现「两张券同时生效」。
- **贪心按面额选券会算贵**：**面额大的券可能门槛高、可能挤掉了能叠加的折扣**，**正确做法是小规模穷举（券数 ≤ 5 时 2^n × n! 完全可算）**。
- **折扣券与满减券的顺序必须固定**：**折扣先做**，满减作用在更小的金额上、优惠更少；**满减先做**，折扣作用在更小的金额上、优惠也更少——**两种都亏，所以要把「门槛按原价、顺序按规则」写死，再穷举选最优**。
- **最优解要能解释给运营**：**输出「选了哪几张、按什么顺序、省了多少」**，而不是只给一个数字；**运营要能看懂为什么没选那张面额更大的券**。
- 易错点：只判门槛不判互斥（两张同组券同时生效）；用贪心代替穷举且没验证差额；券数超过 8 还硬穷举（组合爆炸，要换整数规划或剪枝）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.List;

public class CouponCombination {
    // permille=0 表示减法券；permille>0 表示折扣券（带封顶）
    record Coupon(String id, String group, long thresholdFen, long reduceFen,
                  int permille, long capFen) {
        boolean isDiscount() {
            return permille > 0;
        }

        // 面额：减法券就是固定额，折扣券按原价折算（只用于贪心排序）
        long face(long subtotal) {
            if (!isDiscount()) {
                return reduceFen;
            }
            long cut = subtotal - Math.round(subtotal * permille / 1000.0);
            return Math.min(cut, capFen);
        }
    }

    static String yuan(long fen) {
        return String.format("%.2f", fen / 100.0);
    }

    // 按给定顺序求优惠额；门槛一律按「原价小计」判，这是关键约定
    static long apply(List<Coupon> order, long subtotal) {
        long amount = subtotal;
        long saved = 0;
        for (Coupon c : order) {
            if (subtotal < c.thresholdFen()) {
                continue;                       // 门槛不满足，这张券作废
            }
            long cut;
            if (c.isDiscount()) {
                cut = Math.min(amount - Math.round(amount * c.permille() / 1000.0), c.capFen());
            } else {
                cut = Math.min(c.reduceFen(), amount);
            }
            cut = Math.max(cut, 0);
            amount -= cut;
            saved += cut;
        }
        return saved;
    }

    // 互斥校验：同一 group 最多出现一张
    static boolean exclusiveOk(List<Coupon> picked) {
        List<String> groups = new ArrayList<>();
        for (Coupon c : picked) {
            if (c.group() == null || c.group().isEmpty()) {
                continue;
            }
            if (groups.contains(c.group())) {
                return false;
            }
            groups.add(c.group());
        }
        return true;
    }

    // 穷举：所有子集 x 所有顺序，取最大优惠
    static long best(List<Coupon> all, long subtotal, List<Coupon> bestOrder) {
        int n = all.size();
        long max = 0;
        for (int mask = 0; mask < (1 << n); mask++) {
            List<Coupon> picked = new ArrayList<>();
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) {
                    picked.add(all.get(i));
                }
            }
            if (!exclusiveOk(picked)) {
                continue;
            }
            for (List<Coupon> perm : permutations(picked)) {
                long saved = apply(perm, subtotal);
                if (saved > max) {
                    max = saved;
                    bestOrder.clear();
                    bestOrder.addAll(perm);
                }
            }
        }
        return max;
    }

    static List<List<Coupon>> permutations(List<Coupon> list) {
        List<List<Coupon>> out = new ArrayList<>();
        if (list.isEmpty()) {
            out.add(new ArrayList<>());
            return out;
        }
        for (int i = 0; i < list.size(); i++) {
            Coupon head = list.get(i);
            List<Coupon> rest = new ArrayList<>(list);
            rest.remove(i);
            for (List<Coupon> p : permutations(rest)) {
                List<Coupon> one = new ArrayList<>();
                one.add(head);
                one.addAll(p);
                out.add(one);
            }
        }
        return out;
    }

    static String ids(List<Coupon> list) {
        StringBuilder sb = new StringBuilder();
        for (Coupon c : list) {
            if (sb.length() > 0) {
                sb.append(" -> ");
            }
            sb.append(c.id());
        }
        return sb.length() == 0 ? "（不用券）" : sb.toString();
    }

    public static void main(String[] args) {
        List<Coupon> all = new ArrayList<>();
        all.add(new Coupon("C1 满200减40", "A", 20000, 4000, 0, 0));

                    c.id(), c.group() == null ? "-" : c.group(),

        System.out.printf("  优惠 %s 元，应付 %s 元%n", yuan(bestSaved), yuan(subtotal - bestSaved));

        System.out.println();
        System.out.println("【3. 贪心按面额从大到小 + 固定顺序，会算贵】");
        List<Coupon> sorted = new ArrayList<>(all);

        System.out.printf("  与最优差 %s 元：面额最大的券先做减法，把折扣的基数压小了%n",
                yuan(bestSaved - greedySaved));

        long onlyC1 = apply(List.of(all.get(0)), subtotal);
```

### 83-04 价格分摊与退款分摊

**知识点**
- **分摊是「把整单优惠拆到行」的过程，目的是让退款能按行算**：**用户退一件时，退的钱必须等于「这一行的实付」**，而不是「原价按比例估算」。
- **各行独立四舍五入必然不守恒**：**每行都进 1 分，行数一多，分摊之和就大于优惠总额**，财务立刻对不上——**必须用「最大余额法」：先按比例取整，再把余下的分按小数部分从大到小补齐**。
- **最大余额法的三个性质**：**总额严格守恒**、**每行误差 < 1 分**、**分摊额不超过该行金额**（否则会出现负数行）。
- **退款分摊要用「原分摊额」而不是「重新按比例算」**：**订单退掉一行后，剩余行的分摊额不能变**，否则「先退 A 再退 B」和「一起退」退的钱不一样，用户会来吵架。
- **运费也要分摊**：**包邮订单退到不满足包邮门槛时，要扣回运费**——**运费分摊按行金额比例，扣回时按同样的比例扣**，两边口径必须一致。
- 易错点：分摊用 `double` 累加导致总额差几分；退部分行时重新分摊；优惠金额大于某行金额导致该行为负；运费分摊与优惠分摊用了不同算法。

**示例代码**
```java
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

public class PriceAllocation {
    record Line(String sku, long amountFen) {
    }

    // 分摊结果要带「余数」，排序补齐时才知道给谁
    record Alloc(int idx, long baseFen, long rem, long finalFen) {
    }

    static String yuan(long fen) {
        return String.format("%.2f", fen / 100.0);
    }

    // 朴素做法：每行独立四舍五入，不保证守恒
    static List<Long> naive(List<Line> lines, long total) {
        long sum = 0;
        for (Line l : lines) {
            sum += l.amountFen();
        }
        List<Long> out = new ArrayList<>();
        for (Line l : lines) {
            out.add(Math.round(total * l.amountFen() / (double) sum));
        }
        return out;
    }

    // 最大余额法：先取整，再把剩余的分按小数部分从大到小补齐
    static List<Alloc> largestRemainder(List<Line> lines, long total) {
        long sum = 0;
        for (Line l : lines) {
            sum += l.amountFen();
        }
        List<Alloc> out = new ArrayList<>();
        long given = 0;
        for (int i = 0; i < lines.size(); i++) {
            long num = total * lines.get(i).amountFen();
            long base = num / sum;
            long rem = num % sum;
            out.add(new Alloc(i, base, rem, base));
            given += base;
        }
        long left = total - given;
        // 余数大的先补；余数相同时按行号，保证结果可复现
        List<Alloc> byRem = new ArrayList<>(out);
        byRem.sort(Comparator.comparingLong(Alloc::rem).reversed()
                .thenComparingInt(Alloc::idx));
        for (int i = 0; i < left; i++) {
            Alloc a = byRem.get(i);
            out.set(a.idx(), new Alloc(a.idx(), a.baseFen(), a.rem(), a.finalFen() + 1));
        }
        return out;
    }

    public static void main(String[] args) {
        List<Line> lines = new ArrayList<>();
        lines.add(new Line("SKU-A", 43900));
        lines.add(new Line("SKU-B", 12900));
        lines.add(new Line("SKU-C", 8800));
        long subtotal = 0;
        for (Line l : lines) {
            subtotal += l.amountFen();
        }
        long discount = 10000;

        System.out.printf("【1. 订单原价 %s 元，优惠 %s 元，分摊到 3 行】%n",
                yuan(subtotal), yuan(discount));
        for (Line l : lines) {
            System.out.printf("  %-6s 原价 %9s  占比 %6.2f%%%n",
                    l.sku(), yuan(l.amountFen()), l.amountFen() * 100.0 / subtotal);
        }

        List<Long> naiveAlloc = naive(lines, discount);
        long naiveSum = 0;
        for (long v : naiveAlloc) {
            naiveSum += v;
        }
        System.out.printf("%n【2. 朴素四舍五入】%n");
        for (int i = 0; i < lines.size(); i++) {
            System.out.printf("  %-6s 分摊 %8s%n", lines.get(i).sku(), yuan(naiveAlloc.get(i)));
        }
        System.out.printf("  合计 %s，与优惠总额差 %d 分 -> %s%n",
                yuan(naiveSum), naiveSum - discount,
                naiveSum == discount ? "守恒" : "不守恒，财务对不上");

        List<Alloc> lr = largestRemainder(lines, discount);
        long lrSum = 0;
        for (Alloc a : lr) {
            lrSum += a.finalFen();
        }
        System.out.printf("%n【3. 最大余额法】%n");
        System.out.printf("  %-6s %-10s %-10s %-10s %s%n", "行", "理论值", "取整", "补余后", "该行实付");
        for (Alloc a : lr) {
            long amount = lines.get(a.idx()).amountFen();
            System.out.printf("  %-6s %-10s %-10s %-10s %s%n",
                    lines.get(a.idx()).sku(),
                    String.format("%.4f", discount * amount / (double) subtotal),
                    yuan(a.baseFen()), yuan(a.finalFen()), yuan(amount - a.finalFen()));
        }
        System.out.printf("  合计 %s，与优惠总额差 %d 分 -> %s%n",
                yuan(lrSum), lrSum - discount, lrSum == discount ? "严格守恒" : "不守恒");

        System.out.println();
        System.out.println("【4. 退单行 B：退的是「B 的实付」，不是按比例重算】");
        long bPaid = lines.get(1).amountFen() - lr.get(1).finalFen();
        long reAllocOnRest = Math.round(discount * lines.get(1).amountFen()
                / (double) subtotal);
        System.out.printf("  B 原价 %s，分摊 %s，实付 %s%n",
                yuan(lines.get(1).amountFen()), yuan(lr.get(1).finalFen()), yuan(bPaid));
        System.out.printf("  若退 B 时按比例重算优惠：%s（口径不一致，会多退/少退）%n", yuan(reAllocOnRest));
        System.out.println("  正确做法：退款额 = 行原价 - 行分摊额，分摊额在下单时就固定住。");

        System.out.println();
        System.out.println("【5. 先退 A 再退 B vs 一起退 A+B】");
        long refundA = lines.get(0).amountFen() - lr.get(0).finalFen();
        long refundB = bPaid;
        long together = refundA + refundB;
        System.out.printf("  先退 A %s，再退 B %s，合计 %s%n", yuan(refundA), yuan(refundB), yuan(together));
        System.out.printf("  一起退 A+B %s%n", yuan(refundA + refundB));
        System.out.println("  两者相等，因为每行分摊额是固定的；若退款时重算，两者就会不等。");

        System.out.println();
        System.out.println("【6. 分摊额不得超过该行金额（否则出现负数行）】");
        System.out.println("  场景：1.00 元的小件 + 9.00 元的大件，整单优惠 5.00 元");
        List<Line> tiny = new ArrayList<>();
        tiny.add(new Line("SKU-X", 100));    // 1.00 元
        tiny.add(new Line("SKU-Y", 900));    // 9.00 元
        long smallDiscount = 500;

        // 错误做法：按「行数」均摊，不看每行值多少钱
        System.out.println();
        System.out.println("  错误做法：按行数均摊（每行 2.50 元）");
        long each = smallDiscount / tiny.size();
        boolean negative = false;
        for (Line l : tiny) {
            long pay = l.amountFen() - each;
            negative |= pay < 0;
            System.out.printf("    %-6s 原价 %6s 摊 %6s 实付 %6s%s%n",
                    l.sku(), yuan(l.amountFen()), yuan(each), yuan(pay),
                    pay < 0 ? "   <- 实付为负，财务直接报错" : "");
        }
        System.out.printf("  按行均摊必然出现负数行：%s%n", negative ? "已复现" : "未复现");
        System.out.println("  1.00 元的商品被摊了 2.50 元优惠，等于「卖一单倒贴 1.50 元」。");

        // 正确做法：按金额比例摊，小额行自然不会超
        System.out.println();
        System.out.println("  正确做法：按行金额比例摊（金额大的摊得多，小额行摊得少）");
        List<Alloc> fixed = largestRemainder(tiny, smallDiscount);
        long sum = 0;
        long maxRatio = 0;
        for (Alloc a : fixed) {
            long amount = tiny.get(a.idx()).amountFen();
            sum += a.finalFen();
            maxRatio = Math.max(maxRatio, a.finalFen() * 100 / amount);
            System.out.printf("    %-6s 原价 %6s 摊 %6s 实付 %6s  摊掉本行 %d%%%n",
                    tiny.get(a.idx()).sku(), yuan(amount), yuan(a.finalFen()),
                    yuan(amount - a.finalFen()), a.finalFen() * 100 / amount);
        }
        System.out.printf("    合计 %s 元，与优惠总额 %s 元差 %d 分 -> %s%n",
                yuan(sum), yuan(smallDiscount), sum - smallDiscount,
                sum == smallDiscount ? "守恒" : "不守恒");
        System.out.printf("  按金额比例摊时，单行最多摊掉本行 100%%（这里最多 %d%%），不可能出现负行%n",
                maxRatio);
        System.out.println("  所以「封顶」不是额外规则，而是按金额比例摊的自然后果；");
        System.out.println("  只有当你按件数、按行数、按固定额摊时，才需要额外的封顶 + 余量再分配。");
    }
}
```

### 83-05 券状态机与并发核销

**知识点**
- **券的生命周期是一个状态机**：**已发放（ISSUED）→ 已锁定（LOCKED）→ 已使用（USED）**，**旁支是已过期（EXPIRED）与已作废（VOID）**，**只有明确的状态图才能防住「一券多用」**。
- **「锁定」这一态是必须的**：**下单时锁券、支付成功才置为已使用、超时未付要回滚成已发放**——**没有锁定态就只能「先扣后用」，用户下单不付款会把券白占住**。
- **非法迁移要显式拒绝**：**已使用不能回锁定、已过期不能锁定、已作废不能复活**——**用 `Set<迁移>` 白名单校验，比一堆 `if` 更不容易漏**。
- **并发核销必须用 CAS**：**「读状态 → 判断 → 写状态」三步不是原子的**，**两个请求同时读到 ISSUED 就会双双成功**，**必须 `compareAndSet(ISSUED, LOCKED)`**。
- **幂等键要跟券绑定**：**同一个券的重复请求要返回「第一次的结果」而不是报错**，否则用户重试会看到「券已被使用」而恐慌。
- 易错点：用 `synchronized` 包住整个核销（吞吐掉到个位数）；锁券后没设超时回滚；把「已过期」当异常抛给用户（应该是正常业务态）；状态字段用 String 随便写。

**示例代码**
```java
import java.util.ArrayList;
import java.util.EnumSet;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.atomic.AtomicReference;

public class CouponStateMachine {
    enum State {ISSUED, LOCKED, USED, EXPIRED, VOID}

    // 白名单式迁移表：只允许这里列出的边，其他一律拒绝
    static final Map<State, Set<State>> ALLOWED = Map.of(
            State.ISSUED, EnumSet.of(State.LOCKED, State.EXPIRED, State.VOID),
            State.LOCKED, EnumSet.of(State.USED, State.ISSUED, State.EXPIRED),
            State.USED, EnumSet.noneOf(State.class),
            State.EXPIRED, EnumSet.noneOf(State.class),
            State.VOID, EnumSet.noneOf(State.class));

    static class Coupon {
        final String id;
        final AtomicReference<State> state;

        Coupon(String id) {
            this(id, 1);
        }

        Coupon(String id, int readers) {
            this.id = id;
            this.state = new AtomicReference<>(State.ISSUED);
            this.readBarrier = new CountDownLatch(readers);
        }

        // 非原子写法，只用于演示「为什么不能这么写」
        // 用栅栏把「读」和「写」拉开：让所有线程都读到 ISSUED 之后再一起写
        final CountDownLatch readBarrier;

        boolean redeemNaive() {
            State s = state.get();
            if (s != State.ISSUED) {
                return false;
            }
            readBarrier.countDown();
            try {
                readBarrier.await();     // 等所有线程都读完，再一起写
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
            state.set(State.LOCKED);
            return true;
        }

        // CAS 写法：比较并交换，只有一个线程能成功
        boolean redeem() {
            return state.compareAndSet(State.ISSUED, State.LOCKED);
        }

        boolean transit(State to) {
            while (true) {
                State from = state.get();
                if (!ALLOWED.get(from).contains(to)) {
                    return false;
                }
                if (state.compareAndSet(from, to)) {
                    return true;
                }
            }
        }

        State get() {
            return state.get();
        }
    }

    public static void main(String[] args) throws Exception {
        System.out.println("【1. 合法迁移矩阵】");
        for (State from : State.values()) {
            List<String> to = new ArrayList<>();
            for (State t : ALLOWED.get(from)) {
                to.add(t.name());
            }
            System.out.printf("  %-8s -> %s%n", from, to.isEmpty() ? "（终态，不可再变）" : String.join(", ", to));
        }

        System.out.println();
        System.out.println("【2. 非法迁移被拒绝】");
        Coupon c1 = new Coupon("C1");
        c1.transit(State.LOCKED);
        c1.transit(State.USED);
        System.out.printf("  当前状态 %s%n", c1.get());
        System.out.printf("  已使用 -> 回锁定：%s%n", c1.transit(State.LOCKED) ? "允许（错！）" : "拒绝");
        System.out.printf("  已使用 -> 作废：%s%n", c1.transit(State.VOID) ? "允许（错！）" : "拒绝");

        Coupon c2 = new Coupon("C2");
        c2.transit(State.EXPIRED);
        System.out.printf("  已过期 -> 锁定：%s%n", c2.transit(State.LOCKED) ? "允许（错！）" : "拒绝");

        System.out.println();
        System.out.println("【3. 正常链路：锁券 -> 支付成功置已使用；超时回滚】");
        Coupon c3 = new Coupon("C3");
        System.out.printf("  下单锁券：%s，状态 %s%n", c3.redeem() ? "成功" : "失败", c3.get());
        System.out.printf("  超时未付回滚：%s，状态 %s%n", c3.transit(State.ISSUED) ? "成功" : "失败", c3.get());
        System.out.printf("  再次下单锁券：%s，状态 %s%n", c3.redeem() ? "成功" : "失败", c3.get());
        System.out.printf("  支付成功：%s，状态 %s%n", c3.transit(State.USED) ? "成功" : "失败", c3.get());

        System.out.println();
        System.out.println("【4. 并发核销：20 个线程抢同一张券】");
        int threads = 20;
        Coupon race = new Coupon("RACE", threads);
        CountDownLatch start = new CountDownLatch(1);
        CountDownLatch done = new CountDownLatch(threads);
        AtomicInteger naiveOk = new AtomicInteger();
        for (int i = 0; i < threads; i++) {
            new Thread(() -> {
                try {
                    start.await();
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                if (race.redeemNaive()) {
                    naiveOk.incrementAndGet();
                }
                done.countDown();
            }).start();
        }
        start.countDown();
        done.await();
        System.out.printf("  非原子写法（读-判-写）：成功 %d 次，状态 %s%n", naiveOk.get(), race.get());
        System.out.printf("  20 个线程全部读到 ISSUED、全部判定「可用」，于是 %d 个都返回成功%n", naiveOk.get());
        System.out.printf("  但状态字段只留下最后一次写入，%d 次核销里有 %d 次「成功了却没留痕」——双花的经典形态%n",
                naiveOk.get(), naiveOk.get() - 1);
        System.out.println("  真实环境里这个窗口只有几微秒，靠运气偶尔触发；一旦触发就是资损，所以必须从设计上堵死。");

        Coupon safe = new Coupon("SAFE");
        CountDownLatch start2 = new CountDownLatch(1);
        CountDownLatch done2 = new CountDownLatch(threads);
        AtomicInteger casOk = new AtomicInteger();
        for (int i = 0; i < threads; i++) {
            new Thread(() -> {
                try {
                    start2.await();
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                if (safe.redeem()) {
                    casOk.incrementAndGet();
                }
                done2.countDown();
            }).start();
        }
        start2.countDown();
        done2.await();
        System.out.printf("  CAS 写法：成功 %d 次，状态 %s%n", casOk.get(), safe.get());
        System.out.println("  成功次数恒为 1，这就是 compareAndSet 的作用。");

        System.out.println();
        System.out.println("【5. 幂等：同一请求重试不重复核销】");
        Map<String, String> idem = new ConcurrentHashMap<>();
        Coupon c5 = new Coupon("C5");
        System.out.printf("  首次核销：%s%n", redeemOnce(c5, idem, "req-001"));
        System.out.printf("  重试同一请求：%s%n", redeemOnce(c5, idem, "req-001"));
        System.out.printf("  换一个请求再核销：%s%n", redeemOnce(c5, idem, "req-002"));
        System.out.println("  重试返回第一次的结果，用户看到的不是「券已被使用」而是「下单成功」。");
    }

    static String redeemOnce(Coupon c, Map<String, String> idem, String reqId) {
        String hit = idem.get(reqId);
        if (hit != null) {
            return "命中幂等缓存 -> " + hit;
        }
        String result = c.redeem() ? "锁定成功" : "券不可用（当前 " + c.get() + "）";
        idem.put(reqId, result);
        return result;
    }
}
```

### 83-06 库存扣减与防超卖

**知识点**
- **超卖的根因不是「扣减慢」，而是「读-判-写」三步不是原子的**：**两个请求都读到库存 1，都判断「够」，都写 0，结果卖出 2 件**。
- **扣减必须在存储层做原子操作**：**`update stock set qty = qty - 1 where sku = ? and qty >= 1`**，**靠影响行数判断是否成功**，**这是最可靠的一道闸**。
- **内存里用 CAS 是同一思路**：**`compareAndSet(old, old - n)`，失败就重试**——**注意重试要有次数上限，否则高并发下会活锁**。
- **分段库存（库存分桶）能降低热点**：**把 100 件拆成 4 段各 25 件，请求按 hash 落到某段**——**总成功数不变，但落在同一段上的并发请求从 200 降到约 50，冲突面按段数线性下降**。
- **预扣与实扣要分开**：**下单预扣、支付实扣、超时回补**——**预扣不实扣，库存会被未付款订单长期占用**，**要有超时回补任务**。
- 易错点：先查库存再扣（中间有时间窗）；扣减失败却已经把订单落库；回补时忘了幂等导致库存越补越多；分段库存的段容量写死导致某段先空、整体还有货。

**示例代码**
```java
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.atomic.AtomicLong;

public class StockDeduction {
    // 朴素库存：读-判-写，三步之间没有原子性
    // 用一道栅栏把「读」和「写」拆开：所有线程先读完，再一起写，
    // 把真实环境里几十微秒的并发窗口放大成必然发生
    static class NaiveStock {
        long qty;
        final int expectReaders;
        final AtomicInteger readers = new AtomicInteger();

        NaiveStock(long qty, int expectReaders) {
            this.qty = qty;
            this.expectReaders = expectReaders;
        }

        boolean deduct() {
            long cur = qty;                      // 第 1 步：读
            if (cur <= 0) {
                return false;
            }
            readers.incrementAndGet();
            while (readers.get() < expectReaders) {   // 等所有线程都读完
                Thread.onSpinWait();
            }
            qty = cur - 1;                       // 第 3 步：写（覆盖别人的写）
            return true;
        }
    }

    // CAS 库存：比较并交换，失败重试
    static class CasStock {
        final AtomicLong qty;
        final AtomicInteger retries = new AtomicInteger();

        CasStock(long qty) {
            this.qty = new AtomicLong(qty);
        }

        boolean deduct() {
            while (true) {
                long cur = qty.get();
                if (cur <= 0) {
                    return false;
                }
                if (qty.compareAndSet(cur, cur - 1)) {
                    return true;
                }
                retries.incrementAndGet();
            }
        }
    }

    // 分段库存：按 hash 落到某一段，段内再 CAS
    static class SegmentedStock {
        final CasStock[] segs;

        SegmentedStock(long total, int segCount) {
            segs = new CasStock[segCount];
            long per = total / segCount;
            long extra = total % segCount;
            for (int i = 0; i < segCount; i++) {
                segs[i] = new CasStock(per + (i < extra ? 1 : 0));
            }
        }

        boolean deduct(String key) {
            int idx = Math.floorMod(key.hashCode(), segs.length);
            // 本段空了就试下一段，避免「某段空、整体还有货」
            for (int i = 0; i < segs.length; i++) {
                if (segs[(idx + i) % segs.length].deduct()) {
                    return true;
                }
            }
            return false;
        }

        long left() {
            long s = 0;
            for (CasStock c : segs) {
                s += c.qty.get();
            }
            return s;
        }
    }

    static int runConcurrent(int threads, java.util.function.IntConsumer task) throws Exception {
        CountDownLatch start = new CountDownLatch(1);
        CountDownLatch done = new CountDownLatch(threads);
        AtomicInteger ok = new AtomicInteger();
        for (int i = 0; i < threads; i++) {
            final int id = i;
            new Thread(() -> {
                try {
                    start.await();
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                try {
                    task.accept(id);
                } finally {
                    done.countDown();
                }
            }).start();
        }
        start.countDown();
        done.await();
        return ok.get();
    }

    public static void main(String[] args) throws Exception {
        int stock = 100;
        int buyers = 200;

        System.out.println("【1. 朴素写法：库存 100，200 人各买 1 件】");
        NaiveStock naive = new NaiveStock(stock, buyers);
        AtomicInteger naiveOk = new AtomicInteger();
        runConcurrent(buyers, id -> {
            if (naive.deduct()) {
                naiveOk.incrementAndGet();
            }
        });
        System.out.println("  用栅栏强制「200 个线程先全部读完，再一起写」，把微秒级窗口放大成必然");
        System.out.printf("  卖出 %d 件，库存变量停在 %d，超卖 %d 件%n",
                naiveOk.get(), naive.qty, naiveOk.get() - stock);
        System.out.printf("  %d 次写入互相覆盖，只剩最后一次生效：这就是「读-判-写」不是原子的代价%n",
                naiveOk.get() - (stock - naive.qty));
        System.out.println("  注意超卖不是「扣慢了」，而是「判断和扣减之间有缝」——把窗口放大到必然发生，才看得见。");

        System.out.println();
        System.out.println("【2. CAS 写法：同样的 200 人】");
        CasStock cas = new CasStock(stock);
        AtomicInteger casOk = new AtomicInteger();
        runConcurrent(buyers, id -> {
            if (cas.deduct()) {
                casOk.incrementAndGet();
            }
        });
        System.out.printf("  卖出 %d 件，剩余库存 %d，超卖 %d 件%n",
                casOk.get(), cas.qty.get(), Math.max(0, casOk.get() - stock));
        System.out.printf("  CAS 失败重试 %d 次（说明确实在竞争，但结果是对的）%n", cas.retries.get());
        System.out.println("  成功次数恒等于库存数，这是防超卖的核心：让「判断 + 扣减」变成一个原子操作。");

        System.out.println();
        System.out.println("【3. 分段库存：100 件拆 4 段】");
        SegmentedStock seg = new SegmentedStock(stock, 4);
        for (int i = 0; i < 4; i++) {
            System.out.printf("  段 %d 初始 %d 件%n", i, seg.segs[i].qty.get());
        }
        // 先算清「竞争面」：200 个 key 按同一套 hash 落到 4 段，各段分到多少
        int[] bucket = new int[4];
        for (int i = 0; i < buyers; i++) {
            bucket[Math.floorMod(("user-" + i).hashCode(), 4)]++;
        }
        System.out.printf("  200 个请求按 hash 落到 4 段：%d / %d / %d / %d%n",
                bucket[0], bucket[1], bucket[2], bucket[3]);
        long singlePairs = (long) buyers * (buyers - 1) / 2;
        long segPairs = 0;
        for (int n : bucket) {
            segPairs += (long) n * (n - 1) / 2;
        }
        System.out.printf("  同一把锁上的潜在冲突对数：单段 %d 对 -> 四段合计 %d 对（约 1/%d）%n",
                singlePairs, segPairs, singlePairs / Math.max(1, segPairs));

        AtomicInteger segOk = new AtomicInteger();
        runConcurrent(buyers, id -> {
            if (seg.deduct("user-" + id)) {
                segOk.incrementAndGet();
            }
        });
        System.out.printf("  卖出 %d 件，剩余 %d 件，超卖 %d 件（总成功数不受分段影响）%n",
                segOk.get(), seg.left(), Math.max(0, segOk.get() - stock));
        int totalRetry = 0;
        for (CasStock c : seg.segs) {
            totalRetry += c.retries.get();
        }
        System.out.printf("  四段实际 CAS 失败合计 %d 次（本次运行观测值，随线程调度浮动）%n", totalRetry);
        System.out.println("  真正的收益是结构性的：每段只有约 1/4 的请求在抢，冲突面按段数线性摊薄；");
        System.out.println("  重试次数是观测值不能当结论，冲突对数才是可复现的口径。");

        System.out.println();
        System.out.println("【4. 预扣 / 实扣 / 回补 的三段式】");
        long stockQty = 10;
        long reserved = 3;
        System.out.printf("  初始库存 %d，下单预扣 %d -> 可售 %d%n", stockQty, reserved, stockQty - reserved);
        System.out.printf("  支付成功实扣 %d -> 可售 %d（预扣转为实扣，总量不变）%n", reserved, stockQty - reserved);
        System.out.printf("  另一单超时回补 %d -> 可售 %d%n", 2, stockQty - reserved + 2);
        System.out.println("  预扣不实扣、超时不回补，库存就会被未付款订单长期占死。");

        System.out.println();
        System.out.println("【5. 回补必须幂等，否则越补越多】");
        System.out.println("  先看不做幂等：同一订单 order-1 的回补请求重投 3 次");
        long buggy = 5;
        for (int i = 1; i <= 3; i++) {
            buggy = buggy + 1;
            System.out.printf("    第 %d 次回补 -> 库存 %d%n", i, buggy);
        }
        System.out.printf("  库存从 5 涨到 %d，凭空多出 %d 件——这 2 件就是「无中生有」的货%n", buggy, buggy - 6);

        System.out.println();
        System.out.println("  再看带幂等键：同一 order-1 只认第一次");
        List<String> rolledBack = new ArrayList<>();
        long q = 5;
        for (int i = 1; i <= 3; i++) {
            long before = q;
            q = rollback(q, rolledBack, "order-1");
            System.out.printf("    第 %d 次回补 -> 库存 %d%s%n", i, q, q == before ? "（重复请求，跳过）" : "");
        }
        System.out.printf("  库存停在 %d，只加了一次%n", q);
    }

    static long rollback(long qty, List<String> done, String orderId) {
        if (done.contains(orderId)) {
            return qty;
        }
        done.add(orderId);
        return qty + 1;
    }
}
```

### 83-07 限购与防刷

**知识点**
- **限购要按「维度」设计，不是只按用户**：**用户维度防正常人多买，设备维度防换号，IP 维度防批量注册，支付账号维度防同一张卡**——**单维度一定会被绕过**。
- **「限购 N 件」要区分「每单限购」与「活动期累计限购」**：**每单限购用 `min(购买数, N)` 就能实现，累计限购必须落库计数并原子累加**。
- **计数必须原子且带窗口**：**用 `AtomicInteger` 或 Redis `INCR` + 过期时间**，**「先查再写」同样会超**，**和库存是同一类问题**。
- **幂等键是防重的最后一道闸**：**同一 `(userId, activityId, requestId)` 只允许成功一次**，**重试返回第一次结果**，**这能挡住「网络超时后客户端重试」造成的重复下单**。
- **风控规则要能解释**：**命中「同设备 10 分钟内 20 个账号」要能给出具体证据**，**否则误杀正常用户（如家庭共用设备）时无法申诉**。
- 易错点：只在网关限购（绕过网关直连服务就失效）；限购计数用内存 Map（多实例各算各的）；把「限购」做成「黑名单」导致正常用户被永久拦；风控阈值写死无法按活动调整。

**示例代码**
```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicInteger;

public class PurchaseLimit {
    record Attempt(String userId, String deviceId, String ip, String requestId, int qty) {
    }

    // 多维度计数器：任一维度超限就拒绝
    static class LimitEngine {
        final int perUser;
        final int perDevice;
        final Map<String, AtomicInteger> userCount = new ConcurrentHashMap<>();
        final Map<String, AtomicInteger> deviceCount = new ConcurrentHashMap<>();
        final Set<String> idemKeys = ConcurrentHashMap.newKeySet();
        final Map<String, String> idemResult = new ConcurrentHashMap<>();

        LimitEngine(int perUser, int perDevice) {
            this.perUser = perUser;
            this.perDevice = perDevice;
        }

        String buy(Attempt a) {
            String key = a.userId() + "|" + a.requestId();
            String hit = idemResult.get(key);
            if (hit != null) {
                return "幂等重放 -> " + hit;
            }
            AtomicInteger u = userCount.computeIfAbsent(a.userId(), k -> new AtomicInteger());
            AtomicInteger d = deviceCount.computeIfAbsent(a.deviceId(), k -> new AtomicInteger());

            // 先占额度再判断，失败要回滚，避免「判断通过但额度被抢走」
            if (u.addAndGet(a.qty()) > perUser) {
                u.addAndGet(-a.qty());
                return "拒绝：用户 " + a.userId() + " 累计超限（上限 " + perUser + "）";
            }
            if (d.addAndGet(a.qty()) > perDevice) {
                d.addAndGet(-a.qty());
                u.addAndGet(-a.qty());
                return "拒绝：设备 " + a.deviceId() + " 累计超限（上限 " + perDevice + "）";
            }
            String result = "成功：买入 " + a.qty() + " 件";
            idemResult.put(key, result);
            idemKeys.add(key);
            return result;
        }
    }

    public static void main(String[] args) {
        LimitEngine eng = new LimitEngine(2, 3);

        System.out.println("【1. 单用户：上限 2 件，分两次买】");
        System.out.printf("  %s%n", eng.buy(new Attempt("u1", "d1", "1.1.1.1", "r1", 1)));
        System.out.printf("  %s%n", eng.buy(new Attempt("u1", "d1", "1.1.1.1", "r2", 1)));
        System.out.printf("  %s%n", eng.buy(new Attempt("u1", "d1", "1.1.1.1", "r3", 1)));
        System.out.println("  第三次被拒，因为用户维度累计已经到 2。");

        System.out.println();
        System.out.println("【2. 换账号但同一设备：设备维度兜住】");
        System.out.println("  u1 已经在设备 d1 上用掉 2 件额度，设备上限是 3");
        System.out.printf("  %s%n", eng.buy(new Attempt("u2", "d1", "1.1.1.1", "r4", 1)));
        System.out.printf("  %s%n", eng.buy(new Attempt("u3", "d1", "1.1.1.1", "r5", 1)));
        System.out.printf("  设备 d1 当前计数 %d（上限 %d）%n",
                eng.deviceCount.get("d1").get(), eng.perDevice);
        System.out.println("  u2 是新账号、自己一件没买，但设备额度只剩 1 件，只买到 1 件；");
        System.out.println("  u3 再来一件时设备额度已满 3，即便账号全新也被拒——单维度限购挡不住换号，设备维度能。");

        System.out.println();
        System.out.println("【3. 幂等：同一请求重试不重复扣额度】");
        System.out.printf("  %s%n", eng.buy(new Attempt("u4", "d2", "2.2.2.2", "r6", 1)));
        System.out.printf("  %s%n", eng.buy(new Attempt("u4", "d2", "2.2.2.2", "r6", 1)));
        System.out.printf("  用户 u4 当前计数 %d（重试没有变成 2）%n",
                eng.userCount.get("u4").get());

        System.out.println();
        System.out.println("【4. 只做单维度限购会漏掉什么】");
        Map<String, Set<String>> deviceUsers = new HashMap<>();
        String[] devices = {"d9", "d9", "d9", "d9", "d9"};
        String[] users = {"a1", "a2", "a3", "a4", "a5"};
        for (int i = 0; i < devices.length; i++) {
            deviceUsers.computeIfAbsent(devices[i], k -> new HashSet<>()).add(users[i]);
        }
        System.out.printf("  设备 d9 在 10 分钟内出现 %d 个不同账号 -> 命中风控规则%n",
                deviceUsers.get("d9").size());
        System.out.println("  如果只按用户限购，每个账号各买 2 件，5 个账号就是 10 件，全从同一台设备刷走。");

        System.out.println();
        System.out.println("【5. 风控结论要带证据，否则误杀无法申诉】");
        List<String> evidence = new ArrayList<>();
        evidence.add("设备 d9 关联账号 5 个");
        evidence.add("同一 IP 段 2.2.2.0/24 关联账号 5 个");
        evidence.add("下单间隔中位数 0.8s（正常用户约 35s）");
        for (String e : evidence) {
            System.out.println("  - " + e);
        }
        System.out.println("  有证据才能人工复核；只给一个「风险分 87」等于没给。");
    }
}
```

### 83-08 活动时间窗口与时区

**知识点**
- **活动时间必须用「绝对时间戳 + 明确时区」表达**：**「10 月 1 日 0 点」在代码里等于 `Instant`，不是 `LocalDateTime`**——**`LocalDateTime` 没有时区，落到不同机器上含义就变了**。
- **服务器时区与用户时区可能不同**：**服务器跑 UTC、用户在东八区**，**用 `LocalDateTime.now()` 判活动开始，会提前 8 小时开抢或延后 8 小时结束**。
- **夏令时会让「每天 0 点」这个表述本身失效**：**有的时区某天没有 0 点（时钟跳 2 点）**，**`atStartOfDay` 要处理「不存在的时间」与「重复的时间」两种情况**。
- **活动开始/结束要「按区间判」而不是「按点判」**：**`[start, end)` 左闭右开**，**避免「结束那一刻还能下单、下一毫秒又不行」的边界争议**，**也避免同一秒被两个条件同时命中**。
- **客户端时间不可信**：**用户改系统时间就能绕过「限时活动」**，**判定必须在服务端做，客户端只做展示**。
- 易错点：用字符串比时间（`"2026-10-01" < "2026-10-1"` 为真）；活动结束时间写成 `23:59:59` 漏掉最后一秒；跨时区活动按本地时间各自开抢导致有人早 8 小时。

**示例代码**
```java
import java.time.Duration;
import java.time.Instant;
import java.time.LocalDate;
import java.time.LocalDateTime;
import java.time.ZoneId;
import java.time.ZonedDateTime;
import java.time.format.DateTimeFormatter;

public class TimeWindow {
    record Window(String name, Instant start, Instant end) {
        // 左闭右开：start 可以下单，end 那一刻已经结束
        boolean contains(Instant t) {
            return !t.isBefore(start) && t.isBefore(end);
        }

        String show(ZoneId zone) {
            DateTimeFormatter f = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
            return start.atZone(zone).format(f) + " ~ " + end.atZone(zone).format(f)
                    + " (" + zone + ")";
        }
    }

    public static void main(String[] args) {
        ZoneId shanghai = ZoneId.of("Asia/Shanghai");
        ZoneId utc = ZoneId.of("UTC");
        ZoneId newYork = ZoneId.of("America/New_York");

        System.out.println("【1. 同一个 Instant，在不同时区看到的「活动时间」】");
        Instant start = ZonedDateTime.of(2026, 10, 1, 0, 0, 0, 0, shanghai).toInstant();
        Instant end = ZonedDateTime.of(2026, 10, 8, 0, 0, 0, 0, shanghai).toInstant();
        Window w = new Window("国庆大促", start, end);
        System.out.println("  " + w.show(shanghai));
        System.out.println("  " + w.show(utc));
        System.out.println("  " + w.show(newYork));
        System.out.println("  时间戳是同一个（" + start.toEpochMilli() + "），只是显示不同。");

        System.out.println();
        System.out.println("【2. 用 LocalDateTime 判活动的坑：服务器跑 UTC】");
        LocalDateTime declared = LocalDateTime.of(2026, 10, 1, 0, 0);
        // 正确写法：明确按活动声明的时区解释
        Instant right = declared.atZone(shanghai).toInstant();
        // 错误写法：把「本地墙上时间」直接当 UTC 解释
        Instant wrong = declared.atZone(utc).toInstant();
        System.out.println("  运营声明：东八区 10-01 00:00 开始");
        System.out.printf("  正确解释（按东八区）：%s%n", right);
        System.out.printf("  错误解释（当成 UTC）  ：%s%n", wrong);
        long lateHours = Duration.between(right, wrong).toHours();
        System.out.printf("  两者相差 %+d 小时：按 UTC 解释会让活动晚开 %d 小时，用户到 08:00 才看到入口%n",
                lateHours, lateHours);

        // 反向的坑更常见：库里存的是 UTC 墙上时间，代码却按东八区解析
        LocalDateTime utcWall = LocalDateTime.of(2026, 9, 30, 16, 0);
        Instant misread = utcWall.atZone(shanghai).toInstant();
        System.out.printf("  反向坑：UTC 墙上时间 09-30 16:00 被当成东八区 -> %s%n", misread);
        System.out.printf("  比正确时刻早开 %d 小时，等于活动还没开始就放量了%n",
                Duration.between(misread, right).toHours());
        System.out.println("  结论：时间必须成对存「Instant + 活动时区」，绝不单独存 LocalDateTime。");

        System.out.println();
        System.out.println("【3. 左闭右开：结束那一刻到底算不算】");
        Instant justBefore = end.minusMillis(1);
        System.out.printf("  结束前 1ms  %s  -> %s%n", justBefore, w.contains(justBefore) ? "可下单" : "已结束");
        System.out.printf("  结束时刻    %s  -> %s%n", end, w.contains(end) ? "可下单" : "已结束");
        System.out.printf("  结束后 1ms  %s  -> %s%n", end.plusMillis(1), w.contains(end.plusMillis(1)) ? "可下单" : "已结束");
        System.out.println("  用 [start, end) 就没有「23:59:59 漏一秒」的问题。");

        System.out.println();
        System.out.println("【4. 夏令时：某些时区某天没有 00:00】");
        ZoneId santiago = ZoneId.of("America/Santiago");
        LocalDate d = LocalDate.of(2026, 9, 6);
        ZonedDateTime zdt = d.atStartOfDay(santiago);
        System.out.printf("  %s 在 %s 的「当天开始」= %s%n", d, santiago, zdt);
        System.out.println("  这一天时钟从 00:00 直接跳到 01:00，atStartOfDay 自动给出 01:00，不会抛异常。");
        ZonedDateTime naive = ZonedDateTime.of(d, java.time.LocalTime.MIDNIGHT, santiago);
        System.out.printf("  若强行写 00:00：%s（被自动调整为 %s）%n", naive, naive.toLocalTime());

        System.out.println();
        System.out.println("【5. 重复时间：秋季回拨那天的 01:30 出现两次】");
        ZoneId ny = ZoneId.of("America/New_York");
        LocalDateTime dup = LocalDateTime.of(2026, 11, 1, 1, 30);
        ZonedDateTime first = dup.atZone(ny).withEarlierOffsetAtOverlap();
        ZonedDateTime second = dup.atZone(ny).withLaterOffsetAtOverlap();
        System.out.printf("  第一次 01:30 -> %s%n", first);
        System.out.printf("  第二次 01:30 -> %s%n", second);
        System.out.printf("  两者相差 %d 分钟，是同一个本地时间的不同瞬间%n",
                Duration.between(first, second).toMinutes());

        System.out.println();
        System.out.println("【6. 客户端时间不可信】");
        // 用固定时刻模拟「服务端时钟」，保证输出可复现
        Instant serverNow = Instant.parse("2026-09-30T15:00:00Z");
        Instant clientSays = Instant.parse("2026-10-01T02:00:00Z");   // 客户端时钟被调快 3 小时
        System.out.printf("  服务端时钟 %s（东八区 %s）%n", serverNow,
                serverNow.atZone(shanghai).toLocalDateTime());
        System.out.printf("  客户端声称 %s，比服务端快 %d 小时%n", clientSays,
                Duration.between(serverNow, clientSays).toHours());
        System.out.printf("  若信客户端：%s（客户端以为已开始）%n",
                w.contains(clientSays) ? "允许下单" : "拒绝下单");
        System.out.printf("  若信服务端：%s（还差 %d 分钟）%n",
                w.contains(serverNow) ? "允许下单" : "拒绝下单",
                Duration.between(serverNow, start).toMinutes());
        System.out.println("  服务端只信自己的时钟；客户端时间只用来展示倒计时，绝不能参与「能不能买」的判定。");

        System.out.println();
        System.out.println("【7. 活动时长与「每天几点」的表达】");
        long days = Duration.between(start, end).toDays();
        System.out.printf("  活动跨度 %d 天（按绝对时间算，不受时区影响）%n", days);
        System.out.println("  如果需求是「每天 10 点开抢 1 小时」，就要按用户时区每天算窗口，");
        System.out.println("  不能写死一个绝对时间，否则跨时区用户会在半夜抢。");
    }
}
```

### 83-09 预算控制与超发防护

**知识点**
- **预算不是一个数字，是「预扣 + 实扣 + 释放」的三段式**：**领券先预扣、核销转实扣、过期或退款释放**——**只有预扣没有释放，预算会被未核销的券永久占住**。
- **「先查余额再扣」在并发下必然超发**：**两个请求都读到剩余 100 元，都判断「够发 50」，结果发出 100 元**——**和库存超卖是同一个 bug**。
- **预扣要用原子操作**：**`compareAndSet` 或 `decrementAndGet` 后判负再回滚**——**判负回滚要能区分「真的超了」和「并发竞争」，否则会把正常请求也拒掉**。
- **预算要按「维度」分层**：**总预算 → 活动预算 → 券模板预算 → 单用户预算**，**任何一层超了都要拦住**，**只控总预算会出现「一个券模板吃光全部预算」**。
- **熔断阈值要按速率算，不能按绝对值写死**：**先按「预算 / 计划时长」算出均值，超过均值 3 倍就告警**——**等预算见底才报警，已经晚了**，**按速率才能提前预判**。
- 易错点：预算用 `double` 存（累加误差）；预扣后没有超时释放任务；只控总额不控单券；告警阈值按绝对值写死，活动大小一变就失效。

**示例代码**
```java
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.atomic.AtomicLong;

public class BudgetControl {
    // 朴素预算：读-判-写，必然超发
    // 用栅栏把「读余额」和「扣余额」拉开，把真实环境里的并发窗口放大成必然
    static class NaiveBudget {
        long left;
        final int expectReaders;
        final java.util.concurrent.atomic.AtomicInteger readers
                = new java.util.concurrent.atomic.AtomicInteger();

        NaiveBudget(long left, int expectReaders) {
            this.left = left;
            this.expectReaders = expectReaders;
        }

        boolean reserve(long amount) {
            long cur = left;                     // 第 1 步：读余额
            if (cur < amount) {
                return false;
            }
            readers.incrementAndGet();
            while (readers.get() < expectReaders) {   // 等所有线程都读完
                Thread.onSpinWait();
            }
            left = cur - amount;                 // 第 3 步：写（覆盖别人的扣减）
            return true;
        }
    }

    // 预扣式预算：CAS 保证不超发
    static class Budget {
        final long total;
        final AtomicLong reserved = new AtomicLong();
        final AtomicLong consumed = new AtomicLong();
        final AtomicLong released = new AtomicLong();

        Budget(long total) {
            this.total = total;
        }

        boolean reserve(long amount) {
            while (true) {
                long cur = reserved.get();
                if (cur + amount > total) {
                    return false;
                }
                if (reserved.compareAndSet(cur, cur + amount)) {
                    return true;
                }
            }
        }

        void consume(long amount) {
            // 预扣转为实扣：占用减少、消耗增加，总额不变
            reserved.addAndGet(-amount);
            consumed.addAndGet(amount);
        }

        void release(long amount) {
            released.addAndGet(amount);
            reserved.addAndGet(-amount);
        }

        // 真正还能发的钱 = 总额 - 还占着的 - 已经花掉的
        long left() {
            return total - reserved.get() - consumed.get();
        }
    }

    static String yuan(long fen) {
        return String.format("%.2f", fen / 100.0);
    }

    public static void main(String[] args) throws Exception {
        long total = 1000000;   // 1 万元预算
        long coupon = 5000;     // 每张 50 元
        int threads = 300;

        System.out.printf("【1. 总预算 %s 元，每张券 %s 元，300 人同时领】%n", yuan(total), yuan(coupon));

        NaiveBudget naive = new NaiveBudget(total, threads);
        AtomicLong naiveOk = new AtomicLong();
        CountDownLatch s1 = new CountDownLatch(1);
        CountDownLatch d1 = new CountDownLatch(threads);
        for (int i = 0; i < threads; i++) {
            new Thread(() -> {
                try {
                    s1.await();
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                if (naive.reserve(coupon)) {
                    naiveOk.incrementAndGet();
                }
                d1.countDown();
            }).start();
        }
        s1.countDown();
        d1.await();
        long naiveIssued = naiveOk.get() * coupon;
        System.out.println("  用栅栏强制「300 个线程先全部读完余额，再一起扣」，把微秒级窗口放大成必然");
        System.out.printf("  朴素写法：发出 %d 张，声称占用预算 %s 元，而总预算只有 %s 元，超发 %s 元%n",
                naiveOk.get(), yuan(naiveIssued), yuan(total),
                yuan(Math.max(0, naiveIssued - total)));
        System.out.printf("  预算上限本来只够 %d 张，实际却发出 %d 张%n", total / coupon, naiveOk.get());
        System.out.printf("  更糟的是余额变量只剩最后一次写入：%s 元，账面上看不出已经发了 %d 张%n",
                yuan(naive.left), naiveOk.get());

        System.out.println();
        Budget b = new Budget(total);
        AtomicLong ok = new AtomicLong();
        CountDownLatch s2 = new CountDownLatch(1);
        CountDownLatch d2 = new CountDownLatch(threads);
        for (int i = 0; i < threads; i++) {
            new Thread(() -> {
                try {
                    s2.await();
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                if (b.reserve(coupon)) {
                    ok.incrementAndGet();
                }
                d2.countDown();
            }).start();
        }
        s2.countDown();
        d2.await();
        System.out.printf("  CAS 写法：发出 %d 张，占用预算 %s 元，剩余 %s 元%n",
                ok.get(), yuan(ok.get() * coupon), yuan(b.left()));
        System.out.printf("  发出张数恒为 %d，剩余 %s 元不够一张，所以不再发%n",
                total / coupon, yuan(b.left()));

        System.out.println();
        System.out.println("【2. 预扣 -> 实扣 / 释放】");
        Budget b2 = new Budget(total);
        b2.reserve(coupon * 4);
        System.out.printf("  预扣 4 张：剩余 %s 元%n", yuan(b2.left()));
        b2.consume(coupon * 3);
        b2.release(coupon);
        System.out.printf("  核销 3 张、过期释放 1 张：剩余 %s 元，已消耗 %s 元%n",
                yuan(b2.left()), yuan(b2.consumed.get()));
        System.out.println("  只预扣不释放，那 1 张过期券的预算就永远占着，活动看起来「预算用完了」其实没花出去。");

        System.out.println();
        System.out.println("【3. 分层预算：总预算 / 券模板 / 单用户】");
        long activityBudget = 1000000;
        long templateA = 600000;
        long templateB = 500000;
        long perUser = 20000;
        System.out.printf("  活动预算 %s，券A 模板 %s，券B 模板 %s（两者之和 %s > 活动预算）%n",
                yuan(activityBudget), yuan(templateA), yuan(templateB), yuan(templateA + templateB));
        System.out.println("  模板预算之和可以大于总预算，因为它们是「上限」不是「预留」；");
        System.out.println("  真实发放时先扣总预算，再扣模板预算，任何一层不足都拒绝。");

        System.out.println();
        System.out.println("【4. 单用户预算：同一人最多领 200 元】");
        List<Long> userGrants = new ArrayList<>();
        long userUsed = 0;
        for (int i = 0; i < 6; i++) {
            if (userUsed + coupon <= perUser) {
                userUsed += coupon;
                userGrants.add(coupon);
                System.out.printf("  第 %d 次领券：成功，累计 %s 元%n", i + 1, yuan(userUsed));
            } else {
                System.out.printf("  第 %d 次领券：拒绝，累计 %s 元 + %s 元 > 上限 %s 元%n",
                        i + 1, yuan(userUsed), yuan(coupon), yuan(perUser));
            }
        }

        System.out.println();
        System.out.println("【5. 按消耗速率熔断，而不是等预算见底】");
        int plannedMinutes = 30;                  // 活动计划 30 分钟发完
        long avgRate = total / plannedMinutes;    // 平均每分钟可发
        long limit = avgRate * 3;                 // 超过平均速率 3 倍就告警
        System.out.printf("  预算 %s 元计划 %d 分钟发完，平均速率 %s 元/分钟，告警线 = 3 倍 = %s 元/分钟%n",
                yuan(total), plannedMinutes, yuan(avgRate), yuan(limit));

        long[] perMinute = {30000, 45000, 110000, 120000, 150000};
        long spent = 0;
        int firstAlarm = -1;
        long spentAtAlarm = 0;
        for (int i = 0; i < perMinute.length; i++) {
            long before = spent;
            spent += perMinute[i];
            boolean alarm = perMinute[i] > limit;
            if (alarm && firstAlarm < 0) {
                firstAlarm = i + 1;
                spentAtAlarm = spent;
            }
            System.out.printf("  第 %d 分钟消耗 %s 元（均值的 %.1f 倍），累计 %s 元%s%n",
                    i + 1, yuan(perMinute[i]), perMinute[i] / (double) avgRate,
                    yuan(spent), alarm ? "   <- 超过 " + yuan(limit) + " 元/分钟，告警" : "");
        }
        System.out.printf("  首次告警在第 %d 分钟，此时累计只花掉 %s 元（占预算 %.1f%%）%n",
                firstAlarm, yuan(spentAtAlarm), spentAtAlarm * 100.0 / total);
        long remaining = total - spent;
        System.out.printf("  按最后 1 分钟的 %s 元/分钟，剩余 %s 元只够撑 %.1f 分钟%n",
                yuan(perMinute[perMinute.length - 1]), yuan(remaining),
                remaining / (double) perMinute[perMinute.length - 1]);
        System.out.println("  等预算见底再报警已经晚了：速率告警在只花掉一小部分时就给运营留出了处置时间。");
    }
}
```

### 83-10 营销归因与增量 ROI

**知识点**
- **表面 ROI = 活动期成交额 / 优惠成本，这个数几乎总是虚高的**：**因为下单的人里有一大部分本来就会买**，**券只是把钱送给了原本的买家**。
- **增量 ROI 要减去「本来就会发生」的部分**：**增量 = 实验组成交 - 对照组成交（按同一口径、同一时间窗）**，**增量 ROI = 增量毛利 / 优惠成本**。
- **对照组不能是「活动前一周」**：**大促前后本来就有自然波动（周末、发薪日、天气）**，**必须同时段随机分流做 A/B，才能剥离时间因素**。
- **券的「核销率」高不代表有效**：**无门槛券核销率天然高，但增量可能接近 0**，**有门槛券核销率低，却可能撬动了真实的凑单**。
- **归因窗口要固定**：**「领券后 7 天内下单算活动效果」与「30 天」会得出完全不同的 ROI**，**窗口越长，把自然成交算进来的越多**。
- 易错点：用活动期总 GMV 对比活动前一周；把「用了券的订单」全算成增量；忽略退货（退货后的 GMV 不是真成交）；只算 GMV 不算毛利（高毛利品类被低毛利品类拉低）。

```java
public class MarketingAttribution {
    record Group(String name, long users, long orders, long gmvFen, long grossFen,
                 long couponCostFen, long refundFen) {
        long netGmv() {
            return gmvFen - refundFen;
        }

        double conversion() {
            return orders * 100.0 / users;
        }

        double aov() {
            return orders == 0 ? 0 : netGmv() / 100.0 / orders;
        }
    }

    static String yuan(long fen) {
        return String.format("%.2f", fen / 100.0);
    }

    static String pct(double v) {
        return String.format("%.2f%%", v);
    }

    public static void main(String[] args) {
        // 同期随机分流：实验组发券，对照组不发
        // 口径：GMV 为下单金额，refundFen 为退货金额，grossFen 为「已扣退货后的净毛利」
        Group exp = new Group("实验组（发券）", 500_000, 62_000,
                1_860_000_000L, 470_000_000L, 155_000_000L, 111_600_000L);
        Group ctrl = new Group("对照组（不发券）", 500_000, 54_000,
                1_620_000_000L, 397_000_000L, 0L, 64_800_000L);

        System.out.println("【1. 两组基础数据（同期随机分流，各 50 万人）】");
        System.out.printf("  %-16s %-10s %-10s %-14s %-14s %s%n",
                "组", "订单数", "转化率", "净GMV(元)", "净毛利(元)", "客单价(元)");
        for (Group g : new Group[]{exp, ctrl}) {
            System.out.printf("  %-16s %-10d %-10s %-14s %-14s %.2f%n",
                    g.name(), g.orders(), pct(g.conversion()), yuan(g.netGmv()),
                    yuan(g.grossFen()), g.aov());
        }

        System.out.println();
        System.out.println("【2. 表面 ROI：拿实验组自己的成交去除优惠成本】");
        double surfaceRoi = exp.grossFen() / (double) exp.couponCostFen();
        System.out.printf("  表面 ROI = 实验组毛利 %s / 优惠成本 %s = %.2f%n",
                yuan(exp.grossFen()), yuan(exp.couponCostFen()), surfaceRoi);
        System.out.println("  这个数把「本来就会买的人」的毛利也算成了活动功劳。");

        System.out.println();
        System.out.println("【3. 增量 ROI：减去对照组本来就会发生的部分】");
        long incOrders = exp.orders() - ctrl.orders();
        long incGmv = exp.netGmv() - ctrl.netGmv();
        long incGross = exp.grossFen() - ctrl.grossFen();
        double incRoi = incGross / (double) exp.couponCostFen();
        System.out.printf("  增量订单 %d 单，增量净GMV %s 元，增量净毛利 %s 元%n",
                incOrders, yuan(incGmv), yuan(incGross));
        System.out.println("  注意这里是「单」不是「人」：订单差与人数差不是一回事，口径写错会把结论放大好几倍。");
        System.out.printf("  增量 ROI = %s / %s = %.2f%n",
                yuan(incGross), yuan(exp.couponCostFen()), incRoi);
        System.out.printf("  表面 ROI %.2f vs 增量 ROI %.2f，虚高 %.1f 倍%n",
                surfaceRoi, incRoi, surfaceRoi / incRoi);

        System.out.println();
        System.out.println("【4. 券成本摊到增量订单上，每单花多少】");
        long subsidyPerOrder = exp.couponCostFen() / incOrders;
        long grossPerOrder = incGross / incOrders;
        System.out.printf("  优惠成本 %s 元 / 增量订单 %d 单 = 每单补贴 %s 元%n",
                yuan(exp.couponCostFen()), incOrders, yuan(subsidyPerOrder));
        System.out.printf("  增量订单客单价 %s 元，每单净毛利 %s 元%n",
                yuan(incGmv / incOrders), yuan(grossPerOrder));
        System.out.printf("  每单补贴 %s 元 > 每单毛利 %s 元，单看增量订单是「补贴高于毛利」%n",
                yuan(subsidyPerOrder), yuan(grossPerOrder));
        System.out.println("  这正是增量 ROI < 1 的含义：增量订单自己养不活自己的优惠成本。");

        System.out.println();
        System.out.println("【5. 退货对结论的影响】");
        System.out.printf("  实验组退货 %s 元，占 GMV %.2f%%%n",
                yuan(exp.refundFen()), exp.refundFen() * 100.0 / exp.gmvFen());
        System.out.printf("  对照组退货 %s 元，占 GMV %.2f%%%n",
                yuan(ctrl.refundFen()), ctrl.refundFen() * 100.0 / ctrl.gmvFen());
        long incGmvGross = exp.gmvFen() - ctrl.gmvFen();
        System.out.printf("  含退货的增量 GMV %s 元，扣退货后 %s 元，缩水 %.1f%%%n",
                yuan(incGmvGross), yuan(incGmv),
                (incGmvGross - incGmv) * 100.0 / incGmvGross);
        System.out.printf("  若拿含退货 GMV 去算 ROI 会得到 %.2f，用净毛利算只有 %.2f%n",
                incGmvGross / (double) exp.couponCostFen(), incRoi);
        System.out.printf("  券吸引来的用户退货率更高（%.0f%% vs %.0f%%）时，只看下单 GMV 会高估近两成。%n",
                exp.refundFen() * 100.0 / exp.gmvFen(), ctrl.refundFen() * 100.0 / ctrl.gmvFen());

        System.out.println();
        System.out.println("【6. 归因窗口：7 天 vs 30 天】");
        // 把增量净GMV 按日拆开：前 7 天占大头，第 8~30 天是长尾
        long[] daily = {900_000_00L, 450_000_00L, 260_000_00L, 150_000_00L,
                92_000_00L, 50_000_00L, 30_000_00L};
        long seven = 0;
        for (long v : daily) {
            seven += v;
        }
        long tail = 670_000_00L;          // 第 8~30 天的长尾归因 GMV
        long thirty = seven + tail;
        System.out.printf("  前 7 天逐日增量净GMV（元）：");
        for (long v : daily) {
            System.out.printf("%s ", yuan(v));
        }
        System.out.println();
        System.out.printf("  7 天窗口合计 %s 元，加上 8~30 天长尾 %s 元 = 30 天窗口 %s 元%n",
                yuan(seven), yuan(tail), yuan(thirty));
        double roi7 = incGross / (double) exp.couponCostFen();
        double roi30 = incGross * (thirty / (double) seven) / exp.couponCostFen();
        System.out.printf("  同一笔优惠成本 %s 元：7 天口径 ROI %.2f，30 天口径 ROI %.2f%n",
                yuan(exp.couponCostFen()), roi7, roi30);
        System.out.printf("  窗口从 7 天拉到 30 天，ROI 从 %.2f 涨到 %.2f，涨的 %.0f%% 全是自然成交%n",
                roi7, roi30, (roi30 / roi7 - 1) * 100);
        System.out.println("  窗口越长越好看，所以口径必须活动前定死并写进复盘模板，不能事后挑一个好看的。");
    }
}
```

### 83-11 综合案例：大促券全链路

**知识点**
- **一次领券要穿过 6 个环节**：**校验活动 → 校验资格 → 预扣预算 → 生成券码 → 落库 → 返回**，**任一环节失败都要能回滚前面的预扣**。
- **领券与核销是两个独立的并发场景**：**领券峰值在整点（5 万 QPS），核销峰值在下单时段（2 万 QPS）**，**两者共用预算与库存，要分别压测**。
- **超发与超卖必须在同一套「预扣 + 幂等」框架里解决**：**预算预扣、库存预扣、用户限购计数**，**三个都是「读-判-写」，都要原子化**。
- **券的「可用」判定要在下单时重算**：**领券时满足门槛，下单时可能因为商品变价、券过期、活动下线而不可用**——**不能只信领券时的校验结果**。
- **全链路要有对账**：**发出的券数 × 面额 = 预扣预算**、**核销的券数 × 面额 = 实扣预算**、**过期券要释放**，**三个数每天对一次，差额就是 bug**。
- 易错点：领券成功但预算没扣（重启丢内存）；核销成功但券状态没变（双花）；过期券不释放预算（预算假性耗尽）；活动下线后旧券仍能核销（资损）。

**示例代码**
```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.atomic.AtomicLong;

public class PromotionCase {
    record Coupon(String code, String userId, long faceFen, boolean used, boolean expired) {
        Coupon use() {
            return new Coupon(code, userId, faceFen, true, expired);
        }
    }

    static class Platform {
        final long budgetFen;
        final AtomicLong reserved = new AtomicLong();
        final AtomicLong consumed = new AtomicLong();
        final AtomicLong released = new AtomicLong();
        final Map<String, Coupon> coupons = new HashMap<>();
        final Map<String, Integer> userLimit = new HashMap<>();
        final int perUser;
        final AtomicLong rejected = new AtomicLong();
        final AtomicLong duplicated = new AtomicLong();

        Platform(long budgetFen, int perUser) {
            this.budgetFen = budgetFen;
            this.perUser = perUser;
        }

        // 领券：校验 -> 预扣 -> 落库，任一步失败都回滚
        synchronized boolean claim(String userId, long face, String code) {
            if (coupons.containsKey(code)) {
                duplicated.incrementAndGet();
                return false;
            }
            int got = userLimit.getOrDefault(userId, 0);
            if (got >= perUser) {
                rejected.incrementAndGet();
                return false;
            }
            while (true) {
                long cur = reserved.get();
                if (cur + face > budgetFen) {
                    rejected.incrementAndGet();
                    return false;
                }
                if (reserved.compareAndSet(cur, cur + face)) {
                    break;
                }
            }
            coupons.put(code, new Coupon(code, userId, face, false, false));
            userLimit.put(userId, got + 1);
            return true;
        }

        // 核销：只有「未用、未过期、且属于本人」的券能核销
        synchronized String redeem(String userId, String code) {
            Coupon c = coupons.get(code);
            if (c == null) {
                return "券不存在";
            }
            if (!c.userId().equals(userId)) {
                return "不是本人的券";
            }
            if (c.expired()) {
                return "券已过期";
            }
            if (c.used()) {
                return "券已使用（重复核销被拦）";
            }
            coupons.put(code, c.use());
            // 预扣转实扣：占用减少、消耗增加
            reserved.addAndGet(-c.faceFen());
            consumed.addAndGet(c.faceFen());
            return "核销成功，抵扣 " + yuan(c.faceFen()) + " 元";
        }

        // 过期释放预算
        synchronized void expire(String code) {
            Coupon c = coupons.get(code);
            if (c == null || c.used() || c.expired()) {
                return;
            }
            coupons.put(code, new Coupon(c.code(), c.userId(), c.faceFen(), false, true));
            reserved.addAndGet(-c.faceFen());
            released.addAndGet(c.faceFen());
        }

        // 可发余额 = 预算 - 仍占用 - 已消耗
        long left() {
            return budgetFen - reserved.get() - consumed.get();
        }
    }

    static String yuan(long fen) {
        return String.format("%.2f", fen / 100.0);
    }

    public static void main(String[] args) throws Exception {
        long budget = 25_000_000_00L / 100;   // 25 万元
        long face = 5000;                     // 50 元券
        int perUser = 2;
        Platform p = new Platform(budget, perUser);

        System.out.printf("【1. 活动配置】总预算 %s 元，每张 %s 元，每人限 %d 张%n",
                yuan(budget), yuan(face), perUser);

        System.out.println();
        System.out.println("【2. 领券峰值：1000 个用户并发抢，每人不重复】");
        int users = 1000;
        AtomicLong ok = new AtomicLong();
        CountDownLatch start = new CountDownLatch(1);
        CountDownLatch done = new CountDownLatch(users);
        for (int i = 0; i < users; i++) {
            final int uid = i;
            new Thread(() -> {
                try {
                    start.await();
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                String userId = "u" + uid;
                for (int k = 0; k < 3; k++) {
                    if (p.claim(userId, face, userId + "-" + k)) {
                        ok.incrementAndGet();
                    }
                }
                done.countDown();
            }).start();
        }
        start.countDown();
        done.await();

        System.out.printf("  成功领券 %d 张，占用预算 %s 元，剩余 %s 元%n",
                ok.get(), yuan(p.reserved.get()), yuan(p.left()));
        System.out.printf("  因限购被拒 %d 次（每人都试了 3 次，限 %d 张）%n",
                p.rejected.get(), perUser);
        System.out.printf("  校验：占用 %s == 张数 %d x %s = %s  -> %s%n",
                yuan(p.reserved.get()), ok.get(), yuan(face), yuan(ok.get() * face),
                p.reserved.get() == ok.get() * face ? "对得上" : "对不上");

        System.out.println();
        System.out.println("【3. 核销：正常、重复、越权、过期 四种情形】");
        System.out.printf("  起始：已消耗 %s，占用 %s，剩余 %s%n",
                yuan(p.consumed.get()), yuan(p.reserved.get()), yuan(p.left()));
        System.out.printf("  u0 核销自己的券：%s%n", p.redeem("u0", "u0-0"));
        System.out.printf("    -> 已消耗 %s，占用 %s，剩余 %s（预扣转实扣，总额不变）%n",
                yuan(p.consumed.get()), yuan(p.reserved.get()), yuan(p.left()));
        System.out.printf("  u0 再次核销同一张：%s%n", p.redeem("u0", "u0-0"));
        System.out.printf("  u1 核销 u0 的券：%s%n", p.redeem("u1", "u0-0"));
        System.out.printf("    -> 两次非法核销都没动账：已消耗 %s，占用 %s%n",
                yuan(p.consumed.get()), yuan(p.reserved.get()));
        p.expire("u0-1");
        System.out.printf("  u0 核销已过期的券（u0-1 已被过期任务释放）：%s%n", p.redeem("u0", "u0-1"));
        System.out.printf("    -> 过期释放 1 张后：占用 %s，剩余 %s（释放的预算回到可发池）%n",
                yuan(p.reserved.get()), yuan(p.left()));

        System.out.println();
        System.out.println("【4. 过期释放：预算要还回来】");
        long before = p.left();
        int expiredCount = 0;
        for (String code : new ArrayList<>(p.coupons.keySet())) {
            Coupon c = p.coupons.get(code);
            if (!c.used() && !c.expired()) {
                expiredCount++;
            }
            p.expire(code);
        }
        long after = p.left();
        System.out.printf("  批量过期 %d 张，剩余 %s 元 -> %s 元，释放 %s 元%n",
                expiredCount, yuan(before), yuan(after), yuan(after - before));

        // 对账恒等式：预算 = 已核销 + 仍占用 + 剩余（释放的已经回到「剩余」里，不能再加一次）
        long consumed = p.consumed.get();
        long stillReserved = p.reserved.get();
        long leftNow = p.left();
        System.out.printf("  已核销 %s 元 + 仍占用 %s 元 + 剩余 %s 元 = %s 元%n",
                yuan(consumed), yuan(stillReserved), yuan(leftNow),
                yuan(consumed + stillReserved + leftNow));
        System.out.printf("  校验「已核销 + 仍占用 + 剩余」== 预算 %s 元  -> %s%n", yuan(budget),
                consumed + stillReserved + leftNow == budget ? "守恒" : "不守恒");
        System.out.printf("  累计释放 %s 元（含 u0-1 那 1 张）已经并回「剩余」，对账时再加一次就会重复计数%n",
                yuan(p.released.get()));
        System.out.println("  这是对账脚本最常见的 bug：把「已释放」当成独立的一项去加，凭空多出预算。");

        System.out.println();
        System.out.println("【5. 下单时重算「券可用」，不能只信领券时的校验】");
        long orderAmount = 28000;    // 280 元
        long threshold = 30000;      // 券门槛 300 元
        System.out.printf("  领券时订单 %s 元，满足门槛 %s 元%n", yuan(30000), yuan(threshold));
        System.out.printf("  下单时订单变成 %s 元（商品降价/取消一件）%n", yuan(orderAmount));
        System.out.printf("  重算结果：%s%n", orderAmount >= threshold ? "可用" : "不可用，券要退回");
        System.out.println("  如果下单时直接复用领券时的结论，就会「不满门槛也把券用了」。");

        System.out.println();
        System.out.println("【6. 三本账每天对一次，差额就是 bug】");
        List<String> books = new ArrayList<>();
        books.add("发放账：券数 " + p.coupons.size() + " 张 x " + yuan(face) + " = " + yuan(p.coupons.size() * face));
        books.add("预算账：预扣 " + yuan(p.reserved.get()) + "，实扣 " + yuan(p.consumed.get())
                + "，释放 " + yuan(p.released.get()));
        books.add("核销账：已用 " + p.coupons.values().stream().filter(Coupon::used).count()
                + " 张 = " + yuan(p.consumed.get()));
        for (String s : books) {
            System.out.println("  " + s);
        }
        long issuedTotal = p.coupons.size() * face;
        long budgetTotal = p.reserved.get() + p.consumed.get() + p.released.get();
        long redeemTotal = p.consumed.get();
        System.out.printf("  三本账核对：发放 %s == 预算 %s -> %s；核销 %s == 实扣 %s -> %s%n",
                yuan(issuedTotal), yuan(budgetTotal),
                issuedTotal == budgetTotal ? "对得上" : "对不上",
                yuan(redeemTotal), yuan(p.consumed.get()),
                redeemTotal == p.consumed.get() ? "对得上" : "对不上");
        System.out.println("  本次运行三本账全部对得上；任何一本对不上，就说明有券漏记、预算漏扣、或核销漏更新状态。");
        System.out.println("  对账脚本的价值不在「平时跑通」，而在出事那天能第一时间定位是哪一本账先歪的。");
    }
}
```

### 综合题：双十一前的一次全场券活动落地

**场景**

双十一当天要发一批「满 300 减 50」全场券，总预算 2500 万元，可用库存 10 万件，预计 5 万 QPS 的领券峰值，日活 800 万。运营的目标是「把预算花完、把库存卖完、不要超发、不要被黄牛刷走」，财务的目标是「每一分优惠都能对账、能分摊到行、能按行退」。请设计这套促销引擎并给出验证数据。

**任务**
1. 定链路：画出从原价到应付的价格计算阶段，写清每一步的输入输出，并说明折扣与满减互换顺序会差多少钱。
