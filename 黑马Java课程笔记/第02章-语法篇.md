### 2-01 字面量

**知识点**
- 字面量（字面值常量）是程序中直接写出来的固定数据，如 `18`、`3.14`、`"hello"`。
- 常见分类：整数（无小数点）、小数、字符串（双引号包裹）、字符（单引号包裹）、布尔（true/false）、空值（null）。
- 字符只能放一个内容，必须用单引号；字符串可以放 0 到多个字符，必须用双引号。
- 布尔字面量只有 `true` 和 `false` 两个值。
- 空值 `null` 不能直接用 `println` 输出。

**示例代码**
```java
public class LiteralDemo {
    public static void main(String[] args) {
        // 整数字面量
        System.out.println(18);
        // 小数字面量
        System.out.println(3.14);
        // 字符串字面量：双引号，可以有多个字符
        System.out.println("黑马程序员");
        // 字符字面量：单引号，只能一个字符
        System.out.println('A');
        System.out.println('中');
        // 布尔字面量：只有true和false
        System.out.println(true);
        System.out.println(false);
        // 空字符串也是合法的字符串字面量
        System.out.println("");
    }
}
```

### 2-02 变量

**知识点**
- 变量是内存中的一块存储空间，里面装的值可以随时变化。
- 定义格式：`数据类型 变量名 = 初始值;`，如 `int age = 18;`。
- 变量要先定义才能使用，使用前必须先赋值。
- 同一组大括号内变量名不能重复定义。
- 变量的值可以被覆盖，也可以参与运算：`age = age + 1;`
- 常用搭配：int 存整数、double 存小数、boolean 存真假、String 存一串文字。

**示例代码**
```java
public class VariableDemo {
    public static void main(String[] args) {
        // 定义变量并赋初始值
        int age = 18;
        double height = 1.75;
        boolean isStudent = true;
        String name = "阿玮";
        // 使用变量
        System.out.println("姓名：" + name);
        System.out.println("年龄：" + age);
        System.out.println("身高：" + height);
        System.out.println("是否是学生：" + isStudent);
        // 变量的值可以被修改（覆盖）
        age = 19;
        System.out.println("过完生日，年龄变成：" + age);
        // 变量可以参与运算
        age = age + 1;
        System.out.println("再过一年：" + age);
    }
}
```

**课后练习**
1. 定义变量保存你的姓名、年龄、身高，并输出"我叫XX，今年XX岁，身高XX厘米"。
2. 定义两个 int 变量 a = 10、b = 20，编写代码把两个变量的值交换过来（交换后 a 为 20、b 为 10），并输出交换后的 a 和 b。

### 2-04 变量的注意事项

**知识点**
- 一个变量同一时刻只能存一个值，再次赋值会覆盖旧值。
- 变量必须先声明并赋值后才能使用，否则编译报错。
- 同一作用域（一对大括号内）变量名不能重复。
- 整数字面量默认是 int，定义 long 装大数字要加 L 后缀。
- 小数字面量默认是 double，定义 float 要加 F 后缀。
- 变量只在所属的大括号范围内有效，超出作用域不可访问。

**示例代码**
```java
public class VariableNoteDemo {
    public static void main(String[] args) {
        // 变量只能存一个值，新值覆盖旧值
        int score = 60;
        score = 95;
        System.out.println(score);   // 95
        // long装大数字要加L
        long bigNum = 10000000000L;
        System.out.println(bigNum);
        // float要加F，否则小数默认按double处理
        float price = 9.9F;
        System.out.println(price);
        // 变量必须先赋值再使用
        int count = 0;
        System.out.println(count);
        // 一行可以定义多个同类型变量（了解，不推荐）
        int x = 1, y = 2;
        System.out.println(x + y);
    }
}
```

### 2-05 计算机的存储规则

**知识点**
- 计算机底层只有 0 和 1，所有数据最终都以二进制形式存储；1 字节（byte）= 8 位（bit）。
- 十进制转二进制：除 2 取余，直到商为 0，余数倒序拼接。
- 二进制转十进制：按 8421 码加权求和，如 1010 = 8 + 0 + 2 + 0 = 10。
- Java 里二进制以 0b 开头、八进制以 0 开头、十六进制以 0x 开头书写。
- 原码：最高位为符号位（0 正 1 负），其余为数值位；反码：负数符号位不变、其余按位取反。
- 补码 = 反码 + 1；正数的原反补三码相同；计算机实际用补码存储整数。

**示例代码**
```java
public class BinaryDemo {
    public static void main(String[] args) {
        // 二进制字面量：0b开头
        int a = 0b1010;    // 十进制的10
        System.out.println(a);
        // 八进制字面量：0开头
        int b = 0101;      // 1*64 + 0*8 + 1 = 65
        System.out.println(b);
        // 十六进制字面量：0x开头
        int c = 0x1A;      // 1*16 + 10 = 26
        System.out.println(c);
        // 8421码：二进制1100 = 8 + 4 = 12
        int d = 0b1100;
        System.out.println(d);
        // 无论用什么进制书写，打印出来的都是十进制结果
        System.out.println(0b1111);   // 15
    }
}
```

**课后练习**

### 2-06 数据类型

**知识点**
- Java 有 8 种基本数据类型：byte(1字节)、short(2)、int(4)、long(8)、float(4)、double(8)、char(2)、boolean(1)。
- 整数字面量默认 int，小数字面量默认 double；给 long 赋大值要加 L，给 float 赋值要加 F。
- byte 取值范围 -128~127，int 约 ±21 亿，long 约 ±922 亿亿。
- 选择原则：默认用 int 和 double，明确需要小范围、大范围或节省内存时才用 byte/short/long/float。
- String 是引用类型，不属于 8 种基本类型。

**示例代码**
```java
public class DataTypeDemo {
    public static void main(String[] args) {
        // 整数类型
        byte num1 = 10;            // 1字节：-128 ~ 127
        short num2 = 200;          // 2字节
        int num3 = 100000;         // 4字节：整数默认类型
        long num4 = 8000000000L;   // 8字节：超出int范围必须加L
        // 浮点类型
        float num5 = 3.14F;        // 4字节：必须加F
        double num6 = 3.1415926;   // 8字节：小数默认类型
        // 字符与布尔
        char c = 'A';              // 2字节：单个字符
        boolean flag = true;       // true或false
        System.out.println(num1);
        System.out.println(num2);
        System.out.println(num3);
        System.out.println(num4);
        System.out.println(num5);
        System.out.println(num6);
        System.out.println(c);
        System.out.println(flag);
        // int的取值范围
        System.out.println("int最大值：" + Integer.MAX_VALUE);
        System.out.println("int最小值：" + Integer.MIN_VALUE);
    }
}
```

**课后练习**
1. 为以下信息选择合适的类型定义变量并输出：年龄、身高、性别（单个字符）、是否已婚、银行卡余额（万元级小数）。
2. 定义一个 long 变量保存 11 位手机号 13812345678，再定义一个 byte 变量保存它的最大值 127，输出两者；若把手机号直接赋值给 int 变量会发生什么，把结论写在注释里。

### 2-07 数据类型练习-计算BMI

**知识点**
- 考查内容：double 类型定义变量、公式转代码、结果拼接输出。
- BMI 公式：体重（公斤）÷ 身高（米）的平方。
- 思路：身高体重都用 double；先算 `height * height`（建议加小括号保证优先级），再用体重除以它。
- 易错点：若用整数类型计算会丢失小数部分，结果不准；输出时把单位一起拼出来更清晰。

**示例代码**
```java
public class BmiCalculator {
    public static void main(String[] args) {
        // 定义身高（米）与体重（公斤），必须用小数类型
        double height = 1.75;
        double weight = 70.0;
        // BMI = 体重 / 身高的平方，注意给乘法加小括号
        double bmi = weight / (height * height);
        // 拼接输出结果
        System.out.println("身高：" + height + "米");
        System.out.println("体重：" + weight + "公斤");
        System.out.println("BMI指数：" + bmi);
    }
}
```

**课后练习**
1. 计算身高 1.82 米、体重 68.4 公斤的人的 BMI 并输出结果。
2. 小明身高 1.66 米、体重 52.3 公斤，小红身高 1.58 米、体重 49.6 公斤，分别计算两人 BMI 并输出，从结果观察谁的 BMI 更高。
3. 挑战：已知某人的 BMI 为 24.2、身高为 1.70 米，利用公式变形反推体重，用变量计算并输出。

### 2-08 标识符

**知识点**
- 标识符是对类名、变量名、方法名等的统称。
- 硬性规则：由字母、数字、下划线 _ 和 $ 组成；不能以数字开头；不能是关键字；严格区分大小写。
- 软性建议——驼峰命名：变量名、方法名用小驼峰（首单词小写，后面每个单词首字母大写，如 maxScore）；类名用大驼峰（每个单词首字母都大写，如 StudentScore）。
- 常量建议全大写、单词间用下划线分隔（了解）。
- 不建议用中文或拼音命名。

**示例代码**
```java
public class IdentifierDemo {
    public static void main(String[] args) {
        // 小驼峰：变量名第一个单词首字母小写，后面单词首字母大写
        int studentScore = 95;
        double maxPrice = 99.9;
        boolean userIsLogin = true;
        // 大驼峰：类名每个单词首字母都大写，如本类 IdentifierDemo
        // 合法但不规范的写法（能编译，不建议）
        int student_score = 88;
        // 中文和拼音语法上合法，但实际开发禁止使用（中文标识符仅作反例，已注释）
        // int 学生成绩 = 90;
        int xueShengNianLing = 18;
        // 非法示例（取消注释会编译报错）：
        // int 2name = 1;      // 不能以数字开头
        // int class = 2;      // 不能是关键字
        // int stu-name = 3;   // 不能包含减号
        System.out.println(studentScore + " " + maxPrice + " " + userIsLogin);
        System.out.println(student_score + " " + xueShengNianLing);
    }
}
```

**课后练习**
1. 判断下列标识符哪些合法、哪些非法：`2name`、`_score`、`$money`、`class`、`userName`、`stu-name`、`公共汽车`。
2. 按驼峰命名规范，为下列场景各起一个变量名并赋值输出：学生成绩、订单总金额、当前游戏关卡数、用户是否登录。

### 2-09 键盘录入

**知识点**
- Scanner 是 Java 提供的用于接收键盘录入的工具类。
- 使用三步：① 导包 `import java.util.Scanner;`（写在 class 上面）；② 创建对象 `Scanner sc = new Scanner(System.in);`；③ 接收数据 `int num = sc.nextInt();`。
- 常用方法：nextInt() 收整数、nextDouble() 收小数、next() 收字符串。
- 录入前先打印一句提示语，告诉用户该输入什么。
- 易错点：忘记导包、漏写 System.in 都会编译报错。

**示例代码**
```java
// 1. 导包：告诉程序Scanner在util包下
import java.util.Scanner;

public class ScannerDemo {
    public static void main(String[] args) {
        // 2. 创建Scanner对象
        Scanner sc = new Scanner(System.in);
        // 3. 接收整数
        System.out.println("请输入一个整数：");
        int num = sc.nextInt();
        // 接收小数
        System.out.println("请输入一个小数：");
        double num2 = sc.nextDouble();
        // 把录入的数据输出
        System.out.println("您录入的整数是：" + num);
        System.out.println("您录入的小数是：" + num2);
    }
}
```

**课后练习**
1. 录入你的年龄，输出"我今年XX岁"。

### 2-10 键盘录入练习-两数之和

**知识点**
- 考查内容：Scanner 三步流程的完整使用、int 接收数据、算术运算与拼接输出。
- 思路：先打印提示语 -> nextInt() 接收第一个数 -> nextInt() 接收第二个数 -> 定义 sum 保存 a + b。

```java
import java.util.Scanner;

public class SumCalculator {

        // 录入第二个整数
        System.out.println("请输入第二个整数：");
        int b = sc.nextInt();
        // 计算两数之和
        int sum = a + b;
        // 输出完整算式与结果
        System.out.println(a + " + " + b + " = " + sum);
    }
}
```

### 2-11 键盘录入练习-BMI

**知识点**
- 考查内容：nextDouble() 接收小数、BMI 公式实现、结果输出。
- 思路：录入身高（米）与体重（公斤）-> `bmi = weight / (height * height)` -> 拼接输出。
- 提示语中写清单位，避免用户输错单位。
- 易错点：忘记给 height * height 加小括号会导致运算顺序错误。

**示例代码**
```java
import java.util.Scanner;

public class BmiInputDemo {
    public static void main(String[] args) {
        // 创建Scanner对象
        Scanner sc = new Scanner(System.in);
        // 录入身高（单位：米）
        System.out.println("请输入您的身高（米）：");
        double height = sc.nextDouble();
        // 录入体重（单位：公斤）
        System.out.println("请输入您的体重（公斤）：");
        double weight = sc.nextDouble();
        // 计算BMI：体重除以身高的平方
        double bmi = weight / (height * height);
        // 输出结果
        System.out.println("身高" + height + "米、体重" + weight + "公斤的BMI指数为：" + bmi);
    }
}
```

**课后练习**

### 2-12 算数运算符

**知识点**
- 算术运算符共 5 个：+、-、*、/、%。
- 整数相除只取整数部分：`10 / 3` 的结果是 3；想得到小数，除数或被除数至少一个是小数。
- % 是取模（取余数）：`10 % 3` 的结果是 1，常用于判断整除和拆分数字。
- 小数运算可能有微小精度误差（如 `1.1 + 0.1` 不严格等于 1.2）。
- 整数除数为 0 会运行报错（了解）。
- 当 + 的两边出现字符串时，+ 就不再是加法而是拼接。

**示例代码**
```java
public class ArithmeticOperatorDemo {
    public static void main(String[] args) {
        int a = 17;
        int b = 5;
        // 五种算术运算
        System.out.println("和：" + (a + b));    // 22
        System.out.println("差：" + (a - b));    // 12
        System.out.println("积：" + (a * b));    // 85
        System.out.println("商：" + (a / b));    // 3：整数相除取整
        System.out.println("余：" + (a % b));    // 2：取模
        // 整数相除 vs 小数参与运算
        System.out.println(10 / 3);      // 3
        System.out.println(10.0 / 3);    // 3.3333...：有小数参与才是小数
        System.out.println(10 % 3);      // 1
        // 小数精度误差（了解）
        System.out.println(1.1 + 0.1);   // 1.2000000000000002
    }
}
```

### 2-13 运算符练习-数值拆分

**知识点**
- 考查内容：/ 整除与 % 取余的配合使用。
- 拆分套路：个位 = `num % 10`；十位 = `num / 10 % 10`；百位 = `num / 100`。
- 思路："除 10"砍掉个位、"对 10 取余"取出个位，两个动作组合就能拆任意位数。
- 该套路可以推广到四位、五位数的拆分。
- 易错点：`num / 10 % 10` 是先除后余，不要写成 `num % 10 / 10`（结果恒为 0）。

**示例代码**
```java
public class NumberSplitter {
    public static void main(String[] args) {
        // 待拆分的三位数
        int num = 587;
        // 个位：对10取余
        int ge = num % 10;
        // 十位：先除以10去掉个位，再对10取余
        int shi = num / 10 % 10;
        // 百位：直接除以100
        int bai = num / 100;
        // 输出拆分结果
        System.out.println(num + "的个位：" + ge);
        System.out.println(num + "的十位：" + shi);
        System.out.println(num + "的百位：" + bai);
    }
}
```

### 2-14 运算符练习-时间转换

**知识点**
- 考查内容：/ 与 % 的综合应用、单位换算思路。
- 换算公式：小时 = 总秒数 / 3600；分钟 = 总秒数 % 3600 / 60；秒 = 总秒数 % 60。
- 思路：先用整除拿走"整块"（小时），再用取余得到"剩余"，逐级向下换算。
- 同样的套路适用于"总分钟 -> 天/小时/分""总天数 -> 年/天"等换算题。
- 易错点：全程使用整数运算，不要用小数类型导致结果带小数。

**示例代码**
```java
public class TimeConverter {
    public static void main(String[] args) {
        // 总秒数
        int totalSeconds = 7256;
        // 小时：整除3600
        int hour = totalSeconds / 3600;
        // 分钟：先对3600取余拿到不满1小时的秒数，再整除60
        int minute = totalSeconds % 3600 / 60;
        // 秒：对60取余
        int second = totalSeconds % 60;
        // 输出转换结果
        System.out.println(totalSeconds + "秒 = " + hour + "小时" + minute + "分" + second + "秒");
    }
}
```

### 2-15 类型转换

**知识点**
- 隐式转换（自动类型提升）：取值范围小的数据赋给范围大的变量时自动完成。
- 提升顺序：byte -> short -> int -> long -> float -> double。
- byte、short、char 参与运算时会先提升为 int 再运算，结果也是 int。
- 强制转换：把范围大的赋给范围小的，必须写 `(目标类型)`，可能丢失精度。
- `(int)3.99` 的结果是 3：强制转换直接舍弃小数，不是四舍五入。
- `byte b1 = 10; byte b2 = 20; b1 = b1 + b2;` 会报错，因为 b1 + b2 的结果是 int。

**示例代码**
```java
public class TypeConversionDemo {
    public static void main(String[] args) {
        // 隐式转换：小范围 -> 大范围，自动完成
        int a = 10;
        long b = a;       // int自动提升为long
        double c = b;     // long自动提升为double
        System.out.println(b);
        System.out.println(c);
        // byte参与运算先提升为int
        byte d = 10;
        byte e = 20;
        int sum = d + e;  // 结果是int，不能直接赋给byte
        System.out.println(sum);
        // 强制转换：大范围 -> 小范围，必须写(类型)
        int f = (int) 3.99;    // 直接舍弃小数部分
        System.out.println(f); // 3
    }
}
```

### 2-16 字符运算

**知识点**
- char 底层存储的是编码数字，常用 ASCII：'a' 是 97、'A' 是 65、'0' 是 48。
- char 与 int 运算时，char 会提升为 int，结果也是 int 类型。
- 想把运算结果变回字符，需要强制转换 `(char)`。
- 大小写字母编码相差 32：'a' - 'A' 等于 32。
- 套路：字符数字 - '0' 可以得到对应的整数，如 '7' - '0' 等于 7。

**示例代码**
```java
public class CharOperationDemo {

        char c1 = 'a';   // 97
        char c2 = 'A';   // 65
        char c3 = '0';   // 48
        // 强转成int可以查看编码
        System.out.println((int) c1);
        System.out.println((int) c2);
        System.out.println((int) c3);
        // char与int运算，结果提升为int
        int result = c1 + 1;    // 97 + 1 = 98
        System.out.println(result);
        // 强转回char得到字符
        System.out.println((char) (c1 + 1));   // b
        // 字符数字减'0'得到整数
        int num = '7' - '0';
        System.out.println(num);   // 7
    }
}
```

### 2-17 字符串拼接操作

### 2-18 自增自减运算符

**知识点**
- ++ 让变量加 1，-- 让变量减 1，只能作用于变量。
- 单独使用时，++ 写在前面或后面效果完全一样。
- 参与运算时有区别：++ 在后表示"先用旧值，再自增"；++ 在前表示"先自增，再用新值"。
- -- 与 ++ 的规则相同。
- 实际开发建议把 ++ 单独写一行，避免与运算混用导致难以阅读。

**示例代码**
```java
public class IncrementDemo {
    public static void main(String[] args) {
        // 单独使用：++在前在后效果一样
        int a = 10;
        a++;
        ++a;
        System.out.println(a);   // 12
        // 参与运算：++在后，先用旧值再自增
        int b = 5;
        int c = b++;    // c拿到5，b变成6
        System.out.println("b=" + b + "，c=" + c);
        // 参与运算：++在前，先自增再用新值
        int d = 5;
        int e = ++d;    // d变成6，e拿到6
        System.out.println("d=" + d + "，e=" + e);
        // 自减同理
        int f = 8;
        System.out.println(f--);   // 先输出8，f再变7
        System.out.println(f);     // 7
    }
}
```

### 2-19 赋值运算符

**知识点**
- 基本赋值运算符 =：把右边的值装进左边的变量。
- 扩展赋值运算符：+=、-=、*=、/=、%=，如 `a += 5` 等价于 `a = a + 5`。

- 因此 `byte b = 10; b += 5;` 编译通过，而 `b = b + 5;` 编译报错。

```java
        System.out.println(a);   // 12
        a *= 2;    // 等价于 a = a * 2
        System.out.println(a);   // 24
        a /= 4;    // 等价于 a = a / 4
        System.out.println(a);   // 6
        a %= 4;    // 等价于 a = a % 4
        System.out.println(a);   // 2
        // 扩展赋值运算符隐含强制转换
        byte b = 10;

        System.out.println(b);   // 15
    }
}
```

### 2-20 关系运算符

### 2-21 逻辑运算符

**知识点**
- & 与：两边都为 true，结果才是 true。
- | 或：两边只要有一个为 true，结果就是 true。
- ! 非：取反，true 变 false、false 变 true。
- ^ 异或：两边相同为 false，不同为 true。
- 逻辑运算符两边要么是 boolean 值，要么是能产生 boolean 的表达式（常与关系运算符连用）。
- & 和 | 无论左边结果如何，右边都会执行。

**示例代码**
```java
public class LogicOperatorDemo {
    public static void main(String[] args) {
        boolean hasTicket = true;     // 有票
        boolean hasIdCard = false;    // 有身份证
        // & 与：两边都true才true
        System.out.println(hasTicket & hasIdCard);   // false
        // | 或：一边true就true
        System.out.println(hasTicket | hasIdCard);   // true
        // ! 非：取反
        System.out.println(!hasTicket);   // false
        // ^ 异或：相同false，不同true
        System.out.println(hasTicket ^ hasIdCard);   // true
        // 与关系运算符连用
        int score = 85;
        System.out.println(score >= 80 & score < 90);   // true
    }
}
```

### 2-22 短路逻辑运算符

**知识点**
- && 短路与：左边为 false 时，右边不再执行，结果直接为 false。
- || 短路或：左边为 true 时，右边不再执行，结果直接为 true。
- 短路效果可以提高效率，避免执行无意义的计算。
- 执行顺序从左到右，先算左边的表达式。
- 实际开发中几乎都用 && 和 ||，很少用 & 和 |。

**示例代码**
```java
public class ShortCircuitDemo {
    public static void main(String[] args) {
        int a = 10;
        int b = 20;
        // && 左边为false，右边(++b)不会执行
        boolean r1 = (a > b) && (++b > 0);
        System.out.println(r1);   // false
        System.out.println(b);    // 20：右边没执行，b没有自增
        // || 左边为true，右边(++b)不会执行
        boolean r2 = (a < b) || (++b > 0);
        System.out.println(r2);   // true
        System.out.println(b);    // 20：右边没执行
        // 常见用法：多个条件同时成立
        boolean canEnter = (a > 0) && (b > a);
        System.out.println(canEnter);   // true
    }
}
```

### 2-23 三元运算符

**知识点**
- 三元运算符格式：`关系表达式 ? 值1 : 值2`。
- 表达式为 true 时取值1，为 false 时取值2，整体有运算结果。
- 结果必须有"去处"：赋值给变量或直接打印，单独写会编译报错。
- 冒号两边的数据类型要与接收变量兼容。
- 可以嵌套求三个数的最大值，但多层嵌套可读性差，不建议。
- 典型场景：两数比大小、奇偶判断、真假二选一。

**示例代码**
```java
public class TernaryOperatorDemo {
    public static void main(String[] args) {
        // 三元运算符：关系表达式 ? 值1 : 值2
        int a = 25;
        int b = 31;
        // a > b 成立取a，不成立取b
        int max = a > b ? a : b;
        System.out.println("较大值：" + max);   // 31
        // 结果也可以直接打印
        System.out.println(a > 0 ? "正数" : "非正数");
        // 判断奇偶：余数为0是偶数
        System.out.println(a % 2 == 0 ? "偶数" : "奇数");
    }
}
```

### 2-24 运算符的优先级

**知识点**
- 优先级从高到低大致为：小括号 > 一元运算符（! ++ --）> 乘除模 > 加减 > 关系 > 逻辑（&& 高于 ||）> 三元 > 赋值。
- 小括号优先级最高，拿不准时就加小括号。
- && 的优先级高于 ||：`a || b && c` 等价于 `a || (b && c)`。
- 关系运算符高于逻辑运算符：`a > b && b > c` 可以直接写。
- 赋值运算符优先级最低，总是最后执行。

**示例代码**
```java
public class OperatorPriorityDemo {
    public static void main(String[] args) {
        // 乘除模高于加减
        System.out.println(3 + 4 * 2);     // 11
        System.out.println((3 + 4) * 2);   // 14：小括号改变顺序
        System.out.println(5 % 2 * 3);     // 3：同级别从左到右
        // && 优先级高于 ||
        System.out.println(true || false && false);     // true：先算&&
        System.out.println((true || false) && false);   // false：加括号改变顺序
        // 关系高于逻辑
        int a = 10;
        int b = 5;
        System.out.println(a > b && b > 0);   // 先比较再逻辑与，true
        // 一元运算符优先级很高
        int c = 5;
        System.out.println(-c * 2 + 10);   // 0：先取负再乘2
    }
}
```

**课后练习**
1. 先心算预测输出结果，再写程序验证：`3 + 4 * 2`、`(3 + 4) * 2`、`10 > 3 && 2 > 1`、`5 % 2 * 3`。
2. 对表达式 `6 % 4 + 3 * 2`：先预测不加括号的结果；再通过添加小括号写出至少两个结果不同的版本，逐一验证。
3. 挑战：用三个 boolean 变量 a、b、c 分别计算 `a || b && c` 与 `(a || b) && c`，输出两组结果，并在注释里说明优先级差异如何导致了不同。
