## 本章综合练习

### 综合题：对象传递行为实验

**场景**

延续第 6 章的内存实验，这次换成对象：把对象传给方法后修改字段、给形参重新 new、让两个变量指向同一对象，逐一验证并给出内存解释。

**任务**
1. 写方法 modifyName(Reader r) 在方法内改字段，调用后打印原对象，说明为什么变了。
2. 写方法 reassign(Reader r) 在方法内 r = new Reader(...)，调用后打印原对象，说明为什么没变。
3. 让两个变量指向同一对象，通过其中一个改字段，验证另一个也变，并解释 this 在方法内指向谁。
4. 用 this 在一个方法中调用同类另一个方法，观察与直接写方法名的差异。

**验收清单**
- [ ] 四组实验各有一段可运行代码与一句内存结论。
- [ ] 能明确区分「改对象内部状态」与「改引用指向」两类操作。
- [ ] 实验输出与预期一致，没有靠注释解释而是靠打印结果自证。
- [ ] 代码中的方法名能体现意图（modifyName / reassign），不使用 a、b 之类命名。
