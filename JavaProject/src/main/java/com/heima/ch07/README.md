## 本章综合练习

### 综合题：红包与雨水：两道算法题的组合训练

**场景**

两道经典题的组合：先实现拼手气红包的分配，再实现接雨水的蓄水量计算，最后用大乐透号码生成收尾。三题共用「边界先行、循环推进、双指针收窄」的思路。

**任务**
1. 实现红包分配：总金额分到 n 个人，每人至少 1 分，用二倍均值法，保证金额总和精确等于总金额（以分为单位避免小数误差）。
2. 实现接雨水：给定柱子高度数组，用双指针求能接的雨水总量，并说明为什么双指针只需一次遍历。
3. 实现大乐透号码生成：前区 5 个 1~35 不重复、后区 2 个 1~12 不重复，升序输出并补零到两位。
4. 为三题各写一组边界用例：红包 1 人 / 金额等于人数分、雨水全递增 / 全递减 / 全相等、号码取到区间端点。

**验收清单**
- [ ] 红包总金额误差为 0（按分计算，不用 double 累加）。
- [ ] 接雨水的暴力解法与双指针解法在 10 组随机数据上结果一致。
- [ ] 大乐透每次生成 7 个互不重复的号码，且区间正确。
- [ ] 三题都不使用第三方库，全部纯 JDK 实现。
